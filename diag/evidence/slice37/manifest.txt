## 根因排查（本切片最大坑：初版「并行 flake」定性错误，实为 QuickJS 引擎分歧）

- 现象：make test 三连挂在「quickjs 腿 zero-webview」（681-test 二进制，同 4F 集：
  currentScript NULL / csp target=document / csp style retained=0 / execute-error
  is_err=false），且 quickjs zero-webview **单跑亦 4F 复现**（solo 决定性复现推翻
  flake 定性）；v8 腿全绿。
- 根因（双层）：
  ① QuickJS C 层 JS_GetPropertyInternal2 对**原型链上的 Proxy** 先走 em->get_property
  （js_proxy_get）并把 get trap 返回值（miss = undefined）**当命中返回**
  （rquickjs-sys-0.7.0/quickjs/quickjs.c:7428-7443 + js_proxy_exotic_methods:46769）；
  spec/V8 对链上 Proxy 的属性读经 OrdinaryGet 同样调 [[Get]]（get trap），但
  **变量解析**（JS_GetGlobalVar / V8 LoadLookupSlot）V8 按 gOPD/has 语义判缺失抛
  ReferenceError，QuickJS 走同一 get_property 短路 → 自由变量 miss 静默 undefined。
  后果：a) execute-error 面（ReferenceError 消失）；b) 任何 miss 全局读重入 NPO
  get trap → _zwNPOMainLookup → iframe 扫描 → getElementsByTagName → 查询机器内
  typeof 守卫读再 miss → **递归**，gETN 文档级集合在重入中吞异常返空
  （document.getElementsByTagName('*') 恒 0 → currentScript NULL → CSP 元素
  target/retained 面连坐）。
  ② 排查中的中间实证链（evidence/quickjs-diag/）：querySelectorAll('script')=2 而
  document.getElementsByTagName('script')=0、宿主 __zw_query_all_tagged('*')
  payload 正常、元素 nodeType 正常、页内 setter 调用日志 S1G1:undefG1:undefCC。
- 修复：in-JS 引擎语义探测 _zwV8ProtoProxyGetSemantics（R76 _zwV8ProxySetSemantics
  同款单次直测——临时给 globalThis 挂 miss 透明 Proxy，读保证缺席的自由变量：
  抛 ReferenceError = V8 语义 → 接 NPO 链；静默 undefined = QuickJS → 不接链）。
  wired=false 时 slice36 globalThis own 安装面原样（registry 三面 + renderer 助手
  按 __zwNPO.wired 分流）；_zwNPOMainLookup 加重入门（防御，wired 腿嵌套 miss 读
  不再二次扫描）。Windows 判例：探测必须测**变量解析**面而非属性读续链面——spec
  OrdinaryGet 对链上 Proxy 本就调 [[Get]]（两引擎一致），第一版探针据此写错并被
  node 复现推翻（t.marker37 undefined on V8 too）。
- 初版 flake 矩阵声明作废：make test 挂面 100% = quickjs zero-webview 4F 确定性
  回归（solo 复现），非并行 flake；run2 的 integration etag 1F 为独立 TOCTOU
  （docs/learnings/bugs/2026-08/2026-08-14-test-server-free-port-toctou.md 先例）。

## 引擎分叉申报（如实；FIXME(engine-divergence) 注释在 part05 接线处）

- V8 腿（主语义）：完整 NPO——链形 window → Window.prototype(own constructor) →
  WindowProperties(Proxy) → EventTarget.prototype → Object.prototype；描述符
  {w:true,e:false,c:true}；gPN 排除；[[DefineOwnProperty]]/[[Delete]]/
  [[PreventExtensions]] → false；delete 表达式 window 级 ret 值偏差见残差③。
- quickjs 腿（fallback）：不接 NPO 链，slice36 安装面原样——named prop 为
  globalThis own 非可枚举数据属性（w/e/c=true/false/true）、delete 命中 own 即清除
  （无复活面）、无 WindowProperties class string / Window 构造器链。quickjs C 层
  限制：任何 miss-returning get trap 站链上都会同时杀死自由变量 ReferenceError
  （webview execute-error 钉）并让 miss 全局读重入 trap——NPO 语义在 quickjs 上
  不可用 JS Proxy 表达（Chrome 内部 NPO 非陷阱对象，仅覆盖 [[GetOwnProperty]]）。
  webview quickjs 681/681、renderer quickjs lib 218/218（--test-threads=1，make
  test 同款）全绿为证。
- renderer 钉 renderer_js_worker_npo_faces_s37 改为按 __zwNPO.wired 运行时分支：
  wired 臂断言 NPO 面（own 缺席/gsp 描述符/gPN 排除/delete 复活）；unwired 臂
  断言 slice36 面（own 非可枚举数据属性/delete 清除）；共用面 for-in 守恒 +
  换代重装双腿。
