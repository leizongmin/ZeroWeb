# M2 切片 13 — selected autocomplete value 算法 + HTMLCollection named access R4001（2026-10-19）

## 范围（shim R4001）

forms 域余簇评估定策：**续切**（存量可独立收口簇充足，单 form-autocomplete
66F 即最大单文件簇），本轮收口 autocomplete 簇。

- **selected autocomplete value 算法**（part04）：`_zwAutocompleteFieldCategory`
  （determine a field's category 全表：Off/Automatic/Normal 44 词/Contact 10 词/
  Credential webauthn）+ `_zwSelectedAutocompleteValue`（token 消费序
  credential→contact→mode→section、anchor mantle（input[type=hidden]）恒 ''、
  Off/Automatic 短路多 token 与 mantle 折 default、缺属性/空 token ''）。
  INPUT/SELECT/TEXTAREA 的 autocomplete IDL getter 分支接入；FORM 与其余元素
  保持枚举反射（R5009 片 d/R2850）。
  https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#autofill-processing-model
- **归一取证**：spec 字面仅 section 显式小写，corpus keywords 面（57 测）
  与 Chrome 上游当日 run 67/67（wpt.fyi summary `c:[67,67]`）钉死 field
  token 亦 ASCII 小写——以语料为准落码，实现处注释钉明（经验已沉淀
  [spec-literal-vs-corpus-pin](../../../learnings/patterns/2026-10-19-spec-literal-vs-corpus-pin.md)）。
  spec 的 credential 子步重赋 category（contact 块之门）为第二隐蔽点。
- **setter 缓存旁路**（part05）：INPUT/SELECT/TEXTAREA 不入 `_reflectedAttrs`
  （getter 恒按现值重算，IDL set " NAME" → get "name"；setter 仍原串写内容属性）。
- **HTMLCollection named property**（part03 `_liveQueryCollection`）：get trap
  非 index 串键回落 id/name 树序首匹配（DOM spec supported property names）——
  `document.forms.X` 旧恒 undefined，form-autocomplete 前 4 测读
  'autocomplete' of undefined 的根因。
- **FIELDSET `.form` 入面**（part03，R2841 表补 FIELDSET）：named access 修复
  暴露 HTMLFieldSetElement.html 旧 vacuous-pass（`document.forms.fm1` 与
  `fs_outer.form` 双 undefined 相等，断言空转多轮）；fieldset 为
  form-associated 元素，form-owner 算法 R2841 本就实现，仅 tag 表缺项。
  处置与避免方式见
  [vacuous-pass-exposed-by-named-access](../../../learnings/bugs/2026-10-19-vacuous-pass-exposed-by-named-access.md)。
