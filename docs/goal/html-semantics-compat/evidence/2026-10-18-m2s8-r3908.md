# M2 切片 8 — HTMLOptionsCollection/option list 基建 R3908（2026-10-18）

## 范围（shim R3908/R3908b）

- **spec「list of options」统一构造 `_zwListOfOptions`**（part03，HTML §4.10.7
  https://html.spec.whatwg.org/multipage/form-elements.html#concept-select-option-list ）：
  select 子树 DFS——OPTION 收录且不递归（子孙 option 排除）；select/hr/datalist
  子树整枝排除；optgroup 照常下钻（div 包裹 option 仍在 list），唯 select 与其
  之间存在 optgroup 祖先的**嵌套 optgroup 整枝排除**（nesting 11 案断言面）。
  sel 形走 `_childNodeList`（R100 锚回 + pending overlay），handle 形走
  `_zwLocalChildNodes` + `_handleChildren` 融合；64 层深度帽（R181 同款防环）。
  `select.length`/`select[i]`/options 集合/selectedIndex 视图全部改走该构造
  （口径统一）。
- **HTMLOptionsCollection 代理 `_zwOptionsCollection`**（part03，
  https://html.spec.whatwg.org/multipage/common-dom-interfaces.html#htmloptionscollection ）：
  get（length/item/namedItem/add/remove/selectedIndex/value/索引/Symbol.iterator）
  + set（length grow 逐位补空 option / shrink 末端裁剪；`[i]=null` 移除；
  `[i]=element` n>length 先补空再追加，其余 replace）；[SameObject]（WeakMap
  per proxy）；part04 元素 set trap 的 `select.length =`/`select[i] =` 委托同一
  实现（canonical 索引判定 `_zwIsCanonicalIndex`，'01'/'-2' 落 expando）。
  **replace 序 = 先移除旧项 + 前插到旧项后继**（与 spec insert-then-remove
  等价）：R51 overlay 按 nextSibling **节点 identity** 定插入位（part05
  `_zwOverlayPendingChildNodes`），先插后删时 ref 已出 merge 视图必 miss →
  保守落尾（common-HTMLOptionsCollection「opts[0] = replace」案实证）。
- **`_zwIsSelectTag`**：前缀形态 select 判定——`createElementNS(xhtml,
  'foo:select')` 产真 HTMLSelectElement（接口按 ns+localName 定），tagName
  'foo:select' → `_realTag` 返 'FOO:SELECT'，`=== 'SELECT'` 门全 miss；
  后缀 `:SELECT` 识别（common-HTMLOptionsCollection「new nodes will not copy
  select's prefix」断言面）。已知近似：SVG ns 'foo:select' 亦命中（select 非
  合法 SVG 元素名，corpus 无此形态）。options/selectedOptions/namedItem/
  length/索引/part04 set trap 六处换用。
- **selectedOptions `_zwSelectedOptionsCollection`**：HTMLCollection 形代理
  （item/namedItem/length/索引/迭代器/`constructor === HTMLCollection`）+
  [SameObject] + live（每次读经 `_zwSelectSelectedView` 重建内层集合）+
  非 multiple selectedness 视图归一（多选中最后者胜、空回落 list 首项）。
  Proxy 三 trap 齐：get 未知字符串属性回落 `Reflect.get(target)`（原型方法
  hasOwnProperty/toString 可达——assert_array_equals 调用面）；has（`in`
  判定 + 界内索引）；getOwnPropertyDescriptor（`hasOwnProperty(i)` 走
  [[GetOwnProperty]]，报 configurable:true 防 proxy invariant TypeError）。
- **option.selected IDL setter = dirty selectedness**（R3908b，part05 +
  part01 + part03 getter，HTML §4.10.9
  https://html.spec.whatwg.org/multipage/form-elements.html#dom-option-selected ）：
  setter 只置 selectedness + dirtiness（`_optSelectedDirty`，part01 声明，
  `__zw_reset_form_state` 清空），**不反射** selected 内容属性（defaultSelected
  才反射）；getter 脏态最优先。已知限制：select.value=/selectedIndex= 的
  SelectOption 覆盖不清 dirty（spec 应整体覆盖），当前语料无「.selected= 后
  同 select select.value=」组合，挂账。
- **宿主激活脚本分流**（script_gen.rs `script_set_option_selected`）：R3908b
  使 IDL setter 不再反射属性后，宿主 `HtmlUserAction::Activate` 激活链
  （渲染/序列化/`option_activation_snapshot` 以内容属性承载选中态）改走显式
  `setAttribute/removeAttribute`——行为与旧 IDL-setter 副作用等价，IDL 面
  保持 spec 纯净。`option_activation_conformance_across_hosts` 集成测试
  该链路钉（tests/integration/src/html_compat.rs:563 断言面）。
- part58 新增 `test_html_options_collection_r3908` 行为契约单测（W1–W9）。
