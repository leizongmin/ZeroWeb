## 根因链（R4600 三层 + R4600b 锚点层）

1. **focusing steps 缺失**（part01）：`show()`/`showModal()` 不跑 spec
   dialog focusing steps，`close()` 不跑焦点恢复。spec：show 的 step 7、
   showModal 的 step 8（run the dialog focusing steps given dialog）；
   close-the-dialog 的 closing steps 含焦点恢复到 previously focused
   element。焦点变化从不发生 → focusin/focusout 从不派发。
2. **focusable area 判定缺失**：focusing steps 需要「dialog 的第一个
   focusable area 或 dialog 自身」——autofocus 委派（子树含 `[autofocus]`
   → 委派目标）、focus delegate（shadow hosts delegatesFocus）、inert
   子树传播、closed dialog 内元素排除均无实现。
3. **activeElement 语义**：headless 无真 top-layer/焦点环，focus 落
   document.body 默认值，断言 `dialog.activeElement`/`document.activeElement`
   全 miss。
4. **R4600b（focus-shadow 4F 根因，本轮新定位）**：R371 replaceWith 重键
   后 `_r371Next` 后继快照取到**换行空白文本节点**（nodeType 3，wire
   文本快照条目无 selector）；元素级 QSA R322 树序归并锚点 =
   `link.nextSibling.__zwSelector` 字符串匹配，文本 ref 不可表达 → 新
   元素恒尾插 → 焦点扫描先命中后随兄弟按钮（corpus
   dialog-focus-shadow.html 模板与断言按钮之间恰有换行；探针 markup 无
   换行故此前不复现）。
