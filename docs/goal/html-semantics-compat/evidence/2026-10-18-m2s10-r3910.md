## 范围（shim R3910）

forms 域大簇归因（切片 9 收口后）定出 3 个引擎可修簇，本轮收口：

- **提交路径 construct-entry-list 对齐**（part04 `_zwFormSubmitNavigate` +
  `_zwRunFormSubmit`）：constructing entry list flag 与 part02
  `new FormData(form)` 共用 `__zwFormDataConstructing`（同 spec flag）——
  submit 入口 flag true 早退（先于 submit 事件派发）；条目构造窗口置位、
  formdata 派发后 finally 清位；条目构造后以共享存储派发 formdata
 （`fd._p = entry list`，handler 对 `e.formData` 增删直接改写提交条目——spec
  克隆发生在 fire 之后）。action 解析自函数头移至 formdata 派发 + dialog
  分支之后（spec form submission algorithm 顺序：construct-entry-list →
  cannot-navigate → dialog 分支 → action；解析失败 return 不影响已派发面）。
- **method=dialog 分支**（part04，原「`if (dialog) return`」占位实现）：
  无祖先 dialog → return；subject = form 最近祖先 dialog；result 缺省 null
  —— image 按钮提交者 → selected coordinates "x,y"（`_zwImgSelCoords`，
  非指针激活 0,0），submit 按钮提交者 → optional value（value 内容属性
  present 才设，含空串；缺失不改 returnValue）；`_zwDialogClose(subject,
  result)`，result null 传 undefined（不改 returnValue）。
- **close-the-dialog 步 1**（part01 `_zwDialogClose` 共享路径）：无 open
  属性直接 return false（不设 returnValue、不派 close 事件）——dialog
  close()/requestClose()/Esc/提交分支四处共用。旧实现未 open 仍置
  returnValue（WPT dialog-close「doesn't have an open attribute aborts the
  steps」+ dialog-return-value「no-op close()」根因）。
- **SubmitEvent / FormDataEvent 构造器 WebIDL 语义**（part05）：无 new →
  TypeError；type 必填；FormDataEventInit.formData required 且必须 FormData
  实例（缺省/null/undefined/非 FormData 均 TypeError）；SubmitEventInit
  submitter 为 `(Element or null)`（非 null/undefined 且非元素 proxy →
  TypeError，tagName 字符串面与 requestSubmit submitter 校验同型；init
  dict 可选）。旧实现 plain function 可作函数调用、formData 缺省兜底
  `new FormData()`。
- part59 新增 `test_r3910_*` 契约 6 测（构造器双面 / close 未 open no-op /
  dialog optional value 三态 / 无祖先 + formmethod 覆盖 / formdata 单次

  POST navigate formData）。
