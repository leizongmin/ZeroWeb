# M2 切片 4 — valueAsNumber/valueAsDate setter 抛错面（2026-10-16）

## 范围（shim R3904）

- **valueAsNumber setter spec 步序**（part04，HTML §4.10.5.4
  https://html.spec.whatwg.org/multipage/input.html#dom-input-valueasnumber ）：
  ①新值 ±Infinity → TypeError，**先于适用性检查**（checkbox + Infinity 亦
  TypeError——WPT input-valueasnumber-typeerror 断言面）；②不适用 type
  （七步进类型之外）→ InvalidStateError；③NaN → ''；④数值→字符串设值
  （number/range String(n)；date/time/week/datetime-local ms→格式化串；
  month 月数→YYYY-MM，与 getter 互逆——2c 路径不变重排）。
- **valueAsDate setter spec 步序**（part04，HTML §4.10.5.4
  https://html.spec.whatwg.org/multipage/input.html#dom-input-valueasdate ）：
  ①非 null/undefined 且非 Date 对象 → TypeError——**WebIDL `Date?` 转换
  先于 setter steps**，不适用 type + 非 Date 亦 TypeError；
  undefined→null（nullable 转换）与 null 同面（WPT
  input-valueasdate-typeerror「non-Date object」断言面）；②不适用 type
  （date/month/week/time 之外，含 datetime-local——§4.10.5.1.11
  do-not-apply 表 + WPT datetime-local-valueasdate 断言面）→
  InvalidStateError；③null/undefined 或 Invalid Date（NaN time value）→
  清空 value；④有效 Date→格式化串。复用 value 同步路径
  （_inputValues + _captureInputDefault + attr/form-value 双路径）。
- part16 新增 `test_input_value_as_setter_throw_r3904` 行为契约单测：
  valueAsNumber ±Infinity（number + checkbox 双面，钉步序）/ 不适用
  InvalidStateError / 正常值与 NaN；valueAsDate 非 Date TypeError
  （date/time + checkbox + {} 钉「转换先行」）/ 不适用 InvalidStateError
  （datetime-local + Date、checkbox + Date）/ null、undefined、Invalid
  Date 三清空面。
