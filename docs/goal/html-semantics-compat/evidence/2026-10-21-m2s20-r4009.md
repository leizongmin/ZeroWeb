   时当下（净零变迁 closed→…→closed 仍派发）、同态写不排程（t9/t10）、
   detached 也派发。触发点单一 choke point：part04 `p === 'open'` IDL

   removeAttribute('open') 尾钩；写前 presence 由调用方捕获传入。派发经
   `_zwMakeTrustedToggleEvent4009`：trusted（R312 UA 通道印记 +
   `_zwUaDispatch`）+ ToggleEvent 原型身份（toggleEvent.html 双断言）。
   导航经 `__zw_reset_form_state` 清空（per-page）。
2. **summary 激活行为**（part03 bubble 站钩 `_zwSummaryActivationForward4009`
   + part04 click() post 分支 `_zwSummaryActivate4009`）：spec
   the-summary-element activation behaviour——本 summary 为父 details 首个
   summary 元素子（activation element，children 逐站 `_elKey` 身份比对）
   时翻转 details open，翻转经 proxy `.open` setter 落 toggle 队列。两面
   分工：summary 本体 click() API 面走 part04 post 分支（target 不进冒泡
   链），后代 target 面走 bubble 站钩；交互豁免 `_zwIsInteractiveContentEl`
   （label 同款）+ target 到 summary 站间祖先交互豁免（a[href] 内 inline
   元素——activation target 就近 activatable 祖先语义）。
3. **ToggleEvent 接口**（part05 `_defineEventSubclass('ToggleEvent','Event',
   …)`）：oldState/newState 缺省 ''、source 缺省 null（popover invoking
   element 面未实现，details toggle 恒 null）；part01 `_makeToggleEvent` 的
   popover 同步派发面维持 plain 对象不动（R3071 面语料不查原型身份，本切片
   精准修改纪律）。
4. **宿主空格路由**（webview user_actions）：SUMMARY 入空格激活 buttonish
   表（focus.rs FOCUSABLE_TAGS 既有）→ 递归 Activate 落既有 plan_summary

followup toggle（前 R 时代的同步裸 Event 近似），集成测试
