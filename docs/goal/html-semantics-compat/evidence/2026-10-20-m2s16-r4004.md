# M2 切片 16 — label 激活行为面 R4004（2026-10-20）

## 范围

clicking-noninteractive-unlabelable/labelable-content 57F（label 激活行为）收口。
R4004 落 shim 三块（part03/part04；part60 契约）：

1. **交互内容判定**（part03 `_zwIsInteractiveContentEl`）：HTML §4.2.6.2 名单
   （a[href]/audio[controls]/button/details/embed/iframe/img[usemap]/input
   (type≠hidden)/label/select/textarea/video[controls]，仅 HTML 命名空间；
   tabindex/object 不算）。属性存在性走 `__zw_has_attr_handle === '1'`——
   `__zw_get_attr_handle` 对缺失属性返空串（callbacks.rs
   `unwrap_or_default`），`!= null` 恒真把无 href 的 a、无 controls 的
   audio/video、无 usemap 的 img 全误判交互内容（test-3 簇 12F 根因）。
   https://html.spec.whatwg.org/multipage/dom.html#interactive-content-2
2. **R368 盖章属性回填**（part04 appendChild）：`__zw_create_element` 产裸
   tag 节点，plain attributes（模板解析/克隆产物）不随行——input[type=hidden]
   被 host 当默认 text（误 labelable → 转发自身 clicked 多计）。回填以 plain
   `getAttributeNames` 为源一次写入，host 侧属性读此后正常演进。
3. **label 激活转发三路归一**（spec the-label-element activation behaviour）：
   - 新增 bubble 站挂钩 `_zwLabelActivationForward`（`_dispatchWithBubble`
     bubble 循环 label 站，target 非交互且未取消时对 labeled control 跑
     synthetic click）；含 FIXME（dispatchEvent 直派 label 本体不转发——
     label.click() 走 trap 路径）。
   - R112 post-activation `act:label` 段与 click() trap R155 的控件查找迁移
     `_zwLabeledControl`（for 优先；旧 `__zw_query_all_sub` 子树首个无视
     for），post 段补交互 target 豁免（旧路径缺——audio[controls] 等 target
     被 spec 禁止的转发，语料此前未钉）。
   - 重入互斥双闸：`__zwLblClickInProgress` 全局 flag（spec click in progress
     flag 的同步近似——拦嵌套 dispatch 重转发环：meter.click() control=自身 →
     post 段转发 → 内层全新事件，clicked 冲到 691 的死循环）+ `__zwLblFwd4004`
     事件标记（拦同事件三路双转——hook 转发完成后 flag 已复原，second-child
     语料 buttonClicked==1 断言）。probe t7 钉出旧 post+trap 双转（label.click()
     二次翻转）一并收敛为单转发。
   - 链构建/inDoc walk 补 plainParent hop（R368 盖章 plain 子经
     `_zwNodeParent.plainParent` 反链上行找 handle 站——span.click() 链此前在
     plain 父断链）；R11 loop 媒体原型补链（part01b `HTMLMediaElement.prototype`
     原生原型是 Object.prototype，Audio/Video 已链 Media 而 Media 本体未接
     HTMLElement——audio cloneNode 等原型成员不可达 6F 根因）。
   - `_zwLabeledControl` 无 for 路径从 QSA 逗号表改 childNodes 树序 DFS +
     JS labelable 过滤（运行期动态 handle 子在逗号选择器路径不可见——probe10
     实证单 tag 表命中、七 tag 逗号表 0）。
4. **R368 盖章子事件方法包装**：_zwMEl 本地事件面（R99 listener 表）与 live
   派发两套系统——盖章子获得 live 身份后本地监听对 live 派发不可见，四个事件
   方法（addEventListener/removeEventListener/dispatchEvent/click）按调用时
   `__zwHandle` 现值转 live proxy，无章回落捕获的本实现。
