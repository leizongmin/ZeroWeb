## dialog 语义主体重构（part01）

spec：the-dialog-element（show/show a modal dialog/close the dialog/
requestClose steps）+ toggle 事件任务队列。

1. **toggle 事件任务队列 `_zwDialogToggleQueueNotify4200`**：R4009 details
   同款 per-element key 去重合并——同任务多次开合单事件，oldState = 本
   任务首个真变迁前状态（`preOpen` 由调用方写入前捕获，入队点在写后纯
   读会把 old 记成写后态）、newState = 任务运行时当下状态；净零变迁仍派
   发。setTimeout→microtask→Promise 链排程（R4009 同款模板）。
2. **close 事件排队异步派发 `_zwDialogQueueCloseEvent4200`**：旧同步派发
   使 onclose 早于后续脚本运行（spec queue an element task），dialog-close
   t4 / dialog-close-event-async「close 须晚于当前脚本」断言面 F。trusted
   通道（R312 `__zwMakeTrustedEvent`，isTrusted 断言面）。
3. **`_zwDialogShow` 重写**：已 open → 非模态 no-op / **模态抛
   InvalidStateError**（「已在请求态」，dialog-no-throw-requested-state
   断言面；旧实现静默切非模态与 spec 相悖，part14 ⑧ 契约同步改）；未连
   接抛；**beforetoggle 同步可取消**（preventDefault 中止不开）+ 写后重
   查（处理器内已开不二次写，MO 计数 1 面）；写 open + MO record + toggle
   入队。
4. **`_zwDialogShowModal` 重写**：已 open → 非模态抛 / 模态 no-op（请求
   态对称面）；beforetoggle 可取消；写后重查三面（未连接被移除 / top-layer
   被 beforetoggle 内 showPopover 占 / 已 open）；写 open + MO record +
   top-layer + 模态态 + toggle 入队。
5. **close-the-dialog 核心 `_zwDialogCloseTheDialog4200`**（close()/
   requestClose() 共用）：beforetoggle（open→closed，同步不可取消——取
   消走 requestClose 的 cancel 面）；写后重查（处理器内嵌套 close 已完
   成不二次移除/排队）；移 open + MO record + 模态清理 + returnValue
   （R3910 口径）+ close/toggle 各自排队。
6. **`_zwDialogRequestClose` 新方法**（分发在 part04 DIALOG tag 门）：无
   open no-op；未连接（close watcher 非活跃）no-op；**cancel 同步可取消**
   （trusted 通道，preventDefault → 保持 open、returnValue 不变）；cancel
   派发中重入 → busy 守卫不二次 cancel；否则走核心。
7. part14 ④/⑧ 与 part59 W3 契约同步更新（close 排队断言、show 抛面）。

## 共享基建修复

8. **`Promise.withResolvers` polyfill**（part03，ES2024
   proposal-promise-with-resolvers）：requestclose 语料高频
   `Promise.withResolvers()`，缺失 → 脚本早期 TypeError → promise_test
   全批挂起（75F 主簇根因之一）。
9. **`_insertAdjacentVariadic` sel 项支持**（part05:11866–11948）：
   `prepend(parsedEl)` 等可变参入口此前只处理 handle 项与文本项，sel 项
   （innerHTML 解析产物）被静默丢弃。新增 sel 分支：dedup 表
   `seenSels4200`（sel 去重 + self 跳过，无 `_zwDetachFromRegistry`）+
   `__zw_insert_adjacent_sel_element` host wire（R334 既有）+
   `_zwUnmarkRemoved` + R334 同款同 turn 可见性（`_zwSelPendingParent`/
   `__zwPendReselAdd`/`_zwSiblingBaseInvalidateAll`）。fragment 展开路径
   未改（最小范围）。
10. **matches 裸属性选择器 latest-wins**（part04，`:modal` 分支后）：
    `matches('[open]')` 走 host `__zw_matches`（读已 apply 快照，stale），
    同 turn `close()` 后仍命中。lw 分支：presence-only / 精确等值、name
    小写化；带操作符与 `i` 标记回落 host；仅 sel 路径（handle 属性表本
    就同步）。
11. **addEventListener `{signal}` 选项**（part04:4740–4744）：此前被静默
    忽略 → testharness `t.get_signal()` cleanup 泄漏 listener，前一案
    preventDefault cancel listener 污染后案（修复 9 后暴露的第二层根因：
    requestclose 卡 53F）。record 携带 signal，abort 按 record 身份
    `indexOf` 精确移除（同 fn 换 signal 重注册不受旧 abort 影响——spec
    per-record 语义）。
12. **dialog open 属性 MO record**（part01:653/677/693 调用点 +
    part04:11506/11509 set trap `moAttr='open'`）：内部
    `_zwSetAttr/_zwRemoveAttr('open')` 原不发 MutationObserver 记录 →
    toggle-events observer 断言落 F。show/showModal/close-the-dialog/
    IDL setter 四面覆盖。**决策**：记录在 dialog 调用点发而非 `_zwSetAttr`
    helper 内——该 helper 为 aria 路径共用（11569/11606/11632），helper
    内发会与 moAttr 尾钩双计。
13. **`_realTag` sel tag 印章 `_zwSelSeenTag`**（part03:13489/13533）：host
    `__zw_get_tag(sel)` 命中时写 sel 印章（t8f 同款跨 execute 持久）；
    miss 时兜底返回。修 **detach 窗口**（remove 已 apply、reinsert——R361
    stash/跨批片段重解析——未 apply 的窗口内 tag 解析 miss → DIALOG 门
    方法整面失效，toggle-events "removes" cleanup 链 prepend→close
    "el.close is not a function"）。spec tagName 不可变；印章只在 miss
    服务，误服务面收敛到已移除元素的幽灵 sel（保守已知，无 corpus 消费
    面）。
