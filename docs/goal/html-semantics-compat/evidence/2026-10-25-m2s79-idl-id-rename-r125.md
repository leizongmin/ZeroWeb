`resolve_pointer_target` 每点击输出命中选择器：测试 1 → `#area`（3 次

  （R125 只接 id 面）；resolve 时点 `getAttribute('name')` → null——
  **runner 缺陷 C**（属性写丢失，见 §4）。

## 2. shim 缺陷与修复（R5279 两刀）

1. **写侧**（part04 `.id=` set trap）：IDL 路径与
   `setAttribute('id')` 不同记 R125 sel-based id 覆盖表——同 execute 内
   `getElementById`/改名后查询 miss 新 id；且 latest-wins 缺写使「改名回
   原 id」被残留旧条目毒化（先 `id='other'` 再 `id='testmap'`，gEBI
   命中快照却被 stale 条目判 overridden 剔除）。修复：set trap 补
   `_zwIdOverrideSet(key, idv)`（`!handle` 门与 setAttribute 臂对称）。
2. **读侧**（part06 getElementById）：第二条 pending-by-id 兜底环
   （`_zwPendingAddedById` 复读）缺 `_r125Overridden` 门——快照命中被
   覆盖表剔除后经该环复活（改名后旧 id 仍可取出）。修复：continue 条件
   补 `_r125Overridden(pn)`（与快路径 :3241 / 池路径 :3256 同门）。

契约：part90 `idl_id_rename_getelementbyid_r5279`（8 断言：(a) IDL 改名
新 id 命中/旧 id 落空 (b) 改名回原 id 命中——毒化面 (c) setAttribute
路径对称仍在 (d) map IDL 改名 + 改名回原 (e) 全块无异常）。撤写侧登记
→ (a1) 红；撤读侧门 → (a2) 红。注：`querySelector('[id=…]')` 同 turn
改名可见性不在本修复面（R125 读侧只接 getElementById——查询视图为共享
面，改造须独立切片）。
