## 产品语义（shim）

1. **dialog invoker source store**（part01）：`_zwDialogInvokerSourceR4400`
   （target-key → invoker proxy）+ `_zwDialogTakeInvokerSourceR4400`
   （take=读+删）。激活入口存（`_zwInvokerCommandActivate` DIALOG 分支），
   show/showModal/close-the-dialog 核心入口 take → `_makeToggleEvent` 第 5 参
   + R4200 队列 entry.source → fire 时 `_zwMakeTrustedToggleEvent4009` 携带。
   直接 IDL 调用无条目 → null。`__zw_reset_form_state` 清空。
2. **details invoker source**（part01/part03）：`_zwDetailsToggleSourceR4400`
   同模式，R4009 details toggle 队列 fire 传入；show 已开/hide 已关无变迁
   分支不落 store（防泄漏）。
3. **Invoker Commands API**（part01 `_zwInvokerCommandActivate`）：button
   祖先链（含自身）`commandfor`(id) + `command` 关键字（缺省/非法 → auto：
   dialog→show-modal、details→toggle；`--` 前缀 custom CommandEvent 与
   hide-all-popovers defer）。DIALOG → showModal/show/close/requestClose；
   DETAILS → open IDL 翻转/置位/清除。InvalidStateError 吞（spec 激活行为
   不外抛）。触发定位双形态：sel 祖先链 `__zw_has_attr_lw` 上行优先；sel
   缺失先 `__zw_selector_for_handle` 反解（parsed 元素 commandfor 只在 HTML
   快照 sel 面，handle mutation 面恒 miss——slice48），失败落回
   `_zwNodeParent` handle 走链。
4. **click 默认动作补面**（part03 `_dispatchWithBubble` finally 内 R4400
   块）：四重门（泛型 click + `_zwUaDispatch===true` + 非
   MouseEvent/PointerEvent + 非 synthetic + `_zwDispatching===0` + 未取消）
   → `_zwFindClickActivation` → act:button → `_zwInvokerCommandActivate` /
   act:details → `_zwDetailsActivateR4400`（summary-less DETAILS 点击激活，
   part03）。**须置于 finally 内**：try 体末 `return !event._defaultPrevented`
   之后 try/finally 之外的函数体语句不可达（本段首版误置 finally 外死代
   码，探针 DBG 全空定位）。
5. **签名修正**：`_zwInvokerCommandActivate(key, sel, handle)` →
   `(sel, handle)`——原 `key` 形参未用，R4400 补面块与 R112 post 分支两参
   调用致参数错位静默 no-trigger（part04:4961 调用点同步）。V 桩在 4 个
   return 点打日志定位（`V enter sel=null` → `ret:no-trigger`）。
6. **prevented request-close 丢弃 source**（part01
   `_zwDialogRequestClose`）：cancel preventDefault 返回前
   `delete _zwDialogInvokerSourceR4400[key]`——本命令事件序终结（cancel 非
   ToggleEvent），残留会使后续无关关闭（light dismiss）误携 stale invoker
   （case 6 closeFunc：closeSource 应 null）。

   定加载时 html）；本函数私有批 apply 后即弃 → 共享队列对这批写失明。
   实证链（diag：`R4400LW` 队列 attr 清单 + `R4400PUB` live 发布态 +
   `R4400NB` 批内容）：case 6 openFunc `test_driver.click` → invoker
   showModal 的 `SetAttr(#dialog,open)` 落私有批（apply 成功、live
   open=true），共享队列仍以**前序用例**的 `RemoveAttr(open)` 为 latest →
   R4200 toggle 队列 fire 时 `_zwDialogHasOpen` 读 0 → newState 误算
   closed。case 1-5 内联路径写直接进共享队列故自洽。修复：批 apply 成功后
   `shared.extend(recorded)` + `applied_mutations += recorded.len()`（游标
   同步推进——已应用，泵不得重放；mutation_version 由 apply 内部自增）。
