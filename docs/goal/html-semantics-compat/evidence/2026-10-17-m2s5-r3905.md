# M2 切片 5 — select.showPicker() spec 检查序（2026-10-17）

## 范围（shim R3905）

- **select.showPicker() method steps**（part03 方法分发区新支，HTML §4.10.8
  https://html.spec.whatwg.org/multipage/form-elements.html#dom-select-showpicker ）：
  ①disabled → InvalidStateError——**先于** being-rendered 与激活检查，抛错
  不消费激活；②not being rendered → NotSupportedError——display:none
  （自身或任一祖先）或 content-visibility:hidden 祖先（skipped contents
  子树无 CSS 布局盒；cv:hidden 元素自身有盒仍算 rendered，HTML 渲染
  「being rendered」定义）；③无瞬态激活（`_zwTransientActive`）→
  NotAllowedError；④show the picker：同步消费瞬态激活后返回（headless 无
  picker UI；multiple/size>1 内联列表箱无弹层不抛）。computed style 不可用
  时 lenient 视为 rendered（R3074 `_zwCheckVisibility` 同口径）；属性读
  latest-wins 三级回落（R3903 input.showPicker 同款 `spSelHasAttr`）。
- **textarea 无 showPicker**：HTMLTextAreaElement IDL 无该成员（spec §4.10.11
  核对），切片 4 账本「select/textarea showPicker」候选表述系笔误，本切片
  只做 select。
- 跨源 SecurityError 面（show-picker-cross-origin-iframe.html）归
  navigation-compat M3 iframe 门控域，不实现（与 input 同族口径）。
- part16 新增 `test_select_show_picker_r3905` 行为契约单测：方法恒暴露 /
  无激活 NotAllowedError / 有激活不抛且 isActive 翻 false（消费）/
  消费后再调 NotAllowedError / display:none NotSupportedError（不消费）/
  cv:hidden 祖先 NotSupportedError（不消费）/ cv 转 visible 不抛（照常
  消费）/ multiple 不抛 / 初始 disabled InvalidStateError（不消费）/
  同 turn setAttribute latest-wins disabled 亦抛（不消费）。
