## 范围（shim R4002）

forms 域余簇盘点定策的下一簇：**meter 值净化**（the-meter-element 域内最大
可独立收口簇）。

- **实际值算法 getter**（part04 `_zwMeterActualValues`）：HTML §4.10.16
  the meter element 六 IDL 属性返实际值——minimum = min 属性（浮点解析成功）
  否则 0；maximum = max 属性否则 1、< minimum 折 minimum；value 缺省 0、钳入
  [minimum, maximum]；low 缺省 minimum、钳入区间；high 缺省 maximum、< low 折
  low、> maximum 折 maximum；optimum 缺省中点 (min+max)/2、钳入区间。
  https://html.spec.whatwg.org/multipage/form-elements.html#the-meter-element
- **浮点解析**：「rules for parsing floating-point number values」去前后 ASCII
  空白后**整串**匹配（前导 `+` 跳过——meter-leading-plus-sign corpus 钉死 step 9
  行为）；裸符号/裸点/`+-5`/trailing junk → error 落缺省。R5009 片 e 旧
  「全缺省 0 + 前缀解析（trailing junk 忽略）」钉错行为，由语料修正。
- **double setter**（part04）：六属性 setter 走 WebIDL `double` 转换
  （ToNumber；NaN/±Infinity → TypeError）+ 合法值 `String(Number)` best
  representation 写内容属性 + CE 反应派发（沿 R5009 片 d 分支结构）；METER 从
  `value` 纯反射族（BUTTON/LI/PROGRESS/PARAM/OPTION）移出，PROGRESS 不受影响。
- **既有引用面核对**：part03 `value` getter 的 METER 旁路（不走 dirty 缓存、
  落专用分支）与 part05 `has` tag-gate（`'value' in meter`）语义不变，无需改。
