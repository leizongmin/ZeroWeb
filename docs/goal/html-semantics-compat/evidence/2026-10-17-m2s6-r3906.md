# M2 切片 6 — 文本控件选区语义 R3906（2026-10-17）

## 范围（shim R3906）

- **selectionStart/selectionEnd/selectionDirection setter**（part04，HTML
  §4.10.20 https://html.spec.whatwg.org/multipage/form-controls.html#dom-textarea/input-selectionstart ）：
  setter 经「set the selection range」算法——start setter 设 start 超 end
  则 end 跟至 start；end setter 设 end 低于 start 则 **start 降到 end**；
  unsigned long 转换后 clamp [0, len]（ToUint32 回绕再钳制）；
  direction 仅恒等 'backward' 采纳，其余（'none'/非法/缺省）一律
  'forward'（引擎方向模型不存裸 'none'，与 R2844 getter/setSelectionRange
  同口径）。
- **value setter 折叠选区到末尾**：用户态 `.value=` 写入后选区折叠至值尾
  （spec「value update steps」选区面）。
- **select 事件排程**（part06 `_zwScheduleSelectEvent`）：选区 extent 或
  direction 实际变更时排异步 select 事件（bubbles=true、cancelable=false、
  isTrusted=true；HTML §4.10.20 select 事件派发节）。同值早退不排
  （selectionchange E2 切片 12 既有口径复用）。
- **`_zwSelNormValue` textarea 归一修正**：textarea API 值只做换行归一
  （\r\n→\n、\r→\n），不走 input 净化——detached textarea 长度断言面
  （HTML §4.10.11 API value 无剥换行步骤）；sel/handle 两形经 `_realTag`
  判定（此前 handle 形 textarea 误走 'text' 净化剥掉 \r\n）。
- **`_controlValue`/value getter attr 回落 latest-wins**：detached 元素
  pending SetAttr 只在 `__zw_get_attr_lw` 变体可见（快照读恒 miss，
  `_reflectedTypeEnum` 既有同款理由）；value getter 惰性初始化走稳定
  lazy-init。
- **defaultValue= 真脏态守卫**（part05 INPUT 支）：解析镜像
  （`_inputValuesSet[key]=true` 由 setAttribute 仿真置位）与真实用户编辑
  脏态（`_inputDefaultDirty[key]`）区分——`_clearInputDefault` 前先捕
  `_dvGenuinelyDirty`，真实编辑后 defaultValue= 不再覆盖 API 值；解析镜像
  照常重同步（value-defaultValue-textContent.html 断言面）。TEXTAREA 支
  无 value 内容属性，保持原 `_inputValuesSet` 门。
- **type 变态选区复位 direction 归一**（part01 `_zwApplyInputTypeChange`）：
  非可选 → 可选迁移时选区归零且 direction 复位初始方向——经 spec「set
  the selection direction」归一（form-control-infrastructure.html#set-the-selection-direction）
  存 'forward'。**初版存裸 'none'**（与引擎方向模型矛盾，getter 漏出
  'none'），满账本比对暴露 type-change-state.html 70F + weekmonth 10F
  同名回归后修正，独占重跑取账。
- **runner variant meta 展开**（testharness_html_semantics.rs，uievents
  R329 `case_variants` 机制复用）：声明 variant 的用例只按 variant 矩阵
  跑、不再跑基础 URL（无 query 裸跑对 `location.search` 消费方是伪形态）。
  九域 corpus 仅 selection-not-application.html 一文件声明 variant
  （?default / ?week,month）。
- part16 新增 `test_textfieldselection_r3906` 行为契约单测（W1–W9）：
  selection setter 跟随/钳制模型、方向模型（'none' 不落存储）、非法 type
  枚举回落、detached textarea 换行归一（W2g）、defaultValue= 真脏态双面
  等。
