## 实现面

- `dom/query.rs`：`PseudoClass::Active`/`Hover` 新臂——识别为合法伪类、
  `matches_full` 恒 false（运行时指针交互状态，静态解析不可知，镜像
  `:focus` 家族；CSS Selectors L4 §15）。querySelector validity 与
  style-system `SUPPORTED_SIMPLE_PSEUDO_CLASSES` 对齐。
- `part01.js`：`_checkedDirtyState`（dirty checkedness）+ `_inputFiles`
  （`.files=` 引用面）两 per-element map，入 `__zw_reset_form_state`。
- `part03.js`：`files`/`indeterminate` 门 `_isTag`→`_realTag`（detached 面）；
  `files` 非 file type 恒 null、type=file 读 `_inputFiles` 引用（identity
  保真）回落空单例；`checked` getter 脏态优先于内容属性。
- `part04.js`：setAttribute/removeAttribute('value') 已脏（INPUT/TEXTAREA）
  不覆写 `_inputValues`（spec：属性增删只改 default value）；clone 步骤
  传播 dirty value（textarea 入列）+ dirty checkedness + indeterminateness；
  `files` setter 分派——type=file：FileList 实例存引用、null no-op、非
  FileList 抛 TypeError，其余 type no-op（HTML §4.10.5.4）。
- `part05.js`：`.checked=` IDL set 置 `_checkedDirtyState`；DataTransfer.files
  返回 FileList 视图（裸数组面零改动，视图惰性建 + `_zwFiles` 同一性重绑
  ——`input.files = dt.files` setter 接收 FileList 的 identity 断言面）。
- `part06.js`：querySelector/querySelectorAll compound（tag/attr 组合）形态
  的 pending 元素回落（复用 part05 `_parseCompoundOf`/`_matchCompoundOf`；
  伪类与 unsupported 形态不接）。**轻量预门：仅含 `[` 的选择器走解析 +
  pending 扫描**——全局命名查找/常规 miss 高频复用本回落路径，逐 miss 解析
  + 全 pending 扫描实测 2s+（t8g NPO 扫描钉 600 对 append/remove），门内
  毫秒级。
