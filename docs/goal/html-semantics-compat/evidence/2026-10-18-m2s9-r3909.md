# M2 切片 9 — selectedness/selectedIndex 语义 R3909（2026-10-18）

## 范围（shim R3909）

承接切片 8 的三层读侧模型（`_optSelectedDirty` dirty → `_optSelectedClean`
构造器显式初始 → selected 内容属性），本轮补齐**写侧触发点**与真态读径：

- **selectedness setting algorithm**（part03 `_zwSelectednessSetting`，HTML
  §4.10.7）：非 multiple 互斥——spec 走查只给列表序 last-wins，但 Chromium 对
  setter/属性/插入面一致按**受影响者胜**（affKey 绝对胜出，WPT
  select-ask-for-reset 反向循环与属性面 tiebreak 实测），无选中且 display
  size 1 回落首个非 disabled。
- **ask-for-a-reset 家族**（`_zwAskForReset` 最近祖先 select + part01
  `_mo_notify` 汇流钩 `_zwSelectResetOnMutation`）：option/optgroup 子树增删
  触发（其余 tag 零开销跳过）；插入步对批内每个 option 依序各跑（spec
  insertion steps）；innerHTML= 直写 select 子树落容器级合流 setting；
  Blink 重回落行为——非 multiple size 1 新首项插入且无 dirty-selected 时
  clean 回落态让位（WPT select-validity「Remove and add back the placeholder
  label option」+ Chromium 实测）。
- **selected 内容属性变更步**（`_zwOptSelAttrPre/Post` 两半，part04
  setAttribute/removeAttribute 钩 + part05 defaultSelected 反射尾）：dirtiness
  false 时 selectedness 跟随属性增删、翻转即重置所属 select。
- **selectedIndex setter**（part05 + part04 HTMLOptionsCollection set trap
  共用 `_zwSetSelectSelectedIndex`，HTML §4.10.7 set-the-selected-index）：
  全员 selectedness=false、命中者 true + dirtiness=true，**不**跑 setting
  （-1/越界可全不选）；`options.selectedIndex =` 同路径。
- **select.value setter**（part04）：移除 `!handle && _isTag` 双重排除——旧
  guard 对未 apply 元素与 handle 形整支跳过，写面整条丢失；现双形态统一写
  JS 真态（全员 false、首个 value 匹配者 true + dirty），SelectOption
  mutation 照记（渲染/序列化面）。form-validation-valueMissing「Selected the
  option with value equals to 1」回归面（createElement select 同 turn
  validity 读）。
- **select 复位算法**（part04 form.reset，HTML §4.10.7
  the-reset-algorithm-for-a-select-element）：清 dirty/clean 键 + 跑
  setting（旧 `.selected = defaultSelected` 走 IDL setter 反向置脏）。
- **select.remove(index)**（part04，HTML §4.10.7 dom-select-remove）：无参落
  ChildNode.remove()（WebIDL 重载解析）；负数/越界 uint32 回转 no-op。
- **select.add 祖先检查**（part04 select.add + part03 HTMLOptionsCollection
  add，spec add 步 1）：element 是 select 祖先即抛 HierarchyRequestError；
  select.add 改走**元素代理** appendChild/insertBefore（旧裸 wire 调用对
  sel 父 + handle 子形态不进 list 融合视图——select-add「add option
  element」options[0] undefined 根因）。
- **select value-missing 约束校验**（part03，HTML §4.10.7 constraint
  validation）：required 且 list 无 selectedness true 者、或唯一 selected 即
  placeholder label option（required + display size 1 + 首项 value 空串 +
  与 select 间无 optgroup 祖先）才 missing；旧「value 空串即 missing」把非
  占位空 option 误判（select-validity 全簇断言面）。
- **Option() 构造器**（part02，HTML §4.10.9 构造步）：selected 内容属性只随
  defaultSelected 参（旧 `defaultSelected || selected` 把第 4 参也反射成
  属性）；构造尾落 `_optSelectedClean` 显式初始 selectedness（≤3 参恒
  false，第 4 参取真值），dirtiness 保持 false。
- **读侧归一**：`_zwSelectSelectedView`/selectedIndex getter/
  HTMLOptionsCollection selectedIndex/value 全部改 JS 真态计算（宿主
  `__zw_select_value`/`__zw_select_index` 读短路移除——sel 形先前短路致脚本
  态不可见，selected-index「set and reset」7F 根因）；回落仅限 pristine
  （list 无 dirty/clean 键）且 display size 1，跳 disabled。
  `_zwOptSelState` dirty 层**条目存在即权威**（false 亦然——否则 clean 回落
  态透过 dirty false 误现，ask-for-reset t2 实证）。
- **HTMLOptionsCollection 陷阱补齐**：has/getOwnPropertyDescriptor 三 trap
  （`in` 判定 + `hasOwnProperty(i)` 断言面，selectedOptions 同款）；原型面
  方法兜底（`Object.prototype[prop]`——assert_array_equals 调用面）。
- part11 `test_option_selected_getter_latest_wins_r2999` 两处期望按
  R3909 行为修正（size 1 回落使 removeAttribute/`.selected=false` 后仍
  true——spec 行为非 stale）；part59 新增 `test_r3909_*` 契约 12 测（W1–W12）。
