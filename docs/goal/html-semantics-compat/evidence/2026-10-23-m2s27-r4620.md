## 根因链（探针逐层钉定）

语料 handler（focusin removes-and-reinserts）在 setup 内执行
`position = dialog.nextElementSibling; dialog.remove();
body.insertBefore(dialog, position)`——wire 侧产生同批两条 mutation：

1. `Remove{#dialog}`
2. `InsertAdjacentSelElement{refSel, beforebegin, #dialog}`
3. （show 的）`SetAttr{#dialog, open, ""}`

JS 侧所有 op 引用**本 dispatch 开始时的树态**（spec：insertBefore 的
ref 节点对象不因前序 remove 失效）。refSel 由 R334b 路径在 INS 调用时
计算：`html:nth-child(1) > body:nth-child(2) > script:nth-child(3)`
（button=1, dialog=2, script=3）。

宿主 drain **顺序重放**：Remove 先摘除 dialog → body 元素子序变
[button, script] → script 的 `:nth-child` 索引漂移为 2 → INS target
`find_by_selector` 失配 → lenient warn+skip → **dialog 永久 detached**
（R361 批内 stash 虽记了 NodeId，但 target 先失败走不到 child 解析）；
SetAttr 连锁失配（remove_child 已清 id_map）。

毒化后果：wire 记录毁灭（qsa=0/cb=none/conn=false），后续 29 案 setup
全部 `closedBy` 读 none；ESC close request 找不到 dialog（`open` 停留
true）。探针宿主 warn 实锤（`ZW_SHAPED_ADVANCE_TRACE=1` 起
subscriber，tracing 默认写 stdout）：

```
WARN apply DOM mutations: insert_adjacent_sel_element selector no match, skipped: html:nth-child(1) > body:nth-child(2) > script:nth-child(3)
WARN apply DOM mutations: set_attr selector no match, skipped: #dialog
```

修复前探针 op 流（强制失败倾倒）：`after-esc{qsa=0 gbi=false cb=none
conn=false open=true}`；修复后：`after-esc{qsa=1 gbi=true cb=any
conn=true}`，记录跨越 drain 存活。

### 排除项（诊断中证伪的假设）

- INS 即时应用/RM 入队乱序：两回调均推同一队列（callbacks.rs），批序
  正确。
- id_map 不回填：`insert_before` 463 行 `register_id_map_recursive`。
- 跨批 stash 缺失：生产 drain 传 `Some(&mut detached_sel_nodes)`；且本
  案 RM/INS 同批，批内 stash 即可。
- 回调包装失效干扰读数：宿主回调每次 execute 重注册（R3858），探针改
  用 `Object.defineProperty` getter/setter 钩子存活并记录 CLOBBER。

## 修复（R4620，宿主共享路径）

`crates/engine/src/js_dom_bridge.rs` `apply_dom_mutations_full`：

- **批前预解析**：循环前扫批内 insert-adjacent 族四变体
  （InsertAdjacentHtml/Text/Element/SelElement——同构 target 查找与
  warn+skip 失配语义）的 target selector → NodeId（NodeId 不随树态漂
  移）。

  skip——语义对齐 JS：ref 已脱离时 insertBefore 本应抛错）。
- apply 时 find 优先于表（批内前序合法变更不掩盖）。

批，钉移动语义净效果（dialog 回文档、序保持 script 前、open 落地）。
