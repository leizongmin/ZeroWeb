## 范围

s18 挂账 proxy-modifier tentative 4F 收口。R4008 落三层（part03 + user_actions
+ part60/integration 契约），设计含一次中途重设计（双激活缺陷证伪后转发面上
移），见协作记录。

**三层设计**（commit 88793f87d）：

1. **shim 挂钩身份判**（part03 `_zwLabelActivationForward`）：交互豁免改
   「target 即本站 label 本体时不豁免」——spec 豁免只覆盖 interactive
   content **后代**为 target，label 自身非自身后代（`_elKey` 身份比较；嵌套
   label 的内层为外层交互后代，外层站仍豁免）。
2. **shim R155 post 段同判**：`_r155Self8` 身份判让 label.click() API 面
   不被交互豁免吞掉（not-trusted 转发语义保持）。
3. **宿主面上移**：shim 不承接宿主 generic Event 的转发（`_dispatchWithBubble`
   finally 段留层属注释）——renderer 真实输入路径由 Rust 默认动作层
   `activate_label_at`（既有）；webview plan 路径（testdriver Activate）由
   user_actions 新增 label 链：Activate 落 LABEL →
   `associated_label_control_selector` 解析（labelable 过滤杜绝递归环）→
   click 未取消时递归 control 完整激活管线（disabled → DisabledTarget
   noop，spec label 激活不越过 disabled 控件）。

**双激活缺陷与重设计**：首发实现把宿主 generic Event 转发放 shim finally
段；并发会话以 renderer 集成测试证伪——`dispatch_dom_at` 后 Rust 层
`activate_label_at` 再次激活，checkbox 翻转两次。shim 无法区分 plan 派发与
renderer 派发（同为 generic Event），转发上移 plan 层，1/2 保留。
