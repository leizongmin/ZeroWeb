## 范围

form_attribute 动态关联余案 ~57F（mutation 钩子面）收口。R4005/R4006 落 shim
四块（part01/part03/part05/part06；part60 契约）：

1. **`.form` getter form owner 关联重写**（part03）：
   - 祖先上行改 JS 视图 `parentNode`——pending 槽优先 → sel host 链 → handle
     `_zwNodeParent` 反链三族统一。旧 `_ancestorChain`（host `__zw_parent`）
     两缺口：① handle-only 子（createElement 动态构造产物）无 sel 链恒空，
     basic association 恒 null；② sel 子 append 后 host mutation 异步 drain
     （R334 `_zwSelPendingParent` 槽），读旧树 → parser-inserted reparent 后
     owner 滞后旧 form。
     https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#form-owner
   - form attr 关联的 id 匹配域改**控件所在树**（spec reset the form
     owner——树内树序首个 id 匹配的 form）：root 上行遇 document →
     `getElementById`（树序首个，R4006 门面）；detached 根 → 子树 pre-order
     DFS 首个 id 匹配。控件随 form 出文档（detached 树）时 detached form
     仍是 owner（WPT "not in the document but has the form attribute set"）。
     https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#reset-the-form-owner
   - sel 面属性读走 latest-wins（`__zw_get_attr_lw`，同批 setAttribute 后
     `.form` 立即可见——宿主快照 miss 致 formAttr 空串误判 null）。
   - OBJECT 入 form-associated gate（HTML §4.8.6 the-object-element；
     form.html `object.form` 直接翻绿，form_attribute.html 内 object 断言族
     同面）。TEMPLATE 先于 FORM 命中即无关联（R5009 片 e 同口径保留）。
2. **R52 消零 purge 复活**（part01 旁表 + part05 purge 钩 + part03 读点）：
   `_zwProxyWeakResurrect` WeakRef 旁表——purge 前 stash（仅 '@h' handle 键，
   与 R52 可清范围一致），`_makeProxy` miss 时 deref 活则恢复强缓存并返回原
   对象（同 turn append+remove 后页面仍持有的原 proxy 不重铸——第二 wrapper
   identity 断修复，form_attribute "not in the document" 族
   `assert_equals(this.form, form1)` 根因之一）；页面弃持 deref undefined
   自清条目，R52 泄漏口径不变。
3. **R4006 getElementById pending 窗口树序**（part06）：同 id 多候选（插入序
   ≠ 树序——insertBefore 前插、id 改名重登记）全量过门入池，按 JS 视图公共
   祖先 + 融合 childNodes 位次比较取树序首（`_r4006TreeCmp`——异根/身份分裂
   保守返 0 保插入序，不回退）；单候选走旧直返 fast path（gEBI 高频，池化只
   在真多候选时付费）。`_r125Overridden` 门补入 pending 路径——改名条目
   （form1.id='form-one'）旧键不再命中。助手模块级声明（T8G 墙钟纪律）。
   https://dom.spec.whatwg.org/#dom-document-getelementbyid
4. 契约测试 part60 `test_form_owner_dynamic_r4005`（W1–W4）：handle-only 子
   basic 关联 + reparent 同步跟随（W1）；detached 树 form attr 关联 + R52
   purge 身份（W2）；gEBI 同 id 树序五连（前插胜出/owner 跟随/移除回落/尾部
   重插回位/改名摘键，W3）；OBJECT gate（W4）。与修复同提交。
