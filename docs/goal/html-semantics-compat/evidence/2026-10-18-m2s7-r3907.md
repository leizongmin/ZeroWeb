# M2 切片 7 — option 元素文本/反射语义 R3907（2026-10-18）

## 范围（shim R3907）

- **option.text getter = strip-and-collapse(child text content)**（part03，
  HTML §4.10.9 https://html.spec.whatwg.org/multipage/form-elements.html#dom-option-text ）：
  「collect text value」算法——Text/CDATA → data；`localName=script` 且
  ns ∈ {HTML, SVG} → 整棵排除；MathML/null ns script → 递归计入；
  comment/PI 不计；元素沿**子列表**递归（不推 textContent——嵌套层
  script 须逐层排除）。「strip and collapse ASCII whitespace」——首尾
  剥离 + 内侧折叠单空格，NBSP 保留。
- **option.label / option.value getter**：无命名空间内容属性
  **存在即采纳**（空串不回落文本）；同 local 仅 NS 实例 → 影子不可见；
  缺省回落 collapse 后 child text content（与 .text 同源）。无 ns 判定
  走 R122 `_zwAttrInstances` 实例层（动态权威面），解析快照属性天然
  无 ns；此前裸 `__zw_get_attr` 读 NS 影子可见、裸文本回落无 collapse。
- **option.text setter = textContent setter 委托**（part04）：spec setter
  即「string replace all」，与 textContent 完全一致——旧文本子 node
  identity 更替并脱离树、`.text=''` 清空全部子；零平行记账面
  （`_handleChildren` 清理/本地文本子注册/`_zwTextWritten`/MO childList
  全继承）。
- 新助手 4 个（part03）：`_zwOptStripCollapse` / `_zwOptCollectWalk`
  （64 层深度帽，R181 同款防环）/ `_zwOptChildText`（handle 形容器判定
  + 融合子列表；sel 形先探 R3028 latest-wins——`__zw_get_text_lw` 与
  `__zw_get_text` 不等即 SetText pending，直取 collapse 后 lw；相等走
  子列表 walk 使 script 排除在稳态生效）/ `_zwOptAttrNoNs`。
- part57 新增 `test_option_semantics_r3907` 行为契约单测（W1–W7）：
  strip/collapse 模型（NBSP 保留）、collect text value（HTML/SVG script
  排除、MathML/null ns 递归、comment 不计、嵌套层 script 逐层排除）、
  label/value 无 ns 反射（空串采纳/NS 影子/回落）、text setter 子替换
  身份、解析 option（sel 形）口径、select.value 宿主路径不回退。

## dialog +3P 归因（非本切片因果，stash 对照验证）

interactive-elements 57→60：dialog-showModal.html 2/10→4/10、
dialog-focusing-steps-disconnected.html 0/2→1/2。三个转绿 subtest 均为
`showModal()` InvalidStateError 断言。因果核查：

- M1 基线至 s6 **9 连跑**该三案全 Fail，消息均为 `threw an exception
  from the wrong global`（`assert_throws_dom` 的 `e.constructor ===
  window.DOMException` realm 身份检查不过；守卫本身在抛）。
- 本轮转 Pass 的同时，同文件 d11 案（detached document showModal）
  消息从 `wrong global` 变 `did not throw`（两轮均 Fail，零账本回归）。
- **stash 对照**：摘除本切片 3 文件 diff 重编译后定点跑
  dialog-showModal.html——两个 InvalidStateError 案同样 **Pass**、d11
  同样 `did not throw`；恢复 diff 复编译结果相同。两棵树定点行为
  完全一致，本切片 diff 无 dialog 因果路径（全部改动 option 作用域门控）。
- 结论：全量跑下该三案结果对 runner 执行上下文非确定（多线程上下文
  复用的 realm 身份面），s6 全量跑落 `wrong global` 形态、本轮落
  干净形态；+3P 不计入本切片贡献。**挂账**：runner 案级 V8 上下文
  realm 身份非确定性（`assert_throws_dom` wrong-global 误报面）归
  wpt-runner 通道排查；detached-document showModal 不抛（d11）为
  `_zwIsConnected` detached 面预存缺口。
