# M2 切片 70（s70）——F2 source-set 族收口：共享选择核 + 选中 URL 全状态面 + lazy/detached 更新语义（R5277）

日期：2026-10-25。s67 八族地图 F2（~219F）续片。四个子族一次收口：
parse-a-srcset 49、select-an-image-source 13、update-the-source-set 84、
relevant-mutations 46（另带 current-pixel-density 21、img-picture-ancestor 4、
srcset-media-dynamic 1、source-relevant-mutations 1）。

## 1. 根因

srcset/sizes/picture-source 选择面仅有 R4162/R2419「首 URL」近似：

1. **parse-a-srcset**：无描述符语法（密度 `x`/宽度 `w`+sizes 归一/h 兼容）、
   尾逗号裸 URL 剥除、宽松浮点（`.5x`/`1e0x`/`-0x`）与非非法拒（`+1x`/`1X`/
   `Infinityx`/`0w`）、空组跳过继续。
2. **select-an-image-source**：无去重（同密度保首）、无 DPR 择面（≤DPR 最大
   密度、无则最小密度）；picture source media/type 条件门与 src 缺席——
   update-the-source-set 84F 的主体。
3. **relevant mutations**：src/srcset/sizes/crossorigin/referrerpolicy 属性
   变迁与 picture 树插入/移除不触发重验（46F 全部 + source-relevant-mutations）。
4. **current-pixel-density**：resourceState 无密度字段，naturalWidth 恒原始
   尺寸（21F）。

## 2. 修复面（R5277）

1. **共享选择核**（part03，spec §4.8.4.3.7-12 逐字）：
   `__zwParseSrcsetAttr5277`（解析保 raw——URL 解析属 selection 阶段）、
   `__zwParseSizesAttr5277`（逐项 last-value、media 条件、auto 忽略、视口宽
   回落、source-size-value 单位表）、`__zwCreateSourceSet5277`（default
   source 补挂 + 密度归一）、`__zwUpdateSourceSet5277`（picture 子序 +
   media/type 门 + SVG ns 排除）、`__zwSelectImageSource5277`（去重保首 +
   DPR 择面）、`__zwSelectUrl5277`。
2. **候选 URL 就地绝对化**（create/update-source-set 两出口，复用
   `_zwResolveFetchUrl`——文档基 URL 含 `<base href>`）：spec
   select-an-image-source 的 selected source 是解析后 URL，available-images
   元组键/请求 URL/currentSrc 同源。raw 键与绝对键并存把同图拆成两个 avail
   表项——image-loading-lazy-available P→F 实证（IDL `.src` 往返把绝对形写
   回属性，sweep 与运行期键不一致 → lazy img avail miss → 被视口门拦死）。
   run3 域验证捕获，run4 修复确认。
3. **全状态写入面切选中 URL**：静态 sweep（part04 `__zwFireStaticImgSettle`
   ——srcset-only img 旧 sweep 无 src 跳过）、R56h `.src` IDL 链（part05
   setter 经 `__zwSelectUrl5277` 归一）、revalidate（part03
   `__zwImgRevalidate5277`）；密度入 resourceState，naturalWidth/Height 按
   选中密度折算（`_zwImgNaturalDim` 密度校正）。
4. **relevant mutations 触发面**：`__zwImgAttrMutated5277`（part04
   setAttribute/removeAttribute trap 尾、part05 set trap IDL 臂）——src/
   srcset/sizes 恒重验；crossorigin/referrerpolicy 按 content-state 枚举
   比对（缺省/空/无效归缺省态，「state not changed」行不触发）；SOURCE 的
   srcset/sizes/media/type 变迁 → 父 picture 内其后 img 兄弟重验；img 入/
   出 picture、picture 整体插入/移除树触发面。restart 判定收窄为选中 URL
   变更——同 URL 命中照常 settle + 重派 load（spec available-images 臂 load
   派发仅受 maybe-omit-events 门控；R5275「同 URL 幂等不重派」按 spec 收窄）。
5. **null selection**：src/srcset 移除 → current request broken、URL 清空、
   error 仅在仍有 src/srcset/picture 关联时派（'src removed'/'srcset
   removed' timeout 行）。
6. **detached/lazy 更新语义**（update-the-image-data）：detached 更新延一步
   （重入时重读 loading——src-then-lazy-load 的任务内时序）；lazy 视口门只
   拦 fetch 启动不拦 avail settle（available-images 检查先于 lazy 决定——
   image-loading-lazy-available/use-list 面）；曾有请求（已加载 lazy img 换
   src）不受门（restart 照旧）；scrollIntoView 置 per-element 视口旗标并重验
   （image-loading-lazy-relevant-mutations「mutation 不触发」与
   image-loading-lazy-crossorigin-change「scrollIntoView 后用最新
   crossorigin fetch」两对立面的统一近似——F5 真视口几何收口前的债务标记）。
7. **broken 无 width/height 属性 → IDL 0**（part04 width/height 臂）：broken
   的 density-corrected intrinsic dimension 为 0；300/150 是 UA broken-icon
   渲染尺寸非 IDL 面（naturalWidth-naturalHeight-width-height
   'non existent image (when not rendered)' 行实证，s68 遗留误正改 0）。
8. **css-parser media_query.rs**：MQ4 §error-handling——非空 inner 无法解析
   为已知条件 → 整条 query 不匹配（返回 None），不再退化空条件 all 恒匹配
   （`all and (!)` 面：select-an-image-source 的 source media 走偏，
   update-the-source-set media='all and (!)' 行实证；浏览器
   `matchMedia('(prefers-color-scheme)').matches === false` 对齐）。
   `test_prefers_color_scheme_not_boolean` 钉定更新（旧行为 pin 撤换）。
9. **extract.rs**：srcset 候选收集接解析核（静态管线与运行核同源）。

契约 part87 五测试：`srcset_sizes_parser_r5277`（解析核真值点 a–i）+

重验/sizes 同 URL 重派/DPR 重选密度校正/crossorigin 状态门/referrerpolicy
枚举比对/srcset 移除 null selection/入 picture/前序 source 胜出/后序 source
