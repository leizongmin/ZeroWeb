## M0 — 解码器选型 RFC（门控收口）

- 三路线 RFC 成文（[docs/specs/video-decode-playback-spec-rfc.md](../../../specs/video-decode-playback-spec-rfc.md)）：
  A. ffmpeg 外部进程 / B. Rust crate 组合 / **C. VP9/AV1 开源先行 + 进程内 crate**。
- 2026-09-01 用户批复：D-RFC-1=批准路线 C；D-RFC-2=AV1 M3 再含（`decode-av1`
  feature 默认关，M1 零 C 依赖）；D-RFC-3=H.264/HEVC 单独立项。

## M1 — 首个视频帧上屏

- **M1a 解码管线**：`crates/media`（`zero-media`）——webm/Matroska demux
  （`matroska-demuxer 0.8`，纯 Rust）+ VP9 解码（`rusty_vp9 0.1`，纯 Rust 零 C
  依赖）+ YUV→RGBA（8/10/12bit 与 4:2:0/4:2:2/4:4:4）。fixture 48 帧全解、PTS
  单调、首帧与 ffmpeg 7.1.5 rawvideo 参照逐字节一致（探针实测）。
- **M1b 帧上屏通路**：painter `paint_video_element`（ImagePrimitive，解码像素
  gate）→ pipeline video 固有尺寸段 → layout-engine replaced sizing 白名单 →
  wpt-runner `load_video_first_frames`。e2e 双测常驻（正例帧像素上屏 + 不可解码
  负例占位）。证据：evidence/2026-09-01-m1b-first-frame-on-screen.md。

## M2 — 连续播放 + 语义驱动（切片 A~F）

- **M2a（切片 1~5b）**：`VideoPlayer` 帧率驱动（PlayerState 状态机 + play/pause/
  tick/playbackRate clamp/reset）；duration 真值注入链（`probe_video_media_meta`
  → settle → shim `_zwMediaLoadSequence` 真值 duration）；`videoWidth`/`videoHeight`
  IDL getter；生产侧首帧注入 ImageCache；`VideoPlayerRegistry` + `__zwVideoBridge`
  宿主桥（五回调族）+ tab_worker 帧泵（is_any_playing 快速门）。
- **M2b 精确 seek + 变速**：两阶段 seek（Cues 关键帧落点验证 + 全量回退前向精确
  解码）+ player/registry/桥/shim 四层接线（seeking 不改 paused、时钟锚点重置）。
- **M2c 音频解码面**：`AudioDecoder`（symphonia 0.6 mp3+ogg/vorbis）+ NullSink
  全链 e2e（440Hz 过零率 ≈880 锚点）；后续切片 A+B 补齐 settle 登记生产链路
  （webview/async_load）、增益联动（volume/muted setter 桥推 + play 起播同步）、
  seek 追赶区静默、导航释放（DC-4）、renderer 多进程路径 SetVideoPlayers 对齐。
- **切片 C 色度精化**：WebM Colour 元素解析（matrix/full_range）+ BT.709/BT.601/
  identity 自适应 YUV→RGBA；两处旧解码缺陷根因修复（4:2:0 色度采样索引坍缩、
  limited 值域按 full-range 误释）——RGB 均值与 ffmpeg swscale 对齐；
  reftest replaced-element-003 unmask 收口（reftest-upstream 83.6%）。
- **切片 D+E（A/V 同步，media-audio M2 契约兑现）**：webm 双轨（VP9+Vorbis）
  伴生音频面（`open_webm_audio_track`：CodecPrivate 三段 Xiph 头 → OGG 页重封装
  → symphonia；granule 保守高估防端部裁剪）+ audio clock 主时钟
  （`sync_to_media_time` drift 构造校正 + tick_all 主时钟先行序）+ currentTime
  组合时钟 + seek 双轨对齐（av_sources 字节留存 + 伴生轨重建）。
- **切片 F ended 守卫**：伴音流末 video player 走到 Ended、泵停（回归测试常驻）。
