## 一、Ladybird 的时间账本（一手数据，2026-08-05 复核）

| 里程碑 | 耗时 | 数据 |
|---|---|---|
| 首 commit → 首个完整网页渲染 | ~4 个月 | 2019-06-15 → 2019-10-10 |
| → Acid3 100/100 | ~2 年 9 个月 | 2022-03-30 |
| → 可跑真实网站（22 站实测半可用） | ~3 年 | 2022-07 |
| → 全职化 + 非营利（4 人） | ~5 年 | 2024-07 |
| → WPT 90% 门槛（同源绝对数） | ~6 年 4 个月 | 2025-10-05，1,861,180/2,033,861 |
| → 2026-08-05 实测 | **93.33%**（2,085,135/2,234,099，官方算法复算） | 8 人全职 + 428 贡献者 + 约 95 万行引擎 |
| Alpha 发布 | **未达成**（2026 年内目标，截至 2026-08-06 未发布） | 官方「Target: Alpha 2026」 |

关键定性结论：
1. **全职化是最大加速杠杆**：前 4.5 年 hobby 期产出密度远低于全职化后 2 年
2. **兼容性是幂律曲线**：90%→92% 段（2025-10 至 2026-07）约 2.4 万新增子测试；2026-06→07 单月仅 +108——「低垂果实摘完了」（Kling 自述）
3. **无 100% 目标**：官方最接近表述是「committed to catching up eventually」；测试套件本身是移动目标

## 二、ZeroWeb 现状（2026-08）

- oracle 一致率约 **57%**（Chromium Oracle 口径，rendering-compat.md DC-14），strict 处于 plateau
- 资源：G0 单维护者 + AI-first 开发（无全职团队、无社区贡献者）
- 口径差异提醒：ZeroWeb 的 57% 是 **oracle 严格一致率**（比 Ladybird 月报的同源绝对数严格得多），**不能直接与 Ladybird 的 93.33% 数值对比**——Ladybird 的 DC-14 credible pass（oracle 口径）无公开数字

## 三、目标校准选项（待用户拍板）

**Mission 现状**：`rendering-compat.md` —「上游 WPT 真实 reftest 通过率 **95%+**」

| 选项 | 内容 | 影响 |
|---|---|---|
| **A. 分阶段里程碑（推荐）** | Mission 95% 保留为长期愿景；明确分阶段：2026 年内 oracle **65%** → 2027 **80%** → 长期 95%；plateau 阶段以「轻量修复 + 守成」为执行形态（与 2026-08-04 裁决兼容） | 每轮 rally 有可达成的验证目标，plateau 不再像失败；预期管理与 Ladybird 幂律曲线一致 |
| B. 维持现状 | 95% 短期冲刺目标不动 | plateau 期间每轮都像失败，agent 与用户的预期反复摩擦（现状） |
| C. 降低 Mission | 如 90% | 与 DC-14 既定方向冲突，且 90% 对 ZeroWeb 当前 57% 仍是长期目标，收益有限 |

**推荐 A**：Ladybird 账本表明「95% 是多年级目标」，短期 Mission 与幂律现实不匹配是 plateau 反复的根源之一；A 不降低愿景，只把「何时到达」显式化。
