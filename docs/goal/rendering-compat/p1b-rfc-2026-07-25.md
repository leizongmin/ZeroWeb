## 1. 背景与目标

P1b = JS Bridge 从「selector-shim + 同步 execute」原生化为「真实 DOM 绑定 + 异步回调 + HTML spec event loop」，解锁**交互式网站**（fetch / MutationObserver / 事件循环 / setTimeout 真实化）。这是 M11「浏览器日常可用」最后非环境缺口（master.md 验收矩阵 line 2776）。

## 2. 现状（代码核实）

### 2.1 Sandbox trait（`script-sandbox/src/lib.rs:95-110`）
```rust
fn register_callback(&mut self, name: &str, callback: Box<dyn Fn(&[String]) -> String + Send + Sync>);
```
- **同步**：回调返 String，无 async/Promise resolve 机制
- **参数/返回全 String**：无原生对象绑定（JS element 无法持有 Rust 节点 ref）
- 无回调 ID、无异步 resolve 通道

### 2.2 dom_bridge / js_dom_bridge
- JS element = **selector 字符串句柄**（querySelector 返 selector，非 NodeId）
- DOM 操作 → `__zw_*` → `DomMutation`（selector-based）→ `apply_dom_mutations` 改 HTML 快照
- `Promise.resolve`（dom_bridge.rs:975/977/997）—— 来源待核实（V8 原生 vs polyfill）

### 2.3 V8 runtime（`v8_runtime.rs`）
- **`perform_microtask_checkpoint`（line 270/337）已存在** —— execute 后 drain V8 原生 microtask
- `HOST_CALLBACKS` thread-local（按 index 调度同步回调）

## 3. 缺口分析（修正 R2025 P1a 摸底）

| 缺口 | 状态 | 影响 |
|---|---|---|
| **异步回调通道**（Rust→JS Promise resolve） | **缺失**（register_callback 同步 String） | fetch 网络结果无法 resolve JS Promise；setTimeout 真实延迟、rAF 不可实现 |
| **节点身份**（String selector → NodeId handle） | **缺失**（参数 String） | MutationObserver childList（addedNodes/removedNodes 需节点身份）不可行 |
| **microtask queue** | **待核实**（V8 `perform_microtask_checkpoint` 已存在，原生 Promise.then 可能已工作） | 若已工作，p1b-slice1 的 JS microtask queue 不必要 |

★ **核心修正**：P1b 真硬阻塞 = **异步回调通道**（register_callback trait 同步，Rust 无法异步 resolve JS Promise），**不是** microtask queue（V8 可能已有 `perform_microtask_checkpoint`）。p1b-slice1 的 microtask 假设须 v0.2 核实。

## 4. 目标架构

### 4.1 异步回调通道（核心）
扩展 Sandbox trait 支持异步回调（向后兼容现有同步 `__zw_*`）：
- **方案 A**：回调返回「回调 ID」而非 String；Rust 异步完成后，经 `execute_script_direct` 调 `__zwResolveCallback(id, result)` resolve JS Promise
- **方案 B**：新增 `register_async_callback` trait method，回调接收（id + args），Rust 经专用 channel 异步 resolve
- 选型待 v0.2（A 简单但 poll/轮询风险；B 干净但 trait 扩展）

### 4.2 节点身份 wrapper
- JS element = Rust `NodeId` 的 wrapper（非 selector 字符串）
- querySelector/getElementById 返 NodeId handle；DOM 操作按 NodeId
- MutationObserver childList 可用（addedNodes = NodeId 列表，对应 JS element wrapper）

### 4.3 microtask（核实后）
- 若 `perform_microtask_checkpoint` 已让 Promise.then 工作 → 不需新做
- 若不工作（dom_bridge 覆盖了 Promise）→ 修正 dom_bridge 用 V8 原生 Promise（删除 polyfill）

## 5. 分阶段切片（multi-month）

- **S1 异步回调通道**（核心）：Sandbox trait 扩展 + Rust→JS resolve 机制 + 向后兼容。**解 fetch/setTimeout/rAF 基础**。
- **S2 节点身份 wrapper**：selector → NodeId（替换 `__zw_query_*`/`__zw_set_*` selector 路径）。**解 MutationObserver childList**。
- **S3 fetch 真实化**：走 net crate（M7 已就位）+ S1 异步 resolve Promise。
- **S4 MutationObserver 真实化**：S2 节点身份 + dom 侧 `record_mutation`（已完备，document.rs:239 等 7 处）→ JS callback（异步交付）。
- **S5 setTimeout/setInterval/rAF/requestIdleCallback**：S1 异步 + 定时器队列。

## 6. 风险

- **trait 改动影响双后端**：register_callback 改动影响 V8（`v8_runtime.rs`）+ QuickJS（`quickjs_runtime.rs`）双实现 + 所有 `__zw_*` callback（dom_bridge 全部）。**须向后兼容**（同步 callback 不变，异步走新通道）。
- **线程模型**：JS 单线程（V8 isolate）+ Rust 异步（net crate tokio）—— resolve 须 marshal 回 JS 线程（worker 已有线程边界，见 tab_js_worker）。
- **替换 dom_bridge shim**：节点身份 wrapper 替换 selector-shim 全部 —— 大规模，须分批（S2 按 query/set 两族拆）。
- **p1b-slice1 修正**：microtask queue 假设须 v0.2 核实（V8 `perform_microtask_checkpoint`），可能不必要 → p1b-slice1 降级或撤销。

## 7. 依赖 + 决策点

- **依赖**：M6 JS 运行时（V8/QuickJS feature gate）已就位 ✓；net crate（M7）已就位 ✓（fetch 真实化用）
- **决策点**：授权 multi-month + 接受 trait 改动风险（双后端 + 全 `__zw_*` callback）
- 本 RFC = master.md line 2743 所指的「独立 RFC」v0.1

## 8. 待核实（RFC v0.2）

1. **Promise.then 是否已工作**（`perform_microtask_checkpoint` + dom_bridge Promise 来源）—— 决定 microtask 是否需新做 + p1b-slice1 处置
2. **V8 原生对象绑定 API**（rusty_v8 `v8::Object` / `External` / weak handle）—— 决定节点身份 wrapper 实现方式
3. **QuickJS（rquickjs）对应能力** —— 双后端对等（Sandbox trait 抽象要求）
4. **异步 resolve 线程 marshal** —— tab_js_worker 现有线程边界是否够用，还是须新 channel
