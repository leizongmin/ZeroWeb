# R495 — position:fixed 全-inset stretch：post-extract height override 不传播到 fixed 元素背景绘制（paint 用 taffy measured/content_height）；多 issue 深坑

**日期**: 2026-06-22
**前置**: R492/R493/R494（全量 re-dump 证 R491 net −1；position:fixed 全-inset 垂直 stretch 缺口定位 w=800✓/h=19.2✗；converter stretch 已回退；R494b 建 post-layout height override）。
**本轮动作**: 实现 R494b 建议的 scoped post-layout height override（`stretch_fixed_abspos_viewport_height`，仅 height，CB=视口，不动 x/y 避开旧回归）。**LAYOUT_DUMP 证 height override 在 extract 层生效，但 fixed 元素背景绘制仍用 taffy measured/content 高 → 渲染仍失败 → 回退**。

---

## 1. 实现 + LAYOUT_DUMP 实证

新增 `engine.rs::stretch_fixed_abspos_viewport_height`（post-extract pass，对 fixed 或 absolute-无-positioned-祖先 + 全 Px inset(top+bottom) + auto height → `child.height = viewport_h − top − bottom`；仅 height，不碰 width/x/y）。在 `adjust_absolute_pct_to_viewport` 后调用。

**LAYOUT_DUMP**（`positioning/abspos-containing-block-001`，`body{bg:red;margin:100px} div{position:fixed;top/right/bottom/left:0;bg:white}`）：

```
TEST: body abs_y=100 h=0 x=100 w=600 ; div abs_y=0 h=600(was19.2)✓ x=0 w=600
REF:  body abs_y=0   h=19 x=0   w=800 ; div h=19.2 x=0 w=800
```

**height override 在 extract 层生效**（div h=19.2→600）。但**像素实证全红**（div 内 (50,50)/(200,200)/(400,400) 全 `(255,0,0)` 红，div 白背景未绘制）；white=3% ≈ 600×19.2（content 高）。

## 2. 关键发现：post-extract height override 不传播到 fixed 元素背景绘制

**机制推断**：fixed 元素的背景绘制走**单独的 fixed-element paint 路径**，该路径读 **taffy 的 measured layout**（h=19.2）或 **content_height**，而非 post-extract overridden 的 `LayoutBox.height`（600）。故 height override 在 extract 层成功（LAYOUT_DUMP 见 600），但 paint 层仍按 19.2 绘制 → div 白背景仅 600×19.2 薄条（~3%），红画布从下方/右方透出。

**对照**：pre-R491（无画布传播）div 渲染 ~2.3% 白（intrinsic 小盒，painted）→ 当时白画布 + 小白盒 = 全白匹配 oracle。post-height-override：div h=600（extract）但 paint 仍 19.2 → 红（R491 传播）透出。

## 3. 多 issue 分解（position:fixed 全-inset 覆盖须同时修 3 项）

| issue | 状态 | 性质 |
|-------|------|------|
| ① height stretch（§10.6.4）| extract 层✓（h=600），paint 层✗（仍 19.2）| **post-extract override 不传播到 fixed paint** |
| ② width（§10.3.18）| ✗ w=600（body CB，非视口 800）| **R98 taffy-CB 谱系**（taffy 用静态父 body 作 abspos CB，R324 只修 position 不修 size） |
| ③ fixed 元素背景绘制 | 用 taffy measured/content_height 非 overridden height | **paint 路径读 taffy 直接值** |

**裁决**：position:fixed 全-inset 覆盖是**多 issue 深坑**（非单 clean pass）。post-extract height override 单独无效（paint 不用 overridden 值）。

## 4. 下一步修复路径（须二选一，都比 post-extract 深）

1. **taffy-level stretch**：在 converter 或 build_subtree 设 fixed/abspos 全-inset+auto 的 size（width=CB−insets, height=CB−insets），让 taffy measured 即正确 → paint 读 taffy 值也正确。**难点**：CB=视口（fixed）/positioned 祖先（absolute）在 build 时未必已知；taffy 0.7 对全-inset+auto 的 abspos 已实证忽略 explicit height（R494 converter 试图失败：set size.height=600 → taffy 仍给 19.2）。
2. **paint 路径修复**：让 fixed-element paint 读 post-extract overridden `LayoutBox.height` 而非 taffy measured。须定位 fixed-element paint 入口（可能 in painter fixed-layer handling），改其尺寸源。

**R494 converter 试图**（set size.height=600）已证 taffy 忽略 explicit height（路径 1 对 height 不可行，除非 taffy upgrade R304 DEFER）。**R495 本轮**（post-extract override）证 paint 不读 overridden height（路径 2 须改 paint 尺寸源）。两条路径均已 ruled out 单点修。

## 5. 代码变更

零（`stretch_fixed_abspos_viewport_height` 实现 + LAYOUT_DUMP 验证 height override 在 extract 生效后**回退**——paint 层不读 overridden 值，单独无效；按 code-guidelines 不留非生效代码。engine.rs 恢复 HEAD）。

## 6. 结论

position:fixed 全-inset 覆盖缺口 = **多 issue 深坑**（height stretch paint 不传播 + width body-CB + fixed paint 读 taffy），R492「修 stretch → R491 净正 +7」**过乐观**——须先解决 paint 读 taffy-measured 而非 overridden 的问题（或 taffy upgrade），否则任何 height/width stretch 都不生效。R491 维持 net −1（spec 正确，latent 缺口未解）。plateau 再确认。
