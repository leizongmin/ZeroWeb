# morning-work 4× 高度幻影间隙修复落地（R255）

**日期**: 2026-06-18
**目标**: DC-13 morning-work 89% diff 真主因（R253 定位为元素间幻影垂直间隙）修复
**结果**: **根因=UA 默认 display 表缺 article/aside/details/hgroup/menu/search**（回落 inline→含 block 子元素触发 R109 §9.2.1.1 匿名块拆分→块级子元素间空白被包成幻影匿名块盒）。补齐后 morning-work body **25301px→5677px**（≈chromium 5981px，4.2×→~0.95×），full-page chr-diff **89.14%→48.65%**（-40pp）。reftest 自源 **438/490 零回归**，make test 12235/0，clippy/fmt 干净。

## 根因（BISECT 隔离）

R253 误判「最小复现未重现」——因最小用例未带 `.article` 类/外链 CSS。本轮系统 BISECT：

1. **`<article class="article">` + 外链 CSS（min-height:200px）→ 复现幻影盒**（每对块级子元素间一个 `article.article` w=4 h=200 mt=64 匿名盒）。
2. **`<article>` + 空 CSS（纯结构）→ 仍复现**（幻影盒 h=0 w=4，证明非 CSS 触发）。
3. **`<div class="article">` → 干净无幻影**（排除 .article 类/min-height）。
4. **逐标签扫描**：`<article>`/`<aside>`/`<details>` 触发幻影；`<div>`/`<section>`/`<main>`/`<nav>`/`<header>`/`<footer>`/`<blockquote>`/`<figure>` 干净。

→ 触发条件 = 特定标签被当作 inline。核实 `ua_default_display`（style-system/src/lib.rs:49）的 block 列表**缺少 article/aside/details**（及 hgroup/menu/search）。CSS display 初始值=inline，故这些标签回落 inline；当含 block 子元素（h2/p）时，`inline_block_split::inline_has_block_child` 返回 true → tree.rs R109 路径（line 554-591）为每段连续 inline 内容（块级子元素间的空白文本节点）生成匿名块盒，匿名盒继承父 node_id（→ 标签显示为 article.article）+ 应用 .article 样式（min-height:200、margin:4em）→ 每对块子元素间插入 h=200+mt=64≈264px 幻影高度，累积 4×。

## 修复

`ua_default_display` 的 block 列表对齐 **HTML Living Standard UA 样式表**（13.1.1 节 display:block 列表），补齐缺失标签：

```
新增：article | aside | details | hgroup | menu | search
（原有 address/blockquote/dd/div/dl/dt/fieldset/figcaption/figure/footer/form/
  h1-h6/header/hr/legend/li/main/nav/ol/p/pre/section/summary/ul 不动）
```

`legend`/`dialog` 维持现状（legend 已 block 保留无害；dialog 仍 None，dialog 渲染范围外）。

## 诚实结论

- 800×600 顶部视口 chr-diff 仍 **28.72% 不变**：该视口只截到 nav/title/date/item-tags 顶部区，幻影盒在 article body 折叠下方（abs_y≥257），顶部区不受影响。顶部区 28.72% 主因仍是 item-tag span→block 全宽堆叠（R109 IFC 架构）+ font-weight 未落地（R229），独立于本修复。
- full-page 48.65% 残余 = font-weight（R229）+ fontdue CJK 字体度量 + item-tag R109 + hljs 语法高亮缺失（需 JS）+ body 高度 ~300px 差（5677 vs 5917）。均已知独立子问题。
- **本修复是正确的几何 bug 修复 + 零回归**：消除 morning-work 4× 高度幻影盒，HTML 区块元素 display 正确化。范围限于 style-system `ua_default_display` 单点 + 单测，未触 layout/paint。
