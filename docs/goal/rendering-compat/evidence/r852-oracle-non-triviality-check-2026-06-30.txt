────────────────────────────────────────
1. 动机（先实证退化假绿确实存在）
────────────────────────────────────────

DC-14 spec：「拒绝 test == ref 且接近纯色（或 PNG 退化）的 case 自动判 PASS——必须标记为
可疑/退化并单独审计，防止 harness PNG 加载 bug 等导致的退化假绿」。

R851 oracle 仅按 z_vs_chr 阈值判 pass，不检帧是否退化。本轮先 PIL 采样 400/13793 oracle PNG：
**12 帧（3%）近纯色（>99.9% 单色）**，含 4 帧 **100% 单色**：
  - css-text/parsing/text-wrap-style-valid / text-justify-valid / line-break-computed（解析测试，headless 无视觉输出）
  - css-text/animations/text-indent-interpolation（动画，需 JS/时序）
  - css-position/position-absolute-iframe-print-001_sub（print 媒体 + iframe）
  - CSS2/floats/crashtests/float-dynamic-change-6（crashtest，无视觉断言）
这些用例 chromium 渲染为空白/纯色；若 ZW 也空白 → z_vs_chr≈0% → 假 PASS，污染 38.4% 基线。
故非平凡性检查确有实测价值（非纯防御）。

────────────────────────────────────────
2. 改动（tests/wpt-runner/src/main.rs）
────────────────────────────────────────

(A) 新增 `frame_is_near_solid(fb) -> bool`（pub(crate)）：采样每 16 个像素（800×600→30000 样本），
    HashMap<[u8;4], count> 算主色占比，>99.9% 判退化。O(n/16) 避免 13793 case 全帧扫描。
    空帧 / 无样本视为退化（保守）。

(B) oracle loop：results tuple 扩 oracle_near_solid 标志（第 5 元素）。

(C) 报告新增「DC-14 非平凡性检查」段：
    - 退化可疑 pass（oracle 帧近纯色 + z_vs_chr<loose）→ 排除
    - credible pass = oracle_pass − degenerate_pass（更诚实通过率）
    - 列出退化可疑 case（前 50）供单独审计

零行为变化（不改 pass/fail 判定，只增分类 + 排除报告）。
