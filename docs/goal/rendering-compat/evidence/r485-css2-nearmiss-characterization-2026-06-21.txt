## 2. 伪元素根因（463-case 单一根因，最大新发现）

### 2.1 实证（first-letter-punctuation-001）

测试: `div:first-letter { color: green; font-size: 36px; line-height: 2 }` 作用于 `)T)est`，规范要求首字母含前后标点 `)T)` 全绿。

像素实证（PIL）:
- ZeroWeb test render: **0 green pixels**（`color:green` 完全未应用）
- chromium oracle: 296 green pixels（`)T)` 绿）
- diff bbox (8,18,539,106) = 首字母区

**结论**: ZeroWeb 完全未实现 `::first-letter`。

### 2.2 代码根因

`crates/css-parser/src/parser.rs:303-347` 冒号选择器解析:
- **单冒号** `:name`（CSS2 语法 `:first-letter`/`:before`）→ `PseudoClassSelector::Simple(name)`（伪**类**）→ 无元素匹配该伪类状态 → **规则永不生效**。
- **双冒号** `::name`（CSS3 语法）→ `PseudoElementSelector::Standard(name)`（伪**元素**，parser.rs:307）→ 解析正确，但**无 layout/paint 伪元素盒生成代码** → 同样不生效。

grep 确认: `crates/` 生产代码中 `first-letter`/`first-line` **零命中**（仅测试文件）。

### 2.3 为何非单会话 clean win

- `:first-letter`/`:first-line` 渲染 = 首行起始的 styled inline run（含 Ps/Pe/Pi/Pf/Po 标点 inclusion），**与 IFC/inline-ownership 耦合**（master.md Phase-A deadlock R125/R198/R205；font-size:36px 改变几何，paint-only 不足，须 layout 介入）。
- `:before`/`:after`（generated-content, 58 case）= 独立生成盒（相对可解，非 IFC 死锁），但仍需「伪元素盒生成 + content 渲染」多子系统。
- **修复路径**（多会话）: ① parser 单冒号伪元素分类（:before/:after/:first-letter/:first-line → PseudoElement，~10 行）→ ② style-system 伪元素盒生成（对匹配元素合成子盒 + content/声明应用）→ ③ layout/paint 渲染生成盒 → ④ first-letter/first-line 的 IFC inline-run 集成（Phase-A 子集）。
- **单独①不改任何测试结果**（无渲染管线），按 code-guidelines #2 属投机性，不做 standalone。

## 3. 其他簇 clean-win 排除

- **text-indent (48)**: grep 确认**已完整实现**（`inline/mod.rs:1029/1165` first-line 偏移 + `text.rs:774/918` paint plumbing 全通）；48 case diff = 字体度量噪声，非缺口。
- **margin-bottom-004 像素实证**: diff = 垂直定位偏移（同 x 处 y=25 vs y=32 白/灰互换 = 内容下移 ~7px）+ (8,60) orange 测试标记 → margin 折叠精度 / body 默认 margin / line-height 度量，**结构性噪声非 clean win**。
- line-height/word-spacing/white-space = R471/R225/R463 已 ruled 字体/IFC 精度死路。
- tables-anonymous/positioning = R177/R98 已知结构性。

## 4. 结论

1. **新发现高价值多会话 lever = 伪元素渲染**（463 case 单一根因，CSS2 最大 coherent 缺口）。R484 CSS2 全量捕获首次暴露此簇（prior 子集未含）。多会话实现路径已定位（parser/style/layout-paint 四步，first-letter/first-line 子集耦合 Phase-A）。
2. **CSS2 near-miss 其余 ~1395 case 全结构性/度量噪声/已实现**，0 单会话 clean win（plateau 再确认）。
3. **CSS2 chr<1% 上拉真实路径** = 实现伪元素（+463 潜在 flip，理论 CSS2 44.1%→~51.7%）+ 度量精度攻坚（near-miss 1-2%→<1%，难，Phase-A）。
