============================================================
1. Phase 1 实现了什么（已回退，验证 attribute-mutation 正确）
============================================================

R521 Phase 1（reftest harness JS DOM-shim + reflow）实现：
- execute_scripts(html) -> Option<String>：parse html→Document；注册 __zw_set_attr 回调
  （记 Arc<Mutex<Vec<DomMutation>>>，因回调须 Send+Sync+'static 不能捕获 Document）；
  注入 DOM_SHIM_JS（document.querySelector/getElementById 返回 Proxy，其 set 陷阱调
  __zw_set_attr(sel,prop,val)；body/documentElement 返回占位 Proxy）；跑页面 JS；
  应用 mutations 到 Document（find_element_by_selector 按 #id/.class/tag）；serialize_node
  → 返回 mutated html。render_to_framebuffer_with_base 用 mutated html。
- 导出 zero_dom::serialize_node（dom/lib.rs `pub use serializer::*`）。

★ attribute-mutation 全链路 VERIFIED（REFTEST_JS_DEBUG 实测 img-src-changes）：
  - recorded 1 mutations: [SetAttr("img", "src", "grid-items/support/100x100-green.png")]
  - applied SetAttr(img,src) -> node NodeId(23v1)
  - serialized html 含 `<img src="grid-items/support/100x100-green.png">`（grep 确认）
  → shim + R522 register_callback + Document.set_attribute + serialize 全正确。

============================================================
2. 为什么 0-flip —— grid img-src 下游阻塞（非 Phase 1 缺陷）
============================================================

A/B（css-grid 31/48 不变 = 0 flip；box-display 60/120 不变 = 0 regression）：
grid img-src（~13 案，Phase 1 目标）全 0 flip，根因在 attribute-mutation 之**下游**：

(1) img-src-changes（文件引用）：缺 fixture `grid-items/support/100x100-green.png`
    （wpt-data 导入遗漏；无 grid-items/ 目录）。手工创建 100×100 green PNG（先 colortype 2
    RGB 被 reject → 重建 colortype 6 RGBA 匹配现有 fixture），**仍 images:0**——
    build_image_cache 不加载。extract_img_srcs 应能提取（mutated html 含 src），base_dir
    路径解析（css-grid/grid-items/support/）应命中已建文件。images:0 的真因待查：
    可能是 (a) base_dir 对嵌套路径解析失败，或 (b) img `width:100px;height:100%` 在
    auto-height grid 中得 0 高度→不渲染（grid layout 缺口），或 (c) build_image_cache
    load 静默失败。

(2) grid-with-dynamic-img（data URI SVG）：`src='data:image/svg+xml;utf8,<svg width="100"...>'`
    序列化时 data URI 内的 `"` 破坏属性引号（serialize_node 用 `"` 包属性值，未转义 `"`）；
    且 ZeroWeb image loader 是否解码 data: URI 未验证。双重阻塞。

★ 关键：Phase 1 的 attribute-mutation 正确，但 grid img-src 翻转依赖 **image loading
  from mutated html + grid img sizing + data-URI 解码**三处下游能力，均非 Phase 1 scope。

============================================================
3. 裁决：回退 Phase 1（0-flip，§2 不投机）
============================================================

Phase 1 attribute-mutation 正确但 0-flip（grid 下游阻塞）。按 code-guidelines §2
（不 land 0-flip 投机代码）+ 零回归标准，**回退 Phase 1**（reftest.rs execute_scripts
rewrite + render 改动 + dom/lib.rs serializer 导出 + 手建 PNG fixture 全移除）。

R522 Phase 0（V8Sandbox::register_callback）**保留**——它是 verified 的 V8 绑定基础，
独立单元测试通过，未来 Phase 1 重做（须先解 image-loading-from-mutated-html）可直接复用。
