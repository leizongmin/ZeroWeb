# table_grid_size_col_colspan chromium-diff 修复（R177b）

**日期**: 2026-06-18
**目的**: 落地 R177 实证后**延后**的 colspan/col-width 缺口（R177 仅定位机制未提交修复）。
**结果**: `table_grid_size_col_colspan` chromium-diff **52.27% → 1.70%**；上游 reftest 438/490 持平零回归。

## 背景

R177 实证 `table_grid_size_col_colspan`（同源 0% / chromium 52%）根因：`build_grid` 在 collapsed
border model 下完全跳过 `<col>` 列计数 + colspan 不钳制 + col width 从不读 + 空列裁剪缺失。
R177 定位了「5 耦合部件不可单点」，标 (b)(d) 为「需配套风险」延后。本轮实现这 5 个部件。

## 根因（R177 复核）

`crates/layout-engine/src/table.rs` 的 `build_grid` + `compute_column_widths`：

1. **(a) col 计数**：`build_grid` 只在 separated border model 下 `count_col_elements`，collapsed 模式
   下 `<col>` 完全跳过 → 列数只来自单元格 colspan。
2. **(b) colspan 钳制 / col-width-as-content**：`cell_used_width` 闭包对显式 width 单元格一律取
   `cell_box.width`（taffy block = 行/表全宽），collapsed 模式下未把 td 的 content-box width 换算成
   列宽（border 中心间距 = content + 水平 borders/2，CSS2 §17.6.2）。
3. **(c) col width 读取**：`compute_column_widths` Pass 0 只在 separated 模式读 `<col>`/`<colgroup>`
   显式 width，collapsed 模式丢弃。
4. **(d) 空列裁剪**：table-layout:fixed 时无单元格跨越的列应不参与渲染，但旧代码从不裁剪空列。
5. **(e) 扩展条件**：旧 `(has_explicit_width || is_fixed_layout)` 让 width:auto 的 fixed 表填满容器，
   违反 CSS Tables §17.5.2.1（fixed 布局表宽 = max(width 属性, 列宽之和)）。

## 修复（5 部件配套）

- **(a)** `build_grid` 对 separated + collapsed 均 `count_col_elements`（删 `if !is_collapsed_border` 守卫）。
- **(b)** `cell_used_width` 闭包：collapsed 模式下显式 width 单元格的列宽 = `explicit + (border_l + border_r)/2`。
- **(c)** `compute_column_widths` Pass 0 读 col/colgroup width 不再受 collapsed 守卫限制。
- **(d)** 新增 fixed 布局空列裁剪：`cols_with_cells` 标记被任意 cell 跨越的列，未被跨越的列宽置 0
  （auto 布局保留空列，固定布局裁剪；爆炸半径限于 colspan 类用例）。
- **(e)** 扩展条件从 `has_explicit_width || is_fixed_layout` 收紧为 `has_explicit_width`
  （fixed 空列裁剪保证 colspan 类用例 test==ref）。

## 验证（chromium 独立 Oracle A/B）

对 4 个 table 用例分别取 ZeroWeb-test PNG vs headless chromium 截图（chan_thresh=5）：

| 用例 | BASELINE(HEAD) | R177b(本轮) |
|------|---------------|------------|
| table_grid_size_col_colspan | **52.27%** | **1.70%** ✅ |
| table-cell-width-0 | 13.31% | 13.31%（不变） |
| table-colspan-percent-auto | 1.01% | 1.01%（不变） |
| visibility-collapse-colspan-003 | 4.91% | 4.91%（不变） |

- 上游 reftest 438/490 持平（零回归，唯一同源通过不变）。
- `cargo build` + `cargo clippy`（zero-layout-engine / zero-render-foundation）零警告。
- `table_grid_size_col_colspan` 剩余 1.70% 为 sub-pixel/border 精度残差，非本轮范围。

## 方法论

DC-14 anti-false-pass：同源 reftest 对「正确修复」天然零变化（test==ref），无法判定价值。
必须用 chromium 独立 Oracle 做 A/B（revert→dump→对比 vs with-change→dump→对比）才能确证
chromium-diff 改善。R177 当年仅实证机制未提交修复，故 52% 长期潜伏；本轮以 A/B 落地。
