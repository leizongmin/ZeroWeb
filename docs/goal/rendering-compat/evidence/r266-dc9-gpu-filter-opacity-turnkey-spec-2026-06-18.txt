# R266 — DC-9 GPU filter:opacity 交接级实现 spec（代码级，可直接执行）

**日期**: 2026-06-18
**模式**: read-only 实现设计（读 pipeline.rs + renderer/mod.rs + cpu/effects.rs 完整核实），无代码变更
**承接**: R265（确认本 WSL GPU reftest 可用）+ R249（post-process pipeline dead-coded 就绪）
**目的**: 把本轮对 DC-9 GPU filter:opacity 的完整 scoping 沉淀为**代码级交接 spec**，下一轮直接实现，无需重新调研

## 语义（与 CPU 对齐）

CPU `apply_filter`（cpu/effects.rs:133-150）对 `FilterKind::Opacity(amount)` 做**区域 RGB 乘**：对 `filter.rect` 内每像素 `RGB *= amount`（alpha 恒 255，framebuffer 无 alpha）。GPU 须匹配此**区域后处理**语义（非全屏）。

## 实现范围：headless-only，零默认回归

- **仅 headless 路径**（reftest `--gpu` / 测试用）实现；窗口 surface 路径不变。
- **无 filter 时不触发**（438 reftest CPU 模式完全不受影响；GPU 模式无 filter 的 case 不变）→ 零默认回归保证。
- 仅 `FilterKind::Opacity` 起步（DC-9 三缺口之一）；blur/transform/blend 后续同模式扩展。

## 代码级改动（3 处文件）

### 1. `crates/render-foundation/src/gpu/pipeline.rs`

**新增 OPACITY_SHADER**（紧随 BLUR_SHADER 之后，~line 360）。复用 vs_fullscreen（BLUR_SHADER 已有），新增 fs_opacity：

```wgsl
struct OpacityUniforms { screen_w: f32, screen_h: f32, amount: f32, _pad: f32 };
@group(0) @binding(0) var<uniform> u: OpacityUniforms;
@group(1) @binding(0) var src_tex: texture_2d<f32>;
@group(1) @binding(1) var src_samp: sampler;
// vs_fullscreen 复用 BLUR_SHADER 的（输出 position + uv）
@fragment
fn fs_opacity(in: VertexOutput) -> @location(0) vec4f {
    let c = textureSample(src_tex, src_samp, in.uv);
    return vec4f(c.r * u.amount, c.g * u.amount, c.b * u.amount, 1.0);
}
```
（注意：OPACITY_SHADER 须自带 vs_fullscreen + VertexOutput 定义，不依赖 BLUR_SHADER 的——WGSL 模块独立。或把 vs_fullscreen 抽到共享 shader。最简：OPACITY_SHADER 内含完整 vs_fullscreen+struct+fs_opacity。）

**新增 `create_opacity_pipeline(device, format, uniform_bgl, src_bgl)`**（mirror create_blur_pipeline:703，仅 entry_point 改 `"fs_opacity"`，shader 改 OPACITY_SHADER）。uniform_bgl = 现有（UNIFORM_SIZE=16，OpacityUniforms 4 f32=16 字节匹配）；src_bgl = `create_texture_bind_group_layout`（blur_bgl 复用）。

### 2. `crates/render-foundation/src/gpu/renderer/mod.rs`

**Renderer 结构新增字段**（~line 63 附近，仿 blur_pipeline）：
- `#[allow(dead_code)] opacity_pipeline: wgpu::RenderPipeline,`
- `headless_texture_b: Option<wgpu::Texture>,`（ping-pong 第二张纹理）

**`from_device`（~209）**：创建 opacity_pipeline（仿 blur_pipeline:222）；headless_texture_b 初始化 `None`（懒创建或随 headless_texture 同建）。

**`create_headless_texture`（1549）usage 加 COPY_DST**：
```rust
usage: RENDER_ATTACHMENT | COPY_SRC | TEXTURE_BINDING | COPY_DST,
```
（B→A copy 需要 A 的 COPY_DST；新增 capability，安全。）

**`render_full_scene_gpu`（651）末尾**（scene 渲染到 headless_texture A 之后，`target.present` 之前）插入：
```rust
#[cfg(...)] // 或运行时判 headless
if let Some(amounts) = collect_opacity_filters(&primitives.filters) {
    if self.headless_texture.is_some() {
        self.apply_opacity_filters_headless(width, height, &amounts, scale);
    }
}
```
**新方法 `apply_opacity_filters_headless`** —— 对每个 (rect, amount)：
1. 确保 headless_texture_b 存在（尺寸匹配，need COPY_SRC|RENDER_ATTACHMENT|TEXTURE_BINDING；懒创建）
2. 创建 uniform buffer [w, h, amount, 0] + bind group（src = headless_texture view，layout = blur_bgl）
3. encoder：
   - `copy_texture_to_texture` A→B（全屏，保 B=A 基底）
   - render pass：target=B view，load=Load（保留刚 copy 的 A 内容），scissor_rect=(rect*scale 钳到 [0,w/h])，set opacity_pipeline，bind uniform_bg + src_bg(A)，draw(3,1)（全屏三角，scissor 裁到 rect 内写 A*amount）
   - `copy_texture_to_texture` B→A（把结果写回 A，read_pixels 读 A）
4. submit

`collect_opacity_filters` 返回 `Vec<(Rect, f32)>`（filter.rect + amount），仅 Opacity 变体。

## 风险/注意

- **scissor 钳制**：filter.rect 可能越界（负/超 w/h），scissor_rect 须 clamp 到 [0,w]×[0,h]，否则 wgpu validation error。
- **COPY_DST 新增**：改 create_headless_texture usage 影响所有 headless 纹理（A 也加），纯增 capability 无副作用。
- **多 filter**：逐个 ping-pong（A→B→A→B...），最后一个 copy 到 A。每 filter 2 次 copy + 1 pass，O(n) 成本，filter 低频可接受。
- **read_pixels 读 A**：确保最终结果在 headless_texture（A），不是 B。
- **WGSL 独立性**：OPACITY_SHADER 须自含 vs_fullscreen+struct，不能跨 const 引用 BLUR_SHADER 的。

## 价值

DC-9 GPU 三缺口（transform/filter/blend）之一落地 = 硬门禁 DC-9 实质性进展（9/13→10/13 独立 WGSL 管线），非 passthrough 满足 DC-14。filter:opacity 是三缺口中最简（区域 RGB 乘，无卷积/无混合方程），blur/transform/blend 可同模式后续扩展。本 spec 代码级就绪，下一轮直接实现。
