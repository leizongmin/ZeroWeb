实现（env INLINE_BG_FRAGMENT=1，4 处改动，已 REVERT）
================================================================
1. text.rs render_fragment 宏（非多列路径）：
   - text_width 计算从 glyph loop 之后提前到之前（支持 bg 在 glyph 下绘制）。
   - gate `!is_vertical && INLINE_BG_FRAGMENT=1 && owner(display==Inline) bg!=Transparent`：
     按 frag 几何绘 inline bg fill Rect(frag_base_x, content_y+frag.y+ty, text_width, line_h)，
     line_h = box_node.text_node_line_heights.get(frag_nid) 缺省 fs*1.2。frag_base_x 已含
     text-indent（IFC 首行 current_x=self.text_indent），故首行自动从缩进后起。
2. mod.rs paint_node（步 1 背景色填充）：抑制 inline display 的 box-level paint_background
   （env 门控，防与 per-fragment 双重绘制）。
3. mod.rs paint_node_in_rect（增量路径）：同上抑制（一致性）。

================================================================
裁决：net-negative REVERTED
================================================================
+2 text-indent（CSS2/text）被 -2 normal-flow solid regression + 多个 inline 案 diff%
变差抵消，且 0 solid improvement。per-fragment inline bg 单 session 不可解。

根因（为何单 session 不可解）：
1. line-height 近似（fs*1.2 fallback 或 text_node_line_heights）+ frag 几何对一般 inline
   案不精确匹配 chromium——text-indent-wrap（默认 line-height，单 span）凑巧过，但
   inline-non-replaced-height / inline-table-zorder 等结构性 inline 案被扰动变差。
2. 多行 gating 时序死锁：box-level paint_background 必先于 paint_text 抑制（bg 在 text 下），
   但「该 inline 是否跨多行」由 paint_text 的 fragment 扫描计算——paint_node 抑制点在
   paint_text 之前，无 multi-line 信息。无 narrow 守卫可把改动限于多行 inline。
3. nested/empty inline 未处理：外层 inline 有 bg 内层无（per-fragment 按 frag owner 查 bg，
   内层 frag owner 无 bg→不绘，外层 box-level 又被抑制→外层 bg 丢失）；空 inline 无 frag→
   抑制后 bg 丢失。

================================================================
结论
================================================================
inline-bg = Phase A 结构性经本轮 A/B empirically 坐实（非仅 doc-side 推断）。真修复 =
Phase A 完整：(a) per-line-fragment inline bg/border；(b) 重构 paint_node/paint_text 时序
使 multi-line 状态先于 box-level bg 决策可得；(c) IFC inline/block box-model 统一
（ZW inline 映射 block in taffy，无 inline/block 区分）；(d) nested/empty inline 处理。
多 session 架构，非单 session。
