背景（承 R645）

================================================================
裁决
================================================================
测量路径 word_break/break_word **非 clean lever**（与 R645 no_wrap 不同）。根因：word_break
对 CJK 文本断行影响剧烈（keep-all 把 CJK 当不可拆单词 → 行更长 → 高度变；break-all 反向），
测量路径应用后改变 keep-all/break-all 容器的 box 高度，而**无 driving test** 依赖「break-all
容器测量高度修正」（paint 路径早正确设 word_break，渲染行数对；box 高度偏差不致可见失败）。
唯一影响是 keep-all-011 因测量高度变化而破。

**关键区分**（R645 vs R651）：
- R645 no_wrap：pre/nowrap 容器「测量时换行」是明确错误（pre 不应换行），修后有 driving test
  （line-breaking-024~027 SEA fallback 暴露）→ clean +7。
- R651 word_break：测量路径用 normal vs 真 word_break 的差异**无 driving test**（break-all 容器
  无可见失败依赖此），反而破 keep-all → net-negative。

即测量路径的属性遗漏**非均匀 clean**——no_wrap 是 clean（有 driving test），word_break 不是。
后续勿再以「测量路径遗漏属性 = R645 类 clean lever」笼统外推到其它属性（text_indent / tab_size /
font overrides 同理须先确认 driving test）。

零 landing（代码 git checkout 回退，工作树 clean = HEAD）。本探针价值 = 排除一个假设 +
刻画 R645 的 clean 边界（no_wrap 特例，非通用）。
