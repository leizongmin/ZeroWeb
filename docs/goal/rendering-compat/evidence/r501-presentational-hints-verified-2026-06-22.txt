2. ★ 关键新发现：既有 PARTIAL path（tree.rs:191，px-only，丢 %）
----------------------------------------------------------------
R500e 说「presentational 全仓库零命中→gap 未实现」**不完全精确**。实证发现
layout-engine 侧有一条 **partial** presentational-hints-ish 路径：

  crates/layout-engine/src/tree.rs:185-247  apply_replaced_element_sizing()
  ├── line 186: 仅 <img>（tag != "img" return）
  ├── line 191: attr_w = elem.get_attribute("width").and_then(|v| v.parse::<f32>().ok())
  ├── line 192: attr_h = elem.get_attribute("height").and_then(|v| v.parse::<f32>().ok())
  └── line 218-225: 当 computed.width/height == Auto 时，用 attr 作 taffy size

**两个致命限制**：
  (a) `v.parse::<f32>()` **仅解析纯数字 px**——`width="50%"` parse 失败→None
      →**静默丢弃**。这 EXACTLY 解释 absolute-replaced-width-006 失败：
      `<img width="50%">` 应解析为 50%×#div1(192px)=96px，ZW 丢% → 回落
      intrinsic 15×15（R500e LAYOUT_DUMP 实测值）。
  (b) **绕过 cascade**：layout-time fallback，不走 CSS cascade origin/
      specificity。无法表达 CSS2 App D「presentational hints = author origin,
      specificity (0,0,0)」（低于 inline style (1,0,0)，高于 UA）。

→ 修复缺口精确化：不是「total absence」，而是「percentage 解析 + cascade
   集成缺失」，px-only 路径已存在但语义不完整。

5. 调整方向结论（更新 master.md R501）
----------------------------------------------------------------
(A) presentational hints gap **真实且独立实证**（非 taffy-blocked，DC-2 feature）：
    reftest 杠杆 = positioning/ absolute-replaced-width-*/-height-*/-non-replaced-*
    簇 self-fail（11+ 文件用 width="50%"）+ 285 CSS2 文件广覆盖。
(B) 修复是 **localized style-system 插入**（seam = lib.rs:336，镜像 inline-style
    块，Origin::Author + specificity (0,0,0)），非新 DOM 管线。属性已可达
    （doc.get_attribute 已用于 style=/id/attr-selector）。
(C) **既有 partial path（tree.rs:191 px-only）须一并清理**：把 w/h 移入 cascade
    后，tree.rs:191-247 的 layout-time fallback 可简化为只处理 decoded intrinsic
    size；% 解析作为移入 cascade 的 side-effect 自动修复（cascade 中 % 已支持）。
(D) **与并行 code agent 正交无重叠**：并行 agent 当前在 engine.rs abspos root-CB
    fix（005/006，working tree +131 行未提交）；presentational hints 在
    style-system/src/lib.rs:336 + layout-engine/tree.rs:191，不同文件不同子系统。
    可排在 005/006 commit 后由 code agent 推进。
(E) caveat：285 文件 ≠ 285 fail（多数文件 CSS 显式覆盖属性，presentational
    hints specificity (0,0,0) 低于 author CSS，被覆盖时不生效=正确行为）；
    真 chr<1% yield 须逐案核（11 absolute-replaced-width-* %案是确定性 yield）。
(F) 非 fontdue 死路：absolute-replaced sizing 测试主体是彩色矩形几何（blue/
    orange 方块），fontdue 文本噪声占比低（仅 <p> "Test passes if..." 一行），
    与 R500d「最大 actionable 非 fontdue 单簇」判断一致。
