背景：为什么扫 2-5% band 而非 1-2%
================================================================================
R500b 量化了 positioning/ POLLUTED@1-2% = 139（fontdue 文本噪声钉 1% 线外，fontdue-releasable
但 fontdue 攻坚历史证伪为死路）。但 R500b 同时报 POLLUTED@2-5% = 28 + self-fail@2-5% = 43。
2-5% band 是「sweet spot」：纯度量噪声通常 <2%，2-5% 差更可能含**真实但小的 engine bug**
（一个公式项错，非整体结构错）。本调研扫该 band 找可修簇。

代码核查：ZeroWeb 实现现状（缺口精确定位）
================================================================================
1. converter 传 margin:auto 给 taffy 为 `LengthPercentageAuto::Auto`（converter/mod.rs:94-95），
   **不**对 abspos 解析 auto→0（test_computed_style_to_taffy_margin_auto @1284 确认传 Auto 原值）。
2. `resolve_auto_as_zero` 标志**仅用于浮动元素**（§10.3.5，converter/mod.rs:38/436），**不**用于 abspos。
3. grep 全仓库**无 §10.3.8 约束方程代码**（仅 types/mod.rs:90 + engine.rs:639/1729 注释提到
   「替换元素 auto 尺寸按固有尺寸解析」，指 size 非 constraint-equation）。
4. engine.rs abspos 后处理（adjust_absolute_pct_to_viewport / resolve_abspos_against_root_cb）
   的 `!is_replaced` 守卫**仅跳过 auto-inset size-stretch 块**（§10.3.18/§10.6.4 stretch，正确跳过），
   **不处理** §10.3.8 的 auto-margin→0 / static-position / 约束方程求解。

→ 缺口 = abspos 替换元素的 §10.3.8 约束方程未实现：auto margins 不解析→0，static-position
   （both insets auto 时 left=静态位置）未算，over-constrained 未按 §10.3.7 处理。
   与 R165（margin:auto 居中）/R98/R500 同谱系（converter-passes-but-taffy-ignores for abspos），
   = **ZeroWeb-side 非 taffy-blocked**（post-extract 可补）。

机制推断（小 diff 归因）：width 大体正确（固有/百分比解析对，故非 gross failure），系统偏差在
**位置**——auto margins 未解析→0 致 img 偏移 margin 量，或 static-position 偏移。每子簇 z 值
离散规整 = 几个固定的 margin/static-position offset 量。

================================================================================
单会话可修性评估
================================================================================
- §10.3.7/§10.3.8/§10.6 abspos-sizing 约束方程是**多步算法**（auto margins→0 / static-position /
  over-constrained / min-max），全实现非平凡（中-多会话）。
- **最易入口 = auto-margin→0 解析**（mirror R165 margin:auto centering 谱系，converter 或 post-extract
  对 abspos 替换元素 margin-left/right:auto 当 left/right 任一 auto 时解析为 0，§10.3.8 step 3），
  单点可修，或翻一子簇。
- static-position（both insets auto → left=静态位置）是难点（grep 无生产代码），但 taffy 默认
  abspos placement 或已接近（小 diff 印证），未必阻塞。
- 推荐 code agent 排在 005/006（root-CB，in-flight）之后作为下一 lever。
