**揭示 self-source PASS 是假通过**：
  - chromium 渲染 content-counter-001.xht：**2.869% dark px**（约 13771 px，可见内容）
  - ZeroWeb 渲染：空白（0 dark）
  - → ZeroWeb 与 chromium 不一致 = DC-14 假通过（test/ref 同源空白偶然匹配）

测试内容：`#test span:before { content: counter(c, none) "z"; }` × 12 span。
  chromium：`counter(c, none)` = ""（none list-style 不显示计数器值），拼 "z" = "z"，
    12 span → "zzzzzzzzzzzz"（可见）。
  ZeroWeb：渲染空白 → `content: counter() "字符串"` 拼接**未被渲染**。

根因定位（read-only 代码核查，crates/engine/src/paint/painter/text.rs:509-526 paint_content）：
  ContentComputedValue 是**单值枚举**（String | Counter | ...），paint_content 只渲染
  单一 Counter 或 String。`content: counter(c, none) "z"`（Counter + String 拼接）
  走不到正确渲染路径（解析侧多 token content 或 paint 侧拼接缺失）。另 counter_style
  match（line 518-523）`none` 走 `_` 分支→decimal（非空串），故「渲染空白」更可能是
  解析侧 `counter() "z"` 多 token 整体失败 → Normal → 空。
