R872 — CSS §10.1/§9.3.2 abspos 根元素 left/top inset 应用（taffy 根节点 position:absolute 不解析）
==============================================================================
日期：2026-06-30
谱系：R871（根元素固定 margin）的 abspos 对应物。R871 后续 abspos worst 复查，
abspos-containing-block-initial-009b（5.92%）+ 004a-d（1.75%×4）= 5 案簇。

根因（LAYOUT_DUMP 实证）
------------------------
CSS §10.1：根元素 position:absolute/fixed（无 positioned 祖先）的包含块是初始包含块
（视口），其 left/top Length inset 定位 border-box。taffy 把根节点固定在 layout.location
(0,0) 且**不解析根的 position:absolute**（根无父级提供 abspos CB 上下文，adjust_absolute_*
递归只处理子节点不处理根本身）。

复刻 009b（`<html style="position:absolute;left:50px;top:50px;width:50%;height:50%;
border:10px solid black">`）：ZW html abs_y=0 x=0 ✗（应 50,50）。
004a-d（`<html style="position:absolute;left:100px;top:100px;width:100px;height:100px...">`）：
ZW html 落 (0,0) ✗（应 100,100）。

实现
----
crates/layout-engine/src/engine.rs compute() 根 relative inset 处理（R324）之后，新增根
abspos/fixed inset 应用：仅水平书写模式，当 root_box.is_absolute || root_box.is_fixed，
读根 style.left/top（仅 Px；Em/Percent 保守跳过），赋值 root_box.x = left_px /
root_box.y = top_px（abspos inset 是绝对定位，赋值而非累加；margin 在 abspos 根罕见且
此簇无 margin 故不与 R871 margin 偏移叠加）。
