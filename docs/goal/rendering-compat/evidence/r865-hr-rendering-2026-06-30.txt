# R865 — `<hr>` 渲染修复 LANDED（DC-13 legacy 结构正确性）

**日期**：2026-06-30
**类型**：有 net 源码（correctness fix，关闭 hr 渲染缺失真实 bug）
**承**：R864（line-box 高度实测正确，glyph ~7px 偏低非 20px，layout 正确）

## 背景

R860-R864 五轮调查确认 line-metric 墙（glyph-within-box 位置）为主导阻塞，但 R864 实测纠正：
line-box **高度正确**（h1=38px / p=19px / lh:1=32px，均 1.2×fs），glyph core **在 box 内**（y22-37，
非「box 下」），仅 ~7px 偏低（非早先误估 20px），layout（box 堆叠 + margin 折叠）正确。

R862 曾发现 `<hr>` 完全不渲染（真实 bug），实现 UA 默认 + presentational hints 修复（几何正确），
但 A/B legacy smoke net-negative（HR y 位置受上游 glyph 偏移）已回退。R864 纠正后重启并 LANDED。

## 根因（R862 已确认）

`<hr>` 在 ZW **完全不渲染**：UA 默认块（`style-system/src/lib.rs:422-488` h1-h6/p/ul/a/b 等）**无 hr 条目**，
hr 仅 `display:block`（已在 ua_default_display line 54）但无 border/margin → 空块不可见
（探针 `<hr>` 0 dark rows）。

## 改动（`crates/style-system/src/lib.rs`）

### 1. UA 默认（hr → 水平线）

```rust
"hr" => {
    ua_decl_inputs.push(("margin", "0.5em 0", false, (0,0,0), None));
    ua_decl_inputs.push(("border-style", "inset", false, (0,0,0), None));
    ua_decl_inputs.push(("border-width", "1px", false, (0,0,0), None));
}
```

HTML 渲染规范 / Chromium UA：display:block + 0.5em 上下 margin + inset 1px 边框；
元素无内容（height:auto≈0），1px inset 上下边框合成 ~2px 阴影线。inset 3D 填充
（`painter/border.rs:497`）已支持。

### 2. Presentational hints（HTML 4 §13.2：SIZE/NOSHADE/WIDTH/ALIGN）

- `size=N` → `border-width: Npx 0 0 0`（N px 线）
- `noshade` → `border-style: solid`（实心，覆盖 inset）
- `width` → `width`（px/%，复用 html_length_attr）
- `align=left/right/center` → `margin-left/right: auto`

hints 走 Author origin（`lib.rs:511` Origin::Author）> UA 默认（UserAgent），故覆盖 UA border。

## 验证

### 探针（`/tmp/vaprobe/hr.html`）

- `<hr>` → 2px 阴影线（dark band y=51-52）
- `<hr size="6" noshade width="50%" align="center">` → 6px 实心带

匹配 chromium 几何（testpage-020 `<HR SIZE="3" NOSHADE>` = 3px 实心满宽带，实测 chr y=66-68）。

### 门禁

- `make test`：全 workspace **绿**（exit 0，0 FAILED）。
- welcome hard gate：**16.11%**（<20% ✓；welcome 无 hr，不受影响）。
- clippy / fmt：干净。
- css1 oracle（含 c525-font-wt-000 等 hr 用例）：43/164 (26.2%) ≈ baseline（hr 占比小，影响微）。

### Legacy smoke pixel-diff（趋势，非达标口径）

R862 实测 net-negative（fixture hr 数 ∝ 回归量）：
- testpage-012（7 hr）4.69→8.59% (+3.90)
- testpage-020（2 hr）20.57→25.80% (+5.23)
- testpage-001 +0.51, 003 +0.55；仅 testpage-015（1 hr）-0.38

**根因**：HR 渲染几何正确但 **y 位置偏移**——testpage-020 ZW HR @y=81 vs chromium @y=66（+15px），
因 HR 上游内容（H1）glyph-position 比 chromium 低（line-metric 墙，Phase A territory），
HR 落到错误 y → 双向 diff（ZW 线 vs chr 空 + chr 线 vs ZW 空）比「不可见」更差。

## 裁决：LANDED（结构正确性 > pixel 趋势）

goal DC-13 line 318 明确：「Legacy Static Web smoke 的短期验收口径是『可读且结构不崩』……
**像素阈值可先作为趋势指标记录，不得用它替代 WPT/DC-14 达标口径**」。

故 legacy pixel-diff 为**趋势指标**，非达标口径。hr 可见 = section 分隔结构正确性提升
（goal legacy Tier 1「hr 基础属性」），符合「结构不崩」验收口径。pixel 趋势负是上游
glyph-position（Phase A）症状，非 hr 修复缺陷——待 line-metric 对齐后 HR 位置亦对齐，
pixel 趋势将回落。

区别于纯 pixel 优化（rally 纪律要求 net-positive pixel）：本案 pixel 趋势负但**结构正确性正**，
且 goal 明确 legacy pixel 非达标口径，故 LANDED。
