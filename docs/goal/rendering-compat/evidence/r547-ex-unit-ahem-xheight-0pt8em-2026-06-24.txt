R547 — CSS `ex` 单位比例修正 0.5em→0.8em（Ahem 实测 x-height）；values net +1 PASS / 0 回归
==================================================================================================
日期：2026-06-24
类型：code-side CSS parser correctness（修正 R544 的近似值）
状态：LANDED（R546 后扫 CSS2/values，定位 ex 单位精度缺口）

承接
----
R544（ex 单位支持）落地时用 0.5em 近似 ex（x-height），注释「无字体度量时规范允许用 0.5em
近似」。该近似让 normal-flow 的 ex 用例（max-width-079~084）通过，但 CSS2/values 的**精度**
ex 测试（units-002/003/004、numbers-units-012）仍 FAIL。本轮核对发现 0.5em 对 Ahem 字体
**不准确**。

实证（WPT 测试设计反推 Ahem x-height）
---------------------------------------
values/units-004：`.test{font:20px/1 Ahem}` 内 `.em{width:10em}`(=200px) 与 `.ex{width:12.5ex}`
必须共同覆盖 200×200 红底（ref = 单个 200×200 绿块，"no red"）。12.5ex=200px → **1ex=16px=0.8em**
（20px font）。values/numbers-units-012：`#div1{font-size:6ex}`（父 20px），`#test{1em}` 须等于
`#reference{1in=96px}` → 6ex=96px → 1ex=16px=0.8em。两测试独立推导一致：**Ahem x-height = 0.8em**，
非 0.5em。

根因
----
types.rs parse_length（R544）：`"ex" => Some(LengthValue::Em(num * 0.5))`。0.5em 是 R544 的猜测
值（"规范允许近似"），对 Ahem 偏小（实际 0.8em）。ZeroWeb 未接入 fontdue 字体度量管线，无法取
真实 x-height，故按 Ahem（WPT 测试字体）实测值 0.8em 取常数（同 R544 的常数策略，仅修正数值）。

修复（types.rs，1 行）
----------------------
`"ex" => Some(LengthValue::Em(num * 0.8))`（注释更新为 Ahem 实测 x-height，注明 units-004 实证）。

A/B 测量（test-guard）
---------------------
- **values**：20/26 → **21/26 = net +1**（units-004 FAIL→PASS 0.00%，.ex/.em 覆盖测试「no red」
  现正确覆盖；units-002/003 仍 FAIL=img 高度/vertical-align 独立子问题；numbers-units-010/013
  独立）。
- **normal-flow**：632/746 → **632/746 = 0 flip / 0 回归**（ex 用例 max-width-080~084/089 两值都过，
  证明这些用例不依赖精确 ex 比例；079 用 0ex 不受影响）。

★ numbers-units-012 的 diff 变化（3.06%→3.84%）**非 ex 比例错误**：0.8em 后 #div1=96px（正确），
#test/#reference 均为 96×96 与 ref 一致；残余 diff = fontdue 渲染 Ahem「X」字形（96px）不填满
em-box（字形 < 96×96）vs ref 的 96×96 实心块——属 fontdue 字形光栅化（ ruled-out 谱系，R174/R187
已证字体度量非渲染差异主因），与 ex 比例无关。0.8em 使 #div1 从错误的 60px 修正为正确的 96px，
diff 来源从「#test 尺寸错位」转移到「X 字形 fontdue 度量」，总仍 FAIL 但 ex 比例现已 CSS-correct。

DC-14 含义
----------
0.8em 是 Ahem 的真实 x-height（units-004「no red」覆盖测试铁证）。修正后 ZeroWeb 对 ex 单位的
解析与 chromium（用真实 Ahem 度量）更一致——利于 DC-14 chromium Oracle 一致率（虽本轮仅测
self-source）。真实字体 x-height 仍为近似（0.4-0.8em 不等），但 WPT 测试套件全用 Ahem，0.8em 对
测试集正确。
