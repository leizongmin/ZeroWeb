2. 关键消歧：通用 abspos 拉伸 WORKS，此为 form-control-specific（非通用 bug）
────────────────────────────────────────────────────────────────────
R164 教训应用：先消歧「是通用 abspos-stretch 路径坏（高杠杆但大爆炸半径）还是 form-control-specific
（contained）」。cross-validate 同目录 css-position 实证：
  position-absolute-large-negative-inset           | self-pass | 0.00% | 0.00%  ✅
  position-absolute-under-non-containing-stacking  | self-pass | 0.00% | 0.00%  ✅
  hypothetical-box-scroll-parent / -viewport        | self-pass | ~0.1% | ~0.1%  ✅
  position-change                                   | self-pass | 0.00% | 0.00%  ✅
⇒ **通用 abspos inset 解析 + 拉伸（含 box-sizing:border-box、大负 inset、positioned-CB）全 WORKS**。
  失败仅限半替换（input/button/form control）元素 → **form-control-specific contained 缺口**，
  爆炸半径小（只动 form control sizing，不碰通用 abspos 路径）。

────────────────────────────────────────────────────────────────────
3. 测试语义（position-absolute-semi-replaced-stretch-input.html）
────────────────────────────────────────────────────────────────────
CB：`.cb{position:relative; border:3px solid black; height:100px; width:150px(或350px wide);
display:inline-block}`。
.abs input：`position:absolute; box-sizing:border-box; top/right/bottom/left:3px; width:auto;
height:auto; outline:2px solid lime`。元素=<input type=button/submit/reset/color/text/password/
date/file/range>（#6 input）、<button>（#3 button）、其他半替换（#10 other）。
REF 显式拉伸佐证：`.abs{top/left:3px; width:calc(100%-6px); height:calc(100%-6px)}`。
⇒ 规范断言：**半替换元素 abspos + 两轴显式 inset + auto size → 应拉伸填满 CB-insets**（同非替换
abspos §10.3.7/§10.6.4 stretch 规则，csswg-drafts #6789）。

────────────────────────────────────────────────────────────────────
4. 精确机制（实证）
────────────────────────────────────────────────────────────────────
(a) crates/layout-engine/src/tree.rs:165 `apply_replaced_element_sizing` 读 `img_intrinsic_sizes`
    （HashMap<NodeId>，仅 <img>），line 186 `if tag != "img" { return; }` → **所有 form control
    零替换 sizing**。
(b) style-system/css-parser 全仓无 form control UA 默认尺寸（grep 仅命中 `appearance` 值解析
    parse_extended_visual.rs:232-243，无 width/height UA 默认）→ input 既非替换、又无 UA 默认尺寸。
(c) 后果：abspos form control 走非替换通用路径本应拉伸（§10.3.7），但实际未拉伸到 calc(100%-6px)
    → Oracle 23%。最可能机制：input 在 taffy 中是无内容/无固有尺寸的 leaf，taffy abspos 对其
    width:auto+两 inset 未填满（给 0 或 content-based）；或 ZeroWeb 把 input `value` 当文本渲染
    致 content-based shrink 而非 stretch。
(d) 修复面 contained：
    - 路线 A（最小）：在 abspos sizing 后处理（engine.rs abspos 路径，positioned-CB 分支）显式对
      form control 施加 §10.3.7/§10.6.4 拉伸（两轴显式 inset + auto size → 填满 CB-insets）。
    - 路线 B（更规范）：给 form control 加 UA 默认尺寸 + 把 input/button 列为半替换（扩展
      apply_replaced_element_sizing 或新增 form-control sizing），让通用 abspos 拉伸自然覆盖。
    - 推荐先 A（surgical，验证 family 3 例翻转），再评估 B（覆盖面更广但需 UA 尺寸表）。
