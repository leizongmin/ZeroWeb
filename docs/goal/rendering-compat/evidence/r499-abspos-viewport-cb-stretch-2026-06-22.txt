## 1. doc agent R499b 机制实证确认（img 确被 stretch）

R499b 静态/code-level 推断：未守卫分支对 025/026 的 `<img>`（replaced，无显式 width → `style.width==Auto`，intrinsic 尺寸只写 taffy Style 不写 ComputedStyle）命中 `matches!(Auto)` → 覆写 intrinsic 为视口 stretch。

**本轮 LAYOUT_DUMP 实证（未守卫版本）abspos-025**：
```
test img: abs_y=64.0 h=536.0 x=64.0 w=736.0   ← 被 stretch（应 intrinsic 15×15）
ref  img: abs_y=60.0 h=15.0  x=64.0 w=15.0    ← intrinsic
```
**doc agent 机制分析正确**：分支确把 img 从 intrinsic（15×15）stretch 到视口（736×536）。

**但 reftest 像素结果 025/026 仍 PASS（0.07%/0.03%）**——因为 reftest harness **未加载 PNG**（swatch-green/red.png），img 无论 box 多大都不渲染像素 → test/ref 均空 → 匹配。故「像素回归」被 image-not-loading **掩盖**（非不存在）。**几何正确性违规真实存在**（§10.3.8 replaced abspos 应用 intrinsic 非 stretch），须修。

## 2. 实现（engine.rs +30 / types/mod.rs +7，is_replaced 守卫）

**① 新增 `LayoutBox.is_replaced` 字段**（types/mod.rs）：标记替换元素（有固有尺寸）。在 `extract_layout`（有 doc 访问）按 tag 名设置：
```rust
let is_replaced = dom_id.is_some_and(|id| {
    doc.get(id).is_some_and(|n| match &n.kind {
        zero_dom::NodeKind::Element(elem) => matches!(
            elem.local_name(),
            "img" | "video" | "iframe" | "embed" | "object" | "svg" | "canvas"
        ),
        _ => false,
    })
});
```
（Default `is_replaced: false`。镜像 is_absolute/is_fixed 模式。）

**② absolute auto-inset stretch 分支 + is_replaced 守卫**（engine.rs `adjust_absolute_pct_to_viewport` 的 `is_absolute && !child_has_positioned_ancestor` 分支，Percentage size 块后）：
```rust
if matches!(style.width, LengthValue::Auto)
    && !child.is_replaced
    && let (LengthValue::Px(left), LengthValue::Px(right)) = (&style.left, &style.right)
{
    child.width = (viewport_width - (*left as f32) - (*right as f32)).max(0.0);
}
// (height 同理)
```
分支守卫 = `is_absolute && !has_positioned_ancestor && !is_replaced && width==Auto && left,right 全 Px`。

**安全设计**：①仅双 Px inset + Auto 才 stretch（spec「双 inset specified」§10.3.18/§10.6.4，非历史「无条件扩张」）；②`!is_replaced` 排除替换元素（§10.3.8 replaced 用 intrinsic）；③不动 x/y（位置已由下方 Px left/top 块设好，R98 谱系，避 R493 旧 x/y 回归）。
