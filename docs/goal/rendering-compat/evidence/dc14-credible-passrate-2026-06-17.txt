# DC-14 可信通过率分析（chromium Oracle 视角）

**日期**: 2026-06-17
**数据源**: `cross-validate-full-2026-06-17.txt`（ZeroWeb REFTEST_DUMP 全量 × chromium-oracle-shot.mjs 全量）
**覆盖**: 475 case（含 oracle 截图；R165–R180 修复后的状态）
**口径**: 以 **z_vs_chr**（ZeroWeb-test vs chromium-test 像素差异）为唯一可信指标，取代同源 z_vs_ref

## 核心结论

chromium 一致率（DC-14 唯一达标判定依据）按容差分布：

| z_vs_chr 容差 | case 数 | 占比 | 性质 |
|---------------|---------|------|------|
| < 0.5% | 97 | 20.4% | 真正像素级一致 |
| < 1.0%（严格真通过） | 188 | 39.6% | DC-14 严格容差真通过 |
| 1–3% | 183 | 38.5% | **字体/亚像素/布局定位噪声**（系统性，最大杠杆） |
| 3–8% | 67 | 14.1% | 中等布局差距 |
| ≥ 8% | 37 | 7.8% | 真 bug / 大差距（结构性聚类） |

**严格真通过率 = 188/475 = 39.6%**（DC-14 口径）。对比同源 439/490 = 89.6%——同源数字 **严重高估**真实一致性。

## 关键发现：同源 reference 双向不可靠

- **假通过（self-pass 但 chr≥5%）**：经核验，06-17 数据中 self-pass 用例的 z_vs_chr 普遍 <5%（R165–R180 已修大头假通过：table-colspan 52%、backdrop-inherit 47%、baseline-overflow 45%、html-display-table 33% 均已降至低位）。
- **假失败（self-fail 但 chr<5%）= 116 case**：ZeroWeb-test **实际接近 chromium**，但 ZeroWeb 自渲染的 ref 怪异（如 vrl-004 同源 7.09% vs chr 5.08%——REF 比 chromium 更怪，R164 已证）→ 同源判 FAIL 是**reference 的错，非 ZeroWeb 渲染错误**。这 116 case 在同源 439/90 之外被错误计为失败。

→ **同源 reference 既产生假通过又产生假失败**，DC-14 独立 chromium Oracle 是唯一可信达标判定依据。

## 策略重定向（基于分布）

1. **最大杠杆 = 183 case 的 1-3% 噪声**。AA 基准（`aa-baseline-2026-06-17.txt`）已证 fontdue 光栅化 ≈ chromium（W 0.1% / i 3.0%），故此噪声**非字体光栅化**，而是**布局定位**（文本/元素放置位置略偏）——根因 = layout IFC 用 `estimate_char_width`（0.55×fs）近似而非真实 advance width（R195/R196 定性，self-source 中性故不影响同源 439，但降此噪声可直接推升真通过率）。降低系统性布局噪声是把 188→370+ 真通过的最短路径。
2. **37 case ≥8%** = 结构性聚类（multicol 碎片化 / writing-mode 轴 / flex baseline / large-font IFC），多轮架构，clean-win 已穷尽。
3. **67 case 3-8%** = 中等布局差距，逐个甄别（部分可修，部分结构性）。

## 对 DONE 判定的影响

- DC-2~5「≥95%」当前**远未达标**（严格真通过 39.6%）。同源 89.6% 不构成达标证据（DC-14）。
- 达标路径 = 降系统性布局噪声（advance-width/line-breaking 精度，多轮）+ 修结构性聚类（多轮）。单会话 clean-win 已穷尽。
- DC-14「分母全量 + 严格容差 + 独立 Oracle」三项前置中，**独立 Oracle 基建已就绪**（chromium-oracle-shot.mjs + cross-validate.py），严格容差已用（≤1%），分母待补全上游全量（当前 475/490 子集）。

## 复现命令

```bash
# 1. ZeroWeb 渲染全量 test/ref 到 dump
REFTEST_DUMP=1 REFTEST_DUMP_PASS=1 ./target/test-guard -- cargo run --bin zero-wpt-runner -- reftest-upstream
# 2. chromium 渲染 test 截图
node tests/wpt-runner/scripts/chromium-oracle-shot.mjs --all --out /tmp/oracle-shots
# 3. 交叉验证（产出 z_vs_ref / z_vs_chr 两列 + 判定）
python3 tests/wpt-runner/scripts/cross-validate.py --dump target/reftest-dump --oracle /tmp/oracle-shots
# 4. 本分析（按 z_vs_chr 分布统计）
```
