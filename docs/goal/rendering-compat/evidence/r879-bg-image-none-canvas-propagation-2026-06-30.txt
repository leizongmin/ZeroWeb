R879 — background-image:none 不阻断 body 背景传播到画布（CSS §14.2）
=====================================================================
日期: 2026-06-30
谱系: R878 canvas 传播修复的延续；R720/R721 doc-side 定位 cluster 的 code-side 实现。
有 net 源码: ✅ painter/mod.rs canvas 传播 2 处检查 + helper + 1 单测。

测试（cluster, R720/R721 doc 定位）
-----------------------------------
css/CSS2/backgrounds/background-root-{005,008,009,012a,012b}.xht:
  body { background: green; ... }
  html { background: transparent; ... }   ← 显式 transparent
  * { margin: 1em; padding: 1em; }
  期望（CSS §14.2）：html 透明 → body 的 green 传播到画布（整视口绿）。

根因（R879 实证，纠正 R721「shorthand 产出非 Transparent 变体」假设）
----------------------------------------------------------------------
真实根因**不是** background:transparent 颜色解析（实测 html_style.bg =
Some(Transparent) ✓ 正确），而是 **canvas 传播的「有图片」判定**：

  background-image: none
    → parse_background_image_layers("none") = Some(vec![None])   ← 长度 1！
    → style.background_image = vec![BackgroundImageComputedValue::None]  (非空)

painter/mod.rs::paint canvas 传播块原用 `!hs.background_image.is_empty()`
判「html 有图片背景」→ vec![None] 非空 → 判 TRUE → 取 html 分支 → html
color 透明（add_fill 被守卫跳过）+ image 全 None（paint_bg_image_in_origin
跳过）→ **canvas 不填，body green 永不传播** → 整画布白（实测 ZW canvas
465166px 白 vs 应全绿）。

修复
----
painter/mod.rs canvas 传播块 2 处检查（html_has_bg + prop_style 守卫）：
  `!hs.background_image.is_empty()`  →  `has_paintable_bg_image(&hs.background_image)`
新增 free helper has_paintable_bg_image：layers 含至少一个非 None（Url/Gradient）
图层才为 true。`vec![None]` → false（background-image:none 不算有图片）。
paint_bg_image_in_origin 本就正确跳过 None 图层，故仅决策两处需改。
