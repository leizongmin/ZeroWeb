================================================================
零回归主张核实
================================================================
R244 称「零行为变更（CSS alpha 默认 1.0）」。核实：当前所有 CSS 颜色默认 alpha=255=1.0；
改成 in.color.a * coverage 后，opaque 颜色（a=1.0）渲染 = 1.0*coverage = coverage（与现状
vec4f(in.color, coverage) 完全一致）→ opaque 零变化。仅半透明 CSS 颜色（a<1.0）会从「错误
实色」变为「正确半透明」= 修复非回归（R228b CPU 侧 translucent rounded-rect alpha 的 GPU 同源
修复）。故「零回归」= opaque 零变化 + 半透明修正，主张成立。
