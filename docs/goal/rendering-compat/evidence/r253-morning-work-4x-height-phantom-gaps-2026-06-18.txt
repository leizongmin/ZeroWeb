# morning-work 4× 高度 + 元素间幻影垂直间隙（R253）

**日期**: 2026-06-18
**目标**: DC-13 morning-work 67%（实测 89.14%）diff 真根因定位
**结果**: 定位为**布局层幻影垂直间隙**（非 paint 缺失、非字体度量噪声）。元素间多出
~280-328px 间隙致页面高度 **4×**（ZW 25301 vs CHR 5981）。下一轮隔离根因后修复。

## 实证（product-smoke + LAYOUT_DUMP + region 分析）

承接 R252（pre/pre-wrap paint 多行正确，零回归，但 chr diff 改善有限→重新诊断）。本轮
tall-viewport（800×12000）product-smoke + chromium fullPage 对比：

- **ZW 内容延伸至 y=11897，CHR 止于 y=5896** → ZeroWeb 页面 **~2× 高**（实测 ZW body
  h=25301 vs CHR 5981，**4.2×**）。
- region 分析（500px 桶）：matched-height（5917）对比时 ZW body 区域 content 仅 0-15%，
  CHR 50-62% → **非字体度量噪声**（那样会 ~20%），是 **内容纵向被推开**（ZW 内容下移）。
- chromium fullPage 截图：y=1500-2500 是「步骤 2-4 + 代码块 + 说明文」；ZeroWeb 同区域是
  「问题分析」标题 + 大片空白 → 内容相对位置整体下移。

## 根因（LAYOUT_DUMP 逐元素 y 序列）

article 子元素序列（abs_y / h / mt）：

```
h2  abs_y= 521.2 h=30  mt=52
p   abs_y= 879.2 h=85  mt=16      ← 间隙 = 879-(521+30) = 328px（应 ≈16+collapse）
p   abs_y=1236.2 h=56  mt=16      ← 间隙 = 1236-(879+85) = 272px
h2  abs_y=1620.2 h=30  mt=52      ← 间隙 = 1620-(1236+56) = 328px
h3  abs_y=1978.2 h=28  mt=16      ← 间隙 = 1978-(1620+30) = 328px
p   abs_y=2334.2 h=28  mt=16      ← 间隙 = 2334-(1978+28) = 328px
```

**元素间存在 ~272-328px 的幻影垂直间隙**，远超声明的 mt（16/52）。每个 gap 把后续元素
下推 ~300px，累积致 4× 高度。mt 字段（dmt）正确（16/52），故非 margin 值错误——是**元素
之间被插入了额外高度**（疑似空匿名块 / 未折叠的双向 margin / 多余 line-box / IFC 残行）。

另有**幻影嵌套 article**：`article.article abs_y=257.2 h=200.0 w=4.0`（与真 article 同 abs_y
但 w=4、独立 h=200），疑似 anonymous box / display 异常。

## 与既往诊断的关系（纠正）

- **非 R228b「内容纵向压缩」**：R228b 推断 img 固有尺寸塌缩 / pre min-width 溢出致内容堆顶。
  实测 ZW 是**相反**——内容被**推开**（4× 高，非压缩）。R228b 的 67% 在 1200×1600 viewport
  截到的「y=300-525 空白」= 幻影间隙在固定 viewport 下的表现。
- **非 R247/R252 pre 多行堆叠**：pre 块 abs_y=6328+（ZW 4× 高后），geometry 正确（R252 已修）。
- **非字体度量噪声**（R174/R225）：region diff 93% / content 4× 差异，非 ~20% AA 噪声量级。
