★ 决定性结论：auto-margin→0 假设 REFUTED（4 代表案全不支持）
================================================================================
对 4 个代表案（覆盖 3 个 z 簇 + 006 簇两子组）LAYOUT_DUMP 实测：

  case   | 元素        | ZW test (x, w×h)     | ref (x, w×h)         | 失败维度
  -------|-------------|----------------------|----------------------|--------------------------
  006    | img w="50%" | x=8,  w=15×15        | x=8,  w=96×96        | ★ SIZE（宽高）x 对
  022    | img 96×96   | x=104, w=96×96       | x=104, w=96×96       | ★ 垂直 abs_y（150 vs 70）
  002    | svg h="50"  | x=8,  w=288×h=0      | x=8,  w=200×h=50     | ★ SIZE（宽高）x 对
  004    | svg (无尺寸)| x=8,  w=288×h=0      | x=8,  w=200×h=100    | ★ SIZE（宽高）x 对

★ 全部 4 案：**水平位置 x 全部 CORRECT**（test==ref）。无一案在水平 auto-margin→0 维度失败。
  → R500d「系统偏差在位置 / auto-margin 偏移」假设 **REFUTED**。
  → 「auto-margin→0 mirror R165」入口对这 4 案 **yield ≈ 0**。

失败维度实际是 **SIZE（宽高）** 或 **垂直位置**，机制按元素类型/属性 HETEROGENEOUS：

--------------------------------------------------------------------------------
(1) 006 簇 2.24%（15 案，全 <img>）= 两子组，均非 §10.3.8 auto-margin
--------------------------------------------------------------------------------
  子组 A（9 案：006/013/027/041/048/055/062/069/076）：`<img width="50%">` HTML 表现属性
    → ZW 渲染 w=15（intrinsic blue15x15.png），应 96（50% × #div1 192px）。
    → 根因 = **HTML presentational width 属性未映射 CSS**（grep presentational 零命中，证 R494 §1
       presentational-hints gap 未实现）。img 无 CSS width，回落 intrinsic。
    → 非 §10.3.8；修 = 实现 presentational hints（DC-2 feature，R494 §1 已标「低杠杆」因
       仅查 bgcolor=，但 <img width=> 远多于 bgcolor，须重核 reftest 杠杆）。
  子组 B（6 案：022/029/036/043/050/057/064）：`<img src=blue96x96.png>` 无 width 属性
    → ZW 渲染 w=96×96（intrinsic 正确！），x=104（== ref，正确）。
    → 失败 = **垂直 abs_y 偏移 ~80px**（test #div1 abs_y=150 mt=96 vs ref abs_y=70 mt=0）。
    → 根因 = 内层 `div div{margin-top:1in=96px}` 的 margin-top **穿透 #div1 的 border** 冒泡
       （CSS §8.3.1：父 border-top 应阻断子 margin collapse；ZW 误穿透→#div1 被推下 96px）。
    → 非 §10.3.8；修 = margin-collapse-through-border（独立小 lever，~6 案，或涉 R227/R323
       body+p margin plateau，须实证独立性）。

--------------------------------------------------------------------------------
(2) 002/004/023 簇（svg）= SVG intrinsic sizing 缺口，非 §10.3.8
--------------------------------------------------------------------------------
  002（2.75%）：`<svg:svg height="50">` + `<svg:rect 200×100>` → ZW w=288（=CB #div1 3in 拉伸）
     h=0；应 w=200 h=50（intrinsic ratio / rect bbox + height 属性）。
  004（4.17%）：`<svg:svg>` 无尺寸 + `<svg:rect 200×100>` → ZW w=288 h=0；应 200×100（rect bbox）
     或 §10.3.8 默认 300×150。
  → 根因 = **SVG intrinsic 尺寸未计算**（rect bbox 未作 SVG intrinsic w/h）+ **presentational
     height 属性未应用**（h=0）+ 无 intrinsic 时 width 误拉伸到 CB（§10.3.18 stretch 误施于
     无 intrinsic 的替换 svg）。
  → 非 §10.3.8 auto-margin；修 = SVG intrinsic sizing（SVG 专属，独立 effort）。

对 R500d 「+20~+40 单簇」定论的纠正
================================================================================
R500d 把 40 self-fail 当作**单一**「§10.3.8 auto-margin + 约束方程」簇，估 chr<1% +20~+40，
称「迄今最大 actionable 单簇 / 单会话 lever」。LAYOUT_DUMP 实证推翻此统一框架：

  - 40 案实为 **≥3 个独立 gap** 的几何聚合：
      (A) HTML presentational 属性（width/height）→ CSS  【R494 §1 谱系，DC-2 feature】
      (B) SVG intrinsic sizing（rect bbox / 默认尺寸 / height 属性）【SVG 专属】
      (C) margin-collapse-through-border（垂直位置，~6 案）【或 plateau-entangled】
  - 三者**无单一入口**（auto-margin→0 不修任一）；各自复杂度独立（presentational = App D 表
    多属性；SVG intrinsic = SVG 盒模型；margin-collapse = §8.3.1 已知难点）。
  - 5 离散 z 值（2.08/2.24/2.75/4.17/4.83%）反映**共享失败几何**（如 006 缺 96×96 蓝方块
    ≈ 022 垂直偏移 80px 的像素量偶然相近），**非**共享 §10.3.8 子分支。两异机制同落 2.24%
    是幅度巧合，非同根。

★ 纠正：R500d 不是「单会话最大 actionable 单簇」。auto-margin→0 入口 yield≈0（4 代表案证）。
  +20~+40 上限不可靠；真实分拆为 presentational（~9+）/SVG-intrinsic（~svg 簇）/margin-collapse
  （~6）三个更小、各自非平凡的 gap。勿以「mirror R165 auto-margin→0」为入口。
