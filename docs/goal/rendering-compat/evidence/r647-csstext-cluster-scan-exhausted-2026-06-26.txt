1. **text-autospace-no-001#1 / text-autospace-dynamic-001#1**（text-autospace 特性，
   CSS Text 4）：`text-autospace` 全未实现（parse/store/apply 零命中）。裁决
   **feature implementation，非 clean**——29 个 test 文件用 `text-autospace: normal`，
   当前 30/34 PASS（ZW 忽略属性 = 无 autospacing 渲染）；实现 normal 的 0.125em
   CJK↔Latin 间距会改变 29 测渲染，blast radius 大，须逐测 A/B（match ref 是否也期望
   间距）。advance 数学虽匹配 ref（0.125em×2 transition = manual margin 0.25em around
   Latin span），但属 R225/R631 IFC advance 敏感区 + 多 crate feature（~80 行）。
   defer（须 dedicated feature 实现 + 29 测 A/B）。

2. **text-stroke-width-subpixel**（-webkit-text-stroke 特性）：`-webkit-text-stroke`
   全未实现（零命中）。mismatch（0.1px vs 0.5px stroke 应不同），当前 ZW 不渲染 stroke
   → 两侧均无 stroke → 0.00%。裁决 **feature implementation**（text stroke 围 glyph
   描边），仅 1 测，ROI 低。defer。

3. **text-decoration-skip-ink-upright-002#1 / -vertical-002#1**（skip-ink + 垂直书写）：
   skip-ink 已实现（水平）但垂直书写模式 + skip-ink 组合。裁决 **复杂组合**（vertical
   + skip-ink 交互），非单点。defer。

4. **text-wrap-balance-002 / -004#1**（text-wrap: balance，CSS Text 4）：balance 已部分
   实现（balance_column_geometry）但精度/边界 case。裁决 **结构精度**（balance 算法），
   非单点。defer。

5. **control-chars-00B（VT U+000B）/ control-chars-085（NEL U+0085）/ control-chars-00C
   （FF U+000C）**（R644 残留 4 边界之 3）：R644 的 is_cc_control_char 含 VT/NEL，但
   它们在 **layout 阶段被 Rust `char::is_whitespace()` 折叠/丢弃**（VT/NEL 是 Unicode
   White_Space 属性，但 CSS Text 3 仅认 TAB/LF/FF/CR/space 为空白）。探针证 **双重
   entanglement**：collapse_whitespace（mod.rs:231 `ch.is_whitespace()`）折叠它们 +
   split_into_words 的 `text.split_whitespace()` 也按 Rust 空白分割 → 单 VT 作整段
   text 时被 split 成 0 词 → 永不抵达 paint 的 R644 占位。修须改 collapse_whitespace
   AND split_whitespace 的空白定义（CSS-specific 而非 Rust is_whitespace），触及核心
   文本处理 + 影响NBSP(0xA0) 等。裁决 **entangled**（多点核心改动），非 clean。defer。
   （注：00C FF 是 CSS segment break，应折叠为换行——R644「FF whitespace」判断正确，
   control-chars-00C 期望可见但 CSS 实际视 FF 为 segment break，该测或为 spec 边界。）

6. **object-replacement-1 / -2**（U+FFFC OBJECT REPLACEMENT CHARACTER）：mismatch，测
   试 U+FFFC 不被删除（应占宽使 "e" 不在左缘）。当前 0.00%（U+FFFC 贡献 0 宽 / 被丢）。
   U+FFFC 是 Cf（format）非 Cc，R644 占位不触发；estimate_char_width 给 0.5×fs 但实测
   贡献 0 → 疑被某处 drop 或 fontdue 0 advance。裁决 **须 pipeline trace** 定位 drop
   点，非显然单点。defer（2 测，须追踪）。
