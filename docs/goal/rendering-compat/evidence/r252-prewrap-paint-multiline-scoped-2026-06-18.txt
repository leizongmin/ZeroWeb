# pre/pre-wrap paint 多行渲染修复（scoped，零回归）（R252）

**日期**: 2026-06-18
**目标**: R247 缺陷 3（paint 多行堆叠）的 contained 修复——scope 限定 preserve_whitespace
**结果**: 落地 paint 路径 `with_line_y` scoped 修复，reftest 438/490 零回归；pre 块几何正确（1 行→多行）；morning-work 与 chromium diff 改善有限（主因=字体度量非堆叠）。

## 背景

R247 实证：paint 非多列路径用 `all_fragments()`（片段 y 行内相对恒 0）→ 多行块所有行
渲染在同一 y → **垂直堆叠**。全局改 `all_fragments_with_line_y()` 净 -11 回归（R246），
gated（排除 multicol 容器）仍净 -11（回归用例内部子块走非多列路径）。本轮尝试第 3 种
scope：**仅 preserve_whitespace（pre/pre-wrap/break-spaces）**。

## 修复（crates/engine/src/paint/painter/text.rs:940）

```rust
let fragments: Vec<TextFragment> = if use_stored {
    Vec::new()
} else if preserve_whitespace {
    inline_ctx.all_fragments_with_line_y()  // pre 族：行 y 偏移正确
} else {
    inline_ctx.all_fragments().into_iter().cloned().collect()  // auto-wrap：旧行为
};
```

**作用域判据**：pre 族的多行来自显式 `\n` 强制换行（R247 缺陷 1+2 已让 IFC 正确产出
多行）；auto-wrap（normal/nowrap）的多行块 test/ref 此前都堆叠同错，正确修复反致同源
FAIL（R246 净 -11 的来源）。故仅对 pre 族应用 with_line_y——修 pre 代码块塌缩，不触碰
auto-wrap（保持同源匹配）。

## 验证

- **几何正确**：isolated `<pre>` 3 行 → ZW 渲染 h=51（3 行），旧 h=13（1 行堆叠）。
  LAYOUT_DUMP morning-work pre 块 ifc_lines 正确（3/5/6/9/14 行）；tall viewport（9000px）
  product-smoke A/B（R247-only vs scoped）diff 0.22%（16133 px）集中在 y=7500/8250 的 pre
  块区域——证实 pre 块现正确多行渲染。
- **reftest 438/490 零回归**（pre 族在 wpt-data 仅 4 文件用，R246 footprint；auto-wrap
  未触碰故无 multicol-breaking-*/column-height-009 回归）。
- **make test 12233 passed/0 failed；clippy --workspace --all-targets -D warnings 零警告；fmt 干净。**

## 诚实结论：morning-work 67% 改善有限

isolated pre ZW(fixed 多行) vs CHR = **23.24%**（旧堆叠 1 行时 24.37%）——几何从 1 行→3 行
正确修复，但与 chromium 的 diff **几乎不变**。真因：该 probe 的 23% diff 主由 `#eee` 背景
覆盖 + fontdue vs chromium 等宽字体度量噪声构成，**非堆叠几何**。故：

- 本修复是**正确的几何修复**（pre 块不再堆叠，真 bug 修复，零回归，单测可证）。
- 但**非 morning-work 67% 的主因**——67% 主由字体度量/背景/其他独立问题（font-weight R229、
  img 固有尺寸 R233）构成。pre 堆叠是其几何表现之一，修后几何对但 chr diff 不降。
- **价值定位**：正确性修复（pre 内容不再错误塌缩）+ 为未来含 pre 的页面正确渲染；非
  reftest-multiplier（wpt-data 仅 4 文件）+ 非 morning-work chr-diff lever。

## 与 R247/R246 的关系

- R247 缺陷 1（collapse_whitespace preserve 守卫）+ 缺陷 2（空字符串强制换行）让 IFC 正确
  产出多行——本修复（缺陷 3 scoped）让 paint 正确渲染这些多行。三者配套，前两者是前置。
- R246 实证 ungated/gated(容器级) with_line_y 净 -11；本轮 preserve_whitespace scope 是
  **唯一零回归的 scope**（因 auto-wrap 堆叠的同源用例未触碰）。
