裁决：CSS2 LANLED fix 真改善 chr<1%（与 DC-14 finding 一致）
================================================================================

★ **CSS2 4 个 LANLED-impact 子目录 3 真 win（+62 case）**，证实 CSS2-area LANLED fix 真改善 DC-14 真目标：
  - **normal-flow +4.4pp（最大）**：R544 ex 单位 + R546 ref 解封（+149 case 入比较集）+ R545 inherit + R548 col
    minmax 协同 → 真实 chromium 一致率大幅上升。R546 的 ref 解封尤其关键（解封的 case 渲染本就正确，缺的是 ref）。
  - **positioning +2.2pp**：R502 presentational hints（img w/h）+ R549 border-width。
  - **borders +1.8pp**：R549 border-width medium + R550 currentColor（border-family，DC-14 高 yield 谱系）。

★ **vs 非 CSS2 text-family jitter-flat（R560 grid/R562 flexbox/R566 css-text）的对比强化 DC-14 finding**：
CSS2 LANLED fix 多为 **sizing/border-family**（ex 单位/盒模型 inherit/ref 解封/border-width/currentColor/presentational
/col-width）= DC-14 证实的**真 yield 高**类；非 CSS2 text-family fix（min-size/flex-basis/nowrap/min-content）=
**self-source win 但 chr<1% jitter-flat** 低 yield 类。两类 fix 的真目标 yield 两极分化在 CSS2 vs 非 CSS2 对比中再次确证。

★ **CSS2/tables FLAT（-0.3pp）非回归**：272/361 case 落 1-5% near-miss 带（75%，table 布局度量噪声主导）→ R177b/R168/R548
真 yield 被 near-miss 带 jitter 吞没。与 css/css-tables DIR（R561 +2.3pp）差异 = CSS2/tables 是 CSS 2.1 table 测试
（near-miss 主导）vs css/css-tables 是 CSS-Tables-NG 测试（R177b col-width 簇集中 yield）。

★ **borders self-vs-chr gap 小**（self 85.6% vs chr<1% 74.5% = 11pp）vs text 目录 64-72pp → borders 是 layout/sizing 类，
self-source 更可信；text/font 类 self-source 严重高估。这印证「self-source 对 layout 类可信、对 text 类不可信」。
