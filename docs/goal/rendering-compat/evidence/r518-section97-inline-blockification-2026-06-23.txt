1. WHAT (code agent 实现，read-only 核查 + 预测绘)
--------------------------------------------------
CSS 2.1 §9.7 row 2-3：float != none 时，inline-level 元素的计算显示须「块化」
（blockify）为对应 block-level：
    inline / inline-block -> block
    inline-table          -> table
    inline-flex           -> flex
    inline-grid           -> grid

R511（commit 65b7e89f）仅做 table-internal + float -> block；**inline-level 块化
缺失**，故 `display: inline-block; float: right` 留 inline-block、不按块浮动。

修复（style-system/src/lib.rs compute_element_style_internal 步 8，§9.7）：
对 float != none 的所有 inline-level display 加 blockify match arm
（table-internal -> block 保留自 R511）。+23/-18 行。
