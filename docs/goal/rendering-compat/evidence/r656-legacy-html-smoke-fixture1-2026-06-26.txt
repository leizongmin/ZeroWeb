**关键结论：legacy 渲染功能正常，无 major bug。**
  - 结构色双方一致：#DDDDDD（TR bgcolor 表头）、#FFCCCC（TD bgcolor 红格）、#FFFFEE
    （body bgcolor）、#000080（body text navy）均在两侧渲染。
  - table border/cellpadding/width、font size/color、ul/li、hr、a、b/i/strong/em 均生效。
  - R502 presentational hints + R255 UA display 表覆盖了 legacy 核心需求。

**diff 主因 = font/AA 平台噪声（非 legacy bug）**：
  - navy 文本 (0,0,128)：ZW 16324px vs CHR 5147px——ZW fontdue 锐利少 AA（更多纯 navy），
    chromium Skia 反走样（更多灰阶 (238,238,238)/(154,154,154)）。同 R174/R388 字体墙。
  - 即 legacy 16.70% 与 welcome/morning 17% 同源（字体/行盒度量），非 legacy 特有缺口。

**次要结构差异（minor，潜在小修）**：
  - table width="80%"：ZW 右缘 x=642（宽 634）vs CHR x=634（宽 626），ZW 宽 ~8px
    （percentage-width 或 border-box 计算，~1.3%，R502 谱系）。
  - TH 表头行 y 位置：ZW ~y=175 起 vs CHR ~y=165 起，ZW 低 ~10px（cell line-height/padding，
    字体度量谱系）。
  二者均 < 1.5%，非 user-visible 破损。
