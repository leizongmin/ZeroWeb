list-style-position 簇调查：paint-side marker 启发式（R554 谱系 entangled）
================================================================================

测试 -023：嵌套 `<ol>` 全 `list-style-position:inside`，marker "1." 应为每级 li 的**首个 inline 子内容**
（嵌套 ol 在 marker 后 inline 流动）。ref = 嵌套 div "1." 文本前缀。

**ZeroWeb 实现（painter/text.rs:281 `paint_list_marker` + :346-348）**：
  - marker 在 **PAINT 阶段**绘制（非 layout box），位置 = `marker_x ± marker_size*N` 固定偏移启发式：
    - Outside: `marker_x - marker_size*2.5`（左外）
    - Inside: `marker_x + marker_size*0.5`（略右）
  - marker **不是 layout inline box**——fixed-offset 启发式无法表达 inside marker 作为「首个 inline
    子内容，后续内容 inline 流动」的语义。

**裁决：R554 谱系 entangled，非 clean**。inside marker + 嵌套需 marker 作为**真实 inline layout box**
（嵌套 ol 在其后流动），= R554 伪元素 generated content「需 layout 独立 box」同架构 gap（当前 marker/
伪元素经 paint/inject 合入 flow，无独立 inline box）。Outside 多过（fixed 左偏移近似 OK，lists 81.9%），
Inside（marker 作 inline 内容）需 layout 集成。★ 勿再以 paint 偏移启发式调参攻 inside（无法表达 inline
flow，net-neutral/negative 风险）。
