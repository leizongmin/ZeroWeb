R530 — flex-shrink 不收缩显式宽度 item（min-size:auto 内容测量 + 负值拒绝）
==============================================================================
日期：2026-06-23
类型：code-side CSS-correctness fix（layout-engine measure + style-system apply）
状态：LANDED（css-flexbox net +9 PASS / 0 回归；css-grid 0 flip / 0 回归）

承接
----
R524「flex-grow/shrink 负值拒绝」运行时证伪（byte-identical zero-yield）。R524 当时
正确（flex-shrink-002 在 R524 时改 apply.rs 零变化），但根因未定位。本轮新 session
重新调查，定位到真根因 = min-size:auto，并发现 R524 的负值拒绝在 min-size:auto 修复后
**重新成为有效 lever**（flex-shrink-002 需两者协同）。

症状
----
flex-shrink-001（正 flex-shrink 2/3，应 PASS）实测 FAIL：两个 width:100px 的空 item
在 width:100px flex 容器中**完全不收缩**（item1=100 / item2=100 溢出到 x=108）。
→ 不是负值问题；flex-shrink 对显式宽度 item 普遍失效。6 案聚类：001/002/003/006/007/008。
（004/005 PASS 因 free space 非负或 flex-shrink:0，不触发收缩。）

根因（两步定位）
----------------

(1) min-size:auto = 显式 width（应 = 内容 0）
    LAYOUT_DUMP + 自建 R530DBG 插桩（taffy-local flexbox.rs resolve_flexible_lengths +
    determine_flex_base_size）实证：
      item basis=100 hyp_inner=100 shrink=2 resolved_min=100.0 frozen=false
    resolved_minimum_main_size = 100（应 0）。resolve_flexible_lengths 收缩循环把目标
    钳回 resolved_min=100 → 不收缩。resolved_min 来自 §4.5 automatic minimum：
      min_content_main_size = measure_child_size(node, known={main:None}, MinContent, ...)
      clamped = min_content.maybe_min(child.size.main=100) = min(100,100) = 100
    min_content 本应测得 0（空 item 无内容），却测得 100。taffy 已用
    `child.size.with_main(dir, None)` 剥掉显式主轴（意图测「忽略显式尺寸的纯内容」），
    但 ZeroWeb 的 measure callback 忽略该剥离。

(2) measure_text_content 叶节点分支回退到显式 width（inline_finalization.rs:575-590）
    空 flex/grid 叶节点（无行内内容）分支：
      let explicit_w = known_dimensions.width.or_else(|| style.width 的 Px 值);
    taffy 传 known_dimensions.width = None（主轴由 flex 控制）→ 回退到 CSS width:100 →
    返回 100。显式尺寸本已由 converter 写入 taffy style.size（taffy 自行应用），measure
    仅应汇报内容。此回退在「内容测量」（MinContent/MaxContent）时**错误**：
    它把「忽略显式尺寸的纯内容测量」变回了「显式尺寸」。

修复
----

A. layout-engine/inline_finalization.rs（measure_text_content 叶节点分支）
   内容测量（available_space.width/height ∈ {MinContent, MaxContent}）时不再回退到
   显式 CSS width/height —— 空叶节点返回 0（内容），显式尺寸由 taffy style 提供。
   `measuring_content_w/h` 守卫，仅 gate 内容测量；Definite/正常布局测量保留原回退。

B. style-system/property/apply.rs（flex-grow / flex-shrink 负值拒绝）
   CSS Flexbox §7.3.1/§7.3.2 负值非法 → 按未声明处理（回退初始值 flex-grow=0 /
   flex-shrink=1）。`if v >= 0.0` 守卫，负值跳过赋值，保留 default_impl 初始值。
   ★ 此修复在 R524 时是 zero-yield（因 min-size:auto 未修，flex-shrink=1 也不收缩）；
   min-size:auto（A）修复后，负值拒绝（B）成为 flex-shrink-002 的必要协同：
     flex-shrink=-2/-3 透传 taffy → scaled shrink factor 为负 → `sum > 0` 门控跳过收缩分布
     → 不收缩；拒绝负值→1 → 正常收缩。
   R524 的 refutation 在当时正确，但 lever 在 A 修复后 reopen —— 教训：架构性修复会
   重启曾被证伪的单点 lever，应在新相关修复后重测。
