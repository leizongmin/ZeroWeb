R880 — abspos viewport-CB 位置忽略 CB 链 border/padding（CSS §10.1）
=====================================================================
日期: 2026-06-30
谱系: R98/R500/R872 abspos-CB 谱系的延续（潜伏 bug 显性化）。
有 net 源码: ✅ abspos.rs adjust_absolute_pct_to_viewport 位置公式 + 1 单测。

测试
----
css/CSS2/positioning/abspos-containing-block-010.xht (9.35% diff):
  body { margin: 1em; border: 1em solid red; padding: 1em; background: red; }
  div  { position: absolute; top: 0; left: 0; width: 100%; height: 100%; background: green; }
  期望：div 的 CB = 初始包含块（视口），覆盖整视口（全绿），body 红不外露。
  ZW 修复前：div 落 (32,32) 而非 (0,0) → 左上 L 形红区（43776px = 800×32+32×568）。

根因（R880 LAYOUT_DUMP + 双点 debug 实证）
-----------------------------------------
`adjust_absolute_pct_to_viewport`（engine/abspos.rs）的 viewport-CB 位置公式：
  child.x = target_viewport_x - current_content_origin_x

`current_content_origin_x` 实为父盒（box_node）的 **border-box 视口原点**
（递归 line 传给子的是 border-box origin，命名误导），而子盒 child.x 相对
父盒 **content box**（= border-box + border + padding）。故公式应减父 content
origin，而非 border-box origin。当 CB 链含 border/padding 时二者差 border+padding，
位置偏移。

abspos-containing-block-010：body border(16)+padding(16)=32，div 落
body_border_box(16)+border(16)+padding(16)+child.x = 48+(-16)=32，应 0。

为何 R98/R872 未暴露：其测试 CB 链均无 border/padding（border-box origin ==
content origin），故潜伏。本案 body 有 border+padding 1em 显性化。

修复
----
engine/abspos.rs adjust_absolute_pct_to_viewport：if 块顶部计算
  parent_content_origin_x = current_content_origin_x + box_node.border_left + box_node.padding_left
  parent_content_origin_y = current_content_origin_y + box_node.border_top  + box_node.padding_top
4 组位置公式（%left/top、Px left/top、right/bottom、max-width leftover）的
`current_content_origin_x/y` → `parent_content_origin_x/y`。
尺寸公式（width/height %、auto-stretch）不变（不依赖 origin）。
