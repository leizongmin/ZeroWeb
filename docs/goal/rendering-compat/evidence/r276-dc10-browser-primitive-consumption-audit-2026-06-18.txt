## 审计（全源码闭合）

### 1. append_webview_primitives 本身确仅 fills+glyphs（goal doc 字面属实）

`apps/browser/src/app_render.rs:1851 append_webview_primitives`（body 1851-1944）仅 loop `primitives.fills`（:1865）+ `primitives.glyphs`（:1899）。→ 字面 true。但 goal doc 据此断「浏览器丢弃 11 种」**忽略了并行 extras 路径**。

### 2. get_webview_extra_primitives + transform_webview_primitives 消费另 11 种

`get_webview_extra_primitives`（app_render.rs:143）：
- 取活跃标签页 webview `last_render().primitives`（全 13 类型，webview 渲染产出）。
- 调 `transform_webview_primitives(primitives, content_x, y_offset, scale, Some((clip_top, clip_bottom)))`（:174）——对**全 13 类型**应用 offset/scale/clip（transform_webview_primitives body :1945-2152 逐类型 loop + push 变换后 clone：shadows/fills/rounded_rects/gradients/images/strokes/path_fills/path_strokes/glyphs/clips/transforms/filters/blend_modes）。
- 清 fills+glyphs（:183-184，已通过 append_webview_primitives 混入 chrome 层，避免重复）。
- 返回变换后集（11 extras：rounded_rects/gradients/shadows/images/strokes/path_fills/path_strokes/clips/transforms/filters/blend_modes；fills/glyphs 清空）。

### 3. CPU + GPU 双 render 路径都取 extras 拼 scene_primitives 传 renderer

`render_cpu`（app_platform.rs:171-218）：
- :184 build_scene → (fills, glyphs, overlay_*)（chrome + webview fills/glyphs 经 append 混合）。
- :187 `webview_extras = get_webview_extra_primitives()`（11 extras）。
- :190 `scene_primitives = webview_extras`；:193 `scene_primitives.fills = [fills, scene_primitives.fills].concat()`（chrome+webview fills 前置）。
- :203 `render_full_scene(..., &scene_primitives, ..., image_cache, overlay_fills, glyphs)` → **CPU renderer 收 fills + 11 extras + glyphs**。

`render_frame`（GPU，app_platform.rs:142-158）：
- :142 `webview_extras = get_webview_extra_primitives()`；:145 `scene_primitives = webview_extras`；:146 fills 前置；:157 `renderer.render_full_scene_gpu(&scene_primitives, ...)` → **GPU renderer 收 fills + 11 extras**。

（test 路径 :234-248 同构。）

## 关键结论

1. **浏览器消费全 13 图元类型**（非「丢弃 11」）：fills+glyphs 经 append_webview_primitives→chrome 层；11 extras 经 get_webview_extra_primitives→transform_webview_primitives（含 scale/offset/clip）→scene_primitives；CPU+GPU 双路径都传 renderer。**双路径设计**（fills/glyphs 入 chrome 层，extras 走 extras 路）是合法消费，非静默丢弃。
2. **goal doc「P0 严重不足：仅 fills+glyphs 丢弃 11」stale**（如 DC-8 CPU「3/13」stale）——extras 路径已存在。**DC-10 实质满足**（浏览器传全 13 给 renderer）。
3. **scale_factor + offset + clip 全应用**（transform_webview_primitives 对全 13 处理，DC-10 子项达标）。
4. **CSS painting order**：由 renderer（render_full_scene/render_full_scene_gpu）按字段顺序 loop 图元（CPU render_scene_to_framebuffer 字段序 shadows→fills→rounded→...→glyphs，R270）保证；浏览器侧双路径合并后 renderer 统一排序。
