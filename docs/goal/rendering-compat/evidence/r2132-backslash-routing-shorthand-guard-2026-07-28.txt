R2132 (2026-07-28) — `\` 主循环路由 + 简写首尾空白守卫（escapes-002 PASS，+1 syntax）
==================================================================================================================

背景
----
R2127 land escapes-014/015/016 后，escapes 仅余 escapes-002（syntax 10 fail 之一）。
R2131 定位 escapes-002 根因 = tokenizer `is_ident_start` 不含 `\`，前导 `\` 落 Error：
选择器 `p.class#id \{ background: red; \}` 中 `\{` 被拆成 Error(`\`)+LBrace(`{`)，
LBrace 误开声明块 → `background:red` 错误应用 → 测试 fail（应绿染红）。
R2131 试「主循环加 `\`=>consume_ident_like」：escapes-002 PASS **但** escapes-014 回归
（`\0020red`→`Ident(" red")` 经 shorthand expand_background 剥成 `red` 应用）→ net-zero revert。
R2131 结论：须 `\` routing + shorthand-trim 联合（broad 多点，须 spec-rfc 级 A/B）。

R2132 关键发现（纠正 R2131「shorthand-trim」诊断）
--------------------------------------------------
R2131 认为第 4 个 trim 点在 shorthand expansion（~10 处 value.trim()）。R2132 实读
expand_background 发现：**真正的剥离来自 `split_whitespace()`**（mod.rs:1506），不止
top-level `value.trim()`。即使去掉 top-level trim，`" red".split_whitespace()` 仍产
`["red"]` → bg_color="red" → 应用。根因是简写展开在**值串**上重切分，丢失 token 边界
（转义产生的空白与分隔空白无法区分）。

driving tests
-------------
- escapes-002：`p\.class#id` / `p.class\#id`（选择器转义 `.`/`#`）/ `background\: red`
  （属性名转义 `:`）/ `background: red\;`（值转义 `;`）/ `p.class#id \{ ... \}`
  （选择器转义 `{`/`}`）。全部「转义使分隔符变字面字符 → 规则失效/不匹配 → 不染红」。
- escapes-014/015/016（R2127 baseline PASS，须不回归）：`background:\0020red` /
  `color: red\9` / `color: \9red` 等——转义产生空白使值 ≠ 关键字 → 声明无效应丢。

fix（2 点联合）
---------------------------------------
1. **tokenizer 主循环 `\` 路由**（tokenizer.rs:966）：加 `'\\' =>` arm。`\` 后跟合法转义
   （hex 数字或任意非换行字符，含 EOF）→ `consume_ident_like`（`\` 是 ident 的一部分，
   CSS Syntax §4.3）；仅 `\`+换行（LF/CR/FF）= 非法转义 → `Delim('\\')`。
   → `\{` 产 `Ident("{")`（非 LBrace，不误开块）；`\. ` 产含 `.` 的 ident。
2. **expand_one 简写首尾空白守卫**（shorthand/mod.rs:38）：值字符串首尾若含空白，**直接
   丢弃整个简写声明**。consume_declaration deferred-ws（R2127）已保证声明值无首尾空白
   **token**，故值串首尾的空白**只能来自转义**（如 `\0020red`→`" red"`）。简写展开用
   split_whitespace 重切分会把转义空白当分隔符剥掉（`" red"`→`"red"` 误应用），故守卫
   在切分前丢弃（与 chromium 一致：含转义首尾空白的简写值非法）。长属性（color 等）不经
   简写，由 apply/parse_color 不 trim（R2127）自行拒绝。
   ★ 单一 chokepoint（expand_one 顶部），非 ~10 处分散 trim 去除——更简单且覆盖全简写。
