小聚类逐项实证
--------------
**【css-text-decor text-emphasis（7 case：ruby×4 + punctuation×3）】**
- grep `text_emphasis|TextEmphasis` 于 css-parser/style-system/engine = **零命中**：text-emphasis
  完全未解析（确认 R232「未实现」）。
- ruby 测试（text-emphasis-ruby-001）REF 用 `<rtc>&#x25CF;</rtc>`（● 字符）模拟 emphasis 标记，
  TEST 用真 `text-emphasis: circle` + `<ruby>`。ZeroWeb 既无 text-emphasis 渲染也无完整 ruby。
- punctuation 测试（text-emphasis-punctuation-3）assert「emphasis marks not drawn for punctuation
  (with exceptions)」——需 Unicode 标点分类 + 跳过规则。
- **裁决**：text-emphasis 是 DC-12 in-scope feature gap，但实现需 (a) 解析 4 属性 (b) Unicode
  标点跳过分类 (c) 标记渲染（位置/尺寸匹配 chromium）(d) ruby 交互 = **多会话 feature**，非 bounded
  单会话。基础版（全字符绘标记）会令 punctuation 测试更差（应跳过标点却绘了）。7 case 全需 ruby 或
  跳过规则，基础版零增益。

**【css-position invalidate-opacity-negative-z-index（0.52% self==chr）】**
- 测试用 `class="reftest-wait"` + `requestAnimationFrame`×2 动态改 opacity 0.2→0.99，REF 直 opacity:0.99。
- **裁决**：JS-dynamic 测试（rAF + reftest-wait class 切换），非渲染 bug，是 harness 动态 reftest
  能力限制（reftest harness 执行 JS 但不驱动 rAF/invalidation）。不可渲染层修复。

**【CSS2 near-pass（<2.5% self-fail，未深查）】**
- border-003（0.74% self≈0.71% chr）：简单 5px solid blue hollow square。diff = 边框边缘 AA/亚像素
  精度噪声（CPU 渲染器矩形填充对轴对齐边应像素精确，残余是 AA 边缘），非可修 bug。
- border-001（2.77% self / 0.75% chr）：**self-false-fail**（DC-14）——ZeroWeb TEST 离 chromium 仅
  0.75%（正确），离自渲染 REF 2.77%（REF 用 25px Ahem + word-spacing 模拟空 square 边，怪异）。
  R333 已注。非渲染 bug（self-REF 怪异）。
- floats-rule3-outside-left-002（0.99% self / 0.00% chr）：ZeroWeb 完美匹配 chromium（0.00%）但
  fail 于自渲染 REF（0.99%）= self-inconsistency，DC-14 false-fail 谱系。
- font-family-011（0.54% self / 26.54% chr）：字体度量（chromium 用系统字体族，ZeroWeb 回退度量差）。
- **裁决**：CSS2 near-pass 全落 AA 噪声 / DC-14 self-false-fail / 字体度量，无可单点修的渲染 bug。
