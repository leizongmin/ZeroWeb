# R4530 证据：dotted/dashed 墨迹环带 + 描边 alpha 修复——multiple-backgrounds / complex 双翻绿

- 日期：2026-09-19（R4530 C 轮——R4529 下轮方向①，勘察 + 实施同轮）
- 谱系：`clip-border-area-*`（css-backgrounds-4 §2.1 border-area）余段。

## 勘察定谳（P 面结论，同轮转 C）

1. **CPU reftest 真值路径**：runner 默认 CPU 渲染（`render_full_scene`；`--gpu` 默认
   false），故 stroke 墨迹复刻以 `cpu/stroke.rs` 为唯一基准。
2. **stroke 光栅化是二值判定（无 AA）**：dashed = `proj mod 3t <= 2t`（dash=2t、gap=t、
   相位锚定线起点）；dotted = 圆心距 2t 的圆盘（r=t/2，`dx²+dy²<=r²` 像素中心闭区间）。
   → paint 侧矩形条带可**逐像素复制**墨迹。
3. **ImagePrimitive clip 窗口语义**（cpu render_image）= `[floor(x), ceil(x+w)−1)`，
   与像素中心闭区间 `[ceil(a−0.5), floor(b−0.5)]` 逐像素等价（floor/ceil 恰好互为
   开闭变换）→ 条带矩形整数化（`snap_px`）后可精确重现 stroke 像素集。
4. **叠加病灶（勘察新发现）**：CPU `render_stroke` 全部像素写入 set_pixel 硬编码
   alpha=255——`border: Npx dotted/dashed transparent`（border-area 多值背景测试的
   标准载体）被画成**不透明黑点**盖住背景图。fill/rounded_rect 同族问题已分别修复
   （cpu/mod.rs:826 等），stroke 为最后漏网点。本修复是点阵环带生效的前置。

## 实现

1. **描边 alpha 修复**（zero-render-foundation cpu/stroke.rs）：`color.a == 0` 早退
   （透明描边不绘制）；不透明直写旧行为；半透明走 `blend_pixel` 与背景合成（新增
   `stroke_pixel` helper，solid/dashed/dotted 四处写入点替换）。path_fill/path_stroke
   （SVG path 域）同型问题独立挂账不在本修复面。GPU mesh 路径顶点色带 alpha、管线
   标准混合，无此 bug。
2. **dashed/dotted 墨迹环带**（zero-engine effects.rs `push_side_ink_strips`）：
   - dashed：逐 dash 沿边区间（dash=2t/gap=t、k·pattern 相位、末 dash 截线长）×
     整带厚度，全部 `snap_px` 整数化；
   - dotted：逐 dot（d += 2t 累计口径与渲染器一致）× 逐行圆盘弦段（dy 像素中心、
     `rem = r²−dy²` 弦半宽 `sqrt`），行界 `[floor(c−r), ceil(c+r)]`；
   - solid 族/double 维持 R4529 厚度区间路径（byte-identical，既有测试锚定）；
   - 条带沿边起点/长度与 paint_borders BorderEdgeSpec 同源（上下全宽含角区、左右
     padding 盒竖向区间；pattern 相位锚定线起点 proj=0）。
3. **kill-switch** `ZW_BORDER_AREA_INK=0`（dotted/dashed 回退整带近似；复测
   multiple-backgrounds 0.00→5.34% 红原样——9.16→5.34 差值 = alpha 修复不随开关回退）。
