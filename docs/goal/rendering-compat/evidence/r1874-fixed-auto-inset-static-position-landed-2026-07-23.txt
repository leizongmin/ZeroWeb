2. 根因（empirical LAYOUT_DUMP 实测，非 code-trace）
═══════════════════════════════════════════════
测试 css/CSS2/abspos/static-fixed-inside-abspos.html：
  <div style="display:absolute; w:100 h:100 bg:green">       <!-- display:absolute 无效→block，ZW 正确忽略 -->
    <div style="position:absolute; w:50 h:50 ml:50 mt:50 bg:red">   <!-- middle，abspos，CB=ICB 静态 -->
      <div style="position:fixed; w:50 h:50 bg:green">              <!-- inner，fixed，无 inset -->

期望（chromium）：inner fixed 无 inset → §10.3.7/§10.6.4 位置 = 静态位置（若 position:static
的位置）= middle 内容原点 (58,100.6)，green 覆盖 red → 「filled green square, no red」。

ZW baseline（fix 前）LAYOUT_DUMP：
  inner fixed:  abs_y=-0.4, x=0   → 视口原点 (0,0)
  fill: green@(0,-0.4) + red@(58,100.6) + green@(8,50.6 外层)
  ⇒ green 在 (0,0) 既未覆盖 red（red y=100-150 暴露），又覆盖了顶部 `<p>` 文本 x=0-50。

根因：engine/abspos.rs::adjust_fixed_to_viewport（R324）对所有 is_fixed 一律
`box.x -= parent_offset_x; box.y -= parent_offset_y`（扣除累积祖先偏移使其视口相对）。
该修正的假设（R324 注释）= 「taffy 把 fixed 当 absolute，box.x/y = 相对 positioned 祖先的
left/top inset；视口相对 = 同 inset 值相对视口 → 扣除祖先偏移」。

此假设仅对【有 inset】的 fixed 成立（如 `position:fixed; top:0; left:0`）。对【四 inset 全
auto】的 fixed，taffy 已将其置于【静态位置】（视口正确坐标），扣除祖先偏移反将其错误地移到
视口原点 (0,0)。CSS §10.3.7（width）/§10.6.4（height）：全 inset auto 时 left/top 取静态位置值，
元素停留在静态位置（CB=视口只影响百分比/inset 解析，不影响静态位置本身）。

3. fix（layout-engine，default-on，无 kill-switch 需要——严格 gate）
═══════════════════════════════════════════════
- types/mod.rs：LayoutBox 新增 `pub fixed_insets_all_auto: bool`（default false，init 在
  Default impl line 417 区，复用 declared_width_auto 谱系模式）。
- engine.rs（conversion，computed 在手）：is_fixed 时计算
  `fixed_insets_all_auto = is_fixed && top/right/bottom/left 全 LengthValue::Auto`，写入 box。
- engine/abspos.rs::adjust_fixed_to_viewport：扣除条件由 `if box_node.is_fixed` 收紧为
  `if box_node.is_fixed && !box_node.fixed_insets_all_auto`。全 auto inset fixed 跳过扣除，
  x/y 保持 taffy 算出的静态坐标（视口正确）。offset 向子元素传播逻辑不变（仅 fixed 后代消费，
  本案无嵌套 fixed）。

★ 严格 gate（零回归保证）：仅【fixed 且四 inset 全 auto】的元素行为变化（不再移到 (0,0)）。
  - 有 inset 的 fixed（R324 全部用例）：代码路径完全不变 → 零回归。
  - 非 fixed 元素：不受影响。
  之前 all-auto-inset fixed 都在 (0,0)（几乎必然错误 → 要么 fail 要么 near-pass），修复只能
  改善或中性，不会把一个正确 case 改错。
