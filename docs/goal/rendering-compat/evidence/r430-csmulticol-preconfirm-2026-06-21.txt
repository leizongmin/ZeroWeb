（低于布局类 band 37.9-49.2%，落入/接近 text-decor 28.9% / fonts 34.8% 区间）。

理由：
1. 主导聚类（balance-precision / nested-fragmentation / breaking / fill / change-re-layout）
   全击中 ZeroWeb 最弱结构性区（区别 flexbox 缺口集中在 intrinsic-sizing 子域）
2. 60-子集已显示 multicol 为 #1 失败聚类（~15 self-fail / 60 ≈ 25% self-fail 率）
3. 全量放大结构聚类（子集可能欠采样 nested/breaking/balance）
4. 缺 column-span spanner + orphans/widows 断行控制（R353），单独 parse+store 为
   dead code（code-guidelines 禁零价值修改），须 layout 侧 fragmentation 消费才生效

若预测成立，multicol 会把 7 目录聚合 oracle 从 6 目录 40.5% (516/1275) 下拽至 ~38-39%
（布局类 4 目录 46.3% 加入一个 ~28% 的 multicol 后重新加权）。
