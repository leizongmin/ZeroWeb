幻影匿名块。a2b169e 补了 article/aside/details/hgroup/menu/search 6 个。本轮**系统性审计**

## 2. morning-work 类危险缺口排查（应为 block 容器却 inline，含 block 子 → R109 幻影盒）

对照 HTML UA §13.1.1 display:block 列表，ZeroWeb block 列表**仅缺 `center`**（legacy 居中元素，
display:block）。wpt-data `<center>` reftest footprint = **0 文件**。其余 block 元素全覆盖。
→ **无更多 morning-work 类危险缺口**（article 那种「常见容器 + 含 block 子 + 缺 block 条目」已闭环）。

## 3. `<br>` / `<wbr>` 落 inline 无害（IFC 专门处理）

`<br>` 不在 ua_default_display 任何分支 → 回落 inline。但 IFC 专门拦截：`inline/mod.rs:902
if elem_data.local_name() == "br"`（line-break 处理）。故 `<br>` 落 inline **不影响**换行正确性。
`<wbr>` 未专门处理（line-break opportunity），但仅影响断行建议，低影响。

## 4. 次要完整性缺口（低 footprint / 低影响，留作低优先级）

| 标签 | HTML UA 应为 | ZeroWeb 现状 | wpt-data footprint | 影响 |
|------|-------------|-------------|-------------------|------|
| `meter` | inline-block | inline | 2 文件 | 无 gauge 渲染，inline vs inline-block 仅影响盒尺寸/BFC；2 文件 |
| `progress` | inline-block | inline | 2 文件 | 同上，2 文件 |
| `center` | block | inline | 0 文件 | legacy 罕见，0 footprint |
| `source` | none | inline | 0 文件 | 空 inline 盒（media/picture 子），不可见，0 footprint |
| `track` | none | inline | 0 文件 | 空 inline 盒（media 子），0 footprint |
| `param` | none | inline | 0 文件 | 空 inline 盒（object 子），0 footprint |
| `area` | none（特殊） | inline | 0 文件 | image map，0 footprint |
| `li` | list-item | **Block** | 多 | ⚠️ list-item markers（项目符号/编号）未通过 display 应用——已知简化（非 a2b169e 范围），影响所有 `<ul>/<ol>` 列表的 marker 渲染，但 marker 是更大 feature（marker box 生成+paint），非单点 display 修复 |

**关键判断**：除 `li`→ListItem（list markers，已知更大 feature）外，其余缺口 footprint ≤2 或 =0，
**非 reftest/产品 smoke 杠杆**。`meter`/`progress` 即便补 inline-block 也无 gauge 渲染（paint 层未实现），
对 chr-diff 几乎无贡献。

## 5. 结论与建议

- **a2b169e 已闭合 morning-work 类 UA 默认 display 缺口**——系统性审计确认无更多「应为 block 容器却
  inline」的危险缺口（仅罕见 `center`，0 footprint）。
- **ua_default_display 现已基本完整**，剩余缺口（meter/progress/center/source/track/param/area/li）
  低 footprint 低影响，**非近期杠杆**，可作已知完整性 debt 记录。
- **`li`→ListItem + list marker 渲染**是唯一有广泛真实页面影响的项（列表无处不在），但属更大 feature
  （marker box 生成 + paint），非单点 display 改动，且可能涉及 IFC/paint（与并行 agent IFC WIP 潜在
  交叠），defer 待 IFC 工作稳定后再评估。
- **本轮价值**：把「是否还有 morning-work 同类 UA bug」从开放问题变为**已审计确认无重大缺口**，
  避免后续轮重复排查同类；同时钉死次要缺口清单 + footprint 量级，供代码 agent 低优先级参考。
