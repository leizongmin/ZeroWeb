R771: R109 block-container anonymous block generation LANDED (commit 73e99ada)
================================================================================
Date: 2026-06-28
Status: LANDED, +3 PASS zero regression

Summary
-------
Extended R109 (§9.2.1.1) anonymous block generation to block containers with
mixed text+block children. Only non-whitespace TEXT nodes trigger anonymous
block creation — inline ELEMENTS (img, span, etc.) are excluded since they
already have their own taffy nodes.

Key Design Decisions
--------------------
1. Narrow trigger: only text+block mixed content (not text+inline-element+block)
2. Whitespace-only inline segments skipped (collapse-through preserved)
3. Block container anonymous blocks use plain Block style (no parent style inheritance)
4. No spec-rfc overhead — direct bounded implementation

Changes
-------
- inline_block_split.rs: +block_container_has_mixed_content(), +compute_block_container_split(),
  +is_whitespace_only_inline_segment(), +compute_child_split_impl() shared core
- tree.rs: Extended R109 gate to check block_container_has_mixed_content(),
  block container anon blocks use plain Block style, whitespace-only segments skipped
- app_input.rs: Pre-existing clippy collapsible_match fix
