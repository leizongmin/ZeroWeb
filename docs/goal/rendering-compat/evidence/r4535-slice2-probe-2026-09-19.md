## 勘察定谳一：slice 2 机制可行性（overflow ×5 / shadow 系 / inset-shadow）

- **polygon-clip 机械已确认存在**：`clip_all_primitives_to_polygon`
  （paint/helpers.rs:593，bbox 裁剪 + fills 逐个多边形求交拆分）+ clip-path 消费先例
  （painter/mod.rs:2799 起，Inset/Circle/Ellipse/Polygon 四臂对元素及子树图元快照
  裁剪）——border-shape overflow 裁剪（§7.5.3 内形状裁子树）可完全复用该模式：
  子树绘制前后快照 counts → 内形状多边形裁剪。
- **box-shadow 形状跟随**：ShadowPrimitive 为 rect+radii 模型，多边形阴影需 path 化
  shadow（深域）；inset-shadow 沿形状同域——挂账。
- **geometry-box 9.39% 残差定谳 = 布局域**：test 页 .container（inline-block）+
  子 .test margin 10px 的收缩/塌陷布局 vs ref 页固定 160×160 SVG——四盒横向错位
  ≈20px/盒（45081px diff 主导），非 border-shape 绘制缺陷。修复面 = inline-block
  收缩宽/高是否含子 margin（layout-engine 域，跨域风险高，单独评估）。

## 勘察定谳二：corner-shape 凹角簇解码（~10 案 1.0-1.9% 红簇）

- **R4248 现状**：scoop/notch/bevel/square 采样臂**已实现**但被整体 gate 回退
  round（gate 注释：与 chromium 未对齐回归实证）。当前 corpus 该簇全红 1.0-1.9%。
- **ref 像素解码**（corner-shape-scoop-ref clip-path polygon 逐点 hypot 校验）：
  - scoop 外轮廓 = **盒角点为心、半径 r 的凹 quarter arc**（(75.214,3.263) 距角
    (100,0) 恰 25.0，逐采样点吻合）；
  - scoop **内圈轮廓 = 同一外盒角锚定、半径 r+border**（内采样点距角恰 30 =
    25+5）——非 inset-box 缩半径模型；
  - notch 内圈阶梯点 = 外角 + 内对角 × (r+b)（(70,30) = (100,0)+(−30,+30)）；
  - 采样序须沿 start→end 单调（旧式 a0+180° 起扫产生 bowtie，even-odd 填充碎裂）。
- **实验轨迹**（全部实测）：①gate 撤销 + 负 superellipse 整档采样（≤−8→notch、
  −1→scoop）→ scoop 1.89→1.56；②sweep 方向修正（a1+180° 起扫）→ 1.47；③内圈
  凹角锚点外移 + r+b 半径 + 圆-盒边交点端点重算 → scoop 1.26 / notch 1.37 /
  negative-100 1.41（REFTEST_DUMP 像素取证）——**但 test 渲染出现 BR 角 sliver
  伪影**（细三角伸出盒外，来源未定位）且未过 1% 阈值 → 按零新红纪律整体回退，
  树态还原 R4534。
