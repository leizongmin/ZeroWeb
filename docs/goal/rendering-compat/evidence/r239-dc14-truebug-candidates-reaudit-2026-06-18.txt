2. 首选 contained 目标：#6+#10 position-absolute-semi-replaced-stretch（23%+15%）
────────────────────────────────────────────────────────────────────
测试规范（position-absolute-semi-replaced-stretch-input/-other）：
  "Semi-replaced elements should stretch with an auto main size, and explicit insets in
   that direction." CB relative;width:350px;height:100px。子 .abs{position:absolute;
   top/right/bottom/left:3px; width:auto; height:auto}。元素=<input type=button/submit/
   reset/color/text>（#6）+ 其他半替换（#10）。期望=半替换元素 abspos + 两轴显式 inset + auto
   size → 拉伸填满 CB-insets（CSS2 §10.3.7/§10.6.4 abspos 非替换 stretch 规则）。

精确机制（实证）：
  - crates/layout-engine/src/tree.rs:165 `apply_replaced_element_sizing` 读取
    `img_intrinsic_sizes`（HashMap<NodeId>，tree.rs:51），**仅 <img>**。line 186 `if tag !=
    "img" { return; }` 硬退出 → **所有 form control（input/button/textarea/select）零替换
    sizing**，被当普通非替换 block 处理。
  - 后果：abspos form control 的「半替换拉伸」语义缺失。input button 应在 abspos + 两轴 inset +
    auto size 时拉伸到 CB-insets；ZeroWeb 要么不拉伸（保留 intrinsic/默认宽）、要么拉伸路径未覆盖
    form control。
  - 修复面 contained：扩展 apply_replaced_element_sizing 或 abspos sizing 把 form control 列为
    「半替换」（CSS2 §10.3.8 替换元素的 abspos sizing 特例 + form-control 默认尺寸），让 abspos
    stretch 覆盖。不动 converter/taffy 核心。

R164 教训保留：diff 23%/15% 可能含 form-control UA 默认样式差异（按钮边框/内边距/字号），实现
轮须 chromium Oracle A/B 量化翻转数，勿据推断算 clean +2。但 #6+#10 同族、机制单一、代码面
contained → 是 R177b 之后**最高杠杆 contained 候选**。
