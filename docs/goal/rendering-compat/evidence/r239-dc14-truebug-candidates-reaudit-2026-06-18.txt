2. 实现轮 chromium Oracle 实证复扫（2026-06-18，product-smoke + puppeteer A/B）
────────────────────────────────────────────────────────────────────
对剩余 5 个 contained/可疑候选用例逐个 product-smoke 渲染 ZW-test + ZW-ref + headless chromium 截图，
计算三组 diff（chan_thresh=5）。**关键判据**：若 ZW-test==ZW-ref（同源 0%）且 ZW-test-vs-CHR ≈
ZW-ref-vs-CHR，则 ZW 几何已正确（与显式 stretch 的 ref 一致），chromium 差异来自**图元绘制/控件外观**
（feature gap），非布局 bug，**不是 contained 修复**。

  #6  position-absolute-semi-replaced-stretch-input  ZWt-vs-ZWr=0.00%  ZWt-vs-CHR=23.03%  ZWr-vs-CHR=23.03%
  #10 position-absolute-semi-replaced-stretch-other  ZW-vs-CHR=15.27%（同 #6 族）
  #14 stretch-grid-item-button-overflow              ZWt-vs-ZWr=0.05%  ZWt-vs-CHR=8.17%  ZWr-vs-CHR=8.15%
  #15 collapsed-border-vertical-lr-rtl-overflow      ZWt-vs-ZWr=0.00%  ZW-vs-CHR=4.80%（test/ref 唯一差=will-change:transform）
  #17 collapsed-border-sideways-rl-rtl-overflow      ZWt-vs-ZWr=0.00%  ZW-vs-CHR=4.73%
  #18 collapsed-border-vertical-rtl-overflow         ZWt-vs-ZWr=0.00%  ZW-vs-CHR=4.73%

**结论（推翻初版「#6+#10 contained」推断）**：
  - **#6/#10/#14 全为 form-control 原生控件外观 feature gap**（与 R202 早年 probe 结论一致）：
    ZW 把 `<input>/<button>` 画成 styled box + outline（无 UA chrome / 无原生外观），
    chromium 画原生 widget。ZW 几何完全正确（test==ref@0%，拉伸/min-size 规则均满足），
    **差异 100% 在控件绘制层，非布局**。tree.rs:186 `if tag!="img" return` 确实使 form-control
    无 replaced sizing，但本测试场景（abspos 两轴 inset + auto / grid min-size-auto）的**几何
    结果已正确**，改 apply_replaced_element_sizing 对 chromium-diff **零改善**（实证：test==ref
    已是 stretch 几何）。**修复须实现原生表单控件渲染（大特性），非 contained 单点**。
  - **#15/#17/#18 为 writing-mode(vertical-rl/sideways) + direction:rtl + collapsed border**，
    test/ref 唯一差异 `will-change:transform`，同源 0%。4.7% chromium 差异来自 vertical 轴
    collapsed border 中心间距渲染（writing-mode 结构性，与 R114 axis-swap 族相关），低 ROI + 高风险。
  - **教训**：R239 初版据 tree.rs 代码「tag!="img" return」**推断** form-control stretch 缺失，
    但 product-smoke A/B 实证几何已正确——印证 R203「架构性失败的单点修复须实证，不能据推断」。
    form-control 族（#6/#10/#14）现已**实证归类 feature gap，defer**，勿再以「半替换 stretch 缺失」
    重试。

**18 候选最终归类**：8 已修；feature-gap #2/#6/#10/#14（表单控件 + dialog）；structural #5/#12/#13/
#15/#17/#18（动态 JS / R109 / writing-mode）；字体 #16。**contained clean win 已穷尽，证实 R144/R204
plateau**。
