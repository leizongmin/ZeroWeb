================================================================================
附：transferred size suggestion（CSS Flexbox §4.5）调研 — 真 lever 但多会话级
================================================================================
flex-minimum-{width,height}-flex-items-011/012/020 等 4 案（图片已补齐后仍 FAIL 1.04%）
根因 = CSS Flexbox §4.5 transferred size suggestion 未实现：

机制：替换元素（<img>）有 intrinsic aspect ratio 且 cross 尺寸确定时，flex item 主轴
automatic minimum size（min-size:auto）至少 = cross 经 ratio 推导的尺寸
（row: cross × ratio；column: cross / ratio）。否则 flex item 在窄容器（width:0）中越过
内容测量值塌缩为 0。

定位：taffy-local/compute/flexbox.rs:774-795 `resolved_minimum_main_size`（§4.5 automatic
minimum）只取 content measure，未做 transferred floor。LAYOUT_DUMP 实证
flex-minimum-width-flex-items-011：img w=0 h=50（应为 w=100 = 50×aspect2）。
case B（line 687-694）已把 flex_basis 从 cross×ratio 推导为 100，但 min-size:auto=0
（content measure）→ img 用 flex-shrink 收缩到 0。

实现尝试（已回退）：
  (1) measure_text_content 加 aspect_ratio 参数推导 transferred：修了 011/012/020，但
      REGRESSED flex-minimum-width-flex-items-013（1.04%→81%）——measure 推导 cross-from-main
      与 flex align-items:stretch 冲突（cross 被 aspect 推导为 499.5 而非 stretch 的 50）。
      measure 方向不可知（不知 row/column），transferred 是方向相关（main-from-cross），故
      measure 非正确落点。已回退。
  (2) taffy flexbox.rs min-size:auto 加 transferred floor（FlexItem 存 aspect_ratio）：
      修了 011/020/021，但 REGRESSED 012（1.04%→7.21%，cross=height:2000 未 max-clamp，
      transferred=4000）与 width-013（1.04%→81%，child.size.cross 被 aspect 推导为 499.5
      而非真实 cross）。已回退。

正确实现须解决（多会话）：
  - transferred 须用「真实 cross 尺寸」（CSS-definite 或 stretched），非 aspect 推导值。
    须区分 cross 是「CSS 显式」（011 height:50 → transferred 100）还是「从 main 推导」
    （width-013 height 从 width 999 推导 → 不应触发 transferred）。判据 = main 原始是否 auto。
  - transferred 须 clamp cross by cross max-size（012 height:2000 max-height:50 → 用 50）。
  - 须在 min-size 时点拿到 cross 解析（stretched cross 此时尚未解析 → 须两趟或存 pre-aspect
    cross definiteness）。
  落点 = taffy flexbox.rs min-size:auto + FlexItem 存 (aspect_ratio, cross_was_definite_pre_aspect)
  + transferred = clamp(cross, cross_min, cross_max) ×|/ ar（仅当 main 原 auto）。预期 +4
  （011/012/020/023），width-013 neutral（main 非 auto → skip）。须 A/B css-flexbox + css-grid
  （grid item min-size:auto 同谱系）+ broader 防回归。
