R871 — CSS §10.3.3/§10.6.3 根元素 html 固定 margin 位置偏移（taffy 根节点定位 bug）
==============================================================================
日期：2026-06-30
谱系：R870 后续 abspos worst 扫描。abspos-containing-block-initial-009a（5.92%）→ 逐案像素

根因（LAYOUT_DUMP + 像素 bbox 实证）
------------------------------------
CSS §10.3.3/§10.6.3：根元素（html）的固定 margin 相对初始包含块（视口）定位 border-box。
taffy 把根节点固定在 layout.location (0,0)（根无父级提供定位上下文），根的声明 margin
不被应用到位置——`<html style="margin:50px">` 的 border-box 落在视口原点 (0,0) 而非 (50,50)。

复刻 abspos-containing-block-initial-009a（`<html style="width:50%;height:50%;margin:50px;
border:10px solid black">`）：
  ZW black border bbox: (0,0)-(419,319)   ✗（html 落原点）
  CHR black border bbox: (50,50)-(469,369) ✓（html 偏移 margin 50）
ZW 几何 html abs_y=0 mt=50（margin 存储了但未应用到位置）。

实现
----
crates/layout-engine/src/engine.rs compute() 根 auto-margin 居中逻辑（R165）之后，新增根固定
margin 位置偏移：仅水平书写模式，读根 style.margin_left/margin_top（仅 Px；百分比/Em 保守
跳过，auto 已由居中逻辑处理），把 px 值加到 root_box.x / root_box.y。
