R445 — flex shorthand (R429) type-awareness 影响面量化（read-only grep）
日期: 2026-06-21  轮次: R445（doc-maintenance，承 R444 R429 复核做影响面量化）
代码零变更（仅 grep css-flexbox wpt-data）。

背景
----
R429 定位 expand_flex（shorthand/mod.rs:674-688）位置式 vs spec type-based：
  - flex: <num> <width>（2 值）→ ZW 把 width 派给 shrink（错），spec 派给 basis。
  - flex: <width>（1 值）→ ZW 派给 grow（错），spec 派给 basis。
R426 把 shorthand 列为 css-flexbox 第 3 大簇（152 例 65% self-fail）。
本扫描区分「parser type-awareness bug 命中的 case」与「shorthand 簇主体」。

方法
----
grep tests/wpt-runner/wpt-data/css/css-flexbox/*.html（484 test-side，排除 -ref/-notref）。
  (a) 2 值 number+width/auto：flex: <num> (auto|<len>)
  (b) 1 值 width：flex: <num><unit>

结果
----
  (a) 命中 2 个 test 文件：
      - flexbox_flex-0-auto.html   用 `flex: 0 auto`（reftest，rel=match flexbox_flex-initial-ref.html）
        spec: grow=0, basis=auto(shrink=1)；ZW: grow=0, shrink=auto（错）
      - flexbox-collapsed-item-horiz-001.html  用 `flex: 1 auto`（reftest）
        spec: grow=1, basis=auto；ZW: grow=1, shrink=auto（错）
        注意：该 case 主测 visibility:collapse（R111 已修），flex:1 auto 的 shrink 误派
        可能不影响其通过判定（待 probe 确认）。
  (b) 命中 2 个 test 文件：
      - flex-container-max-content-001.html
      - flex-container-min-content-001.html
        （max/min-content 簇，R97/R107/R118 intrinsic sizing，flex:<len> 只是容器声明之一，
        self-fail 主因是 intrinsic sizing 非 parser）
  2 值 <num> auto（parser bug 主形）独立计数 = 2 个文件。

结论
----
R429 parser type-awareness 修复的真实 reftest 命中面 = **~2-4 个 css-flexbox case**
（非 152 例 shorthand 簇）。152 例 shorthand self-fail 的主体是 flex-basis/grow/shrink
与 definite-size 的 taffy 交互（R426/R429 已述），非 parser 缺口。

裁决
----
- R429 仍是 **spec 正确性修复**（应做），但 reftest 影响 = **SMALL clean win**（~2-4 case），
  远小于 flex min-size:auto probe（R428-R437，+14 flexbox）。
- **战略含义**：flex probe 是 css-flexbox 最大且近唯一的 ZeroWeb-side 杠杆；其后
  ZeroWeb-side lever 要么 small（R429 ~4），要么 taffy-blocked（aspect-ratio 49 例 R304）。
  flex probe commit 后，前向 motion 主要转向：
    (1) DC-14 分母去子集化（并行 agent，第 8 目录 css-writing-modes）；
    (2) 多会话架构（Phase A IFC / multicol fragmentation / baseline-export）。
- 勿再把 R429 当「大 lever」排期；它是 spec 合规小修。

即 css-flexbox）。如并行 agent 做 R429 probe 时可顺带核 cross-dir。
