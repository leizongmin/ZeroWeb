日期: 2026-06-28

================================================================================
背景 / 承接
================================================================================
承 R769d CONTINUE，R740 战略②扫 CSS2/borders oracle top 发散。
border-width-012（10.85%）：`body{border-width:2em;border-style:hidden}`，
`p{border-width:inherit;border-style:solid;border-color:green}`。WPT + csswg #2768/#11494
要求 hidden 元素的 computed border-width **保留**（供 inherit），仅 used（布局/绘制）为 0。

直接对比定位（product-smoke + PIL）
================================================================================
ZeroWeb（修前）：p 仅 13px 绿文本，**无 32px 边框**（border-width:inherit 继承到 0）。
chromium：p 有 2em(32px) 绿边 + 绿文本（border-width:inherit 继承 body 的 computed 2em）。

================================================================================
根因（style-system/src/computed.rs:289-313）
================================================================================
    if matches!(resolved.border_top_style, BorderStyleValue::None | BorderStyleValue::Hidden) {
        resolved.border_top_width = LengthValue::Px(0.0);
    }
    //（right/bottom/left 同）

ZeroWeb 把 **none 和 hidden 都归零** computed border-width。但 csswg #2768/#11494
（覆盖 CSS2.1 §8.5.3 旧表述）：hidden 的 computed border-width 应**保留**（仅 used 为 0），
这样 `border-width:inherit` 才能继承（border-width-012 的 body hidden→p inherit 2em）。

================================================================================
关键：4 子系统各自独立按 hidden=0 used（故 un-zero computed 对渲染无副作用）
================================================================================
1. converter border_lp（converter/mod.rs:130-136）：matches!(None|Hidden) → 布局盒 0。
2. paint border.rs（:82/100/120/140/437）：border_style != None && != Hidden 才绘制。
3. table_borders resolve_collapsed_borders：border_style_priority Hidden=100 最高（:559）
   + line 185「hidden 强制两侧宽度为 0」。
4. computed.rs（本 fix）：仅对 none 归零，hidden 保留 computed（供 inherit）。

================================================================================
修复（computed.rs，4 处 matches 模式 None|Hidden → None）
================================================================================
仅对 border-style==none 归零 border-width；hidden 保留 computed 值（供 inherit）。
