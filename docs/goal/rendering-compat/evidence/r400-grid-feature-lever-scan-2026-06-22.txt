## 候选 + read-only 代码核查

### 1. grid-calc-margin.html — `margin-top: calc(50% - 0px)` on grid item
- **ZW 链路**：css-parser 有完整 calc AST（`CalcExpr`/`CalcParser`，values/types.rs:386）；
  computed.rs:374-375 把**含百分比的 calc 保留**（`calc_contains_percentage`）推迟到布局；
  converter/mod.rs:363 `convert_length_to_lpa`（margin/inset 走此路径，line 94-97）用
  `extract_calc_percentage`（line 1179）提取 `P% ± Npx` 的百分比 → `LengthPercentageAuto::Percent`，
  交 taffy 按 CB 宽解析。
- **裁决**：calc(50%-0px) margin **已被处理**（提取为 50%，-0px 偏移为 0 无损）→ **非 clean win**
  （该案 likely 已过或近-miss 于他因）。⚠️ **但提取是有损的**：`extract_calc_percentage` 丢弃
  非零 px 偏移（`calc(50% - 10px)` → 50%，错），是**潜在正确性 bug**；无当前失败测试驱动
  （grid-calc-margin 用 -0px），按 code-guidelines「不做零价值修改」暂不修，记录为 latent。

### 2. grid-item-percentage-quirk-001.html — quirks 百分比高度 quirk（canvas @ grid @ div(explicit h)）
- **ZW 链路**：style-system 已实现 quirks 百分比高度 quirk（lib.rs:577/595/630 三测试：
  parent-auto→auto fallback / parent-explicit→kept / no-parent）。
- **裁决**：基础 quirk 已实现；本测的 grid+replaced(canvas)+quirk 三方交互是 subtlety，
  非单点 clean win（依赖 quirk 对 replaced element 的特殊规则 + grid CB 解析），likely 复杂。

### 3. min-size-auto-overflow-clip.html — grid item min-size:auto × overflow:clip
- **ZW 链路**：overflow:clip **已解析**（OverflowValue::Clip，parse_basic.rs:149 / color.rs:497）；
  但 layout-engine **无 min-size:auto 逻辑**（grep `min_size_auto`/`MinAutoSize`/`automatic_minimum` 全空）。
- **裁决**：grid min-size:auto 是 taffy 0.7 grid sizing 缺口（与 R97 max-content / R304 DEFER 同族），
  非单会话 clean win，结构性。

## 新发现（非 lever，但值得记录）

**calc() 解析在 ZW 各属性间不一致**：
- `convert_length_to_lpa`（margin/inset）：extract_calc_percentage 有损提取 P%±Npx → Percent（line 363）。
- 另有 **3 个 length-converter**（converter/mod.rs:405 / 426 / 459）对 `LengthValue::Calc(_) => length(0.0)`
  **直接丢弃 calc→0**（用于不接受 auto 的纯 length 属性，如 border-width / 部分 sizing 路径）。
- engine.rs:1328/1341 对 width/height 另有 calc 分支。
- → calc 支持是**散落不一致**的：margin/inset 走百分比提取（有损），其他 length 属性 calc→0。
  统一需跨多属性 + 部分需 CB 上下文，**非单会话 clean win**。lossy 提取（丢 px 偏移）是 latent bug，
  无当前失败测试驱动。
