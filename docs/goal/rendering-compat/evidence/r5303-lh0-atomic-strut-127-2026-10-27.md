## 实现（inline/mod.rs apply_vertical_alignment，无新 kill-switch；ZW_STRUT_NEG_LEADING 复用）

- **捕获标记** `container_strut_lh_zero: bool`：`layout()` 有容器 styles 且解析行高
  恰 0 时置位。把 `container_strut_line_height == 0` 的两义分开——「未捕获」（paint
  Path B 空 styles，须 legacy）vs「显式 line-height:0」。Path B 恒 false，布局/绘制
  两侧口径一致。
- **新接管臂**：`container_strut_lh_zero && strut_neg_leading() && 行内无文本 run &&
  line.height > 0` 时，strut A = −fs/2 + ratio·fs（**替换** legacy 0.8fs 而非托底
  ——本域 legacy 不是保守下界而是错值），D = −A 入 R5298 下限通道。文本行不受影响
  （R5087 bleed 判例口径保持）；塌 0 高行（§10.8.1 行盒移除）仍跳过。
- **负 D 并集下限**：R5298 下限通道 `strut_descent < 0` 时取
  `max(strut_descent, max_glyph_descent)`——行盒围合 = 各盒区间并集，负 strut D 不把
  底边拖到基线之上（127：max(−48, img 0) = 0 → 高 = 48）。正 D 恒走旧下限（c42 域
  零扰动）。
- 条件序：`container_strut_lh_zero` 布尔判前置，runs 扫描仅在 lh:0 容器上发生（热路径
  每行新增成本 = 1 次布尔判断）。
