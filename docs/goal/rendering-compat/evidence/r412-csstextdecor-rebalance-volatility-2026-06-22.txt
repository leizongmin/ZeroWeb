# R412 — css-text-decor 在途 rebalance 波动性：修正 R411 单快照「上修」预测（只读）

**日期**：2026-06-22
**承接**：R411（在途 191 test-side 量化，据单快照把 R409 预测 ~35-43% **上修至 ~38-46%**，称「大概率触及 41% 基线」「本轮是最后一轮前向准备」）。
并行 agent 仍在第 5 轮传输中导入 css-text-decor（未提交）。本轮用更大的 246 样本**独立复验 R411 的 rebalance 结论**。

## 核心发现：R411 单快照 rebalance 非稳健（CONFIRM 后修正方向）

| 指标 | R411 快照（191 test-side, 54%） | R412 快照（246 test-side, 69%） | 变化 |
|------|-------------------------------|-------------------------------|------|
| text-emphasis 占比 | 91 = **47.6%** | 137 = **55.7%** | **+8.1pp** |
| text-decoration 占比 | 81 = 42.4% | 90 = 36.6% | −5.8pp |
| other（underline/ruby/line-through/overline） | 19 = 9.9% | 29 ≈ 11.8% | +1.9pp |

**关键证据**：191→246 增 55 文件，其中 **46 个（83.6%）是 text-emphasis**——并行 agent 是**按子目录分批导入**，emphasis 测试形成大连续块。故在途单快照的簇占比**随导入进度剧烈摆动**（±8pp/15pp 进度增量），R411「样本足够大」假设不成立。

## 修正后的预测：oracle ~32-39%（straddle position 37.9%），非 R411 的 ~38-46%

R411 上修逻辑：emphasis 47.6% 全失败 + text-decoration 42.4%×~75% + other 9.9%×~90% ≈ **41%**（故称「触及基线」）。

R412 修正（emphasis 升至 55.7%，text-decoration 降至 36.6%，other 11.8%）：

| 簇 | 占比 | 通过率假设 | 贡献 |
|------|------|-----------|------|
| text-emphasis | 55.7% | 0%（R392 生产全无 + line-box 定位阻塞） | 0 |
| text-decoration | 36.6% | 70-80%（基础 inset/dotted/thickness 已实现；skip-ink/propagation 子缺口） | 25.6-29.3% |
| other | 11.8% | 55-80%（ruby 多失败 / underline-position 度量耦合 / line-through·overline 基础过） | 6.5-9.4% |
| **合计** | | | **~32-39%** |

**结论**：R411「大概率触及 41% 基线、高于 position 37.9%」**过于乐观**。修正后 oracle 落 **~32-39%，straddle position 的 37.9%**（居中 ~35%，低于 R411 居中 ~42% 约 7pp）。若全量（仍余 31% 待导入）比 69% 更 emphasis-heavy（当前趋势），则落区间下端 ~32%，低于 grid 39.6% / position 37.9% / tables 43.8% 全部三者。

## 方法学教训

1. **在途单快照预测不可靠**：分批导入使簇占比在快照间摆动 ±8pp+。R411 据 191 单点上修预测、R409 据 78 子集预测，两者都被「非均匀采样」污染。**任何在途预测都须标「单快照、待全量+oracle 复核」**，不应做「CONFIRMED / 上修」定性断言。
2. **text-emphasis 是结构性天花板**：无论全量 emphasis 占比 47.6% 还是 55.7%，它**全失败**（R392 line-box 定位阻塞 + Phase A 谱系）。text-decor 目录的 oracle 上限被这个未实现簇硬封顶，de-subsetting 只揭示更诚实的（更低）数字，**不本身提升通过率**。唯一解锁 = Phase A line-box 垂直定位（多会话架构），与 R392/R393 结论一致。
3. **对 R410 fonts 预测的连带警示**：R410 fonts 预测（~33-42%）同样基于 53 子集单快照（47% feature-dependent），未跑 rebalance 验证。按本轮教训，fonts 全量也可能因分批采样而偏移；R410 预测带已较宽（9pp）部分吸收此风险，但**不应据 R410 单快照做定序决策**。

## 裁决

- **R411「上修至 ~38-46%」「触及 41% 基线」修正为 ~32-39%（straddle position）**——单快照非稳健，246 样本显示目录比 R411 估计更 emphasis-heavy。
- **不改变 master.md 总体结论**：text-decor 仍属「子集高估 self-source、全量去子集化必要」目录；oracle 落 ~32-39% 仍在「文字类目录被未实现特性簇封顶」叙事内（与 fonts 同偏低端）。仅修正**具体数值与方向**。
- **本轮仍为只读前向准备**（无代码变更）；并行 agent 提交 text-decor 后，用真通过率对照**修正后**的 ~32-39% 预测（验证是否 straddle position、emphasis 全失败占比）。
- **方法论沉淀**：后续在途预测一律标注「单快照·待复核」，避免重蹈 R411 过早定性。
