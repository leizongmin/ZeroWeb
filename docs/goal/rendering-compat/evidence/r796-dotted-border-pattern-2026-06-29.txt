1. Bug：dotted dot_spacing 固定 2px，圆点重叠成实线
================================================================================

R795 修对 dashed 后，同法测 dotted：

  render-foundation/src/cpu/stroke.rs:107（render_stroke → render_dotted_line 调用）：
    LineStyle::Dotted => render_dotted_line(..., stroke.color, 2.0 * scale);
  dot_spacing = 2.0*scale（固定 2px），但 dot_radius = half_w = stroke.width*scale/2（=4 for 8px）。
  → 圆点每 2px 放一个、半径 4 → 严重重叠渲染成**实线**（probe 实测 ZW y=26 [(1,720)] 近全黑）。

probe 实测（/tmp/dot-probe.html，div border:8px dotted）PIL 沿 top-border 扫描：

  CHROMIUM 中心扫描线 y=33：dot=8, gap=8 → 圆点直径=border-width、圆心距=2×width=16
  ZEROWEB（修复前）：近实线（dot_spacing 2px 致圆点重叠）

================================================================================
2. Fix：dot_spacing = 2× border 厚度（圆心距）
================================================================================

stroke.rs Dotted 分支：`2.0 * scale` → `2.0 * stroke.width * scale`（圆心距 = 2× 像素边框厚度）。
  dot_radius=half_w 已正确（=width/2，直径=width）。圆心距 2×width → 圆点 [c-4,c+4]、gap=8。
