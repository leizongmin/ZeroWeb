# R859 — 空 / overflow!=visible inline-block 基线 = 底 margin edge（CSS §10.8.1）

**日期**：2026-06-30
**类型**：有 net 源码（baseline-export 结构性 lever 的窄 slice）
**承**：R858（纯调查，全 corpus DC-14 诚实基线确立）

## 触发

R858 结论：单 session clean lever 经 R739–R858 全角度穷尽，forward motion 仅剩长期结构性
（R109 / multicol Phase 2 / baseline-export）。本轮选择 baseline-export（master.md 跨会话
#3 lever）的**最窄 clean slice**：inline-block「无 in-flow 行盒」基线规则。

## 根因（spec + code）

CSS 2.1 §10.8.1：inline-block 基线 = 其最后 in-flow 行盒基线；**但「无 in-flow 行盒」或
`overflow != visible` 时，基线 = 底 margin edge（border-box 底 + margin-bottom）**。

ZeroWeb 现状（`crates/layout-engine/src/inline/mod.rs:586`，IFC 收集 inline-block 子元素处）：

```rust
let baseline = if let Some(&b) = self.baseline_overrides.get(&child_id) {
    b
} else {
    match s.display {
        DisplayValue::InlineFlex | DisplayValue::InlineGrid => h * 0.5,
        _ => h, // inline-block, inline-table: 基线在底部（= border-box 底，缺 margin-bottom）
    }
};
```

- `baseline_overrides` **仅对 inline-flex/inline-grid** 填充（`engine.rs:1180` `is_horizontal_flex`），
  从不为 inline-block 填充 → inline-block 恒走 `else` 分支 `baseline = h`（border-box 底）。
- 对**空 inline-block**（无 in-flow 行盒）与 **overflow!=visible inline-block**，应取底 margin edge
  `h + margin-bottom`，ZW 误取 `h`，少算了 margin-bottom。
- 直接驱动的 reftest：`css/CSS2/linebox/vertical-align-baseline-004a`（空 IB + margin-bottom:99px）
  与 `005a`（overflow:hidden IB + margin-bottom:99px）。

## 难点排除（为何此前归「结构性」）

`adjust_inline_block_positions`（engine.rs:298）**早于** `compute_final_inline_layouts`
（engine.rs:361），故 inline-block 自身的 `inline_layout`（行盒）此时未计算 → 无法据「有无
行盒」判定 → 内容 inline-block 的「最后行盒基线」合成确为结构性（循环依赖，需两 pass）。

但**空元素**（无 DOM 子节点）与 **overflow 值**都可**静态判定**（不依赖 IB 自身布局）：
- 空：`doc.first_child(child_id).is_none()` → 必无 in-flow 行盒。
- overflow：直接读 `s.overflow_x` / `s.overflow_y`。

故「空 + overflow!=visible」是 baseline-export 的**可单 session 安全 slice**，内容 IB 的
last-line 合成仍 defer。

## 改动（`crates/layout-engine/src/inline/mod.rs`）

```rust
DisplayValue::InlineBlock => {
    let no_line_boxes = doc.first_child(child_id).is_none();
    let clips = !matches!(s.overflow_x, OverflowValue::Visible)
        || !matches!(s.overflow_y, OverflowValue::Visible);
    if no_line_boxes || clips {
        h + length_px(&s.margin_bottom) // 底 margin edge（§10.8.1）
    } else {
        h
    }
}
```

（另加 `OverflowValue` import；inline-table 维持 `h`。）

## 验证

margin-bottom 可变), text "Xg"]`。大字号文本主导行盒基线（ascent≈160 > ib_baseline），

  （非空）后，overflow:hidden vs visible → hidden 上移约 80px（margin-edge）。PASS。
