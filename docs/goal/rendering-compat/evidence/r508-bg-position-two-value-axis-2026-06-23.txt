R508 — background-position 两值语法轴向修复（vertical 关键字首位交换）
日期: 2026-06-23
承接: R507（bg-image 画布传播；残余 background-root-015 等多特征测试未翻）

============================================================
1. Bug
============================================================

CSS background-position 两值语法（CSS Backgrounds §3.6）：第一值默认水平、
第二值垂直；但若第一值是**垂直专属关键字**（top/bottom），须交换轴向——
"top center" = horizontal=center / vertical=top。

ZeroWeb `parse_background_position`（css-parser/parse_extended_visual.rs:629）
两值分支原样返回 `TwoValue(first, second)`，而 `resolve_background_position`
（engine/paint/painter/effects.rs:925）把 TwoValue 第一项当 x、第二项当 y：
  "top center" → TwoValue(Top, Center) → x=resolve(Top)=0（左）, y=resolve(Center)
  → 图像水平错位到左边（应居中）。

实证 background-root-015（`body { background: ... no-repeat top center; }`）：
  purple 方块 bbox 修复前 (33,183)（左）→ 修复后 (377,87)（居中✓，ref 393,109）。

============================================================
2. 修复（parse-time 归一化，~7 行）
============================================================

`parse_background_position` 两值分支：若 first 是 Top/Bottom（垂直专属），
交换为 `(second, first)`，使 TwoValue 始终为 (horizontal, vertical)：
  "top center" → TwoValue(Center, Top) → x=Center（居中）, y=Top（顶部）✓
  "top left"   → TwoValue(Left, Top)   → x=Left, y=Top ✓
  "center top" → first=Center 非垂直 → 不交换 → TwoValue(Center, Top) ✓
  "left top"   → first=Left 非垂直 → 不交换 → TwoValue(Left, Top) ✓

parse-time 归一化优于 resolve-time：下游所有消费者（resolve_background_position）
见到的 TwoValue 一律 (x, y)，无需各自处理轴向。
