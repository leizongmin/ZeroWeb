承接
----
R545（inherit 关键字）落地后扫 CSS2 normal-flow 残余。R545 记「inline-replaced-width（8）=
inline `<svg:svg>`（ZeroWeb 不渲染内联 SVG，大 feature，非本轮）」——但内联 SVG 渲染被
goal doc（line 99）明确划为**范围外**（"SVG 文档/内联 SVG 渲染：不在本目标范围"），故
上轮建议的内联 SVG lever 不可行。改扫其它缺口，定位到**缺失共享参考文件**：很多 CSS2.1
reftest 引用 `css/reference/` 下的共享 ref（`pass_if_number_5.xht` 等），但这些文件**未随
WPT 导入** → runner 加载时 `No such file or directory` → 该测试**被排除出分母**（不进
Total/Passed/Failed，等于从未运行）。这是 DC-14「分母真实性（去子集化）」缺口：分母被
静默缩小，通过率被人为抬高。

根因
----
runner（wpt_file_loader.rs load_file_reftests）按 `<link rel="match" href>` 权威发现 reftest
对，但若 ref 文件本地缺失，加载时 warn + **跳过该测试**（不纳入运行集）。本轮 grep 全
wpt-data 发现 **14 个唯一缺失 ref 文件**，影响 **161 个测试**（全部在 css/CSS2 + css-fonts
+ css-writing-modes）。缺失文件多为 CSS2.1 测试套件的共享「pass_if_*」描述式 ref（pass_if_
number_5.xht / single_square_list_marker.xht 等），这些 ref 渲染「期望视觉」（如 `<div>5</div>`
对应计数器测试，或 `<div>5</div>` 加粗体对应 font-weight 测试），与 test 像素可比。

机制复现（实证）
----------------
baseline：`reftest-upstream counter-increment-003` → **Total: 0**（ref 缺失 → 测试被排除，
从未运行）。导入 `pass_if_number_5.xht` + `pass_if_number_10.html` 后 `reftest-upstream
counter-` → **Total: 97 / Passed: 97 (100.0%)**。ZeroWeb 的 CSS counter 支持（painter/text.rs
get_counter + content:counter()）本就正确，缺的只是 ref 文件。

修复
----
从上游 WPT（raw.githubusercontent.com/web-platform-tests/wpt/master，via ~/use-proxy 代理）
fetch 14 个缺失 ref 文件，放到 wpt-data 对应路径（11 个 css/reference/ + 1 个 css/css-writing-
modes/reference/ + 2 个 css/css-fonts/）。**零代码变更**。

裁决
----
LANDED。**net +149 PASS / 0 回归**（迄今最大单轮 self-source 净增，超 R536 +52）。12 个
