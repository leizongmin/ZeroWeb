## 1. 缘起与归因

R5405 五域侦察轮（css-backgrounds 37F 清单）发现 clip-text 家族 12+ 案仅
table-cell 一案败（0.28%，max channel diff 255 真色差）。PNG 逐像素量化 +
chromium oracle 双证定谳：

- **独立直测探针**（chrome headless，三 cell 对照）：无声明 cell 文字偏移 = 2px
  （1px UA padding + 1px 字形 bearing）＝显式 `padding:1px`；显式 `padding:0`
  偏移 = 1px。**chromium UA td 默认 padding: 1px 直测定谳**（chromium html.css /
  Firefox html.css 同款事实默认；border-collapse 下仍生效）。
- **根因**：ZW UA 样式表缺 `td, th { padding: 1px }`。corpus 表类案双侧自洽
  （guidelines #33）长期掩盖；本案 test/ref 恰跨 table/inline-block 两渲染路径，
  1px 缺口暴露。
