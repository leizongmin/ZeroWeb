结构性验证（content bbox + 行带 diff 分布，反驳视觉模型误判）
================================================================
用 vision diff 工具初判 testpage-003 时报告「灾难性破损：每字母独占一行 / 图片缺失 / 30% 一致」，
但与 7.65% 像素 diff **数值矛盾**（真破碎应 30-60%+）。PIL ground-truth 像素分解证伪该误判：

  testpage-002: chr/zw 内容均止于 y≈250（结构同高）；diff 跨 y=0-249 均匀分布（文本区），
                y≥250 全 0 → 纯 font/AA + dashed border 噪声，无结构破损。
  testpage-003: chr bbox (8,13,791,244) / zw bbox (8,39,766,245)。
                真实差异 = ZW 起始 y 低 26px（h2/首行 margin/line-height，同 R656 TH-y 谱系）
                + 环绕文本右缘窄 ~25px + diff 集中在 y=150-199 浮动带（峰值 12167px）。
                **图片存在**（ZW bbox 含图像区），float 环绕生效但几何与 chr 有偏差。
  testpage-004: chr bbox (8,25,680,473) / zw bbox (8,39,749,480)。
                ZW 起始低 14px + 某 block（嵌套 table 或 pre）宽 ~69px；diff 集中 y=250-299
                （表格/dl 区，峰值 7712px）。总高接近（473 vs 480），结构匹配。

**结论：三页均结构渲染正常**，差异映射到已知部分实现特性（非新 legacy bug）：
  - 002: dashed border + font/AA（文本域 plateau 噪声）。
  - 003: float 布局 P2-partial（goal line 79/409 明确「仅 inline-context float exclusion，
    clear/containment 不完整」）+ 首行 y 偏移（行盒度量）。
  - 004: 嵌套 table 宽度 + line-height 字体度量（R177/R656 table-width 谱系）。
