================================================================================
缺口 1：trailing-space ref href（1 case）
================================================================================

css/CSS2/tables/border-collapse-005.html 的 `<link rel="match" href="border-collapse-005-ref.html " />`
——href 值带**尾随空格**（上游 WPT 原始写法，python 全 wpt-data 扫描确认仅此 1 处）。

浏览器按 URL 解析语义会 strip 掉属性值的首尾空白；ZeroWeb 加载器 `Path::join` 不
trim → 拼出 `border-collapse-005-ref.html `（带空格文件名）→ No such file → 加载器
continue 跳过整条 case → 测试被排除出分母。

修复：R551 的 `resolve_ref_path` 入口加 `let ref_path = ref_path.trim();`（1 行）。
绝对/相对分支都受益（符合浏览器 URL 解析 strip 语义）。

================================================================================
缺口 2：缺失相对 ref 文件（3 文件，解 5 case，R546 模式）
================================================================================

3 个共享参考文件物理缺失（经 ~/use-proxy 代理从 raw.githubusercontent 上游 fetch）：
- css/css-fonts/font-language-override-02-notref.html（453b）
- css/reference/pass_if_filler_text_match.xht（466b，被 pass_if_filler_text_match_{bold,smallcaps}.xht 引用）
- css/reference/pass_if_filler_text_underlined-notref.html（239b）

导入后引用它们的测试 ref 可达，进分母。

A/B 实测（test-guard 包裹 reftest-upstream，逐案 stem 过滤，stderr 正确捕获）
================================================================================

受影响 6 测试（baseline→with-fix loaded/total/passed 对比）：

  border-collapse-005:                  baseline loaded=0 → with-fix loaded=1 PASS(0.00%)  = +1 PASS
  font-language-override-02 (match#0):  baseline loaded=1 PASS → with-fix loaded=1 PASS    = 0（match-ref 本就存在）
  font-language-override-02 (mismatch#1):baseline loaded=0 → with-fix loaded=1 FAIL(0.00%) = +1 honest exposure（mismatch 假）
  font-language-override-03:            baseline loaded=1 PASS → with-fix loaded=1 PASS    = 0（独立，ref 本就存在）
  pass_if_filler_text_match_smallcaps:  baseline loaded=0 → with-fix loaded=1 FAIL(0.00%) = +1 honest exposure（mismatch 假）
  pass_if_filler_text_match_bold:       baseline loaded=0 → with-fix loaded=1 FAIL(0.00%) = +1 honest exposure（mismatch 假）
  pass_if_filler_text_underlined:       baseline loaded=0 → with-fix loaded=1 FAIL(0.00%) = +1 honest exposure（mismatch 假）

font-language-override-02.html 含两条 reftest link：match→-ref.html（本就存在）+
mismatch→-notref.html（R552 导入）。baseline 仅 match-case 入分母；with-fix mismatch-case
也入分母。

净影响：**+1 PASS（border-collapse-005）/ +4 honest exposure（4 个 mismatch 假）/ 0 回归**。
  「0 回归」by construction：受影响测试 baseline 下被排除（loaded=0），无 case 由 PASS→FAIL。
  4 个 mismatch 假 exposure = test 与 notref 渲染相同（0.00% diff），但 mismatch 期望它们
  不同 → 正确判 FAIL。这是真实 reftest 语义，非 harness 伪影（mismatch 模式经 grep 确认）。
  pass_if_filler_text_{bold,smallcaps,underlined} 是 css/reference/ 下「pass-if」描述式
  mismatch 页面（测样式变体应与基线 notref 不同；ZeroWeb 渲染相同=暴露样式差异缺口）。
