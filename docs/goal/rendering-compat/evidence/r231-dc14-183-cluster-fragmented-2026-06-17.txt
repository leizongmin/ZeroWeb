# DC-14 183 case 1-3% chromium-diff 聚类：碎片化，无单一根因（R231 调研）

**日期**: 2026-06-17
**数据源**: `evidence/cross-validate-full-2026-06-17.txt`（475 case，z_vs_chr 列）
**目的**: R230 确认 font-weight 是 welcome 专有（reftest 用 Ahem 无 weight），故 DC-14 真正的 183 case 1-3% 聚类（R221 标为最大杠杆，advance-width R225 已证伪）真因仍不明。本轮按目录+判定+直方图刻画该聚类。

mode=1.1%(25)、1.2%(16)、1.3%(16)…平滑递减至 3%。median=1.59%、mean=1.71%。tight 1.0-1.3 带=60/183=33%。

## 结论（对 DC-14 达标路径的影响）
1. **无单一高杠杆根因**：advance-width(R225 证伪)、font-weight(Ahem 无 weight，welcome 专有)均非 183 聚类真因；聚类**碎片化**。
2. **~38% 是已知结构性多轮**（multicol 31 + writing-modes 26 + floats-clear 13=70），非新杠杆——达标须经这些多轮子系统。
3. **~15% 是 Ahem 字体度量/解析**（fonts 28），非 font-weight，疑 line-height/kerning/解析边界。
4. **新候选子聚类 = text-emphasis（15，CJK 强调点 1.0-1.3%）**：内聚、此前未单独标记，可能是比 multicol-breaking 更 contained 的修复点（但 CJK 标记度量亦可能难）。建议作为 R229（welcome font-weight）之后、multicol/writing-mode 多轮之外的**独立候选**单独探查。
5. **路径 = 结构性多轮 + 碎片化小修，无捷径**。font-weight(R229) 只解决 welcome 产品 smoke + 非分母，对 39.6%→95% 的 reftest 达标贡献有限（仅含 weight 的非 Ahem 用例）。
