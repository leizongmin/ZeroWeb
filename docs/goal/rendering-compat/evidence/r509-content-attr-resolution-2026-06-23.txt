R509 — CSS `content: attr(<name>)` 函数解析（生成内容显示属性值）
日期: 2026-06-23
承接: R508（bg-position 两值轴向；续扫 high-diff 簇，content-048=100%）

============================================================
1. 缺口
============================================================

CSS generated content 的 `attr()` 函数：`content: attr(bgcolor)` 显示宿主元素
bgcolor 属性的值（如 "#ffff00"）。95 个 CSS2 测试用 `content: attr()`。

ZeroWeb 解析了 attr()（css-parser `ContentValue::Attr`，apply_advanced→
ContentComputedValue::Attr），但**从未渲染**——两处 gate 把 Attr 拦截：

① style-system/lib.rs:199：`before_pseudo` 仅当 content==String 时设置；
   Attr 不设 → 伪元素根本不创建 → 下游 inject/paint 永远看不到。
② painter/text.rs:511 paint_content：`Attr(_) => return`（直接跳过）。
③ engine/pipeline.rs inject_pseudo_text_nodes：原仅匹配 String 内容。

实证 content-048（`body:before { content: attr(bgcolor); } <body bgcolor="#ffff00">`）：
  预期：绿色文本 "#ffff00" + （注：content-048 另有 body bgcolor 表现提示缺口，
  100% diff 主因是 bgcolor→bg-color 未映射，见 §4 caveat，非 attr）。
  attr 文本部分：修复前不显示，修复后显示（content-070 实证 diff 0.90%→0.41%）。

============================================================
2. 修复（两处，~15 行）
============================================================

① style-system/lib.rs:199-204：before_pseudo/after_pseudo 的 gate 从
   `matches!(content, String(_))` 扩为 `String(_) | Attr(_)`——Attr 内容的伪元素
   也创建。

② engine/pipeline.rs inject_pseudo_text_nodes：抽出 `resolve_text` 闭包，
   String 直接用、`Attr(name)` 读宿主元素（nid）的属性值
   （`doc.get(nid).get_attribute(name)`）→ String。Counter 仍由 paint_content
   渲染，此处返回 None。

★ 设计：attr() 在**注入时**解析（host 元素 nid 已知），转成 String 注入为文本
节点——复用既有 String 注入路径，无需改 paint_content 签名（不线程化 doc）。

4. caveat / 残余
============================================================
