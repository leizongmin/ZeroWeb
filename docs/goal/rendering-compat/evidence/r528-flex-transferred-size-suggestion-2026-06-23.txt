机制
----
CSS Flexbox §4.5 Automatic Minimum Size of Flex Items：替换元素（<img>）有 intrinsic
aspect ratio 且 cross 尺寸确定时，主轴 automatic minimum size（min-size:auto）至少为
cross 经 ratio 推导的尺寸（row: cross × ratio；column: cross / ratio）。否则 flex item
在窄容器（width:0）中越过内容测量值塌缩为 0。

LAYOUT_DUMP 实证 flex-minimum-width-flex-items-011：img w=0 h=50（应 w=100=50×aspect2）。
taffy case B（flexbox.rs:687）已把 flex_basis 从 cross×ratio 推导为 100，但 min-size:auto
（flexbox.rs:774-795）只取 content measure=0 → img 用 flex-shrink 收缩到 0。

实现（taffy-local/compute/flexbox.rs，~25 行）
----------------------------------------------
1. FlexItem 加两字段：
   - `aspect_ratio: Option<f32>` —— intrinsic width/height ratio（line 503 已算）。
   - `cross_size_definite: bool` —— cross 尺寸是否在 aspect 解析前已确定（CSS 显式）。
     须 pre-aspect 判定（否则 maybe_apply_aspect_ratio 会把 auto 填成确定值）。
2. generate_anonymous_flex_items：`cross_size_definite = child_style.size()
   .maybe_resolve(node_inner_size).cross(constants.dir).is_some()`。
3. min-size:auto（§4.5 automatic minimum）末尾：
   - transferred = cross（clamp by cross min/max）×|/ ar，仅当 aspect_ratio.is_some()
     && cross_size_definite。
   - min_size = content_min.maybe_max(padding).maybe_max(transferred).maybe_min(max_main)。
     ★ maybe_min(max_main) 关键：transferred 可能超 max-main（如 max-width:100% 容器内
     transferred=200），§4.5 规定 automatic min 须经 max main 钳制。

关键设计点（两轮回归定位）
--------------------------
- 判据 = cross_size_definite（非 main）：011 cross(height)=50 是 CSS 源 → 触发；
  width-013 cross(height) 由 main(999) 经 aspect 推导为 499.5 → 不触发（避免 double-apply
  aspect）。第一版误用 main_size_definite（011 tree.rs 已把 width 填成 100 使 main「确定」
  → 误 skip → 011 仍 FAIL）。
- max-main clamp：auto-margins-002（img max-width:100% max-height:100px，cross=intrinsic 150）
  transferred=min(150,max-h=100)×2=200，未钳 max-main → min-width=200 与 max-width=100 冲突
  → REGRESSED。加 maybe_min(max_main) → transferred 钳到 100 → 修复。
