R850 — block-level position:relative 百分比 top/bottom inset 修复（R711 complex lever clean slice LANDED）
=============================================================================================================

日期：2026-06-30
谱系：pending-clean-levers R711（原标 complex/deferred，R715 disambig 后降级）→ 本轮实证「vertical % 子集」为 clean slice

────────────────────────────────────────
1. 根因（LAYOUT_DUMP + chromium Oracle A/B 双证）
────────────────────────────────────────

CSS §9.4.3：relative 元素的 top/bottom/left/right 百分比 inset 应相对包含块尺寸解析。
taffy 0.7（vendored）对 block-level position:relative：
  - 应用 Length inset（R715 实证 `.len{relative;top:50px}` abs_y=58 应用 ✓）
  - 应用 left/right %（水平轴，R850 实证：left-113/left-103/right-103 等已 pass，水平 % 已工作）
  - **丢弃 top/bottom %**（垂直轴，R715 实证 `.pct{relative;top:100%}` 不应用）

bottom-113 anchor：`#parent{height:1in;margin-top:2in} > #div1{position:relative;height:1in;bottom:100%;border-top:1in red}`
  → #div1 应向上偏移 100% of #parent height(1in=96px)，旧实现 taffy 丢弃 % → 不偏移 → 露红 47.46%。

────────────────────────────────────────
2. fix scope（engine.rs，~60 行，self-contained post-process）
────────────────────────────────────────

新增 `apply_block_relative_percent_insets(box_node, styles, viewport_height)`（engine.rs），
在 compute() 步骤 11.x（adjust_absolute_* 之后，root 居中之前）调用。

  - 自上而下后序：对每个 block-level relative（is_relative && is_block_level && !is_absolute && !is_fixed）盒，
    读 style.top / style.bottom 的 Percentage。
  - CSS §9.4.3 优先级：top 优先（正值下移），否则 bottom（正值上移，故取负）。
  - CB 高 definiteness：仅当父 content_height 来自 style.height==Px（definite）时解析 %；
    Auto/Percent 高 → top/bottom % 不解析（None，CSS：indefinite CB 时 % inset compute to auto）。
    根的 CB = 视口（ICB），viewport_height definite。
  - ★ **仅垂直轴**：R850 A/B 实证 taffy 0.7 已应用 left/right %（水平轴）；若本 pass 也应用会 double-count
    致 left-103/104/113、right-103/104、relpos-calcs-003/004/005 回归（首版 +水平轴 时 0.46%→4.28%）。
    故本 pass 只补 top/bottom % delta（Px 已由 taffy 处理，无 double-count）。
  - 改 box.y 后子树绝对坐标随累积偏移自然跟随（relative 偏移整个子树）。

与既有路径正交：
  - inline-level relative → apply_relative_offsets_inline（Px，converter/mod.rs）
  - root relative → resolve_relative_inset（Px，engine.rs）
  - 本 pass 仅 block-level 垂直 %，三者无重叠。

5. 意义
────────────────────────────────────────

R711 是 pending-clean-levers 最后一个「complex/deferred」lever 的 clean slice 收割：
  - R715 把 R711 降级为 complex（taffy 0.7 限制，需 CB-definiteness cascade + double-count 防护）
  - R850 实证「仅垂直 % + 仅 definite CB」是 clean slice（taffy 不 double-count Px，CB-definiteness
    用现有 style.height==Px 判定足够覆盖 anchor）
  - +10 case PASS / 0 回归，是 positioning dir 当前可收割的最大单点 yield

与同区组 A（R695/R699 parent content-height post-process）同属 engine.rs sizing/offset post-process 簇，
模式可复用（自上而下后序 + style-driven definiteness 判定 + 累积偏移跟随子树）。
