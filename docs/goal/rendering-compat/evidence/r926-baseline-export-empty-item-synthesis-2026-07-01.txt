R926 — baseline-export 空-item/空-container baseline 合成（CSS Writing Modes §4.4）
==================================================================================

承 R925「baseline-export 是当前最可治的结构性 lever（taffy baseline_overrides API 已接线，
gap = 空 item + writing-mode baseline 合成）」。本轮实施 + 深查。

★ 关键纠正：grid-container-baseline-synthesized-001~004（16-17%）真根因 ≠ baseline-export
----------------------------------------------------------------------------------

R924/R925 把 grid-container-baseline-synthesized-001~004 归为「baseline-export」lever。本轮
LAYOUT_DUMP + 像素 forensics 推翻该归因：

1. baseline 已正确：探针实测 inline-grid 容器 taffy_baseline=Some(60.0)（= 正确的 margin-box
   下沿）。仅因 guard `taffy_bl < child.content_height`（60<60=false）拒绝 → 落入手动路径。
   手动路径经本轮修复后也给 60。即 baseline 现已正确（60），但 diff 仍 16.23% 不变 →
   baseline 偏移非 diff 主因。

2. 真根因 = inline-grid intrinsic 宽度 bug（R370 inline-flex 的 grid 类比）：
   探针实测 `.container`(inline-grid, grid-template-columns:60px, 空 item) 的
   width=6 / content_width=6（仅 item border 3+3=6），而 grid item child w=60（正确 track）。
   → 容器塌缩到 6px 宽，grid item(60px) 溢出，cyan 背景只画 6px 列。
   ZW-TEST cyan 面积 = 2671px（vs REF/Oracle ~58345px，差 22 倍）。

3. 第二层阻塞（width 修复后暴露）：IFC line-box 高度 bug——60px 高 inline-grid 容器行间重叠
   （band0 高 177px 应 ~57px；inline-block ref 同尺寸却正常 5 分离 band）= Phase A 行盒度量
   结构性。

实施（LANDED，css-flexbox +1，零回归）
----------------------------------------

engine.rs `adjust_inline_block_positions` baseline_overrides 闭包三处修改：

(a) 空 inline-flex/inline-grid 容器（child.children.is_empty()）：此前 return None → IFC
    回退 central（h/2）。改：按 §4.4 合成 alphabetic = 容器 margin-box 下沿
    （child.height + child.margin_bottom）。

(b) 第一行首 item 为空（doc.first_child(id).is_none()）：first_item_bottom 回退从
    content-box 底沿（c.y + c.content_height）改为 margin-box 下沿
    （c.y + c.height + c.margin_bottom）。有内容的 item 保留既有 content-box 启发式（精准，
    不影响 text-item 案）。

(c) 最终 guard 从 `baseline < child.content_height` 放宽到
    `baseline <= child.height + child.margin_bottom + 1.0`（合成基线可落在 content-box 之外
    的 border-box/margin-box 下沿，旧 guard 会误拒）。

grid-container-baseline-synthesized 真 lever（已 ruled out 单 session·给未来 session）
--------------------------------------------------------------------------------------

grid-container-baseline-synthesized-001~004 须同时修两层方能过：

1. inline-grid intrinsic 宽度（R370 grid 类比）：设计已就绪——grid_fixed_track_width helper
   （intrinsic_sizing.rs，解析 grid-template-columns 全固定 track 求和 + gap + frame）+
   shrink_inline_blocks_to_content（float_positioning.rs）的 InlineGrid 分支 grow-or-shrink
   接线（taffy 算 6 应 60，须 grow，shrink-only 路径会拒）。本轮实现后实测 cyan 2671→48492
   （宽 6→60 正确），但被第二层阻塞，且 synthesized-001 diff 16.08→16.66%（略退步，因更多
   cyan 落入错误重叠位置），css-grid oracle 仍 18/49 net-zero → 按「不做零/负价值修改」
   + rally 零收益回退纪律 **回退 width fix**（仅留设计于此供未来 session 复用）。

2. IFC line-box 高度（tall inline-level box 行间重叠）：inline-block ref 同 60×60 正常
   （5 分离 band），inline-grid 却重叠 → inline-grid 与 inline-block 在 IFC line-box 高度
   贡献路径不同。结构性 Phase A 行盒度量（同 R630/R848 谱系）。

裁决：grid-container-baseline-synthesized = (1) inline-grid intrinsic width + (2) IFC line-box
height 两层叠加，均结构性，非单 session clean fix。R924「全结构性」结论再确认，但本轮把
「baseline-export」误归因纠正为「inline-grid intrinsic width + IFC line-box」，给未来 session
精确指针。
