============================================================
1. 问题发现（R504 引入的回归，self-source 假通过掩盖）
============================================================

R504 的全局 positioned-descendant 延迟把 positioned 后代上提到最近 scope
祖先（positioned 元素或根）。但 opacity<1 元素**不是 scope**（CSS3 SC 触发器
未纳入 creates_stacking_context），故其 positioned 后代被上提到祖先的图元
范围之外。paint_node 末尾对 [counts_before, now] 应用的 opacity 漏掉它们
→ opacity:0 不再隐藏 positioned 后代内容。

实证（css/CSS2/stacking-context/opacity-change-parent-stacking-context.html）：
  结构: <div abspos lightblue> > <div #target opacity:0> > <div lightgray position:relative>
  期望: #target opacity:0 → lightgray 隐藏（test）；ref opacity:1 → lightgray 可见
  R504 实测（PIL）: test lightgray=2500（可见！bug）= ref lightgray=2500 → 0.00% self-source PASS（假通过）
  ★ chromium: test opacity:0 → lightgray 隐藏 → 与 ZeroWeb-test 大差异（chromium FAIL）

R504 A/B（+7/0）未捕获此回归，原因：
  (a) stacking-context 目录不在 R504 的 12 个 A/B 目录内；
  (b) self-source 0.00% 看似「通过」而非回归（DC-14 假通过）。

============================================================
2. 根因机制
============================================================

painter paint_node 末尾对节点子树图元应用 per-node 效果（opacity/filter/
transform/mask/blend），范围 [counts_before, now]。R504 把 positioned 后代
上提到最近 scope 祖先——若中间祖先（如 opacity 元素）非 scope，后代被绘
到祖先范围之外，per-node 效果漏掉它们。

CSS 正确性：opacity<1（CSS3）/ transform≠none / filter≠none / mask /
mix-blend-mode≠normal / isolation:isolate 均**建立堆叠上下文**，即应为
scope，包含其 positioned 后代。

============================================================
3. 修复（最小、针对已确认 bug）
============================================================

代码-guidelines §2（最小、不投机）：仅修已确认的 opacity 回归。transform/
filter 等同机制缺口（per-node 效果同样被 R504 上提破坏）但被其自身 M7 渲染
缺口掩盖（TransformPrimitive/Filter 渲染未完整），未单独确认 → 留作 follow-up。

修改 1 — crates/layout-engine/src/engine.rs:733 creates_stacking_context:
  原: positioned && z-index:Integer
  新: (positioned && z-index:Integer) || opacity < 1.0

修改 2 — crates/engine/src/paint/painter/mod.rs:619 is_scope:
  原: self_positioned || is_root_scope
  新: self_positioned || box_node.creates_stacking_context || is_root_scope
  （self_positioned 已覆盖所有 positioned；新增覆盖 = opacity<1 非 positioned 元素成为 scope）

修改 3 — crates/engine/src/paint/painter/mod.rs collect_positioned_descendants:
  in-flow 子节点若 creates_stacking_context（opacity 等）→ 不下钻（scope 屏障）。
  避免 double-collect：否则父 scope 经 in-flow opacity 元素下钻会重复收集其
  positioned 后代，与 opacity 元素自身 scope 重复绘制。
