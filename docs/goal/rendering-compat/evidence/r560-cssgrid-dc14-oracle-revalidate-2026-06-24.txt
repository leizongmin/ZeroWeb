================================================================================
裁决：-3 非代码回归，是 near-miss 带 jitter + 1 新分母案
================================================================================

★ **-3 chr<1% 非代码回归**，由两个良性因素主导：

1. **near-miss 带 jitter（主因）**：9 case 落在 1.05%-1.43%（刚过 brittle 1% 阈值）——
   grid-item-percentage-quirk-001/002(1.21%×2) / grid-with-aspect-ratio(1.05%) /
   anonymous-grid-items-001/002(1.16%/1.18%) / chrome-bug-001(1.09%) /
   grid-flex-spanning-items-001(1.31%) / grid-with-orthogonal-child(1.20%) /
   table-grid-item-dynamic-001(1.43%)。这些 case 的 z_vs_chr 在 R401 时刚低于 1%，
   任一微小渲染 nudge（如 R542 min-content sizing 调整）即推过阈值。1% 阈值在近-miss 带
   本质 brittle——9 case 的 chr<1% 计数对亚百分点漂移极敏感。

2. **+1 新分母案（R551/R552 ref 解析带来的 grid case）**：分母 48→49，新案进入 >5% 带
   （grid-within-flexbox / dynamic-* JS 簇），贡献 >5% 带 6→9 中的 1 案。

3. **>5% 带 6→9 的 +3 全为已知结构性簇**（R538 已文档化，非新缺口）：
   - grid-container-baseline-synthesized-001/003（78.69%×2，baseline 合成）
   - replaced-element-percentage-height-in-grid-nested-in-flex-001/002（8.97%/33.97%，嵌套替换元素）
   - stretch-grid-item-button-overflow（8.17%，form control stretch）
   - nested-grid-item-block-size-001（20.41%，嵌套 grid）
   - table-grid-item-dynamic-003（23.79%，JS-dynamic "document is not defined"）

无新 gross 回归（78.69% ×2 = baseline-synthesis 既有缺口，R538 documented）。
