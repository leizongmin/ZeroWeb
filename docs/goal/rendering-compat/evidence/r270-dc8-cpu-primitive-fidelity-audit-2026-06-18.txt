## 关键结论

### ① goal doc「CPU 仅 fills+rounded+glyphs（3 图元）」严重 stale

goal doc「已知缺口」表 + DC-8 checkbox 记「CPU 渲染器仅支持 FillPrimitive + RoundedRectPrimitive + GlyphPrimitive」。**实际 CPU 实现 12/13**（9 真实 + 3 近似，仅 blend stub）。这是 M7 render-foundation CPU 扩展完成后 goal doc 未同步更新所致。**DC-8 checkbox 多数实已 loop + 真实/近似实现**，须按真实保真度重评（本轮不改 goal doc，见下「对 goal doc 建议」）。

### ② DC-8（CPU 100% 覆盖）真实状态：远比 goal doc 所示接近完成

- **9 图元真实达标**（fills/rounded/gradients/shadows/images/strokes/path_fills/path_strokes/glyphs）。
- **3 图元近似**（clips 白填/transforms 白填+裁剪/filters opacity 变暗）——覆盖满足但保真度待提（framebuffer 无 alpha 是根因，需 alpha 通道架构才能真确）。
- **1 图元 stub**（blend）——DC-8 真实缺口仅此一项（且 blend 需 source+dest 双图层，非简单补，见 R269）。

→ **DC-8 真实剩余 = blend 实现（stub→真）+ 3 近似提保真**。blend 是唯一「未覆盖」，3 近似是「覆盖但不够准」。goal doc「CPU 仅 3/13」与「DC-8 大面积未做」的印象**错误**。

### ③ 对 DC-9 GPU 的对照（CPU 是 reference，GPU 对齐 CPU）

GPU 现状（master.md header）：9/13 独立 WGSL 管线（shadow/fill/rounded_rect/gradient/image/stroke/path_fill/path_stroke/glyph）。**CPU 已 12/13**。故 DC-9 GPU「对齐 CPU」剩余：
- filters：opacity 已落（R268/f6fed44），blur 同模式可落（R269 sound），其余 filter 子类后续。
- clips / transforms：CPU 有近似参考（白填 quirk），GPU 可 ping-pong 复刻近似（须对齐 quirk，R269）。
- blend：CPU stub → GPU 无参考，须 CPU+GPU 双端从零（R269，大特性）。

→ DC-9 GPU 对齐 CPU 的**最实质缺口仍是 blend**（CPU 也没做）；clips/transforms 可复刻 CPU 近似；filters 正推进。这与 R268/R269 一致。
