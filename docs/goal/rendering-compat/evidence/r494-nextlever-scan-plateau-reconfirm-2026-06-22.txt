## 3. normal-flow 百分比高度簇（核查 min-height-percentage-003/max-height-104）

- `min-height-percentage-003`（98%）：`html,body{height:100%;bg:red} p{min-height:100%;bg:green}`——p min-height:100% 应填满视口（绿遮红）；ZW 96% 红 = min-height:100% 未解析（百分比 min-height 需 CB height 定，body height:100%→视口链）。**§10.7 百分比 min-height + §10.5 百分比高度链 complex，非 clean**（耦合 R491 画布红 + 百分比解析）。
- `max-height-104`（32%）：`max-height: inherit`（inherit 关键字 on max-height）——窄边缘，中等复杂。
- 裁决：**百分比高度/min-height 簇 = §10.5/§10.7 complex，非单点 clean**（R492 §2 normal-flow dismissal 复核成立）。

## 4. selectors-002（`* { background: green !important }`，92% POLLUTED）

- 测试：`* { color:white; background:green !important } p { color:yellow; background:red }` → 应全绿。
- 像素：oracle 100% green / ZW test 92% white + 8% green（仅 p 区绿）/ 0% red 0% yellow。self-PASS（ZW test==ZW ref 0.00%）= POLLUTED（同源假通过）。
- **`*` universal selector 已实现**（`matcher/mod.rs:144 TypeSelector::Universal => true`，单测 `test_matches_universal_selector`）→ matcher 匹配 OK。
- 故 `* { background }` 未覆盖画布的根因在**下游**：cascade 应用到 html？background 简写展开？R491 画布传播读 html.background_color？——**未确认**（须 build 调试，本轮并行 agent 未提交 converter 阻塞 build）。
- **leverage**：114 CSS2 文件用 `*` 选择器，但多数是 `*{box-sizing}` reset 非 background-canvas；selectors-002 是孤例 POLLUTED。**潜在 clean gap 但低 leverage + 根因未确认**，记录待 build 解封后查。

## 5. content-048（`content: attr(bgcolor)` + `<body bgcolor>`，100%）

- 测试：`body:before{content:attr(bgcolor)}` + `<body bgcolor="#ffff00">`。
- 像素：oracle 100% **yellow**（`<body bgcolor>` → background-color 黄，铺画布）/ ZW test 100% white。
- **根因**：ZeroWeb **未实现 HTML 表现属性 → CSS 映射**（CSS2 Appendix D / §15 presentational hints）——`body bgcolor="#ffff00"` 应映射 `background-color:#ffff00`（+ R491 画布传播黄）。codebase grep `bgcolor|presentational` **零命中**（clean 未实现）。
- **次要根因**：`content: attr(X)`（R487 仅实现 content:String，未覆盖 attr()）。
- **leverage**：CSS2 wpt-data 用 `bgcolor=` 仅 **2 test 文件**（低 reftest 杠杆）；但 HTML 表现属性（bgcolor/text/link/vlink/alink/align/background）是 CSS2 App D 正式 feature（DC-2 范围），且**产品 smoke 旧页可能用 bgcolor**（潜在 DC-13 相关）。clean 但低 reftest 杠杆。
