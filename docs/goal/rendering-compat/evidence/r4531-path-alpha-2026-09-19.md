- 日期：2026-09-19（R4531 C 小轮——R4530 下轮方向②）
- 谱系：CPU 光栅器 alpha 合成族（R4530 stroke 修复的域内收口）。

## 实现（zero-render-foundation cpu/stroke.rs）

1. `render_path_fill`：`color.a == 0` 早退（全透明路径填充不绘制——旧行为
   set_pixel 硬编码 alpha=255，transparent → 不透明黑多边形盖背景）；填充循环
   改 `stroke_pixel`（不透明直写旧行为、半透明 `blend_pixel` 合成）。
2. `render_path_stroke`：`color.a == 0` 早退；`render_thick_line` 像素写入改
   `stroke_pixel`。
3. 至此 CPU 光栅器 alpha 家族全部收口：fill（既有）、rounded_rect（既有）、
   StrokePrimitive（R4530）、PathFill/PathStroke（本轮）；GPU mesh 顶点色带 alpha
   走管线标准混合，无此 bug。
