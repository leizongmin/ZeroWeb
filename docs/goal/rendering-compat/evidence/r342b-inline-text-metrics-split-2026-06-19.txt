动作（纯移动）
--------------

`crates/layout-engine/src/inline/text_metrics.rs`（229 行）：

  - 常量 DEFAULT_FONT_SIZE / NORMAL_LINE_HEIGHT_RATIO
  - estimate_char_width / estimate_string_width（字符/字符串宽度估计）
  - AdvanceSource trait + EstimateAdvance 默认实现
  - is_cjk_character / is_emoji_character（字符分类）
  - resolve_font_metrics / resolve_inline_block_dimension（字体度量/尺寸解析）
  - bidi_reorder（BiDi 重排序）

API 保持（零调用点改动）：
  - `inline/mod.rs` 加 `mod text_metrics; pub use text_metrics::*;`（glob 再导出）。
  - `DEFAULT_FONT_SIZE`/`NORMAL_LINE_HEIGHT_RATIO` 被 inline/mod.rs 的 `impl InlineFormattingContext`
    广泛使用——经 glob 再导出保持作用域（inline/mod.rs 内 bare 引用不变）。
  - 外部调用方（intrinsic_sizing.rs、inline_finalization.rs 经 `crate::inline::estimate_char_width`/
    `resolve_font_metrics`）路径不变（pub use 再导出）。
  - `LineHeightValue`（第三方类型，随 resolve_font_metrics 移走）在 text_metrics 内 `pub use`
    再导出，经 `pub use text_metrics::*` 链传到 inline，供 inline/tests 子模块经 `super::super::*`
    glob 访问（与其余类型 LengthValue/ComputedStyle 同源；不用 #[allow]）。

依赖边界：text_metrics 仅依赖 zero_css_parser::LengthValue + zero_style_system::{ComputedStyle,
LineHeightValue} + unicode_bidi（bidi_reorder 局部 use）；不依赖 InlineFormattingContext 主逻辑，
单向干净。
