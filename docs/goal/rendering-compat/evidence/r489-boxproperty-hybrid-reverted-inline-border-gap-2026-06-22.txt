# R489 — box-property hybrid 注入尝试 + 回退；真根因 = inline-element border 不渲染（更广缺口）

**日期**: 2026-06-22
**前置**: R488 诊断 box-property 伪元素 24 案不渲染（build_subtree 非 flex/grid 块仅处理元素子节点，文本节点无盒）。
**目标**: 实现 hybrid 注入（盒属性伪元素→inline 元素+文本子节点承载 border/bg；纯文本→文本节点不变）以修 box-property 局限。

## 1. hybrid 实现（已回退）

`engine/pipeline.rs` inject_pseudo_text_nodes 增 `pseudo_has_box_decoration`（任一边 border-style≠None 或 background_image 非空）→ 盒属性伪元素注入为 `<span>` inline 元素 + 文本子节点（元素路径承载 style 的 border/bg），纯文本保持文本节点注入（R487 行为零回归）。+ 单测 `inject_box_property_pseudo_as_element`。make test 12287/0（R487 12286 + 1 hybrid 单测）零回归。

## 2. 实证：hybrid **未达成 border 目标** → 回退

re-dump generated-content（REFTEST_DUMP=1 REFTEST_DUMP_PASS=1 reftest-upstream，test-guard 包裹）+ cross-validate：

- generated-content chr<1% **83/211=39.3%**（R487=82/211=38.9%，+1 噪声）。
- **关键反证**：`after-inheritable-002`（`div:after{border-color:orange;border-style:solid;content:'PASS PASS'}`）橙边框 **仍缺失**——PIL 实证 ZeroWeb(hybrid)=**0 orange pixels** vs chromium=768。hybrid 注入的 inline `<span>` 元素**没有渲染 border**。
- 案例从 7.20%(base)→3.69% 的改善来自 **文本内容渲染**（span 内文本经 IFC 出现），**非 border**。
- chr<1% +1（`before-after-positioned-004` 2.89→0.85 pass）**不能归因 hybrid**——可能是 R487 文本注入所致（无 R487 逐案基线对比），且该案未必有盒属性。

## 3. 真根因：inline-element border 不渲染（更广缺口，非伪元素独有）

hybrid 把盒属性伪元素做成 **inline-display 元素**（::before/::after 默认 display:Inline），但 **ZeroWeb 不渲染 inline-display 元素的 border** → border 仍缺失。证据：
- after-inheritable-002 的 inline `<span>` border 不渲染（上述 0 orange pixels）。
- 对照：borders 子目录 chr<1% **72.7%**（block 级 border 渲染良好）+ `border-applies-to-009`(block) 0.72% pass；但 `border-applies-to-008`(**inline**) 缺失于 R484 数据（missing-ref skip，174 scoping artifact 之一）。
- **推断**：ZeroWeb 渲染 block 元素 border，但不渲染 inline-display 元素 border（border-applies-to-008 inline 案是关键验证缺口，须补 dump 证实）。

**这把 box-property 局限重新归因**：非「伪元素盒属性无处挂载」（R488 表层），而是 **ZeroWeb inline-element border 渲染缺口**（更广，影响 border-applies-to-008 + 任何 inline 元素 border，不止伪元素）。修 inline-element border 渲染会同时帮 border-applies-to-008 与盒属性伪元素。

## 4. 裁决：回退 hybrid（code-guidelines #1/#2）

hybrid 注入**未达成 border 目标**（inline border 不渲染），+1 不可归因且为噪声，~24 生产行+40 测试行复杂度无对应收益 → **回退**。`git checkout HEAD -- crates/engine/src/pipeline.rs` 恢复 R487 文本节点注入（已验证 12286/0）。R487 伪元素文本内容渲染**保持有效**（94.5% 纯文本伪元素正确）。

**伪元素状态总结（R485-R489）**：::before/::after **文本内容渲染完成+正确**（4 子系统 R486-R487）；盒属性伪元素 border 受 **ZeroWeb inline-element border 渲染缺口**阻塞（非伪元素独有，须修 inline border 渲染，更广 lever）。
