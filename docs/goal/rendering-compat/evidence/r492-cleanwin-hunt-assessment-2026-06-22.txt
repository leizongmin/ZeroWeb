## 4. 关键发现：R491 暴露 latent `position: fixed` 覆盖缺口（6 案）

**6 positioning 回归全是 `position: fixed` 全 inset 覆盖测试**（abspos-containing-block-001~006）。代表 case `positioning/abspos-containing-block-001.xht`：

```css
body { background: red; margin: 100px 100px; }
div { background: white; position: fixed; top: 0; right: 0; bottom: 0; left: 0; }
<!-- div 应覆盖整个视口（800×600），遮住 body 红；"no red" 为通过 -->
```

**像素实证（800×600）：**

| 图 | white% | red% | 解读 |
|----|--------|------|------|
| ORACLE（chromium test） | 99.8% | 0.0% | fixed 白 div 覆盖红画布 → 全白（spec 正确） |
| ZW test（post-R491） | **2.4%** | **97.4%** | fixed 白 div 仅 ~11194px（2.3% 视口）未覆盖，红画布透出 |
| ZW ref（post-R491） | 99.8% | 0.0% | ref 渲染全白（匹配 oracle） |

**机制（已确证）**：
1. R491 把 body 红（html 透明）传播到画布 → 画布红（**spec 正确**，chromium 同样传播）。
2. ZeroWeb 的 fixed div `top/right/bottom/left:0` **未 stretch 到 CB**（§10.3.18：全 inset 定义时 width=CB−left−right=800），渲染为**固有尺寸 ~2.3%** 而非 800×600 → 红画布透出。
3. **Pre-R491 此 bug 被「白画布」掩盖**：画布白 + 过小白 div = 全白，恰好匹配 oracle 全白 → 0.42% PASS。R491 把画布变红后，过小 div 暴露红 → 97.84% FAIL。

**性质裁决**：
- R491 本身 **spec 正确，不应回退**（修了 8 案真实画布传播缺口，含 backgrounds + abspos 两大簇）。
- 6 回归**非 R491 引入的 bug**，而是 R491 **暴露的 latent `position: fixed` 全-inset stretch-sizing 缺口**（CSS §10.3.18/§10.6.4：abspos/fixed 全 inset 定义时 width/height 应 = CB − insets，ZeroWeb 落到固有尺寸）。
- 此缺口属 **R98/R124 abspos-inset taffy-bound 谱系**（master.md 已 ruled out 单会话 clean fix；position:fixed 经 R324 `adjust_fixed_to_viewport` 接 viewport，但 width/height stretch 仍缺）。
- **若修此 stretch 缺口**：6 positioning 案将翻回 PASS，R491 净变为 +7（8 improved − 1 borders/gc 噪声）。故 R491 + stretch 修复 = 真实净正向；R491 standalone = net −1（因 latent bug 未修）。

**给代码 agent 的建议**：定位 fixed/abspos 全-inset width/height 计算（converter 或 engine abspos sizing），用 `LAYOUT_DUMP=1` 跑 `positioning/abspos-containing-block-001` 确认 div 尺寸（预期 ~2.3% vs 应 100%）。修复后 6 案翻 PASS + R491 净正。

## 5. 结论与方向调整

1. **R491 标称纠正**：R491 非「R484 后首个净正向 chr<1% win」；全量 CSS2 实测 **net −1 chr<1%**（8 improved / 9 regressed）。targeted backgrounds +2 测量误导（未捕获跨簇回归）。**R484 后 net-positive chr<1% streak 仍未破。**
2. **R491 保留**：spec 正确，修 8 案真实画布传播缺口（backgrounds + abspos），不应回退。
3. **新 lever（代码 agent）**：latent `position: fixed` 全-inset stretch-sizing 缺口（6 案），R98/R124 taffy-bound 谱系；修后 R491 净正 +7。
4. **plateau 再确认**：R491 是 R484 后唯一接近正向的 round（spec 修复 8 案），但 strict chr<1% 仍 flat。其余 huge-diff 全 M7/JS/结构性/精度，无 clean missing-feature（§2）。
