R533 — table-cell (td) position:relative inset 应用（CSS-position-3）
==============================================================================
日期：2026-06-23
类型：code-side CSS-correctness fix（layout-engine table.rs）
状态：LANDED（css-position net +2 PASS / 0 回归；css-tables 0 flip）

承接
----
R532 后扫其它目录找 clean lever。css-position 64.2%（61/95），聚类
position-relative-table-{td,tr}-{top,left}（4 案均 1.04%）= position:relative 在
table-internal 元素上的 inset 应用。dump 定位 td 分支。

根因
----
LAYOUT_DUMP（position-relative-table-td-top）：td.relative（top:100px）abs_y=8（应 108），
inset 完全未应用。

table.rs `position_cells` 对每个 cell 设 `cell_box.x = cell_x; cell_box.y = 0.0;`，
但**不应用 cell 自身的 position:relative inset**。对比：行（tr）在 line 1638 有
`row_rel_dx/dy = resolve_length_inset(row_box, ...)` 并 `row_box.y = local_y + row_rel_dy`；
行组（tbody）在 update_row_group_positions（2021）同理。**唯独 table-cell（td）漏了**。

机制：table-internal 元素（td/tr/tbody）由 table.rs 自定义布局定位，不经 taffy 正常流，
故 taffy 的 relative-inset 应用（layout.location 仅对正常流 block 生效）不到它们。
行/行组已在 table.rs 显式应用 inset，cell 漏了。

修复（table.rs position_cells，~7 行，镜像行/行组处理）
--------------------------------------------------------
设置 cell 位置处加 cell 自身 relative inset：
  let (cell_rel_dx, cell_rel_dy) = if cell_box.is_relative {
      (resolve_length_inset(cell_box, styles, true),
       resolve_length_inset(cell_box, styles, false))
  } else { (0.0, 0.0) };
  cell_box.x = cell_x + cell_rel_dx;
  cell_box.y = cell_rel_dy;
（resolve_length_inset 读 style.left/top 的 Px 值，已存在用于行/行组。）
