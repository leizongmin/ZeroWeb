R511 — CSS §9.7 display 转换：table-internal + float → block（部分修复）
日期: 2026-06-23
承接: R510 后续扫 floats-clear（118/214，96 fail）。float-applies-to-001/002/003/004/007
      共享 13.76% diff → 同因。

============================================================
1. 缺口
============================================================

CSS 2.1 §9.7：float 不适用于 table-internal display。float!=none 时
table-row-group / table-header-group / table-footer-group / table-row /
table-column / table-column-group / table-cell 的**计算 display 变为 block**
（元素脱离表格结构成为浮动块）。

ZeroWeb 无 §9.7 处理——`float: right` on `display: table-row-group` 原样应用
（元素仍是 table-row-group，填满表格）。float-applies-to-001 实测：#test 蓝
x=[8,791]（满宽）count=75264；ref 蓝 x=[696,791]（右侧浮动块）count=9216。

============================================================
2. 修复（style-system/lib.rs compute_element_style_internal 步 8，~15 行）
============================================================

post-cascade adjustment（quirks 之后、return 之前）：
```rust
if float != None && display ∈ {TableRowGroup, TableHeaderGroup, TableFooterGroup,
   TableRow, TableColumn, TableColumnGroup, TableCell} {
    display = Block;
}
```

仅 table-internal（不含 table 本身——§9.7 table+float 保持 table 浮动；不含
table-caption——可浮动；不含 inline-table——→table）。position:absolute/fixed
的 float→none 是独立 §9.7 规则，未纳入（float-applies-to 用 static position）。

4. 裁决：LAND（部分修复，§9.7 style-layer 正确）
============================================================

★ §9.7 display 转换是 **style-layer 正确**实现（table-internal+float 的计算
display 确为 block）。残余 4.43% diff 非 §9.7 缺陷，而是**独立 layout gap**：
#test 转 block 后仍**未被浮动**（block 在 table 内填满宽，而非右侧浮动块）——
float 定位（adjust_float_positions）对 table 子元素不生效。修此须 table+float
布局交互（table layout 须把 block+float 子元素按浮动处理），独立复杂 lever。

★ 0 self-source 翻转但**真实 diff 大降**（13.76→4.43，blue 75264→15775 趋 ref 9216，
70% 降幅），DC-14 真实改善（区别 R502 zero-像素-yield revert）。R507 先例（land
0-flip diff-reduction correct fix）。§9.7 是正确的第一步——待 float-in-table
layout gap 修后，display 转换已就位，这些测试将自然趋近通过。

caveat：float-applies-to-007（display:table+float）未修——table+float 应保持
table 浮动（§9.7 table 不转 block），须 table 浮动布局（独立 gap）。
