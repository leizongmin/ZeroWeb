═══════════════════════════════════════════════════════════════
真根因（本轮 paint 存储片段探针实证）：float 排除未传播到 inner-div 的 IFC
═══════════════════════════════════════════════════════════════
DOM 结构：div1(orange,300×200) > [ div2(float:right,100×100) , inner-div(block,"X X X") ]
div2 与 inner-div 是 **兄弟**（同为 div1 的子），非父子。

paint_text use_stored 探针（IFC9_PAINT_PROBE，已回退）实测 inner-div 存储的 IFC：
  line[0] y=0   h=100 frags=[x=0   fs=100 t="X", x=200 fs=100 t="X"]   ← line 1 = "X X"（2 个 X）
  line[1] y=100 h=100 frags=[x=0   fs=100 t="X"]                       ← line 2 = "X"（1 个 X）

**line 1 有 2 个 X（x=0 和 x=200），说明 line 1 用了满宽 300px——float 未被排除**。
（行高 h=100 正确，line.y=0/100 间距正确 → R355 多行存储 + paint line.y 工作正常。）

机制：
  - inner-div 是 block，有自己的 IFC；其直接子只有文本节点，**无 float 子** →
    compute_final_inline_layouts / remeasure_text_with_float_exclusions 收集 exclusions 时
    `box_node.children` 不含 div2 → exclusions 空 → inner-div IFC 不排除 float。
  - div1 直接子是 div2(float)+inner-div(block)，均为块级，div1 无直接 inline 内容 →
    div1 不存储 IFC；paint 渲染 inner-div 的存储布局（无 float 排除）。
  - 故 "X X X" 在 inner-div IFC 按满宽 300px 排版：line1="X X"(X+sp+X=300)，line2="X"。

为何 diff 仅 2.08%（看似 float 在 line 1 生效）？**巧合**：line 1 的第 2 个 X 在 x=200-300，
恰被 div2 float（blue，top-right x200-300 y0-100）**绘制覆盖**——视觉上 top 行 = [blue X][orange][blue float]
与 REF 一致，但第 2 个 X 实际存在只是被 float 盖住。line 2 仅 1 个 X（x0-100），x200-300 无文本
= orange，REF 要 blue → 唯一 diff = 右下 100×100。

CSS 规范要求：float 会 **侵入（intrude）** 同一 BFC 内未建立自己 BFC 的后代 block 的 line box。
inner-div 不建立 BFC（普通 block），div2 float 应缩短 inner-div 的 line 1 宽度到 200px →
line 1 仅容 1 个 X，line 2（float 下方）满宽 300px 容 "X X"。ZeroWeb 当前不实现此跨 block
float 侵入 → ifc-009 错。

为何不在本轮修复（裁决：float 跨 block 侵入 = 架构性，多会话）
═══════════════════════════════════════════════════════════════
修复 = 让 inner-div 的 IFC 收集 **祖先 BFC 内垂直重叠的 float**（intruding floats），需：
  (1) 自底向上遍历 layout tree 找祖先 float（建立 BFC 的祖先为止）；
  (2) 把祖先 float 的几何换算到当前 box 的相对坐标（y 减去 box 在祖先内的偏移）；
  (3) 加入当前 box IFC 的 exclusions。
此与 R355 float guard（multicol-fill-auto-001 ref 用 float div 模拟列，浮动容器保 R84 单行）
反向依赖墙耦合——扩大 float 排除范围可能打破该 guard 的 test/ref 对称。属 M4「完整 float 布局」
/ Phase A 所有权分裂（文本 IFC 拥有者 ≠ float 容器）架构工作，单会话高回归风险，defer。
