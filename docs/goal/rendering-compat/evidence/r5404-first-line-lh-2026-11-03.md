### 1.1 案面语义

- test 页：`div:first-of-type::first-line { line-height: 0px; color: purple }`，
  div 行高 40px，首行文本 + `<br>` + 次行文本。
- ref 页：首行包进 `<span>`（同款声明直接命中 inline 盒），其余全同。
- 断言（CSS Pseudo-4 §first-line-styling）：`::first-line` 生成盒行为类似 inline 级
  元素——两块渲染须逐像素相同。

### 1.2 双段根因

**段一（上轮在途稿，布局期）**：`::first-line` 伪样式的 line-height 位在布局期无消费
——容器直接文本 run 行高恒取容器/继承值，首行域 run 与 ref 页 span 变体 run 不同槽
同值。

**段二（本轮取证，paint Path B）**：在途稿修掉段一后案面仅 ✗1.89%→✓0.44%（近似通过，
非真通过）。REFTEST_DUMP PNG 双页量化 + 临时布局探针〔用后即删〕定谳：

- 布局层两变体已一致（span 变体与 ::first-line 变体 IFC 行盒完全同构：L0 h=20
  baseline=16.8 / L1 y=20 h=40 baseline=26.8）。
- 渲染层 test 页 block 1 两行整体下坠（首行字形顶 +17 vs ref +7、次行 +57 vs ref
  +37），块高不变——**paint Path B 重装配以次行行高渲染了首行**。
- 根因：`LayoutBox.text_node_line_heights`（节点键，`frag.height` 逐 run 存储）经
  `build_text_parent_override_map` 重键为「父元素 → 值」喂给 paint IFC 的
  `line_height_overrides`（R2189 父键约定）。003 案首行 t1（lh 0）与次行 t2（lh 40）
  同父 div → 父键塌缩后写覆盖 = `{div: 40}`，paint Path B（空 styles）重跑 collect
  时两个 run 都取 40 → 首行行盒 40（字形下坠 (40−20)/2 = 10px）+ 次行 y=40（再坠
  10px，溢出底边框）。父键粒度在案时无损的前提是「同父文本节点同值」——::first-line
  首行域首次引入同父异值（003 案 PNG 实测与「两行全按 40 重装配」模型逐像素吻合）。

存储路径说明：Path A（`compute_final_inline_layouts`，真实 styles）有 store 门 =
纯 Ahem 才存；003 案默认字体 → 拒存 → paint 走 Path B（空 styles 重跑 IFC），命中
父键塌缩。

## 2. 修复（三处单点）

1. **collect_items.rs（上轮在途稿，本轮复核保留）**：容器直接文本 run 的行高在首行域
   （首个强制断前）取 `::first-line` 伪样式解析行高。激活门四重：kill-switch
   `ZW_FIRST_LINE_LH`（default-on）+ 有真实 styles（Path B 空 styles 走 override
   传导臂）+ 容器为块容器（CSS Pseudo-4 仅块容器生效）+ 伪样式 font-size 与容器一致
   且解析行高不同（字号域差异属切片 3b——001/002 伪样式含 font-size，仅施行高会全段
   错置）。域终止：`<br>` / FloatAnchor（R3784 断行语义同 BlockBreak）/ BlockBreak。
   已知边界（FIXME 记账）：嵌套 inline 子树走 R4300 扁平化等独立路径（切片 3b）；
   首行软折时伪样式只应施首个视觉行，本切片施整域（断行期第 0 行成员判定）。

2. **inline/mod.rs + collect_items.rs（本轮，Path B 传导缺口）**：IFC 新增
   `text_node_line_height_overrides: NodeIdMap<f32>`（节点键）+ builder
   `with_text_node_line_height_overrides`；Path B 行高覆盖查询**节点键镜像优先、
   父键回退**——同父异值场景逐 run 精确恢复，空表时逐字节回退既有父键行为（未注入
   路径零扰动）。数据复用既有 `frag.height → store_font_sizes_from_ifc →
   text_node_line_heights` 链路（U1b 谱系），不新增存储。

3. **painter/text.rs（本轮，注入点）**：paint Path B builder 注入
   `box_node.text_node_line_heights.clone()`（不经 `build_text_parent_override_map`
   父键塌缩）。与 `ws_overrides` / `glyph_verticals_overrides` / `ascent_ratio_overrides`
   同型先例一致：节点键通道仅 paint Path B 注入，Path A（真实 styles，覆盖臂不可达）
   不携带。kill-switch 共用 `ZW_FIRST_LINE_LH`（关断后同父异值源消失，镜像自动失活，
   无需独立 env）。
