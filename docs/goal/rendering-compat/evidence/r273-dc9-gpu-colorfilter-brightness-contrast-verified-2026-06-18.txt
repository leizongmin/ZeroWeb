## 核实：GPU fs_color_filter == CPU apply_filter（全源码闭合）

GPU `COLOR_FILTER_SHADER::fs_color_filter`（pipeline.rs:426-440）按 `uniforms.mode` 分派：
```wgsl
let c = textureSample(src_texture, src_sampler, in.uv);
let p = uniforms.param;
if (mode < 0.5) {              // opacity
    let a = max(0.0, min(1.0, p));
    return vec4f(c.r*a, c.g*a, c.b*a, 1.0);
} else if (mode < 1.5) {       // brightness
    return vec4f(c.r*p, c.g*p, c.b*p, 1.0);
} else {                       // contrast
    return vec4f((c.r-0.5)*p+0.5, (c.g-0.5)*p+0.5, (c.b-0.5)*p+0.5, 1.0);
}
```

CPU `apply_filter`（effects.rs）参考：
- Brightness（:42-54）：`(RGB as f32 * amount).round().clamp(0,255)`，alpha=255。
- Contrast（:60-72）：`((RGB as f32 - 128.0) * amount + 128.0).round().clamp(0,255)`，alpha=255。
- Opacity（:133-148）：`RGB *= amount`（R268/R272：RGB 变暗近似）。

**逐项对齐**：
| 滤镜 | GPU | CPU | 对齐 | 性质 |
|------|-----|-----|------|------|
| opacity | RGB*clamp(amt,0,1) | RGB*amt | ✓ | 近似（RGB 变暗，非真 alpha 合成，R268/R272） |
| brightness | RGB*amt | RGB*amt | ✓ | **正确 CSS 语义**（filter:brightness = RGB*amount，amt 可 >1，硬件写钳 [0,1]） |
| contrast | (RGB-0.5)*amt+0.5 | (RGB-128)*amt+128 | ✓ | **正确 CSS 语义**（filter:contrast = (RGB-0.5)*amt+0.5） |

→ **brightness/contrast 是真实 CSS filter 语义（区域 RGB 数学），非近似**——比 opacity（RGB 变暗近似真合成）更正确。mode-dispatch 单通道 color-filter 通用化 **SOUND**（三者都是区域单通道 RGB op，同一 ping-pong scissor 后处理管线复用合理）。

## 关键结论

1. **fc86937 前提 SOUND**：GPU color-filter pipeline 正确复刻 CPU opacity/brightness/contrast 语义，CPU/GPU 对齐（DC-9 对这三 filter 子类覆盖 + 对齐满足）。
2. **brightness/contrast 非「opacity 同近似」**：它们是 CSS filter 的**正确实现**（RGB*amt / (RGB-0.5)*amt+0.5 就是规范语义），不同于 opacity 的 RGB 变暗近似（opacity 因 framebuffer 无真合成 / post-process 无法恢复背景才近似，R272）。故 DC-9 brightness/contrast 是**真覆盖**，opacity 是**近似覆盖**。
3. **可同模式扩展**：CPU apply_filter 还有 grayscale/invert/saturate/sepia/hue-rotate（effects.rs:78-190）——均为区域单通道 RGB op，可同 color-filter pipeline 加 mode 扩展（sound 同模式，区别于 blur 需邻域采样 / blend 需双图层）。

## 微差（可忽略，非 premise flaw）

- **contrast midpoint**：GPU 用 0.5（normalized f32），CPU 用 128.0（u8 [0,255]，=128/255≈0.50196）。差 ~0.2% midpoint → 对比度输出微差 <1 level，reftest 容差内。
- **rounding**：CPU `.round()` 后写 u8；GPU f32 计算后硬件写钳。亚 u8 级，容差内。
（同 R268 opacity 的 amount-clamp/rounding 微差谱系，均非 premise flaw。）

## 对优先级队列的影响

- DC-9 GPU filter 覆盖推进：opacity（f6fed44）→ brightness+contrast（fc86937 color-filter pipeline）。**剩 blur/transform/blend**（R269：blur sound 同模式但需邻域采样、transform 近似、blend stub）。
- color-filter pipeline 为 grayscale/invert/saturate/sepia/hue-rotate 提供现成 sound 扩展路径（区域 RGB op，加 mode 即可）。
- 不改变「DC-9 active forward motion」；细化：filter 子类（opacity/brightness/contrast + 可扩 6）= sound 同模式集群，blur/transform/blend 各异。
