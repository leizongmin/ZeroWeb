================================================================================
根因
================================================================================
ZeroWeb border-color 既不正确初始、也不解析 currentColor：
  (a) border-*-color 初始值 = Rgba(0,0,0,255) 黑（default_impl.rs + registry.rs），
      违反 CSS §8.5.1（initial = currentColor）。
  (b) color_value_to_render(ColorValue::CurrentColor) => 黑（paint/color.rs:12），
      无元素上下文，从不解析为元素计算 color。

后果：
  - `border: solid`（无显式色）在彩色文本元素上渲染黑边框（应取元素文本色，同 Chromium）。
  - border-color-011：`.inner { border-color: inherit }` 继承的是**已解析黑值**而非
    currentColor 关键字 → 黑边框（应绿，因 .inner color:green）。
  - shand-border-000：`border: medium solid` 简写重置 border-color 到 initial，
    旧=黑 → 黑边框（应绿）。

CSS 正确语义：currentColor 作为关键字经层叠/继承保留（CSS-Color §resolving），
paint 时解析为「当前元素 color 属性使用值」。

================================================================================
1. style-system/default_impl.rs + registry.rs：border-*-color 初始 0,0,0,255 →

   converter 在 R549 fix2 把 style=none 时 width 抑制为 0）。
2. engine/paint/painter/border.rs：paint_borders 把 4 条边框颜色经新 helper
   resolve_border_current_color 解析（currentColor → style.color），再交 paint_border_edge。
   collapsed border override 路径同样覆盖（collapsed_border_color 后再 resolve）。

   回落黑；需正确解析的调用点须先替换（border.rs 已替换）。

+ 新单测 resolve_border_current_color（border.rs #[cfg(test)]）：currentColor→元素 color、
  非 currentColor 原样返回。
