================================================================
前提核对：transform/filter/blend 是真缺口（非 clip 式 no-op）
================================================================
R220 证 ClipPrimitive 生产路径从不生成（add_clip 0 处非测试调用）= no-op。
本轮核对 transform/filter/blend 相反——**三者在生产 paint_node 真生成**：
  - apply_backdrop_filter  painter/mod.rs:383
  - apply_filter           painter/mod.rs:697  → add_filter（FilterPrimitive）
  - apply_transform        painter/mod.rs:705  → helpers::apply_transform → add_transform（TransformPrimitive）
  - apply_blend_mode       painter/mod.rs:730  → add_blend_mode（BlendModePrimitive）
故 R249 spec 前提成立：filter/transform/blend 由 paint 生成、GPU 静默丢弃 = 真缺口
（区别于 clip 的 no-op）。Transform 注：translation 经 apply_transform_offset
（text.rs:673 等）烘焙进坐标，但 a/b/c/d 旋转/缩放/倾斜靠 TransformPrimitive，GPU 丢弃→此类变换 GPU 渲染不正确。
