## 3. 归因链（clone/slice ✗1.27）

1. **isolate 门无关证明**：临时移除门① isolate 腿重建 → clone/slice 仍 ✗1.27 → 中间树单次 ✓0.75 为 run-to-run 漂移 flake（R5326/R5327 骑阈先例同型）；两页只含 RLE/LRO 控制符、无 isolate，门①不触达。
2. **旗标关对照（决定性）**：同树 `ZW_PARA_BIDI=0` → ✓0.75 双页稳定；旗标开 → ✗1.27 双页稳定（≥3 次）→ para 路径激活的真阈值骑跨，非 flake。
3. **dump 像素对比**：两态 ref/test 均变（ref 同过 ZW 管线）；ON 态行序整体反转 `[bca][dfe]` → `[dfe][bca]`。
4. **根因**：行级 ② 的反序 run 含**混合 level 片段**时，①（片段内完整 L2，前提「片段即整段」）+ ②（序列反序）复合对片段内字符双重计账——clone-nowrap 的 F2=[2,3,4]（LRO 跨元素）复合 = `[efd][bca]`，全局 L2 真值 = `bcdfea`。
5. **可精确性边界（设计论证）**：一致 level（min==max）片段在 ①+② 下与全局 L2 恒等（F1=[2,2] F2=[3,3] F3=[2,2] → ①各片段内反转 + ②序列反序 = `vubayx` = 全局逐层推演恒等）；混合片段需按 level 拆片段方可精确（= box-decoration-break:clone 拆分能力 FIXME 家族）。**守卫**：② 反序 run 逐成员要求 min==max，含混合成员的 run 维持逻辑序（保守近似，同 isolate 门①哲学）。
6. **修复后**：clone/slice ✓0.75（base parity）；bidi-011 ✓0.15（其片段一致 level，精确 L2 修复不受守卫影响）；counter-styles-102 ✓0.61；bidi-005/006（straddle 守卫页）✓0.95/0.62/0.51 零位移；line-breaking-bidi-001/002/003 ✓0.00。
