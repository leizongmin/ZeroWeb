# R491 — CSS §14.2 画布背景传播实现；backgrounds chr<1% +2，gross failure 修复（R484 后首个净正向 chr<1% win）

**日期**: 2026-06-22
**前置**: R485-R490 伪元素线 precision-limited（box-property border exhausted）；本轮 pivot 到 CSS2 gross-failure clean-win 猎寻，定位 **CSS §14.2 画布背景传播缺失**（非 Phase-A 精度，是 clean 特性缺口）。

## 1. 定位：CSS §14.2 画布背景传播缺失（clean-win，非精度）

CSS2 gross failure（chr>5%）扫描：backgrounds 子目录 31 案，其中 `background-body-001`（97.72%）、`background-root-001`（92.37%）、`background-root-004/005/...`（70-90%）差异巨大 → 强信号「特性完全缺失」非精度。

**根因**：CSS §14.2.3 — 根元素（html）的背景覆盖整个画布（视口）；若根背景透明且 body 有背景，则 body 背景传播到画布。ZeroWeb **未实现此传播**：html/body 背景只绘制在元素自身盒（html 盒可能不覆盖视口高度；body 有 8px margin 不覆盖视口边缘）→ 视口大面积白 → 70-97% diff。

**像素实证**（修前）：`background-body-001`（`body{background:green}`）ZeroWeb corner(8,8)=**白**（body 盒未覆盖视口，画布白）；`background-root-001`（`html{background:green}`）corner=绿但 center=**白**（html 盒不覆盖视口高度）。chromium 整画布绿。

## 2. 实现（`crates/engine/src/paint/painter/mod.rs` + `pipeline.rs`）

- `Painter` 增 `viewport_w/viewport_h: f32`（pub，默认 0.0；测试默认 0→不绘制画布背景，零回归）。
- `paint()` 入口、`paint_node(root)` 前：若 viewport>0 且 doc 可用——取 html 背景色（非透明）；html 透明则取 body 背景色（非透明）；得画布色则 `add_fill(0,0,vw,vh, 画布色)` 先绘制画布背景。
- 根/body 自身背景仍照常绘制（**同色叠加无可见重绘**——画布填充把背景延伸到全视口，元素盒背景在自身区域同色覆盖）。
- pipeline 4 处 `painter.paint()` 前设 `viewport_w/h = self.viewport_width/height`。

**CSS 正确性**：html 背景永远传播到画布（§14.2），故无「不该传播」的回归风险；body 仅在 html 透明时传播。make test **12286/0** 零 Rust 回归。

## 3. 实证：gross failure 修复 + chr<1% 净正向

re-dump backgrounds 子目录（339 案，REFTEST_DUMP=1 REFTEST_DUMP_PASS=1，test-guard 包裹）+ cross-validate：

| 指标 | BEFORE（R484） | AFTER（本轮） |
|------|---------------|--------------|
| backgrounds chr<1% | 188/339 = 55.5% | **190/339 = 56.0%（+2）** |
| `background-root-001` | **92.37%**（gross fail） | **0.87%（pass）** |
| `background-body-001` | **97.72%**（gross fail） | **0.87%（pass）** |

像素验证：两案修后 corner=center=(0,128,0) 全画布绿（修前 corner=白 / center=白）。

**+2 净正向**（vs R490 medium fix 的 −3）：2 个 70-97% gross failure 翻转为 pass。其余 background-root-002+ 未翻转（它们测 background-image/position 等其他特性，画布传播不解决）。画布传播**仅解决 html/body 背景色→画布**这一特性缺口，符合预期范围。
