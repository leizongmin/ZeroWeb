R869 — CSS §8.3.1 min-height 溢出阻止末子 margin collapse-through 穿透父底部
==============================================================================
日期：2026-06-30
谱系：R868 下一步（normal-flow in-scope worst 评估）。R868 列 min-height-106 /
max-width-110 / margin-collapse-min-height-001 三候选；逐一评估后仅 margin-collapse
-min-height 簇为 clean in-scope lever（min-height-106 = scrollbar feature gap；max-width-110
= float shrink-to-fit + replaced max-width，R845 已证 float shrink net-negative 谱系）。

根因（LAYOUT_DUMP 实证）
------------------------
CSS 2.1 §8.3.1「Adjoining margins」：块级元素的上下 margin 仅当其 height 计算为 auto
且 min-height 为零时才 adjoining，从而允许末子 margin-bottom「collapse through」父底部
（父有效下 margin = 末子 margin-bottom）。当 min-height 把块撑到高于其 in-flow 内容时，
末子 margin 不再穿透——父下 margin 回到自身声明值，后续兄弟紧随父。

taffy 0.7 的 CollapsibleMarginSet 未实现此 min-height 细节。复刻 margin-collapse
-min-height-001 实测 ZW 几何：

    div.wrapper   abs_y= 51  h=700  mb=0    ← 应 150
      div.parent  abs_y= 51  h=100  mb=550  ← 应 mb=0（min-height 撑到 100）
        div.child abs_y= 51  h=30   mb=550  ← child 自己 margin，正常
      div.footer  abs_y=701  h=50          ← 应紧随 parent（abs_y=151）

child 的 550px margin-bottom 穿透 parent（parent.mb 从 0→550），footer 被推到
parent_bottom+550=701，wrapper h=700。期望（ref = 100×150 绿块）：parent(100) +
footer(50) 连续 = 150px 绿矩形。

判定性 3 案簇（验证规则精确边界）
---------------------------------
- 001（min-height:100 > content 30）：应阻止穿透 → ZW 旧 10.20%
- 002（min-height:200 > content 30）：应阻止穿透，margin 困在 parent 内 → ZW 旧 4.15%
- 003（min-height:5 < content 30）：min-height 不生效，穿透仍合法 → ZW 旧 1.11%
  （本规则的守卫：min-height_px > in-flow 内容伸展量 才触发）

实现
----
crates/layout-engine/src/engine.rs 新增 `prevent_collapse_through_min_height` 后处理
（compute() 步骤 5.3，在 exclude_floats_from_non_bfc_auto_height 之后）+ 辅助
`in_flow_content_extent`。自顶向下：对每个容器遍历块级 in-flow 子元素，当子元素是
min-height 溢出型（min-height_px > in_flow_content_extent）且 height:auto、非 BFC、
无 bottom border/padding 时，剥离其 margin_bottom 超出自身声明值的部分（=穿透进来
的末子 margin），把该子之后所有兄弟 .y 上移同量，并收紧容器 content_height/height。
仅 Px min-height 触发（百分比保守取 0）。
