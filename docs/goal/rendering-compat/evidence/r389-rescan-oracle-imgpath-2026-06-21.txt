### 根因（6 案共享，结构性）

像素定位 flex-abspos-inset-cross-size-001：ZW-test 绿 = **1×201px 竖条**（img 仅 cross 轴
拉伸到 200px 高，main 轴保持 1px 内容宽）；chromium 绿 = **200×400**（flex 容器更宽）。

根因 = **abspos flex 容器（top/bottom inset 给定 definite height，无 left/right）的宽度解析**：
ZW 按 shrink-to-fit 取内容宽（1px），chromium 取更宽。这是 abspos §10.3.7 + flex
definite-size 交互——R363/R97 已确认为 **taffy-blocked 结构性**（flex sizing 复杂，R304
taffy 升级 DEFER）。**非单会话 clean win**。

3 个 self-pass 案因 test 与 ref 用**同 flex 结构**（两端同 bug）故 self 一致；chromium
正确 → 真实 chr 发散。修复须等 flex definite-size 架构（多会话）。
