R510 — border 简写重复组件值拒绝（CSS 声明合法性）
日期: 2026-06-23
承接: R509 后 fresh lever 扫描（lists/colors 100%；box-display/borders 多为 IFC；

============================================================
1. Bug
============================================================

CSS border 简写（`border` / `border-top` 等）的 width/style/color 各至多一个；
重复组件值使整个声明**非法，必须忽略**（CSS 2.1 §4.1.8 / §8.4 error handling）。

ZeroWeb `parse_border_shorthand`（style-system/shorthand/mod.rs:485）对重复值
**静默覆写**（后者覆盖前者，声明被接受）：
  `border: red solid 16px red`（两个 color）→ color=red 接受 → 渲染红边框。
  shand-border-001 实测：100352 红 px（应 0，「no red」测试）。

============================================================
2. 修复（~15 行，parse_border_shorthand 返回 Option）
============================================================

parse_border_shorthand 改返回 `Option<BorderShorthand>`，每个分类（width/style/
color）首次出现标记 seen_*，**第二次出现即 return None**（声明非法）。未识别 token
仍跳过（保持旧行为，不回归）。

expand_border_side / expand_border_all：`let Some(parsed) = parse_border_shorthand()
else { return vec![] };`——None 时返回空 vec（声明被丢弃，不生成子属性）。

仅拒绝**重复分类**，非重复/未识别 token 行为不变（精准修改，§3）。
