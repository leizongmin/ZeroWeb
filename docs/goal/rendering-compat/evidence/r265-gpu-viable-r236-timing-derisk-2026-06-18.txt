# R265 — 两个去风险发现：GPU reftest 模式在本 WSL 可用 + R236 multicol baseline-export 有时序问题（read-only，docs-only，基线 438/490 持平）

**日期**: 2026-06-18
**模式**: 实证核实（跑 GPU reftest + 读 engine.rs flex baseline 路径），无代码变更
**目的**: 为后续 DC-9 GPU / R236 multicol baseline 工作去风险

## 发现 1：GPU reftest 模式在本 WSL 环境可用（DC-9 GPU 可验证）

实测 `./target/test-guard -- cargo run --bin zero-wpt-runner -- reftest-upstream --gpu baseline-000`：
- **通过（1/1），wgpu adapter 成功初始化，无 Vulkan/GL/backend 错误、无 panic**。
- 命令格式：`zero-wpt-runner reftest-upstream --gpu <filter>`（`--gpu` 是 args[2..] 的全局选项，须在子命令之后；放在 args[1] 会被当 command 报 "Unknown command"）。

**含义**：DC-9 GPU transform/filter/blend 工作在本 WSL 环境**可验证**（headless wgpu 可用，不必依赖真 GPU 桌面）。后续实现 DC-9 图元可用 `--gpu` 跑 reftest 验证零回归 + 用 GPU 单元测试断言 framebuffer。这移除了 R249 隐含的「GPU 验证环境不确定」风险。

## 发现 2：R236 multicol baseline-export 有时序问题——非 R253 所述「简单 plumbing-gap」

R253 称 R236 = 「字段/extract/consume 路径全在，仅缺 multicol.rs 填充」。本轮读 engine.rs flex baseline 路径 + multicol.rs 列后处理时序，**纠正此判断**：

**时序冲突**：
- baseline-000~008 的结构 = `<div style="display:flex; align-items:baseline">` 内含 multicol 子项。flex 的 baseline 对齐（项按 baseline 对齐）发生在 **taffy flex 布局期间**。
- multicol 的列布局（`adjust_multicol_layout` → `layout_multicol` → `position_multicol_children`）是 **taffy 布局之后的 post-pass**。
- 故即使 multicol.rs 在 post-pass 算出正确 first-column baseline 写入 `LayoutBox.taffy_baseline`，**flex 项已在 taffy 阶段按错误（taffy 通用 block）baseline 对齐完成**，post-hoc 改字段**不改变已定位的 flex 项位置** → 不修复 007/008。

**为何 baseline-000~006 仍 self-source PASS**：其结构简单（multicol 内直接文本），taffy 通用 block baseline ≈ 首行 baseline，偶然对齐。007/008（column-span:all / 空 first region / line-height）结构复杂，taffy block baseline ≠ 正确列 baseline → 失败。

**真实修复路径（非「简单填充」）**：
- 选项 A：**pre-pass 估测** multicol baseline 喂给 taffy（在 taffy 布局前算列首行 baseline）——但列结构在 post-pass 才确定，chicken-and-egg，需迭代或近似。
- 选项 B：**post-alignment 调整**——multicol post-pass 算出正确 baseline 后，回溯调整同 flex line 其他项的 y（需识别 flex 容器 + 同 line 项，复杂，回归风险高）。
- 两选项均**多轮、非单会话**，且对 baseline-000~006（现 PASS）有回归风险（改 baseline 可能使 test≠ref 翻 FAIL）。

**结论**：R236 非简单 contained fix，R253「仅需 multicol.rs 填充」判断**不完整**。勿以「填 taffy_baseline 字段」单点重试 R236（会因时序不生效，浪费 + 潜在回归）。R236 降级为**结构性多轮**（同 R131 multicol column-aware IFC 谱系）。
