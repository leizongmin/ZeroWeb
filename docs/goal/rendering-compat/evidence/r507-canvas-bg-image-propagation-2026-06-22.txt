R507 — 画布背景图像传播（CSS §14.2，扩展 R491 color-only → 含 image）
日期: 2026-06-22
承接: R506（DC-14 验证发现 background-root-018 gross failure 89.73%）

============================================================
1. 缺口（R506 发现）
============================================================

R491 实现了 CSS §14.2 画布背景**颜色**传播（html/body 背景色 → 画布 fill）。
但 **background-image 未传播**——body 的背景图像只绘在 body 盒，画布（视口）
其余区域只有色。CSS §14.2 要求 body 的**完整背景**（color + image）传播到画布。

实证 background-root-018（`body { background: red url(support/cat.png); } html { transparent }`）：
  R491 状态：cat 图像绘在 body padding-box（37,37 起），画布其余 ~90% 区域红色（应 cat 平铺）
  → self-source 89.73% fail（test 红 vs ref cat 平铺）。

诊断历程（排除若干假设）：
  - shorthand 解析：expand_background 正确提取 url()（shorthand/mod.rs:1380）✓
  - image 加载：build_image_cache 经 extract_css_urls 加载 cat.png，key=simple_hash ✓
  - paint 生成：paint_background_image 生成 16 个 ImagePrimitive（tiled body box）✓
  - key 匹配：simple_hash("support/cat.png")=11802275033518931388 == paint key ✓
  - interlaced：cat.png 是 Adam7 interlaced，但 png 0.17 正常解码（IMGDEBUG: buf_size 正确，非零数据）✗ 非 因
  - draw_order：add_image 注册 DrawOp::Image ✓；reftest 传 image_cache ✓
  ★ 真因：cat **正确绘在 body 盒**；画布（body 盒外）缺 image（R491 仅传 color）

============================================================
2. 修复
============================================================

① 抽出 `paint_bg_image_in_origin(origin_x, y, w, h, style)`（effects.rs）：
   元素背景与画布背景共用平铺逻辑（DRY）。paint_background_image 计算 origin
   （按 background-origin）后调用；画布以视口 (0,0,vw,vh) 调用。

② paint() 画布块（mod.rs）：传播判定改为「html 有任意背景（color 非透明 或
   image 非空）→ html；否则 body」（原 R491 仅看 color）。传播元素的 color + image
   都在画布绘制（image 经 paint_bg_image_in_origin(0,0,vw,vh)）。

③ Painter 字段 `canvas_propagated_node: Option<NodeId>`（mod.rs）：记录传播元素。
   paint_background_image 顶部守卫：若 box_node == canvas_propagated_node → 跳过
   自身 image 绘制（CSS §14.2「must not paint a background for that element」）。
   否则 body 盒 image（padding-box origin）与画布 image（viewport origin）相位
   错位 → 可见错位重影。
