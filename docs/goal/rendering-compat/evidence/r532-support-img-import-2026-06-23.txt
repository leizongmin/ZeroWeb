修复
----
创建 RGBA8 PNG（color type 6，与现有 1x1-green/300x150-green 一致）：
  - 100x100 / 200x200 / 20x50 / 40x20-green.png → (0,128,0,255)（CSS green，匹配现有）
  - solidblue.png → 从 WPT 仓库 raw fetch（16×16 RGB blue (0,0,255)，via ~/use-proxy 代理；
    min-{width,height}-auto 测试用显式 width/flex-basis/height，intrinsic 16×16 仅 aspect
    ratio 1:1 影响 min-height 测试的派生 width=height，与 WPT 实际一致）
  - blue-200x100.png → 从 WPT raw fetch（200×100 RGB blue (0,0,255)）
零代码变更——仅新增 6 个二进制资产。

意义
----
DC-14「分母真实性」要求 support 文件齐全。6 张缺失图片使引用它们的 reftest 不可正确
运行（img 缺失→0 尺寸→假通过）。补齐释放 21 css-flexbox + 3 css-writing-modes 真实
通过，并暴露 5 个被掩盖的真实 layout bug（aspect-ratio clamping / flex-grow 分布）供
后续修复。R527/R529/R532 三轮共补齐 css-flexbox + css-grid + css-writing-modes 的 WPT
support 资产完整性。
