R853 — :lang() 伪类匹配实现 LANDED（CSS 2.1 §5.11.4）
=======================================================

日期：2026-06-30
谱系：css/CSS2/selectors dir fresh scan（R740-R846 未深扫此 dir）发现 lang-pseudoclass-001/002
@24.54% 完全一致 → :lang() 伪类解析已存在（css-parser ast.rs:251 Lang(String)）但 matcher
完全不支持（matcher/mod.rs:237 `Lang(_) => false`，coverage.rs:243 测试显式断言 unsupported）。

────────────────────────────────────────
1. 根因
────────────────────────────────────────

`:lang(<range>)` 选择器在 css-parser 已正确解析为 `PseudoClassSelector::Lang(String)`，但
style-system matcher 的 `matches_pseudo_class` 对 `Lang(_)` 直接返回 false（注释「需要语言上下文，
暂不支持」）。故所有 :lang() 规则永不匹配 → lang-pseudoclass-001/002 全部用例颜色错（应绿不绿）。

────────────────────────────────────────
2. 改动（crates/style-system/src/matcher/mod.rs）
────────────────────────────────────────

新增 `matches_lang(doc, element, range)`：
  - 元素语言 = 自身或最近祖先的 `xml:lang`/`lang` 属性（向上 walk，xml:lang 优先于 lang）
  - 匹配：`lang_lower == range_lower` 或 `lang_lower.starts_with("{range_lower}-")`（连字符前缀边界）
  - 大小写不敏感（双方 to_ascii_lowercase）
  - 无 lang 祖先 → 不匹配

`matches_pseudo_class`：`Lang(range) => matches_lang(doc, element, range)`（替 false）。

CSS 2.1 §5.11.4 语义：`:lang(es)` 匹配 lang="es"/"es-MX"/"ES"，不匹配 "MX-es"/"en"。

────────────────────────────────────────

  略多），非 :lang() bug；待字体度量统一（多会话）后此案将 <1% PASS。
