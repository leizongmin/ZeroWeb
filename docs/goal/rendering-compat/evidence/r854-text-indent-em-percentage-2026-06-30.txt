R854 — text-indent Em/Percentage 解析修复（CSS §10.3.1·Px-only gap·IFC 双路径同源）
=========================================================================

日期：2026-06-30
谱系：fresh dir scan（css/CSS2/css1 c547-indent @7.84%）发现 text-indent 仅解析 Px，
Em/Percentage 被丢弃（R716/R711 Px-only 谱系）。承 R853 :lang() feature-gap vein。

────────────────────────────────────────
1. 根因
────────────────────────────────────────

CSS §10.3.1：text-indent 支持 length（Px/Em）+ percentage（× containing block width）。
ZW 两处 IFC 路径均不完整：
  - **layout/storage 路径**（inline_finalization.rs:409）：`Px(v)=>v, _=>0.0` — **丢 Em + Percentage**
  - **paint 路径**（painter/text.rs:803）：`Px + Em(×font_size), _=>0.0` — **丢 Percentage**
两路径不一致（Layout/Paint IFC 双路径问题，DC known gap），且 Em/Percentage 缩进完全失效。

c547-indent-001 anchor：`text-indent: 5em` + `text-indent: 50%` — 两者均被丢 → 首行不缩进。

────────────────────────────────────────
2. 改动
────────────────────────────────────────

(A) `crates/layout-engine/src/inline_finalization.rs`：新增 pub(crate) `resolve_text_indent(
    text_indent, font_size, container_width) -> f32`，统一解析 Px/Em(×font_size_px)/Percentage
    (×container_width)/其他→0。font_size_px 从 ComputedStyle.font_size（通常已 compute 到 Px）
    解析，防御性回退 16。line 409 调用点改用此 helper。

(B) `crates/engine/src/paint/painter/text.rs:803`：paint 路径补 `Percentage(v) => v/100 *
    container_width`（container_width 已在作用域 line 723），与 layout 路径同源（IFC 双路径一致）。

零行为变化对 Px（原已工作）；新增 Em（layout 路径）/ Percentage（双路径）正确解析。

────────────────────────────────────────
3. 验证
────────────────────────────────────────

(A) 单元测试 `test_resolve_text_indent_px_em_percentage`（inline_finalization::tests）：
    Px(40)→40 / Em(5)@16px→80 / Percentage(50)@800→400 / Auto→0。PASS。

(B) clippy -p zero-layout-engine -p zero-engine --all-targets -- -D warnings 零警告；fmt 干净。

(C) chromium Oracle A/B（c547-indent-001）：baseline 7.84% → WITH fix 7.66%（-0.18pp）。
    改善小因该测试 font-noise 主导（text-indent 仅影响首行 x 位，占比小）；但修复正确
    （Em/Percentage 现解析，首行缩进到位）。

(D) 0 回归：product-smoke welcome **16.11% 不变**（welcome 不用 text-indent Em/%）。

(E) make test：全量绿。

────────────────────────────────────────
4. 意义 + 诚实评估
────────────────────────────────────────

- **关闭 Px-only gap**：text-indent Em/Percentage 此前完全失效，现按 CSS §10.3.1 正确解析。
- **修复 IFC 双路径不一致**：layout（storage）与 paint 路径现共享同一 Em+Percentage 解析
  （inline_finalization::resolve_text_indent + text.rs 对齐），是 Phase A IFC 统一的增量切片。
- **yield 小但 correctness 实质**：anchor 仅 -0.18pp（font plateau 主导），无 case 翻 PASS；
  但 Em/Percentage 缩进对真实页面（如中文段落首行缩进 2em）是基础排版正确性，product smoke
  无覆盖不代表无价值。
