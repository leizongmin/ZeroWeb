## 审计（全源码闭合）

### 1. 9 图元类型全 dispatched（gpu/renderer/mod.rs:680-695）

`collect_*_vertices/resources` 对 shadows/fills/rounded_rects/gradients/images/strokes/path_fills/path_strokes/glyphs **全生成顶点/资源**（无静默丢弃）。→ 9 类型 GPU-rendered。

### 2. 仅 6 独立 WGSL 管线（非「9 独立」）—— master.md 措辞纠正

gpu/pipeline.rs shader 常量 + renderer pipeline 字段：
| 管线（pipeline 字段） | WGSL shader | 覆盖图元 |
|------|------|------|
| `pipeline` | FILL_GLYPH_SHADER | **fills + glyphs + strokes + path_fills + path_strokes**（draw_fill_pass :759-761 三角化后 solid fill） |
| `rounded_rect_pipeline` | ROUNDED_RECT_SHADER | rounded_rects |
| `gradient_pipeline` | GRADIENT_SHADER | gradients |
| `image_pipeline` | IMAGE_SHADER | images |
| `blur_pipeline` | BLUR_SHADER | **shadows + filter:blur**（shadow = 模糊） |
| `color_filter_pipeline` | COLOR_FILTER_SHADER | filter:opacity/brightness/contrast（R273） |

→ **6 独立 WGSL 管线**（strokes/path_fills/path_strokes 共享 FILL_GLYPH via 三角化）。master.md line 5「9/13 独立 WGSL 管线」**措辞不准**（9 是图元类型数，独立管线是 6）。已纠正。

### 3. stroke sound：含 Solid/Dashed/Dotted（== CPU）

`gpu/mesh.rs:178 push_stroke_mesh` → `:190 match stroke.style`：
- `LineStyle::Solid` → `push_solid_line_mesh`（含 LineCap）
- `LineStyle::Dashed` → `push_dashed_line_mesh`（dash_len=width*3，gap_len，:300）
- `LineStyle::Dotted` → `push_dotted_line_mesh`

→ **GPU stroke 三样式全覆盖**，匹配 CPU `render_stroke`（stroke.rs，R270 确认 CPU 真实含三样式）。SOUND，非简化。

### 4. path_fill/path_stroke 经三角化 FILL 非 passthrough

`push_path_fill_mesh`（mesh.rs:359）/ `push_path_stroke_mesh`（:389）把多边形/路径生成三角网格顶点，经 `draw_fill_pass`（renderer/mod.rs:760-761）用 FILL_GLYPH_SHADER（真 WGSL vertex+fragment）渲染。→ **真 GPU 渲染（三角化 + 着色器），非 CPU passthrough**，满足 DC-9「每种图元须有 GPU 端实现 + 非 passthrough」。SOUND。

## 关键结论

1. **GPU 9 图元类型 sound**：全 dispatched + 真 WGSL 管线渲染（6 独立，stroke/path 共享 FILL 经三角化）+ 非 passthrough → **满足 DC-9 对这 9 类的覆盖 + 非 passthrough 约束**（DC-14）。
2. **无 R266/R267 式前提瑕疵**：stroke 含 dashed/dotted（非 solid-only stub）；path 经三角化（非空/stub）。GPU 基元实现扎实。
3. **措辞纠正**（已同步 header line 5）：「9/13 独立 WGSL 管线」→「9 图元类型经 6 独立 WGSL 管线渲染（fill/glyph/stroke/path_fill/path_stroke 共享 FILL_GLYPH；rounded_rect/gradient/image/blur[color_filter 独立]）」。9=类型数，6=独立管线数；DC-9 覆盖按类型计仍 9 类达标。
