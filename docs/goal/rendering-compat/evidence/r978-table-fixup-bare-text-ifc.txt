# R978 Evidence — table-internal 裸文本 IFC partial fix（table-row-group-color 8.99%→0.79% PASS）

Date: 2026-07-03
Lever type: ZeroWeb-side clean code fix（非 font-metric 墙）
Driving test: css/css-tables/table-row-group-color-inheritance-001.html（R977 定位 root cause）

## Root cause（R977 精确定位，R978 实施）
`<div display:table-row-group; font:200px/1 Ahem>X` → 「X」orphan 渲染 16px 默认（chromium 200px 绿方块）。

R977 二次 probe 确证双重 orphan：
1. **table_grid.rs:197-301** row-group 子节点循环仅 match 元素（is_table_row/is_row_group/is_table_cell），
   裸 text node `get_display → None` → **无 branch match → 不生成匿名 cell**（违反 CSS Tables §3.1）。
2. **engine.rs:1007** `is_block_level` 不含 TableRowGroup/HeaderGroup/FooterGroup/Row →
   **compute_final_inline_layouts 在 inline_finalization.rs:520 早返 → 裸文本不跑 IFC**。

故「X」既无匿名 cell、又无 IFC，完全 orphan → 某默认 fallback 渲染 16px。

## 修复（inline_finalization.rs:520 is_block_level 门控）
加窄例外：`is_table_internal_with_text` = table-internal 行/行组 display **且** `doc.child_nodes(node_id)`
含直接 Text 子节点时，放行 compute_final（跑 IFC）。正常 table（rows/cells 子元素，无直接 text）不触发——
`is_table_internal_with_text=false`，仍早返，零影响。

这是 CSS Tables §3.1 匿名 cell 生成的 **partial fix**（ZW 未实现真匿名 cell：text node 非 LayoutBox child，
无法 wrap 成 TableCell）。partial = 让裸文本至少经 IFC 按容器 font/size 渲染（不再 orphan 16px）。
对 pure-Ahem 容器（如 driving test），IFC 结果存 inline_layout → paint 按容器 font 渲染。
