# R392 — text-emphasis 实现 net-negative（line-box 垂直定位阻塞），已回退

**日期**：2026-06-22
**触发**：R391 锁定诚实基线后，扫描 near-pass（1-5% z_vs_chr）集群发现 **32 个
text-emphasis 测试**完全未实现（ZW 渲染 0 标记，0.8-10% 发散=缺失的标记区域），
疑为「缺失特性」类 clean win（非结构性 bug）。

## 实现（全栈，已 100% 回退）

- **style-system 侧**（types/computed_style/default/registry/parse/apply/inherit）：
  TextEmphasisStyleValue（Mark(char) 解析 filled/open × dot/circle/double-circle/triangle/
  sesame 为 Unicode 字形）/ TextEmphasisPositionValue（OverRight 等）/ ColorValue 三长手
  + text-emphasis 简写；解析、存储、继承（is_inherited）、apply 全接通。
- **paint 侧**（painter/text.rs render_fragment! 宏）：每非空白字符渲染一个标记 glyph，
  over/under（水平）/right/left（垂直）定位，text-emphasis-color。

### 实现 bug 修复（过程中）

发现并修了一个**继承 clobber bug**：把 `text-emphasis`（简写）加入 `is_inherited` 后，
继承循环（iter known_properties，对 inherited-and-not-in-cascaded 调 inherit_property）
对简写「text-emphasis」调 inherit_property → **用父元素 None 覆盖了长手 text-emphasis-style
设的 Mark**（因简写 handler 写同一字段，区别于 text-decoration 简写有独立字段）。
修复=简写不入 is_inherited（仅 3 长手）。此 bug 模式对未来加简写属性有参考价值。

## 实测：net-negative（已回退）

| 指标 | 实现前 | 实现后 | Δ |
|------|--------|--------|----|
| text-emphasis 32 案 avg z_vs_chr | 1.44% | 1.52% | **+0.08pp（退步）** |
| chr<1% 一致 | 15/32 | 9/32 | **-6（退步）** |

标记**渲染了**但位置错（实测 glyph_y=63.8，标记 my=47.8 紧贴文本上方；chromium 标记在
**line-box 顶部** y=18）。**根因**：32 案**全部用 `line-height: 5`**（巨大行距），暴露
ZW 的 line-box 垂直定位与 chromium 分歧——ZW 把文本放近 line-box 顶（glyph_y=63.8），
chromium 居中偏下（文本 69-98，标记 18-33）。标记须 line-box 相对定位（line-box 顶部），
而 ZW 的 line-box/line-height 几何本就与 chromium 不同（IFC 垂直定位 / Phase A 谱系）。
故即使实现正确的「标记存在」，位置仍发散 → 加错位标记 = 加发散。

## 裁决

- **text-emphasis 非 clean win**——阻塞于 **line-box 垂直定位**（line-height 半行距分布，
  ZW vs chromium 分歧，IFC 垂直 positioning = Phase A / R247 multiline-stacking 谱系）。
  实现本身（parse/store/render）正确，但标记定位依赖 ZW line-box 几何对齐 chromium，
  该对齐是未解决的结构性前置。
- **100% 回退**（git checkout 9 文件），零残留（grep TextEmphasis=0），build 干净。
  self-source 443/490 零回归（代码回到 R391 状态）。
- 与 R384 plateau 一致：near-pass 集群（text-emphasis 32 案）经实测**非 clean win**，
  根因落 line-box/IFC 垂直定位（Phase A 多会话）。**勿再以 text-emphasis 为单会话 lever**
  重试，除非先解 line-height 半行距分布对齐。
