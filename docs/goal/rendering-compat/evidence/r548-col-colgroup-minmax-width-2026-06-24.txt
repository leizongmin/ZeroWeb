根因
----
compute_column_widths 的 Pass 0（table.rs:1128）遍历 `<col>`/`<colgroup>` 读显式 `width`（Px）
设列宽 `col_max_widths[idx].max(w)`，但**完全不读 min_width/max_width**——CSS Tables §17.5 +
CSS §10 规定 col/colgroup 的 min-width 为列宽下限、max-width 为上限。故 `min-width:1in`/
`max-width:1in` on colgroup/column 被忽略 → 列宽不受约束 → cell 塌缩（min-width-005 cell
w=9.6 应 96）或溢出。

修复（table.rs，~30 行）
------------------------
1. resolve_col_width 旁加 resolve_col_min / resolve_col_max（仅读 Px，同 width 策略）。
2. Pass 0 三个分支（colgroup 无内 col / colgroup 有内 col / 独立 col）改为取 style 一次，
   解析 width+min+max，循环内对 col_max_widths[idx] 应用：
     if width → .max(w)
     if min  → .max(mn)   （下限）
     if max  → .min(mx)   （上限）
   min/max 仅在属性声明（Px）时生效 → **gated on 属性设置**，blast radius 极小（仅影响显式
   声明 min/max-width on col/colgroup 的表，即 applies-to 测试）。
