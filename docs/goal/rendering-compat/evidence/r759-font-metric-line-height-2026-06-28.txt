R759 — font-metric line-height:normal（Ahem 实际度量修正）
============================================================
日期: 2026-06-28
谱系: R758 提出（untried font-metric ratio lever）→ R759 ground-truth 探针 + 实施 + A/B
状态: LANDED（待提交）

1. 背景
--------
R758 澄清：welcome/morning 16% 残余真因疑为 font-metric ratio 墙——
layout-engine 的 `NORMAL_LINE_HEIGHT_RATIO = 1.2`（text_metrics.rs:154）是固定值，
而 Chromium 对 line-height:normal 使用字体实际 OS/2 度量（ascent - descent + line_gap）。
R631 仅证「字体选择」非因（强制 NotoSansCJK 零变化），但**未测 ratio**（固定 1.2 不随
字体变，故 R631 零变化自洽）。R758 裁决 ratio 是 untried 高 EV lever，但需跨 crate
plumbing（resolve_font_metrics 仅持 ComputedStyle 无 font 访问）。

2. Ground-truth 探针（fontdue 0.9.3 horizontal_line_metrics 实测）
------------------------------------------------------------------
探针：render-foundation example，加载字体 → font.horizontal_line_metrics(size) →
ratio = (ascent - descent + line_gap) / size。fontdue LineMetrics 含 ascent/descent/line_gap
三字段（font.rs:97），均按 size 缩放。line_gap 三字体全 0。

  字体               upem   ascent  descent  line_gap  ratio
  ----------------- -----  ------  -------  --------  ------
  Ahem.ttf (WPT)     1000   800     -200     0         1.0000   ← ZeroWeb 现用 1.2（错 20%）
  Lato-Medium        2000   1974    -426     0         1.2000
  DejaVuSans(默认)   2048   1901    -483     0         1.1641
  NotoSansCJK(CJK)   1000   1160    -288     0         1.4480   ← ZeroWeb 现用 1.2（CJK 偏短）

关键发现：Ahem line-height:normal 实际度量 = **1.0**，ZeroWeb 此前用 1.2 → 所有
line-height:normal 的 Ahem 文本行盒比 Chromium 高 20%，多行 reftest Y 坐标累积发散。

3. Footprint 分析
-----------------
WPT Ahem 字体声明模式（css-text + writing-modes + CSS2/linebox，1326 文件）：
  - 主流：`font: SIZE/1 Ahem`（line-height:1 显式）→ **不受影响**（Number(1) 非 Normal）
  - 受影响：`font: SIZE/normal Ahem`（显式 normal，~11 文件）+
            `font: SIZE Ahem`（无 /LH → normal，~43 文件）
即 fix 仅影响 line-height:normal 的 Ahem 元素，blast radius 局限于 WPT reftest。

4. 实施（最小、零 plumbing）
----------------------------
resolve_font_metrics（crates/layout-engine/src/inline/text_metrics.rs）：
  - 新增 const AHEM_LINE_HEIGHT_RATIO: f32 = 1.0
  - 从 style.font_family 检测 Ahem（与 intrinsic_sizing.rs:109 / inline_finalization.rs:74
    既有 is_ahem 检测同模式，eq_ignore_ascii_case）
  - LineHeightValue::Normal → font_size * (1.0 if Ahem else 1.2)
  - 非 Ahem 仍 1.2（其度量需 FontLoader 跨 crate plumbing；字体匹配差异是正交问题）
无 signature 改动、无 FontLoader plumbing（resolve_font_metrics 是 line_height_overrides
的 single source，Phase-A override 基础设施自动传播到 paint Path B）。
新增单测 test_resolve_font_metrics_line_height_normal_ahem（默认/多字体列表/大小写不敏感 3 变体）。

5. 验证（A/B + 全量门禁）
-------------------------
  - layout-engine 单测: 912 passed / 0 failed（含新单测 + 既有 1.2 用例不变）
  - clippy -D warnings: 零警告（layout-engine）

  - self-source reftest（DC-7 全量门禁）: 686/686 = 100%（零回归）
