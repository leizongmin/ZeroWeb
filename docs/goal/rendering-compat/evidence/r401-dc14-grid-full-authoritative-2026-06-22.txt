# R401 — DC-14 Phase 2：css-grid 扩到全量权威集，揭示真通过率 62.5%（vs 子集 ~100%）

**日期**：2026-06-22
**承接**：R394 量化 DC-14 分母 gap（N_imported 仅上游 ~5-6%）。本轮建**权威 reftest 发现
工具**（按 `<link rel="match">` 解析，非文件名启发式），并扩 css-grid 到全量，验证工具 +
揭示真通过率。

## 工具：`tests/wpt-runner/scripts/discover-reftests-authoritative.py`

- GitHub API 列目录 → 逐 test 文件 raw fetch → 解析 `<link rel="match" href>` → 产出权威
  test→ref 对。正确处理 `../ref`（相对 test 目录）与 `/ref`（仓库根相对，strip 前导 /）。
- 区别于 `discover-wpt-reftests.py`（文件名启发式，grid 实测仅得 21 对，miss 非标准 ref 命名
  如 `reference/` 子目录、`css/reference/` 共享 ref）。
- reftest runner（`wpt_file_loader.rs:load_file_reftests`）本就按 link rel=match 权威发现，
  无需 manifest——故导入文件后 runner 自动纳入。

- **self-source 真通过率：css-grid 30/48 (62.5%)**（vs 18-子集时 ~100%）。
