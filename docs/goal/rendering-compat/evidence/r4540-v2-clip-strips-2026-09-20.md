# R4540 证据：clip 多边形条带 v2 机制（去 drain 化 + 中点采样 + op 插入）——缺陷 B/C 根除、语料零回归

- 日期：2026-09-20（R4540 C 轮——R4539 下轮方向②，helpers.rs 1 修复面 + 2 单测 + 2 测试测量模型更新）
- 谱系：R4536 三缺陷（B 条带顶采样漏带 / C 嵌套快照失准）→ R4537 splice/重建两版未收敛 → 本轮。

## 架构洞察（R4537 卡点的确定性解法）

`draw_order` 是顺序表：**op 的插入/替换只改顺序表本身，任何 op 的索引载荷无需更新**。
R4537 两版失败均在「条带进 fills 向量 → 索引位移 → 整表重建」，而 v2 让条带根本不进
fills：原 fill 原地清零，条带以 `path_fill` 发射，op 在原 `Fill(i)` 槽位替换/插入——
fills 向量长度不变，任何时点的 `PrimitiveCounts` 快照与 op 索引永久有效。嵌套 clip
消费（缺陷 C）因此可安全叠加，无需任何快照重建。

## 实现（helpers.rs）

1. `clip_fills_to_polygon_inplace`：对 `[start..len)` 每 fill——0 条带（多边形外）→
   清零；1 条带 = 原 rect（含于多边形）→ 原样保留；部分相交 → 清零 + 逐条带
   `add_path_fill`，原 op 槽位替换为首个条带 `PathFill` op、余下依次 `insert` 其后
   （同一 fill 条带互不重叠内部序无关，z 序 = 原 op 槽位保序）。
2. `clip_fill_to_polygon` 中点采样（`midpoint` 参数）：条带**顶采样**在多边形顶点恰落
   采样线时按半开边规则漏计该行、且 `y2>=y` 半开规则多算底行——整数坐标页条带整体
   移位一行、顶点行形状扭曲；中点与整数顶点天然错开（R4536 已验证的修正，本轮落地）。
3. `clip_all_primitives_to_polygon` 内 v2 分支 + kill-switch `ZW_CLIP_V2=0`（回退旧
   drain/重灌路径）；四个消费臂（corner-shape/circle/ellipse/polygon）统一受益。
