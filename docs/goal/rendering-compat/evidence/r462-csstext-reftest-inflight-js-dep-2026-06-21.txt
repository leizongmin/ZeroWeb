  - self-source（ZW-test vs ZW-ref）: 双侧同退化 → 同源一致 → **假通过**（抬高 self 通过率）
  - chromium-Oracle（ZW-test vs chromium-test）: chromium 能执行 JS → 正确渲染，ZW 退化 → **真发散**（拉低 oracle）
  → JS 失败扩大 self↔oracle 差距，self 偏高 / oracle 偏低
- 与已折回文字类目录一致性:

  （fonts/text-decor 的 JS 依赖比例未单独量化，但 self 99% 已证明 self 高估严重）
