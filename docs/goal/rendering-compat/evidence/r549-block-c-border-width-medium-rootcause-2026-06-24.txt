根因定位（探针 LAYOUT_DUMP 逐步二分）
-------------------------------------
最小探针 `div(border) > div(margin-top)` → 父 mt=0（border **阻断**折叠正确，同 R323 实证）。
故 block C 非通用 border-block 失败。二分 006 的 #div1 CSS：
- `border-top: 2px solid`（显式宽度）→ 阻断（mt=0）✓
- `border: solid black`（**隐式宽度** = medium）→ **不阻断**（mt=96，margin 穿透）✗
- `border: 2px solid black`（显式宽度简写）→ 阻断 ✓

→ **根因 = `border: solid`（隐式 width=medium）解析为 border-width:0**。死代码 parse_basic.rs:16-24
**有** thin/medium/thick→Px(1/3/5) 处理，但活代码 types.rs:991 `parse_length`（mod.rs `pub use types::*`
实际指向）**遗漏**（R544 ex-unit 死代码陷阱同谱系复发）→ `border-top-width: medium` → parse_length
返回 None → 回落初始值 Px(0.0)（registry.rs:36）→ border_top=0 → **无边框绘制 + 不阻断 margin 折叠**。

影响：grep 全 wpt-data **1550 文件**用 `border: solid`（隐式宽度）模式。006 的 #div1 `border: solid`
→ border=0 → 不阻断橙色 div margin → margin-collapse-through-border → img 位置错（block C）。
