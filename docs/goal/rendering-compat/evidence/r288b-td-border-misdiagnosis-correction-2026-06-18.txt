# R288b — 纠正 R288 的 td-border 误诊（边框齐全；真实 bug = img valign:bottom 偏低 6px）

轮次：R288b（纠正 R288 evidence `r288-nearpass-css2-diagnostic-2026-06-18.txt` 第 2 节「td 仅渲染顶边框，底/左/右缺失」的**错误诊断**）

## 纠正原因

R288 的 PIL 竖直边框扫描从 **x=60 起、步长 10**，**漏掉了 x=8（左边框）和 x=211-214（右边框）**，导致误判「左右边框缺失」。底边框则被溢出的蓝 img 覆盖（中段变蓝）误判「缺失」。本轮精确重扫（x=8/9/10/211-216 逐列 + 底边框角落采样）纠正。

## 纠正后的事实（background-043 REF）

td `<table height:206><td border:3 valign:bottom><img height=15>` 渲染几何：

| 边框 | 位置 | 状态 |
|------|------|------|
| 顶 | y=70-72（x=8-214，206px 宽） | ✅ 渲染 |
| 底 | y=273-275 | ✅ **渲染**（角落(9,274)/(212,274)=黑；中段被蓝 img 覆盖） |
| 左 | x=8-10（y=70-275，206px 竖直 run） | ✅ **渲染**（R288 漏扫） |
| 右 | x=211-213（y=70-275） | ✅ **渲染**（R288 漏扫） |

**td border-box = x[8,214] y[70,275] = 206×206**，四边框齐全，**几何完全正确**（与 test div 206×206 一致）。

## 真实 bug（修正后）

**img（td vertical-align:bottom 内容）定位偏低 6px**：
- td content box = x[11,211] y[73,272] = 200×200（border-box 206 − 2×3 border）。
- img（15px）vertical-align:bottom 应底对齐 content 底 = **y=272**。
- 实际 img 底 = **y=278**（偏低 6px）→ 溢出 content 6px，**越过 border-box 底（275）共 3px**。
- 蓝条 TEST y[258,272] vs REF y[264,278]，差 6px = 此 bug。

**疑似机制**（待运行时探针确认）：vertical-align:bottom 的参考用了 **td border-box 高度（206）** 而非 **content 高度（200）**——img 底 = content_top(73) + 206 ≈ 279（实测 278，1px 取整），即未扣除 td border。6px ≈ td 上下 border 之和（但单边 3px，差 6px 说明可能双计或用了 border-box-bottom+border）。需探针确认 valign:bottom 计算入口与参考盒。
