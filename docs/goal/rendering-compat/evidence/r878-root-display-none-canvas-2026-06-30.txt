R878 — 根元素 display:none 不传播背景到画布（CSS §9.2.4/§14.2）
====================================================================
日期: 2026-06-30
谱系: R871/R872 根元素定位（margin/position）的延续；canvas 背景传播子问题。
有 net 源码: ✅ painter/mod.rs canvas 传播块 +2 单测。

测试
----
css/CSS2/box-display/root-box-003.xht:
  html { display: none; background: green; color: red; }
  body { background: red; color: yellow; }
  <body><p>FAIL</p></body>
  <link rel="match" href="root-box-003-ref.xht" />  (ref = body{background:green})

期望（chromium 实测）: 纯白 canvas（display:none 抑制整树 + 不传播背景）。
ZW 修复前: 纯绿 canvas（html green 错误传播）→ 100% diff。
ZW 修复后: 纯白 canvas → 0.00% PASS。

根因
----
CSS §9.2.4 / §14.2: 根元素 display:none → 不生成盒、整文档树不参与渲染，
故根元素（及作为其后代的 body）背景**均不传播到画布**，canvas 保持默认白。

ZW 的 canvas 传播逻辑（painter/mod.rs::paint §14.2 块）原本只判断
「html 有任意背景 → html 传播；否则 body 传播」，从不检查 html 是否 display:none。
故 html{display:none} 仍被当作「html 有背景」→ green 传播到画布。

修复
----
painter/mod.rs::paint canvas 传播块（R878）:
  let html_is_display_none = html_style.is_some_and(|hs| hs.display == DisplayValue::None);
  let html_has_bg = !html_is_display_none && html_style.is_some_and(...);
  let (prop_node, prop_style) = if html_has_bg {
      (html_id, html_style)
  } else if html_is_display_none {
      (None, None)   // html display:none → body 后代亦不渲染，不传播
  } else {
      (body_id, body_style)
  };
DisplayValue 已在 painter/mod.rs 导入（line 19）。
