## 关键纠正：R388 的 43.2% 含 5 个假一致

广义从 R388 的 205 降到 200（-5），**完全来自 R389 修的 6 个 css-flexbox 测试**（图片
404 时 ZW-test 与 oracle 均全白 → 假一致 ~0.7-0.87%；图片加载后真实 abspos-flex-width
bug 显现 → 9-19% 真发散）：

```
flex-abspos-inset-cross-size-001   0.87% → 17.45%
flex-abspos-inset-nested-001       0.73% →  9.02%
flex-abspos-inset-nested-002       0.74% → 19.44%
flex-aspect-ratio-cross-size-001   0.87% → 17.45%
flex-cross-size-border-box-001     0.87% → 14.28%
```

**这些不是 ZW 回归**——是 R389 让度量变诚实（假一致 → 真发散）。故 R388 报的 43.2%
被 5 个假一致轻度高估；真实诚实广义一致 = **42.1%**。
