# 半透明圆角矩形背景 alpha 丢失修复（R228）

**日期**: 2026-06-18
**目的**: R227 后继续推进 DC-13 产品 smoke。复扫 morning-work 67% diff 时定位到一个独立的真实渲染 bug。
**结果**: CPU 渲染器 `fill_rounded_rect` 半透明圆角背景修复（alpha 不再硬编码 255）。reftest 438/490 持平零回归。

## 根因

`crates/render-foundation/src/cpu/mod.rs` 的 `fill_rounded_rect`（圆角矩形栅格化）：
```rust
let color = [rr.color.r, rr.color.g, rr.color.b, 255];  // ← 硬编码 alpha=255，丢弃 rr.color.a
...
fb.set_pixel(x, y, color);  // ← 直接覆盖，不与底色合成
```
而矩形填充 `fill_rect` 正确处理 alpha：`src_a = color.a/255`，不透明→`set_pixel`，半透明→`blend_pixel` 合成。
于是**任何半透明圆角背景都被渲染成实色**——border-radius 的元素背景丢失 rgba() alpha。

## 触发链（morning-work .item-tag 实证）

`article.css` 定义 `--color-primary-alpha-05: rgba(96, 124, 210, 0.05)`，`.item-tag { background-color: var(--color-primary-alpha-05); border-radius: 3px; }`：
- 无 border-radius → `add_fill` → `fill_rect` → 正确淡蓝 tint (247,248,253)
- 有 border-radius → `add_rounded_rect` → `fill_rounded_rect` → 实色蓝 (96,124,210) ❌

逐步二分锁定：`var()` 解析、`background-color` longhand、`inline-block`、`color:var()` 均非因；**唯一触发条件 = `border-radius` + rgba/半透明背景**（var 或 literal 均触发）。

## 修复

`fill_rounded_rect` 改为与 `fill_rect` 一致的 alpha 处理：
```rust
let src_a = rr.color.a as f32 / 255.0;
// ... inside loop, after is_inside_rounded_rect check:
if src_a >= 1.0 {
    fb.set_pixel(x, y, [rr.color.r, rr.color.g, rr.color.b, 255]);
} else if src_a > 0.0 {
    blend_pixel(fb, x, y, rr.color, 255);
}
```

## 验证

- 独立测试页 `border-radius:3px + rgba(96,124,210,0.05)` 背景：修复前 (96,124,210) 实色 → 修复后 (247,248,253) tint ✓
- 新增单元测试 `rounded_rect_translucent_alpha_blends`（cpu/tests.rs）：alpha=13 圆角矩形在白底应 blend 为浅 tint，断言非实色。
- reftest 上游 438/490 持平（零回归）；smoke 686/686。
- make test 全绿；clippy 零警告；fmt 干净。

## morning-work 67% 的剩余主因（独立问题，本轮未修）

`.item-tag` 实色蓝修复后，morning-work 整体仍 67%（未明显下降）。区域分析表明真正大头是
**内容纵向压缩**：ZW 把暗色内容集中在 y=150-300（21k+6k px），y=300-525 几乎空白（0 px），
而 chromium 暗色内容均匀分布在 y=150-600。ZW 内容 y 范围 [13,551] 与 CH [5,588] 相近，
但分布差异巨大——疑为 `<img>`（logo_lei.jpg / qrcode jpg / cc png）固有尺寸塌缩或 `pre code { min-width:700px }`
溢出处理致内容堆叠到顶部，属独立布局问题（DC-11 替换元素 / 块格式化），下一轮排查。

## GPU 渲染器同类问题（DC-9，未修，记录）

GPU mesh `color_to_f32`（gpu/mesh.rs:11-12）只返回 RGB 三通道，**全局丢弃 alpha**——
GPU fill/rounded-rect 均无法渲染半透明图元。属 DC-9 GPU 全量图元覆盖的子项（需 WGSL pipeline
blend 配置 + 顶点格式带 alpha），与本次 CPU 修复同源不同层，单列后续。
