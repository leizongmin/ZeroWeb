**主要真实缺口**（self-fail 高 → ZW test≠ref 真发散）：
1. **aspect-ratio transferred size**（90% self-fail）—— flex item 的 aspect-ratio 固有尺寸传递
   未实现（与 R325 img aspect-ratio 同谱系，flex 容器内未传递）。
2. **flex min-size:auto**（79% self-fail）—— flex item 的 min-width/height:auto 默认值
   （=min-content）未正确应用（已知 R97/R304 taffy 缺口）。
3. **flex shorthand resolution**（65% self-fail）—— flex grow/shrink/basis 组合解析边界 case。
4. **writing-mode + flex**（60% self-fail）—— 垂直/侧向 writing-mode 下 flex 主轴/交叉轴。

**实现良好的子域**：align/justify（22% self-fail）、baseline（32% self-fail）——这些是 flex 核心
对齐，taffy 0.7 支撑到位。

## 裁决

- **flexbox chr<1% 49.2% 是迄今最高**，但 self-source 49.6%（布局类最低）——flex 有最多真实
  self-source 发散（aspect-ratio / min-size:auto / shorthand / writing-mode），这些是**可定位的真实
  渲染缺口**，非 plateau 式结构性死锁。
- **潜在 clean-win 面（区别于前 5 目录 plateau）**：aspect-ratio transferred size（49 例 90% self-fail）
  和 flex min-size:auto（57 例 79% self-fail）是**高密度、同质**的失败簇——若实现，可批量提升。
  但单会话是否可解须进一步 probe（aspect-ratio 传递耦合 R325 谱系；min-size:auto 耦合 taffy R304）。
- **align/justify 实现良好**（22% self-fail）确证 taffy 0.7 flex 核心对齐可靠，flex 缺口集中在
  intrinsic-sizing 子域（aspect-ratio/min-size/shorthand），非全面 flex 实现缺陷。
- DC-14 去子集化：**6/9 目录完成**，余 3 目录（multicol 537 / writing-modes 855 / CSS2 ~5000+）。
