## 1. 关键实证：推翻 R495「paint 读 taffy measured」推断

**R495 推断**：post-extract height override（LayoutBox.height=600）「在 extract 层生效但 paint 读 taffy measured 19.2」，故回退。

**本轮 LAYOUT_DUMP + REFTEST_DEBUG 双开实证**（`positioning/abspos-containing-block-001`，test-guard 包裹）：

painter `paint_background`（painter/mod.rs:1165）读 `Rect::new(abs_x, abs_y, box_node.width, box_node.height)` —— **直接读 LayoutBox 字段，无独立 fixed paint 路径读 taffy**。LAYOUT_DUMP（reftest.rs:582 打印 `b.height`/`b.width`）与 paint 读**同一 LayoutBox 树同一字段**（pipeline.rs:226 compute → 237 paint 读 layout_result.root；dump 读 result.layout.root = 同树 clone）。

**baseline（无 fix）**：
```
div abs_y=0.0 h=19.2 ... x=0 w=600
fill[2]: (0.0,0.0,600.0,19.2) rgba(255,255,255,255)   ← div 白背景，paint 读 box_node=19.2/600
```

**fix 后**：
```
div abs_y=0.0 h=600.0 ... x=0 w=800
fill[2]: (0.0,0.0,800.0,600.0) rgba(255,255,255,255)   ← paint 读 overridden box_node=600/800 ✓
✓ abspos-containing-block-001.xht (0.00%)
```

**结论**：paint **确实读** post-extract overridden `LayoutBox.height/width`。R495 height-only override 不生效的真因**不是**「paint 读 taffy」，而是 **width stretch 也缺失**（R495 只 override height，width 仍 600 body-CB → 白 600×600 漏右侧 200px 红条 → fail；R495 像素测量「white=3%」与 dump「h=600」矛盾的根因 = 误判/旧 binary）。**补 width stretch 后** fill[2] = 800×600 全白，001 PASS。

R496 推断（option b：post-layout override 有效，R495 误诊）**实证确认**。

## 2. 实现（engine.rs，+52 行纯新增）

`stretch_fixed_to_viewport_size(box_node, vw, vh, styles)` —— 在 `adjust_absolute_pct_to_viewport`（步 11.5）后调用（步 11.6），递归 mutate `root_box`：

仅对 `child.is_fixed`（position:fixed）：
- `height:auto` + 全 Px `top`+`bottom` → `child.height = vh − top − bottom`（§10.6.4）
- `width:auto` + 全 Px `left`+`right` → `child.width = vw − left − right`（§10.3.18）
- `height:Percentage(p)` → `child.height = p% × vh`（§10.1，fixed CB 恒为视口）
- `width:Percentage(p)` → `child.width = p% × vw`

**scope 纪律**：仅 fixed（CB=视口无条件已知，位置已由步 4 `adjust_fixed_to_viewport` R324 修正）。**不动 absolute** —— 历史 `adjust_absolute_to_initial_containing_block`（engine.rs:1596）因同调 x/y + auto 宽高致多回归（static-inside-inline-block / background-329）已 `#[allow(dead_code)]` 禁用；本函数 size-only 不触 x/y。002/004（absolute，R496c 证实 viewport CB）是下一 lever（见 §5）。
