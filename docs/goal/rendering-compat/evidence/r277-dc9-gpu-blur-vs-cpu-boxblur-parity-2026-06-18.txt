# R277 — DC-9 GPU blur（3a3530f）vs CPU box-blur parity 分歧：三角核 separable vs 多遍 box（非「==CPU」，纠正 R269）

**日期**: 2026-06-18

**基线**: 438/490（自源）持平
**承接**：并行 agent 提交 3a3530f「DC-9 GPU filter:blur — 2-pass H+V Gaussian via the dead-coded blur pipeline（零回归）」。R269 曾称「blur=sound 同模式 apply_box_blur 真实参考」（隐含 ==CPU）。本轮核实 GPU blur 算法——**结论：GPU 三角核 separable vs CPU 多遍 box-blur，是真实 CPU/GPU parity 分歧（非 ==CPU），纠正 R269**。

## 核实（全源码闭合）

### GPU fs_blur（pipeline.rs:357-375，committed 3a3530f）

```wgsl
fn fs_blur(in) -> vec4f {
    let radius = max(uniforms.blur_radius, 1.0);
    let dir = select(vec2f(1.0/screen_w,0), vec2f(0,1.0/screen_h), uniforms.direction>0.5);
    let r = i32(radius);
    var color = vec4f(0); var total_weight = 0;
    for (i = -r; i <= r; i++) {              // 2r+1 taps
        let weight = 1.0 - abs(f32(i)) / (radius + 1.0);   // ← 三角/帐篷核（线性衰减）
        let offset = dir * f32(i);
        color += textureSample(src, samp, in.uv + offset) * weight;
        total_weight += weight;
    }
    return color / total_weight;
}
```
→ **可分离 2-pass**（H 一遍 + V 一遍，由 `uniforms.direction` 选轴），**三角/帐篷核**（weight = 1 − |i|/(r+1)），2r+1 taps，归一化加权平均。commit 称「Gaussian」**命名不精**——核是三角（tent），非真高斯（exp(−x²/2σ²)）；tent 是 crude Gaussian 近似，blur 合法但非字面 Gaussian。

### CPU apply_box_blur（effects.rs:200-227）

`apply_box_blur(fb, l,t,r,b, radius)` → 注释「三遍 box-blur 近似高斯模糊」→ `box_blur_channel` 对 R/G/B 多遍调用（:223-227）。box-blur = **均匀平均**（uniform kernel，非加权）。

### 算法差异 → parity 分歧

| | GPU blur（3a3530f） | CPU blur |
|---|---|---|
| 核 | 三角/帐篷（加权 1−\|i\|/(r+1)） | 均匀（box，各 tap 等权） |
| pass | 可分离 2-pass（H+V） | 多遍 box（注释「三遍近似高斯」） |
| taps | 2r+1 | box 窗口 |
| 性质 | tent filter | multi-pass box ≈ Gaussian |

→ **同 radius 下 GPU 三角 separable 与 CPU 多遍 box 产出不同像素**——真实 **CPU/GPU parity 分歧**（filter:blur 用例 CPU vs GPU 模式渲染不同）。**非机制 stub**（两路都是合法 blur 近似），但**非 ==CPU**（R269 隐含假设错误）。

## 关键结论

1. **GPU blur sound（覆盖满足）**：有真实 WGSL fs_blur 着色器（非 passthrough），DC-9 filter:blur 覆盖达标（同 R268/R273 opacity/brightness/contrast）。
2. **但非 CPU-parity**：GPU 三角核 separable vs CPU 多遍 box-blur 算法不同 → filter:blur CPU/GPU 输出分歧。**纠正 R269「blur sound 同模式」的隐含「==CPU」**——blur 是「同后处理模式」但「不同算法」，parity 分歧（同 opacity RGB-darken 谱系：机制 sound 但非 CPU 精确对齐）。
3. **影响低**：filter:blur reftest footprint ≈0（R250），parity 分歧罕见 manifest；但 DC-9/DC-14 parity 准确性须记。
4. **命名不精**：commit「Gaussian」实为三角核（tent），非真高斯——不影响 blur 合法性，仅术语。

## 对优先级队列的影响

- DC-9 filter 覆盖：opacity（f6fed44）+ brightness/contrast（fc86937）+ **blur（3a3530f）** 已落，全 sound（真 WGSL 覆盖）。剩 grayscale/invert/saturate/sepia/hue-rotate（color_filter 可扩 R273）。
- **DC-9/DC-14 parity caveat**：opacity（RGB-darken 近似 R272）+ blur（三角 vs box R277）是两处 CPU/GPU 算法分歧——覆盖满足但非像素 parity。brightness/contrast 是真 parity（R273 正确 CSS 语义）。
- 不改变 DC-9 active forward motion；细化 filter parity 性质（opacity/blur 非精确 parity，brightness/contrast 精确）。
