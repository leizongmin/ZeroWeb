2. **简单 text-multicol（column-count:N + 直接文本，无 block 子）现状 = paint even-split 已正确**
   （R200 证）：paint 侧 `target_h=total/col_count` 顺序填充 = chromium §8 顺序填充。类 A 低 diff
   （columns-001 4.88% / fill-000 6.54%）残余是**精度**（列宽/glyph x/平衡高度精确值）非算法。

3. **失败类全结构性**（设计 doc §1.2）：
   - B 混合内容（containing-002）：`has_in_flow_children` 门控跳过列分配 → 混合内容整列堆叠。
   - C 嵌套/breaking（breaking-004/005/006）：嵌套 multicol + column breaking + inner 子列布局。
   - D baseline（baseline-007/008）：baseline-export（R316 后处理 ruled out，须 taffy 升级 R304）。
   - A 精度：advance-width 谱系（R225 死路）。

4. **layout-side column-aware IFC（设计 doc §2/§R317）= 跨 4 子系统协调改动**：① IFC 接受
   ColumnFragmentationContext 产 per-column 行盒 ② multicol layout 把列几何喂 IFC ③ 存
   LayoutBox.inline_column_lines ④ paint 消费存储 per-column 行盒（删 text.rs:713 重算）。
   = 多 session 规模，单会话全做高风险（同 R554/R558/R317 net-negative 谱系）。
