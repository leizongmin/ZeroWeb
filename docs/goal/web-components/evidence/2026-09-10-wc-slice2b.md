## 修复内容（3 处，全在 part03 `_ce*` 段）

### ① define/whenDefined 异常类型 DOMException 化

- 无效名：plain `Error` → `SyntaxError` DOMException（spec `dom-customelementregistry-define`
  + `dom-customelementregistry-whendefined`——`assert_throws_dom`/`promise_rejects_dom`
  要求 DOMException 接口）；
- 重复名/重复 ctor：plain `Error` → `NotSupportedError` DOMException。
- 消费面：`valid-custom-element-names.html` 的 1753 invalid-name 断言整簇 +
  `CustomElementRegistry.html` 的 define 校验族。

### ② PotentialCustomElementName 产生式（spec 对齐）

- 旧：`/^[a-z][a-z0-9.-]*-[a-z0-9.-]*$/` 纯 ASCII——WPT 参考
  `elementLocalNameRegex` 允许非 ASCII 码点（含 astral）。
- 新：首 `[a-z]` + 至少一个 `-` + 其余字符非禁集（NUL/tab/LF/FF/CR/space/`/`/`>`/
  ASCII 大写），reserved 表拒——与测试参考校验器同语义。
- 收益：`valid-custom-element-names.html` **104→1975 全绿**（+1871，单案最大增量）。

### ③ `CustomElementRegistry` 接口对象

- 新增 interface 构造器（`new` → TypeError「Illegal constructor」）+ prototype 五方法
  （define/get/getName/whenDefined/upgrade，委托 `customElements` 实例）；
  `customElements` 原型接入接口 prototype（`instanceof CustomElementRegistry` true）。
- 收益：`CustomElementRegistry.html`「CustomElementRegistry is not defined」簇解除。
