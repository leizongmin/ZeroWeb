## 修复内容

### ① customized built-in 升级链路（spec element-definition / concept-create-element）

- **define 记录 extends**：entry.localName + isCustomizedBuiltIn；extends 非内建 tag 抛
  NotSupportedError；`HTMLDetailsElement` 接口补入（此前 details 映射 HTMLElement）。
- **createElement(tag, {is}) 升级**（主文档 part06 + detached 工厂 part03）：is 命中
  registry（localName 匹配）→ `_ceRunCtor` + is 内容属性。**registry 按 document 隔离**
  （detached/iframe 文档查 own `_zwCERegistry` 槽；普通 detached doc 空 registry 永不升级——
  WPT upgrading.html 的 browsing-context 断言面）。
- **`new klass()` 产生真实元素**：接口 stub（`__zwHtmlTagIface` 全表 ~70 接口）与
  HTMLElement 桥在无升级在途时建 tag 元素 + `new.target.prototype` + is 属性返回
  （derived-ctor 语义——旧返 plain 对象，cloneNode/DOM 面全断，builtin-coverage 110F）。
  media 接口（HTMLAudioElement/HTMLVideoElement，part01b Illegal constructor）同款包装。
- **cloneNode 重升级**：`_zwDeepCloneEl` 产物按 tag+is 反查重放（builtin-coverage 的
  cloneNode().constructor === klass 断言）。
- **getPrototypeOf trap is-aware**：parser 产物 `<a is="my-a">` 的 instanceof/constructor 面。
- **连接/属性反应**：`_ceEntryFor` is 反查（含 per-key 缓存 + set/removeAttribute('is')
  失效钩子 `__zwCeInvalidateEntry`）+ set trap 头 CE 捕获的 registry 空门（OPTIMIZATION：
  非 CE 页面零开销）。

### ② IDL 反射 setter handle 路径的 moAttr 汇流补齐

- crossOrigin（AUDIO/VIDEO/IMG）、preload、track kind/label/srclang、_REFLECTED_BOOL
  （required/readOnly/…）、autofocus/inert 的 handle 分支此前不设 moAttr → 无 MO record
  也无 CE 反应。补齐后 reactions/customized-builtins 全族 attributeChanged 派发生效。

- `_ceUpgradeNode` 补 is 属性反查（customized built-in 的 define 后升级路径）。
