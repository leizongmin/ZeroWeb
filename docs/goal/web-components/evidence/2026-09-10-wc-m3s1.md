## 修复内容

### ① HTMLSlotElement 接口原型

- `name`（IDL 反射：读/写 name 内容属性，缺省 ''）、`assignedNodes({flatten})`、
  `assignedElements({flatten})`（元素过滤）。
- slot 元素挂接（`__zwWireSlotElement`）：createElement('slot')（part06）/ `_zwMEl`
  plain 工厂两处 setPrototypeOf 到 HTMLSlotElement.prototype。**customized built-in
  优先**——`getName(el.constructor)` 命中（元素已按 registry 升级）跳过覆盖
  （builtin-coverage slot customized built-in 断言面）。
- assignedNodes 算法（spec assign slottables）：上溯 shadow root 容器 → host 的 light DOM
  子收集（树序；flatten 含后代）→ slot=name 匹配（指名只进同名 slot；未指名/文本只进
  默认 slot）→ flatten 递归展开嵌套 slot + 空 slot 的 fallback 子（循环守卫）。
- 双世界实现：handle 世界（part05 `__zwSlotAssignedNodes`——`_shadowHandleMeta`/`_handleChildren`
  registry）为主；plain 世界（part03 本实现——parentNode 链 + host.childnodes）兜底。

### ② slot/assignedSlot IDL

- `el.slot`（get/set 反射 slot 内容属性，set 走 CEReactions 汇流——attributeChanged 对
  CE 生效）。
- `el.assignedSlot`（只读）：handle 世界（parentHandle 链找 shadow root 内 name 匹配
  slot）+ sel 世界（沿 `__zw_parent` 上溯找 `_shadowRoots` 键 hostSel 匹配祖先 → shadow
  树 DFS）。在 shadow 树内的 slottable 恒 null（spec）。

### ③ slotchange 事件（microtask 时序）

- `__zwQueueSlotchangeForRoot`：shadow 树内全 slot 的 slotchange 派发（`Event('slotchange')`
  挂 slot 自身），**Promise.resolve().then 微任务时序** + **同根去重**（同轮多次分配变化
  只 fire 一次——spec slotchange 合并语义）。
- 触发点：handle 父 appendChild/removeChild（part04 挂钩）——三形态：父=shadow root
  （shadow 树内增删）、父=shadow host（light 子增删——`_shadowRoots['@'+handle]` 键反查）、
  深层父链上溯。
