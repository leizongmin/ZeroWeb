## 修复内容

### ① 非 HTML namespace host → NotSupportedError（spec attach a shadow root step 1）

- part05 `_attachShadow`：`_nsHandles` 印记**存在即采信**（null/'' ns 是合法印记——
  createElementNS(null/'') 产物须 throw）；无印记 = HTML ns。
- part03 轻量路径：namespaceURI 读（null/'' 回落 HTML ns——sel 世界 proxy 空串非真
  null ns 印记）。

### ② valid shadow host name safelist（spec step 1 续）

- HTML ns host localName 须在 safelist（article/aside/blockquote/body/div/footer/
  h1-h6/header/main/nav/p/section/span）或为 valid custom element name（含连字符小写
  近似）——'non-safelisted elements'（img 等）NotSupportedError。
- localName 来源：_nsHandles.qualifiedName（剥前缀）→ `_realTag` 回落。

  NotSupportedError 断言同因转绿）。
