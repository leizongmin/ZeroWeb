## M2/M3 失败簇（202 non-pass，按簇归域）

1. **Timeout 簇（71 T，最大簇）**：等 worker 消息往返/close 事件/fetch_tests_from_worker
   回报超 30s 案级预算——WorkerGlobalScope/ close+event 面 35 T、constructors 7 T
   等。多数随 M2 语义修齐自动收敛（消息不再悬挂）；fetch_tests_from_worker 回报
   通道属 worker harness 面（见排除表末行）。
2. **worker 全局面缺失簇**：`WorkerNavigator is not defined`（wctx 无 navigator）、
   `WorkerLocation is not defined`（.any.js 变体内引用）、worker 内 FormData/
   indexedDB 缺位——M2 全局作用域最小面（DC-2：self/navigator/location）。
3. **importScripts MIME/网络错误簇（~34 F）**：scripty MIME 白名单（text/javascript
   等 5 种放行、非 scripty 抛）、不存在脚本 TypeError（NetworkErr）、nosniff 拦截、
   跨源/重定向错误报告——现实现正则内联 + 无 MIME 检查。DC-2（classic + importScripts）。
4. **postMessage transfer/ports 簇（~12 F）**：transfer 序列 WebIDL 校验
   （空/null/非序列应 TypeError）、port 随消息转移、e.ports 只读冻结——DC-3
   transferable 面。structured-clone（ImageData/dedicated.html 2 案）同域。
5. **ErrorEvent 语义簇（~15 F）**：filename/lineno/colno 取真实脚本位、
   importScripts 错误源归属、未捕获错误向 window 传播、bubbles/cancelable——DC-2。
6. **构造器 WebIDL 簇（~8 F）**：无参 TypeError、非法 URL SyntaxError/DOMException
   分型、`[object Worker]` class string（原型 Symbol.toStringTag）、同源校验——DC-2。
7. **terminate/事件循环簇（~4 F）**：死循环 worker terminate 不中断（同 realm 同步
   执行结构性限制）、terminate 后事件队列排空语义——M2 事件循环评估记账项。
8. **WorkerLocation URL 分解零散（~3 F）**：空 port undefined、空 query `""` vs
   `"?"`——顶层散修。
