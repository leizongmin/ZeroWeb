## 挂账定稿（P6）

### SharedWorker

- **范围**：SharedWorker 构造器/端口/跨文档共享实例语义，全不实现。
- **账面**：M1 排除 66 案（constructors/SharedWorker/ 42 + 顶层 SharedWorker-\*
  等，[M1 evidence 排除表](2026-10-20-m1-baseline.md)）；corpus 内残留
  exposure.any.js 1F——根因定性：失败在 **window 变体**（页面无 SharedWorker
  接口；worker 变体已 Pass）。上游案假设完整实现平台，Android Chrome 等无
  SharedWorker 平台上同形态 Fail——实现范围选择而非 spec 偏离，与 66 案同账。
- **不做理由**：SharedWorker 本质是跨 browsing context 共享同一 worker 实例，
  同 realm 近似无承载物；加仅 exposure 桩不承载语义，属为过测试加面，不取。
- **重入条件**：独立 isolate/线程化立项时一并评估（跨文档共享是其前置能力）。

### nested worker

- **已实现**：worker 内嵌套构造（三源脚本 + 独立 wctx），Worker exposure 案
  （嵌套构造面）Pass。
- **残余边界**：terminate 中断深度（Worker-terminate-forever 1F +
  Worker_terminate_event_queue 1T）——同 realm 近似无法中断正在执行的同步脚本，
  固有边界记账，重入条件同 isolate 化。

### module worker

- **范围**：`workers/modules/` 目录级 35 案 + 顶层 `type:'module'` 构造 6 案，
  共 41 案排除。
- **评估结论**：module worker 需要 ES 模块图装载管线（静态 import 图解析/
  import.meta/module preloading），当前 script-sandbox 装载为 classic 单脚本
  形态；同 realm 近似下 worker 模块图若与页面共享模块注册表会破坏 worker
  顶层作用域语义，独立装载器成本不匹配本 goal 边界。**评估结论：不实现，
  记账挂账**（M1 起排除规则 `workers_case_skipped` 兜底，全程稳定）。
- **重入条件**：script-sandbox 模块装载器落地，或 isolate 化立项时一并评估。
