## 本轮修复（全部 WPT driving 用例驱动，单测 + WPT 双覆盖）

### 1. createImageBitmap float16 覆盖层补全（主 + worker）

- **part05.js**：float16 ImageData 源 → ImageBitmap 携带原始浮点像素 `_zwBitmapF16`
  （u8 wire 无法表达越界值 2/-1）；drawImage 3 参进 float16 上下文记录覆盖层；
  getImageData float16 按覆盖层优先回读（像素在覆盖层内 → 原始浮点，否则 u8/255）；
  clearRect/putImageData/reset 写像素操作使覆盖层失效（避免陈旧原始浮点）。
- **part04.js**：DOM canvas getContext（`document.getElementById('c')` 路径）补
  `_f16` 标记——此前仅 standalone `_zwMakeCanvas` 有（WPT 用例走 DOM 路径）。
- **part05.js**：OffscreenCanvas.getContext 补 `_f16` 标记（worker 变体路径）。
- driving: `2d.imageData.createImageBitmap.srgb.rgba.float16`（主 + worker）。
- 单测：`test_canvas_float16_overlay_roundtrip_r34xx`（standalone + DOM 双路径 +
  clearRect 失效断言，engine part05.rs）。

### 2. 外链样式表相对 url() 解析（webview.rs）

- **URL 基准修正**：外链 CSS 内 `url(...)` 相对引用按**样式表 URL** 绝对化（此前
  混入 combined 后按页面 URL 解析 → 外链 @font-face/背景图 404）。
  `absolutize_css_urls` 大小写不敏感扫描（ASCII 小写保持字节位），引号/裸值、
  data:/绝对 URL 不动。
- **headless 样式表本地提供**：外链样式表经 `image_source_fetcher`（wpt-data 映射）
  获取（None → 回退 HTTP 网络，与图片子资源同款）。
- driving: `2d.text.variationSelectors`（variation-sequences.css 的
  `url(../../resources/vs/...)` 字体引用）。

### 3. 呈现感知字体选择（canvas context_impl.rs）

- `shape_text_with_presentation_fallback`：VS15（U+FE0E，text 呈现）在 color 字体
  （COLR/SVG 表——emoji 字体）下回落 'sans-serif' 文本字体；VS16（U+FE0F，emoji
  呈现）保持 color 字体。Chromium 语义：emoji 字体仅用于 emoji 呈现。
  **近似**：整串按是否存在 VS15 选字体（Chromium 逐字回退细化，文档化）。
- cmap14（Unicode variation sequences）glyph 替换为 **rustybuzz 0.20 原生支持**
  （ot_shape_normalize 的 handle_variation_selector_cluster）——无需自实现；
  VS 零宽/合并语义由单测锁定。
- driving: `2d.text.variationSelectors`（⚓+FE0E vs ⚓+FE0F 宽度不同——
  ⚓+FE0E → DejaVu 文本 glyph；⚓+FE0F → NotoColorEmoji（subset 无 ⚓ → notdef 宽））。
- 单测：shaper `test_variation_selector_zero_width_and_cmap14`（ℹ+FE0E cmap14 合并
  为 1 字形、VS 不贡献宽度——NotoEmoji-VS-subset）；canvas
  `test_variation_selector_presentation_fallback`（emoji vs text 呈现宽度差，
  DejaVu 系统字体 + NotoColorEmoji subset，资产缺失跳过）。
- 资产：wpt-data `css/css-fonts/resources/vs/*.ttf` ×7 入
  `imported-resources.txt` + `fetch-canvas-subset.sh`（重拉不丢）；
  `tests/wpt-runner/fonts/` 提交 NotoEmoji/NotoColorEmoji 两个 subset 供单测。

### 4. ImageData 构造器 WebIDL 重载回退（part05.js）

- data union 转换失败（Uint8Array/Array 等）→ 试 `(sw, sh[, settings])` 重载：
  sw = ToUint32(对象) → 0 → IndexSizeError（ctor.basics 的 Uint8Array 2 参
  INDEX_SIZE_ERR）；settings 参数非对象 → TypeError（字典参转换失败终止重载链——
  ctor.basics 的 `(self, 4, 4)` 3 参 TypeError）。
- driving: `2d.imageData.object.ctor.basics`（此前 2 断言被误判「spec 冲突不可兼得」——
  实为重载回退语义）。

### 5. getIndexFromOffset 边界语义（part05.js + part06.js）

- ltr 命中规则改**字形中点**计数：中点 = 相邻字形原点中点、末字形 = 与文本右缘
  中点；严格 `<`（exact 中点不归）。edge-cases：a_width/2 → 0、a_width/2+1 → 1、
  a_width → 1、a_width+b_width → 2。
- DOM 对照侧 `caretPositionFromPoint`（part06）同步（几何补 `pens` 并行数组，
  Range.getClientRects 的 4 字段 rects 不变）。
- driving: `2d.text.measure.index-from-offset-edge-cases.tentative`（主 + worker）。
