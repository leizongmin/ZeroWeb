## 本轮修复（全部 WPT driving 用例驱动，Rust 单测 + WPT 双覆盖）

### 1. 渐变插值色彩空间（fill-and-stroke-styles）

- **stop 含 CSS Color 4 现代函数（color-mix/相对色）→ 渐变 OKLab 插值**；legacy 颜色
  直 sRGB 插值（spec "without premultiplying the alpha value"）。
- driving: `2d.gradient.colormix`（stop1 = color-mix(in srgb, #0f0, #00f)，
  期望像素 (212,81,61)/(167,106,88)/(113,120,109) = OKLab 插值逐点吻合 ±1）、
  `2d.gradient.relativecolor`（rgb(from red g r b) = green）。
- 实现：canvas crate 三渐变类型加 `oklab_interpolation` 标志（engine 桥 addColorStop
  检测 ColorValue::Mix/RelativeColor 置位）；`sample_gradient_stops` 按标志走
  render-foundation `interp_pair`（Oklab/Srgb，premultiplied CSS Color 4 §12.3）。
- 单测：`test_gradient_oklab_interpolation_colormix` / `..._relativecolor` /
  `test_gradient_premultiplied_alpha_interpolation`（3 个，types.rs）。

### 2. alpha 序列化最短可回滚（fill-and-stroke-styles）

- u8 alpha 无法精确保存 0.5（127.5→128）；序列化改最短十进制使 `round(d*255)==a`：
  'rgba(255,255,255,0.5)' 回读 '0.5' 而非 '0.502'。
- driving: `2d.fillStyle.get.halftransparent`（0.5）、semitransparent（0.45 正则）。
- 单测：`test_serialize_alpha_roundtrip`（全 u8 域回滚验证）+ `test_color_to_canvas_css_alpha`。

### 3. WebIDL 参数语义分流（drawing-rectangles + transformations）

- 570b552c 把非有限（NaN/Infinity）误当缺参抛 TypeError；spec 语义分裂：**缺省
  （undefined/null）→ TypeError（missingargs）；非有限 → 方法静默忽略**。
- `_zwFiniteNum` 拆为 `_zwNumArg`（缺参 TypeError）+ `_zwAllFinite`（非有限 → return）。
- 覆盖 18 个调用点：path（moveTo/lineTo/arc/arcTo/quadratic/bezier/rect）、
  rects（fillRect/strokeRect/clearRect）、text（fillText/strokeText）、isPointInPath、
  transforms（translate/rotate/scale/transform/setTransform）。
- **setTransform 双重重载**：0 参 → `optional DOMMatrix2DInit` 重载（identity）；
  1-5 参 → 6 必参重载 TypeError。
- driving: fillRect/clearRect/strokeRect/rotate/scale/transform/setTransform/translate
  `.nonfinite` 8 个 + `setTransform.multiple` + `conformance.requirements.missingargs`
  （worker 变体保持全过）。

### 4. ImageData 构造器 spec 化（pixel-manipulation）

- 重写 ImageData 构造器：非 new 调用 → TypeError；WebIDL union（Uint8ClampedArray/
  Float16Array）类型错 → TypeError；pixelFormat 类型不匹配 → InvalidStateError；
  长度算法（spec imagebitmap-and-animations §ImageData constructor）：
  byte 长度非 bytesPerPixel（4/8）非零倍数 → InvalidStateError；像素数非 sw 倍数 →
  IndexSizeError；sh 给出不符 → IndexSizeError；宽高 0 → IndexSizeError。
- `pixelFormat` 枚举（'rgba-unorm8'/'rgba-float16'，默认 unorm8）——float16 存储用
  V8 原生 Float16Array（ctr 层全过）。
- driving: `2d.imageData.object.ctor.basics`（1 陈旧断言除外——Uint8Array 2 参
  INDEX_SIZE 与同文件 3 参 TypeError 不可兼得，当前 spec WebIDL 行为）、
  `ctor.size.bounds` / `ctor.array.bounds` / `ctor.pixelFormat` / `ctor.array` /
  `ctor.size`。

### 5. fontKerning + 默认字体真度量（text）

- `setFontKerning` op 接线（原为 no-op）：canvas crate `FontDescriptor.kerning_none`，
  measure/draw shape 传 `kern=0` feature（rustybuzz 默认开 kern）。
- **系统默认字体预载**：WebView `load_canvas_system_sans_font`（DejaVu 等带 kern 的
  真字体 → canvas 注册表 'sans-serif'）——无 @font-face 页面默认字体面
  （fontKerning 宽度对比、measure.width 真度量）。
- **resolve_font_id 族名大小写不敏感**（潜在 bug 修复）：resolver 键为注册原样
  （'CanvasTest'），小写查询 miss 后回退 sans-serif 恰逢首字体被掩盖；系统字体
  预载后暴露。
- **fillText maxWidth ≤ 0 → 不绘制**（spec text preparation algorithm）。
- **ctx.font 二次设置保留 fontKerning**（桥层 setFont 继承，同 letter/wordSpacing）。
- driving: `drawing.style.fontKerning` / `reset.fontKerning.none` /
  `draw.fill.maxWidth.zero` / `maxWidth.negative` / draw.* 全族（回归保护）。
- 单测：`test_font_kerning_none_widens_measure`（Lato-Medium GPOS kern 驱动）、
  `test_font_kerning_state_roundtrip`。

### 6. % 字号解析（text）

- ctx.font 的 % 字号预解析：基准 = canvas 元素内联 font-size（无样式默认 10px）——
  '50% serif' + inline 144px → '72px serif'；'1000% serif'（无样式）→ '100px serif'。
- driving: `2d.text.font.parse.size.percentage` / `.percentage.default`。
