## 3. border 坐标系错位定谳（g36 主刀）

有边框 CB 的区域/inset 定位观测 offsetLeft=2（期望 0）、top-left
98×148@2,2（期望 100×150@0,0）。探针链定位：

1. 引擎单测探针（g1f）：container 2px border + span-all 满填 →
   `anchored.x=2 w=400`（引擎自身算术正确：区域 = 全 padding box）。
2. plain abs 对照（left:50）→ `plain.x=50`：普通 abs 通路不烘 CB border。
3. rect 提取层口径实证：`V(child) = V(parent) + parent.border + child.x`
   （plain offsetLeft 50 = 50+2−2 ✓；区域通路 offsetLeft 2 = 2+2−2 ✗）。
4. **根因**：`collect_anchors`/`apply_walk`/`apply_inset_walk` 三 walk
   origin 累计用 `origin + b.x`（不含 border），锚几何与格坐标为
   D=0 系；rect 提取/渲染递归为 D=border 系（V 系）。旧代码以
   `cb_x − vx`（border+padding）烘入补偿 D=0 锚几何——borderless CB 下
   两系重合（14 个既有 g1f 全 borderless 故全过），bordered CB 下错位显形：
   inset 通路多 +border、区域通路偏移多 +border 且满填尺寸各缩 2。

## 4. V 系统一修复

anchor_pos.rs 全链统一到 rect 提取/渲染递归口径（V 系）：

- 三 walk origin 累计改 `origin + b.border_left + b.x`（b.border_top 同）；
- `cb_x = vx + b.padding_left`（vx 已含 border，去 border 项）；
- inset 写入直用 V 系 padding 相对量：`child.x = lv + ml`（lv 已是
  `ax − cb_x` V 系量）/ `child.w = cb_w − rv − mr − width` 等四式；
- 区域格 `col = [0, ax−cb_x, ax+aw−cb_x, cb_w]` 两边同 V 化，语义不变；
- `apply_axis_align` 删 `to_parent` 参数（区域几何与 child.x 同基准，
  无需换算）。
