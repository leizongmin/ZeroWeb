- 新增 `_zwRangeRenderedText(range)`：Selection 专用渲染文本提取。
  - **display:none 子树剔除**（HTML 渲染节 rendered text collection steps
    「not being rendered → return items」；walk 级剪枝，style/script UA 默认
    none 不入串，作者/inline 翻 block 后内容入串）。

    flow-root/table-caption）时 out 非空且未以 `\n` 结尾 → 补 1 个 `\n`；
    pre 族（pre/listing/plaintext/xmp，HTML 渲染节 preformatted 元素）边界
    不与相邻空白合并 → 无条件发。

    控件选区回落 raw `range.toString()`（FIXME：value 子串形态未对齐，零回归
    优先）。

    端点切片与包含判定按 boundary point 比较实现。
