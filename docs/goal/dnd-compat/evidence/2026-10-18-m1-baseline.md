## 失败聚类（M2 待收敛面，七簇）

1. **draggable 反射不在原型链**（157 fail = draggable_attribute.html 154 +
   dom/draggable.html 3）：`assert_idl_attribute`/`assert_inherits` 沿
   prototype 找不到 `draggable`——现实现走 element proxy get trap（own 面），
   接口原型上无 accessor。`video` 默认 draggable 期望 false 得 true 同族
   （default state 计算面）。
2. **DataTransfer types FrozenArray 语义**（5 fail）：`Object.isFrozen` /
   同对象恒等（dataStore 未变返同一 FrozenArray，变则换新）/ 只读 setter /
   'Files' 排序面。
3. **DataTransferItem disabled mode**（1 fail）：`items.remove(i)` 后被捕获的
   item 对象 `kind`/`type` 应清空（现 items 每次 access 重建对象，捕获实例不
   随 remove 变化）。
4. **element 上 `'ondrag*' in el'`**（7 fail）：element proxy has trap 不认
   on* 名（get/set trap R2933 已通；window/document 已绿）。
5. **`HTMLDocument` 未定义**（1 fail，historical.html）：legacy alias 缺失。
6. **DragEvent init dict dataTransfer 类型校验**（1 fail）：`{dataTransfer:{}}`
   须 TypeError（现静默收编任意对象）。
7. **dropzone 反射 IDL**（2 fail）：`el.dropzone = null` 不落 null + 内容属性
   反射缺失。
