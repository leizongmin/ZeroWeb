## 根因（视图双计）

`with_query_view_doc` 的视图 bake = parse(dom_html 快照) + 重放 `[prev..count)` 的
`InsertAdjacentHtml`。dom_html 存在**换代写入点**（R55 dispatch_event 每次重注册换
新 Arc = 最新 cached_html、user_actions 批末 `*dom_html.lock() = cached_html`）——
换代后基座已含「已 apply 的落地拷贝」（尾簇 9 的序列化落地 op），重放区间仍含同一
op → **双计**。R47 视图语义（Remove 不重放、已移除元素保持可查询）使 cleanup 后的
幽灵残留雪上加霜：hit test（qsa → 视图）命中幽灵/残影，宿主派发回落 img。

## 修复（两件）

1. **基座已反映去重**（callbacks.rs 视图重放过滤）：fragment 首元素带 `id="..."` 且
   基座 `query_selector('#id')` 已命中 → 视该 op 已反映，跳过重放；无 id 片段照旧
   重放（无法判重，保守）。R358 就地换代语义保持（基座恒为当下 dom_html，无钉定）。
2. **hit test 幽灵过滤**（runner `resolve_pointer_target` area 循环）：`isConnected
   === false` 跳过——R47 幽灵经 live-first `__zw_contains` 判否（live 已 apply
   remove）。

## 候选方案史（两版钉定均废弃，勿重试）

- **注册/读取侧基座钉定 v1**（Arc 对身份 + drain_gen 匹配）：读取侧首见即钉在多
  文件序列钉到**导航过渡态的上一页 html**（新 drain_gen + 旧内容）→ 整页视图基座
  错页 → selectorFor('body') null → "testdriver target has no stable selector"
  断链（boundary_events 邻域复现实证）。
- **钉定 v2**（registration hook + `set_view_base_html` 导航装载点）：破坏 R358
  就地换代可见性契约——`test_query_view_doc_inplace_snapshot_swap_gen_r358` 等
  3 单测红（视图必须跟随当下 dom_html 内容）。
- **结论**：视图基座必须恒为当下 dom_html（R358/R47 契约），双计只能在**重放侧
  按内容去重**解决（本版）。
