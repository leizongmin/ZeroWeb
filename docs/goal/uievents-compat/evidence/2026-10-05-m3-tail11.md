## 修复（四件）

1. **UA 指针 click/auxclick/contextmenu → PointerEvent 实例**（shim `__zw_dispatch_event`
   分支条件 + up/down 序列 detail 携 `pointerType`/`pointerId:1`）：PE spec §The click,
   auxclick, and contextmenu events——触发激活行为的 click 是 PointerEvent，pointerId/
   pointerType 随源 pointer；`detail` 透传（连击计数）。R108 pre-click activation 经
   PE 原型链 `instanceof MouseEvent` 恰好接通一次；webdriver 折叠 click（宿主激活事务）
   不传 pointerType 走泛型分支零变化——checked 双翻转历史坑（R108 注记）不复现。
2. **PointerEvent wrapper 的 constructor 身份**（part05 `PEM3Wrapped`）：wrapper 接管
   `window.PointerEvent` 后 inner 工厂产物 `.constructor` 仍指 inner ctor——
   `event.constructor === window.PointerEvent` 断言面（is_a_pointerevent 族）失配。
   own non-enumerable 覆盖为 wrapper（new.target === wrapper 时；子类 super() 不盖）。
3. **click() API + formless buttonish 的 Enter → 非指针生成 click**：PointerEvent
   {pointerId:-1, pointerType:''}（PE spec；WPT non-pointing-device 断言面）。
   - click() API：PE 构造 + `_zwSyntheticClick` 标原样（R108 isClickApi 协作契约不动）；
     R57 守卫改标优先（API 路径 R57 保持、UA 路径跳过——R108 已做翻转+input/change）。
   - **Actions 键盘链 ENTER 默认动作补齐**（runner keydown op）：旧版 Enter 落
     `InsertText{'\u{E007}'}` → text-control snapshot 对 button 类 input 抛
     InvalidStateError「does not support text selection」→ actions.send() 整链拒绝
     （non-pointing 子测试永挂 → 文件 Timeout 的根因）。formless buttonish → PE click；
     in-form Enter→click→submit 链与非 buttonish 维持既有语义。
4. **send_keys 通道同语义**（runner `_` 臂）：uE007 + formless buttonish → PE click
     （与 Actions 链一致；此前 Submit 臂 formless noop）。

## 排除路径（实证，勿重试）

- host Activate（webdriver click）**不可** PE 化：plan_checkbox 的 `prepare: SetChecked`
  翻转在宿主侧，PE 实例接通 R108 → checked 双翻转（R108 历史坑、三宿主 conformance）。
- pointerType 判空必须 `!= null`：`''` 是非指针生成合法值，`||` 会塌成 'mouse'。
- bisect 陷阱：iape4/iape5 轮「revert click() PE 后 rejection 消失」是**假因果**——子
  测试在首个 assert 即中止，send() 根本未执行；真实根因在 Actions 链 Enter 的
  InsertText 通道（与 click() 类无关）。
