   π/2），不做换算；单集给值仍走权威分支整集派生。PE spec 转换节；WPT

   补 `pointerType: st.pointerType`（touch/pen 流的边界事件此前被 dispatch 层
   缺省标成 mouse）。
3. **处理站内 release 的延迟生效三态**（`part04.js` releasePointerCapture +
   `part06.js` 前置站门控 + up 序列入口站传参）：gotpointercapture 派发期内
   release → 'armed'；站点调用方按相位转换（前置站内站 → 'fire'；touch 显式站
   → 'skip'——本站 in-flight 事件跳过结算）；'fire' = 下一 pointer 事件边界结算
   （lost + 悬停跨界）。Chrome 实测序 got → [rawupdate] → move@captured →
   lost → 次事件@物理目标。配套：**站外入口站的 lost handler 重捕获抑制**
   （capture_mouse_and_release_and_capture_again——lost listener 内
   setPointerCapture 的 pending 不在本事件前置站结算，按派发序号（dispSeq）
   一次性对齐，Chrome 同型 up 落物理目标；gate 站内重捕获不抑制——capture at
   lostpointercapture 照常下一事件结算）。修复 WPT capture_{touch,mouse}_
   and_release_at_got_capture + lostpointercapture_is_first +
   pointerrawupdate_changes_pointer_capture 六子测全绿（五流验证，中间两版
   arm/ready 两拍与命令代际作用域设计被五流证伪后收敛到派发序号模型）。
