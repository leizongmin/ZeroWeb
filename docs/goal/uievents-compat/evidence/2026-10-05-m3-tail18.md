## 修复（三件）

1. **range input 拖拽取值默认动作**（shim down/move/up 三站 hook）：INPUT[type=range]
   按下 → 按指针位置设 value + `input` 事件；拖拽 move 持续更新；release 派
   `change`。轴向：水平（缺省）pct=(x-rx)/rw；垂直（**inline style writing-mode 含
   vertical**——WPT 用 `writing-mode:vertical-lr; direction:rtl`）pct=1-(y-ry)/rh
   （顶=max，「up drag → value 100」断言面）。尾簇 17 回退的 w/h 比启发式由
   inline-style 检测 + 反转修正替代。
2. **runner `resolve_pointer_target` 空命中坐标保持**：命中扫描为空（指针移出任何
   元素盒到文档空白区）→ 旧版回落 `origin_sel + RAW offset`——坐标错页：GBCR 算得
   (93,202) 被弃用、move 派到 (0,186) 左上角（trace 实证）。改派 **body 落点 +
   计算坐标**（真浏览器事件落 html/body）。
3. **touch move 早退路径补 range 取值**：touch 无 hover/move 对（早退在事件派发
   前），取值是默认动作非事件面。
