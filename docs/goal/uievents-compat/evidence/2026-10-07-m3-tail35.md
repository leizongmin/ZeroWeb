**日期**: 2026-10-07
**结果**: wheel 族 **1F/2TO → 3P 全绿**（wheel-basic + wheel-multiple-sources-deadlock +
wheel-scrolling）。回归扫：pointercapture_in_frame 17P/1F（?touch subtest 4 上游即

## 落地（四段通道）

1. **stub**：`Actions.prototype.scroll(x,y,dx,dy,{origin,sourceName})` 编码 tick
   （此前 no-op「记帐不重放」）+ `addWheel/setWheel`（wheel 源注册）。
2. **stub send()**：scroll 步入 plan（`wheel_scroll` op——viewport origin = `'@'`
   绝对形；元素 origin = 中心 + x/y 偏移）。
3. **runner**：`"wheel_scroll"` 命令——`resolve_pointer_target` 命中（指针命令同款
   refresh 门控）→ `script_wheel_scroll(hit, px, py, dx, dy)`。
4. **shim**：`__zw_wheel_scroll`——WheelEvent 派发（deltaX/Y/deltaMode=0、
   cancelable true、composed true；R312 UA trusted 印记；滚动默认动作 headless 无
   真滚动管线不消费——cancelable 语义保留）。

## 判例注记

- **「wheel-scrolling 需真滚动」预判推翻**：wheel-scrolling 案实际断言 EventRecorder
  的 wheel 事件 target 序（wheelbox → scrollbox），滚动面未断言——wheel 事件派发
  接通即绿。三案均只断言事件面，headless 无真滚动管线不阻塞本 goal 语料。
- **deadlock 案**：双 wheel 源（vertical/horizontal）delta 透传——wheel 事件面接通
  即绿（「deadlock」为 Servo 上游的并发 bug 名，非滚动死锁）。

## 余挂

- **wheel-scrolling 的真滚动默认动作**：wheel 事件的滚动消费（页面可滚动区域的
  scrollY 变化）——headless 无滚动管线，本 goal 语料未断言（若有语料断言滚动面
  再立项）。
