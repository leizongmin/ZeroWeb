## 修复（两件）

1. **跨界序中移除/替换 hover 目标 → move 对重定向最近连通祖先**（shim move 步）：
   跨界序派发中页内 listener 移除/替换目标（mouseover remover）时，move 对重定向到
   **最近连通祖先**而非原目标——UI Events「mousemove 落最后存活 mouseenter 链最深
   目标」。**不用命中测试**——替换场景新子已占同点位但未入 enter 链，spec 排除之
   （child.remove()/outerHTML 替换 → parent；parent.remove() → grandparent）。
   mousemove_after_mouseover_target_removed 移除两案 +2P；替换两案余挂（见下）。
2. **runner selectorFor 安全 id 门**（testharness.rs）：id 仅在合法 CSS 标识符
   （`/^[A-Za-z][\w-]*$/`）时产 `#id` 形——`id="outerFrame body"`（带空格）曾产
   `#outerFrame body`（descendant 选择器）→ 宿主解析 miss → 「testdriver target not
   found」（pointercapture_in_frame 全簇 18F 首断面）。非安全 id 落 attr 筛选路径
   （`body[id="..."]` 合法唯一）。修复后该文件转为 pending Timeout——事件不入
   subframe 文档（见挂账）。
