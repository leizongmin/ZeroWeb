## 修复（七件，均 engine shim 面）

1. **pointerrawupdate 派发**（move 步新站点）：secure context（`isSecureContext`）且
   页内存在 pointerrawupdate listener（`_zwHasAnyRawListener`——`_listenerStore` +
   `_onHandlers` + window handler 全页近似）时派发；站点序：跨界序 → **rawupdate** →
   pointermove。**无 listener 整站跳过**（Chromium 性能语义——changes_pointer_capture
   尾子测「每 move 只跑一次 process pending」断言面）。bubbles=true / cancelable=false
   （spec——parent 冒泡 listener 可达性是 changes_pointer_capture variant 2 的判据）。
   **Process-Pending / capture 重定向复用 dispatch 层既有机制**（`__zw_dispatch_event`
   对 pointer 系事件派发前置结算 + capture override 重定向）——rawupdate handler 的
   capture set/release 落效于随后的 pointermove 派发前置结算，与 PE spec「fire a
   pointer event」逐点对齐（changes_pointer_capture 全簇序列）。
2. **chorded button 键序**（down/up 序列早退分支）：已有键位按下时再按他键 →
   pointermove（非 pointerdown，button 携**变化键位**非 -1）；仍有他键按下时释放 →
   pointermove + **click/auxclick 照常组合**（buttons 携剩余掩码，Chrome oracle——
   click_on_chorded_mouse_button；pointerup/mouseup 末键才派，click 组合目标不变）。
3. **WebDriver button index → PE buttons 位掩码映射**（`_zwButtonMask`）：index
   1(middle)→bit4、2(right)→bit2（spec §11.1 位序与 WebDriver index 互换；旧
   `1 << button` 对 middle 落 right 位）。down/up 七站统一替换。
4. **got/lostpointercapture buttons 显式携带**：dispatch 缺省对非 down/move/up 型落
   1——lost 于末键释放后应为 0（pointercapture-not-lost-in-chorded-buttons
   「lostpointercapture should happen when all buttons are released」面，基线即 2F）。
5. **coalesced 队列克隆**（`coalescedClone`/`coalescedMove`）：pointerrawupdate /
   pointermove 的 getCoalescedEvents() 返**同属性非冒泡克隆**（bubbles false /
   cancelable false / isTrusted true / target 恒等——首派回填、redispatch 保持原值、
   `_zw19Clone` 印章限定 UA 克隆不污染构造注入序列）。coalesced_events_attributes
   ?mouse/?pen 3P→4P、on_redispatch 3 变体 0P→1P、rawupdate_coalesced 3 变体
   Timeout→22P+6F（target 恒等 6 子测余挂）。
6. **deferred mouse 层跨界**（`_zwPointerCross` 第 5 参）：move 步 rawupdate 前的跨界
   只结 pointer 层，compat mouse 边界序延至 rawupdate 之后（Chromium 站序
   pointerover → pointerrawupdate → mouseover → pointermove；
   boundary_events_before_pointerrawupdate 在 rawupdate handler 内摘 mouse listener
   的断言面）。flush 挂 `_zwFlushPendingCross`（guard 防插入型变异二次跨界双结）。
7. **反射面收口**：`onpointerrawupdate` IDL handler（window/document defineProperty +
   element has-trap 白名单补列，secure-only——PE spec「only within a secure context」）；
   `persistentDeviceId`（PointerEventInit，缺省 0，w3c/pointerevents#495 tentative）；
   `pseudoTarget`（UIEvent.prototype own accessor，MouseEvent 原型链继承）。

## 挂账（本簇新暴露/确认）

- **coalesced 真采样管线**：under_load（多入口列）×3 + movement 累加 ×1 + rawupdate
  coalesced target 恒等 ×6（克隆 target 回填对 touch/pen variant 的 pointermove 无
  UA 派发路径）——headless 无真指针采样，挂账。
- **touch 域 rawupdate**：touch 无 move 派发面，rawupdate_coalesced ?touch 文件级
  Timeout 残留——随 touch move 语义专项。
- **iframe 捕获面**（既有挂账 b）：remove_target 2F + after_adoption 1F +
  pointercapture_in_frame 18F + click_during_parent_capture iframe 面同根因。

  probe 实证事件序正确后定位上游 `<script>` 引用缺失（showPointerTypes 未 include，
