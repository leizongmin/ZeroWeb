## 缺口

`pointerevent_mouse-pointer-preventdefault` 7F：① Actions move 命令 + down 序列的
隐含迁移**各派一对 move**（got 双 pointermove/mousemove——真实浏览器 pointerdown
无位移不产 move）；② pointerdown 取消后 mousemove/mouseup 未抑制；③ pointerup
自身取消反而抑制了 mouseup（过泛化）。

## 修复（shim 三件）

1. **down 序列同位幂等**（mouse 分支）：`st.overSel === sel && st.x === x &&
   st.y === y` → 跳过隐含 `__zw_pointer_move`（首次接触/跨界照旧完整迁移）。
2. **`st.compatSuppressed` 手势级标记**：pointerdown prevented 且非 touch → 置位
   （至下次 down 清除）；`__zw_pointer_move` 双路（捕获/非捕获）的 compat
   mousemove 与 up 序列的 mouseup 随之抑制——PE spec §11「canceling the pointerdown
   event ... prevents ... compatibility mouse events」（click 例外照常）。
3. **撤销 upPrevented 门**：pointerup 自身取消**不**抑制 mouseup（Chrome 实测——
   WPT「canceling pointerup 仍有 mouseup」面；旧门为 suppress_compat 族 pointerdown
   面的误推广）。
