## M2 主根因

`Touch` / `TouchList` 全缺失、`TouchEvent` 仅有空壳子类（part05.js
`_defineEventSubclass('TouchEvent','UIEvent',[])`，无 dict 属性映射）：

- touch-touchevent-constructor 0/5——5 Fail 全为 `Touch is not defined`
  （构造器 TypeError 矩阵 + TouchList 列表语义全被同一根因掩盖）。
- historical 5F 同根因（`Touch::webkit*` 4F + `TouchList::identifiedTouch`）；
  3P 面（`TouchEvent::initTouchEvent` / `Document::createTouch` /
  `createTouchList` 缺席即过）在 Touch/TouchList 落地后仍须保持——historical 是
  M2 的双向门。
- GEH 2 PreconditionFailed：`'ontouchstart' in document` 为 false →
  `assert_implements_optional` 中性短（桌面 Chrome 同型）；1P 面（不在
  `Element.prototype`）已绿。expose-legacy 16P 为全缺位一致性面（四个 handler
  在四个 target 上同缺）——M2 落构造器不落 `ontouch*` 曝出面，这两案应保持
  原状（桌面 Chrome 对齐）。

## M2 工作面

按 touch-events spec（w3c.github.io/touch-events）落 `Touch` 构造器（TouchInit
dict：identifier/target 必填 TypeError 矩阵 + page/screen/client 坐标 +
radiusX/radiusY/rotationAngle/force 缺省 0）、`TouchList`（length/item/indexed、
`[object TouchList]` class 串）、`TouchEvent` dict（touches/targetTouches/
changedTouches TouchList 化 + altKey/ctrlKey/metaKey/shiftKey 布尔）。目标态：
touch-touchevent-constructor 5/5、historical 8/8（保持 3P + 收 5F）、GEH/expose-legacy
维持现值（构造器存在性与 `ontouch*` 曝出解耦）。

运行入口：`make testharness-touch-events`（test-guard 包裹；filter 透传，
`--json` 捕获证据）。
