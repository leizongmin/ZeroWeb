## 修齐内容（part02.js / js_dom_bridge.rs）

1. **urlencoded 容错 percent-decode**（`_zw_usp_decode`，urlencoded-parser 67→75/105）：
   `%XX` → 字节、非法 % 序列字面保留、UTF-8 lossy 解码——**不抛 URIError**（
   `decodeURIComponent` 的 %FE%FF/%C2 面根因）；复用 M2-S1 `_zwPercentDecodeBytes`
   （surrogate pair 感知）。URLSearchParams 构造/解析全路径切换。
2. **URLSearchParams 构造 sequence 形态**：数组优先于 forEach（Array.forEach 的
   (val, index) 形态曾把数组当 record → 索引键）；逐项恰为二元组（非二元组 →
   TypeError，spec）——urlsearchparams-constructor 19→22/27。
3. **live 光标迭代**（entries/keys/values 基于当前 `_p`——delete-during-iteration 面，
   Headers live 语义同型）+ **size getter**（urlsearchparams-size）+ **delete 第二参
   optional**（显式 undefined = 未给——「Two-argument delete respects undefined」）。
4. **URL.parse 静态**（url-statics-parse **16/16**）：解析成功返 URL 实例、失败返
   null，不抛。
5. **port setter 剥离解析**（`set_url_port_stripping`，url-setters-stripping 168→198/260）：
   先剥 TAB/LF/CR（spec integer 解析的 whitespace 剥离）→ 最长 ASCII 数字前缀
   （后续垃圾截断——`90\x0000` → 90）→ 越 u16 / 无数字 → **setter 无操作**（保留原
   port——leading 非 strip 控制符面）；scheme 默认端口归一由 url crate 承接。

## 残余簇（记账）

- **setters-stripping protocol/host/hostname c0 面**（62）：scheme/host setter 的
  U+0000/U+001F 行为（host 侧 url crate set_scheme/set_host 严格形态 vs spec 的
  剥离/percent-encode 语义）——URL record 深保真，后续切片。

  字节合并为单 U+FFFD（spec 每字节一 U+FFFD——%FE%FF → 2 个）——TextDecoder
  解码保真，encoding-compat goal 域相邻，记账。
