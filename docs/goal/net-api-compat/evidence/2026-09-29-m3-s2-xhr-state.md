## 修齐内容（part03.js / part05.js / testharness.rs）

1. **responseType 状态机**（xhr.spec §3.6.8）：枚举外值忽略（nosuchtype 面——getter
   恒 ''）；LOADING/DONE → InvalidStateError；**sync 标记 + OPENED → InvalidAccessError**
   （responsetype.any 13→**50/50**）。
2. **同步 XHR**（open async=false）：send 经 host `__zw_fetch` 同步契约直返（runner
   路径；异步 host 回落 error——浏览器同步 XHR 已知限制注记）；readyState 同步推到
   DONE。响应填充抽 `_zwFillFromResponse` 共享路径（async/sync 同构）。
3. **overrideMimeType**（xhr.spec §3.6.7）：LOADING/DONE → InvalidStateError；MIME
   parse 失败 → **application/octet-stream**（spec 逐字——非 text/plain）；charset
   参数 → final encoding 优先（override wins over response charset——「enforcing
   Shift-JIS」面）；blob final MIME：override 逐字 → CT 提取（失败 → text/xml 回落）。
   overridemimetype-blob 1→**77/77**、done-state **1/1**。
4. **responseType 效果**：json（解析失败 null）/ arraybuffer（Uint8Array）/ blob
   （final MIME）/ text。responseXML 恒 null（XML 解析未实现注记）。
5. **getResponseHeader 空值修复**：'' 头返回 ''（`|| null` 吞空值——getresponseheader
   「content-length expects 0」形态）。
6. **ProgressEvent init dict IDL 转换**（progressevent-constructor 4→**10/10**）：
   `_defineEventSubclass` 第 4 元可选转换器（boolean→Boolean、unrestricted double→
   Number）；`_makeEvent` type DOMString 化（`new ProgressEvent(null)` → 'null'）。
7. **P7 fixture 续**：`xhr/resources/status.py`（上游逐字等价——code/text/content/
   type 四参；content 保留原始字节经 body_bytes 保真，不落 lossy UTF-8）+ 站点根
   `wpt.test /` 最小根页（responsetype DONE 腿 `open('get','/')` 非空响应体）。
