## 修齐内容

### runner fixture（testharness.rs，上游逐字等价、零落盘）

- **`xhr/resources/content.py`**（XHR 域公共回显端点）：回显请求体（`?content=`
  覆写）+ `Content-type text/plain`（`?response_charset_label=` 追加 ;charset=）+
  `X-Request-Method/Query/Content-Length/Content-Type` 探针头。置于 handler 非 GET
  拒绝**之前**（POST 面）。
- **`xhr/resources/*.asis` 原始 HTTP 响应通道**（6 文件嵌入）：状态行（含 280/444
  非常规状态）+ 头列表（空值/重复头/`\t` 形态逐字保留）→ FetchResponse。

### shim（part01/02/03）

- **URLSearchParams 序列化 spec 化**（url spec urlencoded serializer）：`*-.` `_` 字
  母数字直出、0x20→`+`、其余 %XX 大写——原 `encodeURIComponent` 漏 `!'()` 与 `~`
  （send-usp 0x21/0x27/0x28/0x29 断言面）。
- **fetch body init：type-less Blob 不再派生 `application/octet-stream`**
  （fetch spec——仅 `Blob.type` 非空才派生 CT；X-Request-Content-Type: NO 断言面）。
- **UA 内部 Content-Length**：fetch 层对已知字节体补齐（byte-wire 计数 / UTF-8 字节
  长度；forbidden header 名单内 JS 不可自设）。
- **XHR send() 语义**（xhr.spec，同步/异步共用路径）：GET/HEAD → data 置 null
  （无体、无派生 CT）；USP 体 + 作者 CT 带 charset → charset 替换为 UTF-8。
- **同步 XHR 体类型分发**对齐异步路径（R3014/R3020）：Blob/FormData 经 byte-wire
  二进制保真（原 `String(body)` → '[object Blob]' 线上垃圾）+ 派生 CT + Content-Length。
