## 修齐内容

### shim（part02/05）

- **live cursor 迭代**（WebIDL value pairs iterator）：entries/keys/values 返 cursor
  迭代器（迭代中 delete 使后移元素跳过、append 元素可达；迭代器自可迭代）。
- **Blob/File 值 File 化**（spec entry value）：`new File([value], filename ??
  value.name, { type, lastModified 保真 })`——get 恒返同一实例。
- **(form, submitter) 双参构造**：submitter 校验（非 submit 按钮 → TypeError；
  form= 属性/getElementById 或 closest 属主 ≠ 本 form → NotFoundError）；枚举改
  **文档树序 + form owner 过滤**（form= 关联的站外元素入列——outerNamed 面）；
  submit 按钮仅 submitter 本尊入列（image → name.x/name.y）；元素身份经 `_elKey`
  稳定键（proxy 重建无关）。
- **append filename 校验**：非 Blob 值带 filename → TypeError。
- **FormDataEvent**（part05——**eval 序根因**：块初置 part02 引用 part05 才定义的
  `Event.prototype` → ReferenceError 使 shim 装载中止、part03+ 全失（webdriver
  「document is not defined」五连根因），二分定位后迁至 ProgressEvent 之后）+
  构造器 'formdata' 事件派发（e.formData 可变、构造结果为事件对象副本、
  `__zwFormDataConstructing` 重入 → InvalidStateError）。

### runner fixture（testharness.rs）

**`xhr/resources/upload.py`**（上游行为等价）：multipart/form-data 解析（boundary
自 Content-Type——**`boundary=` 为 9 字符**，off-by-one 探针定位）→ 无 filename part
按名排序输出 `key=value,` + `\n` + filename part 按名排序输出
`key=filename:ctype:len,`。
