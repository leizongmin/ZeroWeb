## 修齐内容（part02.js）

### 1. Tee composite cancel（spec ReadableStreamDefaultTee cancel1/2Algorithm）

- 分支 cancel 记 reason → 双 canceled → 源 `_doCancel([reason1, reason2])`
  （「canceling both branches should aggregate the cancel reasons into an array」双序
  面）；单 canceled → teeCancelPromise 挂至对侧；分支自身先关（cancelInternal）再聚合。

### 2. 源 error 前向传播（spec tee 步骤 19）

- reader.closedPromise rejection → **立即** error 两分支（不待分支 pull——
  「errors in the source should propagate to both branches」面）；branch controller 经
  start 外捕获锚挂接（构造期 TDZ 规避）。

### 3. canonical 构造器捕获 + prototype 方法委托

- tee 分支用 `self.constructor` 捕获的原构造器构造（页面替换全局 ReadableStream 后
  tee 不受扰——「should not use a modified ReadableStream constructor」面）。
- **prototype 方法委托**：getReader/cancel/values/tee/pipeTo/pipeThrough 上移
  prototype（转发到实例闭包别名）——页面捕获 `prototype.getReader` 后 `.call(rs)` 面
  （「Cannot read undefined.call」根因）。
