## 变更清单

### shim — send() invoked 状态机（xhr.spec §3.5.6）

- **send() 步骤 2**：`_zwXhrSent` 已置 → InvalidStateError（loadstart-and-state
  「send() during loadstart」面——原实现缺该守卫，handler 内重入 send 沿 loadstart
  无限递归，页面级 Timeout）。
- **send 步骤 11.6**：loadstart 后 state 非 opened 或 send() invoked 已撤 → return
  （handler 内 abort()/open() 不发题、无 upload 事件）。
- **open() 步骤 11**：upload listener flag / upload 完成标记随 open 重置。
- **handle response end-of-body 步骤 8**：正常完成撤 `_zwXhrSent`；request error
  steps 步骤 2：error/timeout/abort 路径同撤。

### shim — upload 事件 finite 模型重做

- **upload listener flag**（spec send 步骤 5——send 时点快照）：addEventListener
  注册或 on* 处理器属性任一即置位；transmission 与 upload 事件仅 flag 下派发
  （event-upload-progress「registered too late」面——late 注册不回溯）。
- **upload loadstart**：send 同步派发（spec 11.5——upload complete false 且 listener），
  `(0, ulen)`、length 0 → computable false（§5.1 fire 语义）。
- **upload progress/load/loadend**：挂 fetch 成功路、先于 fill（processRequestEndOfBody
  时序；CORS 失败/超时不派 progress——event-error-order「no progress events due to
  CORS failure」面；abort-during-upload：abort 先至则不派不发）。
- **request error steps 步骤 6**：abort/timeout/error 路径补 upload `{event}` +
  loadend `(0,0,false)`（event-error-order upload.error 面 / event-timeout-order
  upload.timeout 面）。
- **error/loadend ProgressEvent 化**：rejection 与 fill 错误分支改 `fireP`
  `(0,0,false)`（event-error「instanceof ProgressEvent」+ security-consideration
  零值面）。

### shim — 响应事件 Content-Length 语义（§5.1 fire + handle response end-of-body）

- fill 补 **progress** 事件（async 限定，先于 DONE rs）；
- load/loadend 的 total/lengthComputable 改按响应 **Content-Length** 提取
  （非整数 → 0、computable = length ≠ 0）——firing-events-http-{content-length,
  no-content-length} 面；
- LOADING rs 双发（processBodyChunk 每块一发——event-readystatechange-loaded 面）。

### shim — 其他语义面

- **GET/HEAD body 置 null 前移**（spec send 步骤 3——upload complete true，无 upload
  事件，修复 GET 带参体误派 upload loadstart）。
- **ArrayBuffer/ArrayBufferView 体**：XHR String 化豁免 + fetch shim byte-wire
  （XMLHttpRequestBodyInit 合法体——send-data-arraybuffer / send-data-arraybufferview）。
- **responseType 'document'**：final MIME 提取后 response 置 null（set a document
  response 非 HTML/XML MIME return——responsexml-invalid-type 面；XML/HTML 文档解析
  深水记账）。
- **TextDecoder UTF-8 decode 剥流首 BOM**（encoding spec；json.any.js data: URL
  BOM 面）。EventSource `_process` 原地 `replace(/^﻿/)` 移除（双重剥除曾致
  format-bom-2 误伤——修复后 35/35 归位）。注意 decode 入参为 host wire array-like
  （无 subarray）——BOM 剥除用泛型拷贝。
- **FormData.set filename 守卫**：非 Blob 值带 filename → TypeError（上轮遗留 WIP，
  set-formelement 面）。
- part01 fetch shim：wptserve trickle 管道语法 `?pipe=trickle(d1)`/`trickle(1)`
  shim 侧延迟映射（fetch 域 trickle 页前置）。
