## 修齐内容（part02.js tee）

- **分支字节流身份**：字节源 tee → 分支 `type: 'bytes'`（byob reader/pull-into/
  byobRequest 在分支上可用——byte tee 31 腿的公共前置）。
- **双分支 chunk 克隆**：spec ReadableByteStreamTee——branch1/branch2 均收 chunk 克隆
  （原 buffer 属源；「chunks should be cloned for each branch」双缓冲独立面）。
- composite cancel/源 error 前向/canonical ctor 继承（M4-S8）。
