## M1 基建注记（随基线同轮落地）

1. **runner 通道**：`zero-wpt-runner testharness-net-api`（`NET_API_CORPUS_SUBDIRS` 24 目录 +
   `net_api_case_skipped` 内容筛减 + `run_net_api_subdirs` 扫描执行——`.html` 直跑 +
   `.any.js` window 变体，timing/wasm/fs 先例）；Makefile `fetch-wpt-net-api` /
   `testharness-net-api`（test-guard 包裹，FILTER 透传）。
2. **goals/lib.sh 扩展**（opt-in 语义，既有 goal 零行为变化）：
   `GITHUB_TOKEN` 认证列目录（未认证 60 req/h 限流对六 corpus 一轮拉不完）；
   `GOAL_PULL_ANY_JS=1` 拉 `.any.js`（streams/ 以该形态为唯一面）；`.json` 数据
   依赖随 .js 拉取（mimesniff/url 用例 fetch 的数据资产）。
3. **幂等快路径陷阱**（复跑经验）：目录已含 `.html` 即跳过 API 列目录——历史轮
   非 any.js 形态拉过的目录（xhr/、streams/ 顶层）在 opt-in 后会永久漏拉 `.any.js`，
   需删该目录 `.html` 触发重列；目录内含 `.html` 且曾有瞬时 fetch 失败同样不自愈
   （fetch/api/resources/utils.js 需手动补拉）。后续 goal 启用 any.js 拉取时注意。
