## 失败簇（141F + 3T 全归因）

| 簇 | 数量 | 根因 | M2 动作 |
|---|---|---|---|
| brotli 格式缺失 | 70 | mission 明确 defer（需 brotli crate，不新引重依赖）；Chrome 137+ 支持，本仓不支持构造抛 TypeError 后仍 Fail | 挂账不修 |
| 非 BufferSource chunk 未拒 | 48 | `_zw_bufToBytes` 宽松（undefined→[]、array 误收）；write 不 reject | 严格 BufferSource 校验 → transform 抛 TypeError |
| corrupt-input 期望 error | 15 | flate2 读路径不校验 trailer（截断/trailing junk 静默成功）、错误以 DataError 抛出（期望 TypeError）、zlib 头 CMF/FLG/FDICT 校验缺 | 手工帧校验（CMF/FLG/FDICT/adler32/CRC32/ISIZE + 截断/多余输入检测）+ 全部错误 TypeError 化 |
| 空流误报错 | 3 | 合法空 gzip/deflate/deflate-raw → shim `!out && bufs.length` 误判为错误 | 流式 finish 语义（0 输出 = done 非 error） |
| 构造器异常类型 | 4 | `NotSupportedError`（期望 TypeError）；undefined 不走 ToString | WebIDL enum 转换：ToString + 不在枚举 → TypeError |
| 流式解压缺失（死锁） | 3T（9 子测试） | buffer-then-flush：write 后未 close 读不到输出 → read() 永挂（correct-input/extra-input/uint8array-output 整案 Timeout） | 流式 update/finish 状态机（flate2 增量解压） |

## 结论

- DC-1 满足：导入 + 基线 + csv planned 行转数据行（同 commit）。
- M2 = 实现轮：上述 5 个修复簇对齐后，非 brotli 面预期全绿；
  终态分母 309、brotli 70 挂账 → 理论上限 239/309（77.3%）。
- 依赖复用确认：flate2 = engine 既有直接依赖（WOFF zlib 解码先例），M2 不新增依赖；
  CRC32/adler32 用 flate2 内建（`Crc`）或最小内联实现，不动 manifest。
