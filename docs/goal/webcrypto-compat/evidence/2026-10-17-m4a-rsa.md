# M4a RSA 家族——OAEP/PSS/RSASSA-PKCS1-v1_5（2026-10-17）

crypto.subtle 签名与加密系 RSA 三算法全链落地：importKey（spki/pkcs8/jwk）、
generateKey（CryptoKeyPair）、exportKey（spki/pkcs8/jwk）、encrypt/decrypt
（RSA-OAEP）、sign/verify（RSASSA-PKCS1-v1_5/RSA-PSS）、wrapKey/unwrapKey
（RSA-OAEP wrapper + 非对称 spki/pkcs8 回导）。全量 **32,899 = Pass 17,741
（53.9%）+ Fail 15,157 + Timeout 1**（M3b 15,390 → **+2,351**），123 文件逐一
对比**零回归**；全绿案 27→**41**（+14：rsa_importKey、generateKey RSA 六文件、
rsa_oaep/rsa_pss/rsa_pkcs、wrapKey_unwrapKey、serialization rsa 三文件、
failures_bad_algorithm）。

## 改动

1. **依赖**：`rsa = "0.9"`（RustCrypto，pure Rust）+ sha1/sha2 `oid` feature
   （DigestInfo 前缀）。选型对比与影响面见
   [M4a 依赖选型](2026-10-17-m4a-deps.md)。
2. **host** js_dom_bridge/crypto.rs：RSA 原语九枚——`rsa_generate`（e≥3 奇数
   校验，e 非法先于生成失败）、`rsa_import`（spki/pkcs8 解析后规范化再编码，
   DER round-trip 逐字节稳定）、`rsa_jwk_import`（n/e/d/p/q 分量合成，素数成对
   校验、d-only 反推、p·q=n 与 d·e≡1 一致性）、`rsa_key_attrs`（n 位长 + e 大端）、
   `rsa_export_der`（私派生公）、`rsa_export_jwk`（CRT 分量 dp/dq/qi 按
   RFC 8017 §3.2 重算）、`rsa_oaep`（label 经 UTF-8 FIXME——corpus 均 ASCII）、
   `rsa_sign`/`rsa_verify`（prehash 后 Pss::new_with_salt/Pkcs1v15Sign，verify
   坏签名返 "0" 不报错）。callbacks.rs 注册对应 `__zw_crypto_subtle_rsa_*` 九枚。
3. **shim** part01b.js：`_zw_normalizeImportAlgorithm` RSA 臂（hash 成员缺失 →
   TypeError、非注册摘要 → null、RSASSA 名回写规范拼写）；RSA helper 簇——
   家族判定/全 usages/类型子集/jwk alg 映射（RFC 7518 §A.2）、`_zw_rsaImportKey`
   （usages 家族 SyntaxError → spki/pkcs8 DER DataError → 类型 usages SyntaxError
   → jwk kty/use/key_ops/ext/alg 链 → private 空 usages SyntaxError 置最后）、
   `_zw_rsaGenerateKey`（非法 usage SyntaxError → 生成 OperationError → 私钥空
   usages SyntaxError，publicKey 恒 extractable、usages 按类型拆分）、
   `_zw_rsaExportKey`（非 extractable → InvalidAccessError、pkcs8 仅 private）、
   OAEP/签名 host 调用桥（decrypt 长度预检 + 空明文空返——密文 csv 空串歧义消除，
   WPT transferred-plaintext 组依赖）。
4. **shim** part02.js：importKey/generateKey/exportKey/encrypt/decrypt/sign/
   verify/wrapKey/unwrapKey 九方法加 RSA 分派；unwrapKey 格式扩 spki/pkcs8，
   jwk kty 校验归 importKey（RSA-OAEP 可封装非对称密钥）；encrypt/decrypt 算法
   名匹配统一 ASCII 折叠比对。
5. **测试**：part53 `test_crypto_subtle_rsa_m4a`——1024 位（快）语义锚定：
   密钥对结构断言（RsaHashedKeyAlgorithm 成员/usages 拆分/extractable）、OAEP
   round-trip + 密文 128 字节 + 两次加密密文不同、RSASSA 两次同签确定性 +
   篡改验签 false + 跨算法 InvalidAccessError、PSS saltLength=0 确定性 + 错
   saltLength false、spki/pkcs8/jwk round-trip 逐字节一致、非 extractable 导出
   InvalidAccessError、错误矩阵 ×6（e=1 OperationError、空算法 TypeError、
   类型 usages SyntaxError ×2、jwk kty/alg DataError ×2）、RSA-OAEP 封装
   wrap→unwrap round-trip。
