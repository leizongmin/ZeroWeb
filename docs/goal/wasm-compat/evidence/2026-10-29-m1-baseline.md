## 前置修复：runner 页面环境 async wasm 编译面收敛（M3 项下）

首跑（修复前）全语料每案顶满 30s 单案超时（3600s 守卫切零输出）。最小复现页
（`WebAssembly.compile(bytes)` promise 链 + async_index `chain` waiter）隔离出根因：
**回挂原生后，原生 V8 `WebAssembly.compile/instantiate` 的 async 编译完成回调依赖平台
foreground task 泵，runner 页面循环只驱动 microtask/setTimeout——promise 永不 settle**。
同步面（Module/Instance/Memory/Table/Global 构造与反射）不受影响。

修法（`testharness.rs` runner 预热回挂点，生产路径不动）：async 四件
（`compile`/`instantiate`/`compileStreaming`/`instantiateStreaming`）以原生同步原语重接，
语义按上游 jsapi 钉齐：

- `instantiate` 双重载——Module 形参同步读导入（getter 同步触发）+ resolve 裸
  `Instance`；Buffer 形参**调用时同步快照字节**（「Changing the buffer」钉死）+ 编译
  链接推迟到 promise job（导入 getter 不得同步触发）+ resolve `{module, instance}`。
- 非对象 `importObject` → rejected promise（上游 `promise_rejects_js` 语义，非同步 throw）。
- `compileStreaming`/`instantiateStreaming` 走 Response `arrayBuffer()` + Content-Type
  `application/wasm` 判定（大小写不敏感、参数剥离）。
- `length` 按上游 IDL（`importObject` optional → 1）；具名函数表达式保 `name`。

## 缺口明细（36F，M2 归簇）

**memory64 簇（9F）**——64 位地址面，定性为 V8 memory64 proposal 门控语义差
（挂账 M3：开 flag 实验涉及 runner V8 初始化面，影响全 wasm 通道，须单独轮次验证）：

- 8F 形态 `assert_equals: expected false but got true`——spec 解释器期望
  `WebAssembly.validate` 判 false 的模块，本环境判 true（`memory64.wast:8`、
  `table64.wast:9`、`table.wast:9` 编译面）
- 1F 形态 `unexpected instantiation error, observed TypeError: ... (reading 'source')`
  ——wast harness 错误对象形态差（`memory64.wast` 实例化面）

- `memory64.wast.js.html` #6/#7/#36/#37/#38——`memory64.wast:8/9` 编译面 + 实例化
- `table64.wast.js.html` #10/#33——`table64.wast:9` 编译面
- `table.wast.js.html` #8/#55——`table.wast:9`（64 位 index 语法边界）

**webapi streaming 集成簇（27F）**——同根因：runner fetch 桥 Response 缺标准
`arrayBuffer`/`headers`/body 流面，四件 streaming 包装的 Response 鸭子判定拒真：

- `contenttype.any.js` 6F（含合法 `application/wasm` 应过面——拒真证据）
- `abort.any.js` 6F（AbortError 竞态语义）、`empty-body.any.js` 4F（期望 CompileError）
- `wasm_stream_compile_test.any.js` 3F、`wasm_stream_instantiate_test.any.js` 3F
- `body.any.js` 2F（body 消费交互）、`rejected-arg.any.js` 2F、`historical.any.js` 1F

顶层残差 2F（`table.wast.js.html`，已归 memory64 簇 64 位 index 面）。
