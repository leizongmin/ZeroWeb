## 可执行性甄别（DC-3 前置结论）

上游 26 `.html` + 30 `.window.js` 中，**可执行子集仅 `.window.js` 25 案**；排除面：

| 排除域 | 案数 | 不可执行原因 | 归属 |
|---|---|---|---|

| `*window_open*.window.js` / `storage_session_window_reopen.window.js` | 4 | window.open 第二 browsing context（会话历史/持久性断言） | 同上挂账 |
| `localstorage-cross-origin-iframe.https.window.js` | 1 | 跨源 iframe | 同上挂账 |
| `document-domain.html`、`*.partitioned*.html`（2）、`localstorage-share-data-unrelated-origins.html` | 4 | document.domain / 存储分区（第一方-第三方） / 跨源双 iframe——origin 隔离的跨上下文面，单文档静态 runner 无对应域 | origin 隔离单文档面已入可执行子集；跨上下文面挂账 |
| `storage_local-manual.html` / `storage_session-manual.html` | 2 | manual（真实用户操作打开多窗口） | 不执行 |
| StorageEvent **构造面**（`event_constructor.window.js` / `event_initstorageevent.window.js`） | 2 | **可执行**（纯构造/init 语义，无派发）——已入执行面，M3 甄别切片的 runner 侧可执行子集即此 | DC-3 可执行子集 |

## 失败聚类（M2/M3 修齐方向）

| 簇 | 案面 | 形态 | 归属 |
|---|---|---|---|
| named property 写入/定义语义 | defineProperty 0/12、set 8/20、symbol-props 6/14、storage_builtins 0/2 | `Object.defineProperty(storage, k, {value})` 不入存储（Proxy defineProperty 未拦截，直接落在 target）；`Object.prototype` 上数据/访问器属性对 named set 的遮蔽序；Symbol 键与 builtins（getItem 等）不可被 named property 覆盖 | **M2 P1**（shim Proxy trap 面） |
| 方法缺参 TypeError | missing_arguments 0/10 | `getItem()`/`setItem(k)` 等以 JS function 实现，无 WebIDL arity 校验 | **M2 P2** |
| `key()` 大 index 转换 | storage_key 14/22 | `key(4294967296..9)` 应按 WebIDL `unsigned long` modulo 2^32 取模（4294967296→0） | **M2 P2** |
| 配额强制缺失 | 4 案 quota（各 0/1） | 无 QuotaExceededError 抛出；local/session 配额独立性无从验证 | **M2 P3**（配额为 UA 定义值，shim 可取规范常见 5MiB/origin 近似） |
| StorageEvent 构造/init | event_constructor 3/6、event_initstorageevent 0/5 | `StorageEvent` 构造器与 `initStorageEvent` 成员缺位（当前仅 3/6 靠 Event 基类兜底） | **M3**（DC-3 可执行子集） |

## M1 结论

- DC-1 达成：通道 + 基线 + csv 回填齐备；基线 94.9%（1187/1251）。
- DC-3 甄别结论：runner 可执行子集 = StorageEvent 构造/init 2 案（上表）；派发面
  17+5 案挂账 frame 树依赖，与 navigation-compat M3 同门槛，不单方面开。
- M2 切入点：失败聚类前四簇（P1 Proxy trap 面 → P2 arity/转换 → P3 配额）。
