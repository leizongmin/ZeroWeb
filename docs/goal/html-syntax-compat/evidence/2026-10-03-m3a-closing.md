## 关键诊断（记账）

1. **probe-dbg1**：浅 selector 条目（`{"k":"E","s"}`）在 fragment 树形下失效——shim
   `_zwMBuildNode` 全文档 re-parse 二次定位把 bare `<noscript>` 归置 head 且
   scripting enabled rawtext 内容吞掉 → `fragment_children_json` 改深 JSON
   （`deep_entry_json`，与 `template_contents_json_doc` 同形态）全子树直发。
2. **probe-dbg5/8**：document.write 写入 div 的 `querySelector` 命中（R57 view doc
   烘焙 InsertAdjacentHtml）但 `__zw_child_nodes` 读链走 live doc（无 pending
   structural mutations）——**查询视图/子树读链分裂 seam**：wrapper 子树读恒空。
   `getElementById` 定点修：`_zwPendingAddedById` 命中优先返回（全子树本地视图），
   in-doc 门扩展到 `_zwSelPendingParent` 补偿槽。
3. **ensureTree() 无返回值**——detached doc.write 首版 `var t = ensureTree()` 得
   undefined（改闭包变量 `_tree` 直用）。

## 残差（本轮记账，非阻塞）

- **ambiguous-ampersand.html**（1/3）：char-by-char `document.write` 流已同步重放
  （静态 div 存活），但写入子树的 `div.childNodes` 读链仍 hit live/view 分裂 seam
  （`__zw_child_nodes` live-aware vs 查询视图烘焙）——解析插入子树的**同 turn 全
  API 面读一致性**需 view doc 统一（`__zw_child_nodes` 接 view doc 的架构片），
  归 M3 后续/R57 体系。
- **XHR XML MIME**：responseXML 的 XML 文档解析仍 null（spec XML parser 面，
  FIXME 保留）。
- **静态 `<template><noscript>` 文档解析面**：html5ever 文档解析恒 scripting
  enabled → 静态模板内 noscript 字面（spec 期望 template contents owner document
  disabled）——语料面（动态 innerHTML）本轮已修；文档解析面待 html5ever 0.39 升级
  片一并评估。
