## html5ever 0.39 升级评估——结论：升级无法闭合 svg-script 残差

M4 残差账「html5ever 0.29 core 8F（升级评估账）」逐项实证重归因：

1. **definitionurl 调整**：html5ever 0.29.1 的 `adjust_mathml_attributes` 与
   main 逐字相同，DOM 存储正确（调整后小写 definitionURL 入属性表）——
   R5004 落地后 math-parse01/03 整页全绿（28 子测 0F），读侧假设证伪。
2. **annotation-xml integration point**（math-parse 3F）：我方 TreeSink 缺口
   （0.29 已有协议方法，默认 false）——R5004 已修，与升级无关。
3. **unclosed-svg-script 2/4 残**：`complete_script` 在 0.29 与 main 均为
   **死 API**（树构造器从不调用——上游 tree_builder 源码比对）；「已闭合/未闭合
   script 执行态」「HTML breakout 判别」不可从树形态区分，需 tokenizer 状态。
   升级 0.39 无法闭合「SVG scripts without end tag should not run」与
   「ended by HTML breakout should not run」两案。
4. case 5（self-closing `<script href>`）：我方 extractor 缺口——R5005 已修。

**账目变更**：升级评估账 8F → 实际升级可闭合 0F；残差改记「html5ever
tokenizer 能力缝 2F」（svg-script 2 案）+ shim 读侧 definitionURL 面
（math-parse03 余 1 子测，读侧未再深挖）。升级评估项关闭。
