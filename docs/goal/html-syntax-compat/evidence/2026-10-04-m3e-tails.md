## 修齐簇

| 簇 | 修法 |
|---|------|
| form.action/formAction URL 反射（~210F） | FORM action 分支解析绝对 URL（parse_url + 文档 base，missing → ''）；input/button/select/textarea/output 的 formAction gated getter——非空解析、空/missing → 文档 URL（spec form owner action 缺省） |
| formMethod/formEnctype 枚举（~390F） | gated 枚举 getter：[get,post,dialog] invalid → 'get'、三值 enctype invalid → urlencoded（置于 R3037 MAP 直读之前——同遮蔽规避） |
| form.autocomplete enumerated（51F） | on/off 小写归一，invalid/missing → 'on' |
| progress.max double 反射（90F） | gated double getter（spec 浮点解析 + >0 有效，invalid/≤0 → 1）；li.value signed long（default 0） |
| embedded URL 族（img.lowsrc/longDesc、object.data/codeBase、video.poster、audio/source/track.src、blockquote/q/ins/del.cite、img.src、script.src 等 ~500F） | `_REFLECTED_URL_TAGS` 表 + `_reflectedUrlAttr` gated getter：非空解析绝对 URL、missing/空 → ''（harness resolveUrl 自洽口径） |
| embedded 枚举（referrerPolicy 324F、decoding 70F、loading 106F、a.referrerPolicy） | gated 枚举 getter：referrerPolicy 九关键字（含空串，invalid → ''，img/iframe/area/link/**a**）、decoding → auto、loading → eager |
| embedded/obsolete 杂面（~400F） | FLAT + border/srcdoc/integrity/hreflang/charset/rev/clear/event/for；BOOL + allowFullscreen/noModule（IDL 名修正）；useMap MAP 映射；canvas standalone 属性方法面（setAttribute/getAttribute/hasAttribute/removeAttribute + dir 枚举 + width/height attr 反射读——setter 位面/复位语义不动） |
| 未定义元素全局枚举（undefinedelement.inputMode/enterKeyHint ~170F） | inputMode/enterKeyHint 全局枚举 getter（8/7 关键字，missing/invalid → ''） |
| iframe/embed/object width/height string 面 | 数值 width/height 分支收窄 IMG/CANVAS/VIDEO（iframe/embed/object 归 FLAT string 面） |
| obsolete marquee 数值/布尔（185F） | scrollAmount/scrollDelay gated unsigned（default 6/85）；frameset cols/rows string 面专用（与 textarea UINT 同名异型） |
