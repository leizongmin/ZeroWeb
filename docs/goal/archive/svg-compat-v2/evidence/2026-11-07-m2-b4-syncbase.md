## 1. 实现落点（`crates/engine/src/js_dom_shim/part09.js`，+253/−93）

- **interval 链 = 文档级时间序离散事件模拟 `_docChains(doc, t)`**：每元素
  记录 pendB/pendE（升序实例集）、ib（消费指针）、ivs（已建 interval）；
  deps 槽按引用目标 id 每查询从现行文档重建（remove/重建自动重挂——
  syncbase-after-removal 定谳面）。主循环反复取全文档最早未消费 begin
  实例建 interval（guard 2000；t 之后每元素至多一个 pending——gap 期
  getStartTime 取下一 interval + 终止界）。interval end = 首个 > b 的
  end 实例与 b+actDur 取 min（M1 口径恒持）；e ≤ 0 剪枝 interval 建而不
  传播（first-interval dont-contribute 定谳方向恒持）。
- **传播（SMIL #Timing-SyncbaseValueSemantics）**：已建 interval 的 b →
  `.begin` 依赖、e → `.end` 依赖写给依赖者 dep.rec；传播值恒 ≥ 当前全局
  最小事件时刻，sorted-splice 插入不落消费指针前。自引用（0s;anim.end
  自续链）与互指环（a↔b）按时间序自然展开；零实例源环恒死锁（SMIL
  未解析口径）。end 实例截断依赖者已建含 v 区间（dependent-end 定谳面）。
- **begin 属性缺省回落 '0s' 收紧**：仅属性缺省/空白回落（spec
  #Timing-DefaultBegin）；属性在但零实例（indefinite / 查无目标 syncbase /
  B5 未接实例源形态）保持无实例——SVGAnimationElement-exceptions 定谳面
  不可回退。
- **转义 id 解析 `_parseTimingSpec`**：`a\.b.begin` 形态反斜杠转义点分段
  （SMIL ID 转义文法）；syncbase/event(repeat(n)/事件名) 识别，eventbase
  仅识别不解析（B5 FIXME）。
- **泵 tick 过冲窗口重放 `_scanDocEvents`**：自然 tick 对 (lastT, t]
  （首见 lastT=−∞）内真实流逝的 interval 边界按 b 升序补派——窗口内整体
  走完 → begin+end 成对；跨窗口结束 → 仅 endEvent；窗口内开始 →
  beginEvent（被替代旧 interval 未报 end 先补 end）。泵 tick 抖动跨过
  多边界时事件不丢不乱序（correct-events-for-short-animations-with-
  syncbases 的 assert_unreached 面）；seek 只推进 lastT 不重放（B3 矩阵
  恒持）。
- **链缓存 per (doc, t)**：`beginElement*` 作废（动态实例入集）；属性
  变更靠泵轮询下 tick 重算（同 tick 窗口 = 已知近似）。
- **`_scanDoc` 维持 doc.querySelectorAll**：本批实测文档作用域查询对
  动态 append 动画元素同步不可见（见 §4），child 链手工遍历可即时发现
  但产物 wrapper 族与消费端 `_elKey` 跨族失配（#32）17 子 P→F，已回退
  ——SMIL 动态元素发现挂引擎查询层归一，FIXME 落 `_scanDoc` 注释。
