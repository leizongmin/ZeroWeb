### 1.2 part09b.js — path d 域采样器（`_sampleAnimPathStr`）

- 复用 B6a/B6c 相位（`_smilPhase`）与文法 machinery，输出契约
  `{kind:'segs'|'raw', segs?, delta}` 接既有三明治层（`_zwSmilAnimPath`
  replace/sum + delta 预乘）。
- **解析与定标**：`_zwPathSegsOf`（comma-wsp 全文法，arity 校验，ERROR/
  前导数字 → null 无效不采样）、`_zwPathAbsOf`（双侧转绝对——H/V/A/M
  相对分量按 current point 折算，Z 闭合计 sx/sy）、`_zwPathCompat`
  （段数+段型序列一致才可插值）、`_zwPathEmitStr`（输出字母随采样值
  侧，lowercase 经 current point 行走重导 delta——in_array 双形态）。
- **四形态**：from-to 线性 lerp（全参数含 A 7 参，字母随 to 侧）；
  from-by/by-only 原始分量加法（`k·by` delta 预乘，by-only
  replace/sum 同值）；accumulate=sum 迭代叠加（from-to 侧 iter·to
  全值、by 侧 (segF+iter)·by 分叉）；mismatch/invalid 强制 discrete
  half 直通（含空 token 边界——both-empty 案 corpus 定谳）。
- **to-animation 定谳（本批主修）**：compat 且非 discrete → 线性
  lerp(base, to)——animate-path-to-animation @2.0/dur 4s = lerp@0.5
  中值非半程切换；不配或 discrete → half 切换 raw token（to-empty-base
  corpus 注释明示 structurally incompatible → discrete at 50%，空 base
  = [] 对非空 to 恒不配自然落此支）。
- **EDM 整数 ms 相位模型（精度定谳，本批主修）**：`_smilPhase` 追加
  `em/dm`（simpleTime/dur ×1000 取整；freeze 钳制后 em=dm 精确终值；
  degenerate/无限相位 null）。插值单参数式
  `(a·dm + (b−a)·em)/dm`——分子全精确整数、单次除法 correctly-rounded，
  与 Blink 全部 toFixed(2) 边界一致；by 增量缩放同法 `by·em/dm`。
  门控 `useEDM = em/dm 在场 && !accumulate && 无 keyTimes &&
  calcMode linear`（含 paced 别名）——accumulate 迭代比与
  keyTimes/spline 预映射 segF 面保持原路径。

### 1.3 已否决精度模型（node 双精度模拟逐案对照 corpus 字面量）

- float32 全链：svg1 by @3999 → "159.98" 与 corpus "159.97" 矛盾
  （Blink 非全 float32）。
- double omp C1–C4（`a(1−p)+bp`、`a+(b−a)p` 变体，p=3.999/4 或
  3999/4000）：预计算 frac 双精度偏上（3999/4000 =
  0.9997500000000000199…）乘积越界，cC-sS-inverse S y2 "40.00" vs
  "39.99"、MmAaZ a1 "60.00 40.00" vs "60.01 40.01" 域全 FAIL。
- to-frame（delta 域插值）可修 MmAaZ 但翻转 CcSs（s y2 delta
  0.005→"0.01" vs corpus 序列化 "0.00"）——否决，保持 abs-frame。
- harness 比对粒度：双侧经 serializePathSegList roundNumbers
  toFixed(2)（kDecimals=2）——corpus 字面量为 Blink shortest-repr，
  got 侧 emit shortest；真值恰落 .xx5 边界时两侧按各自舍入序对齐，
  EDM 模型 12/13 文件逐案一致。
