# DC-5② 前置：一期锚 → m2s4 单跳连续性证明 + 退役清单预编账（2026-11-02）

## 目的

收口重定基（DC-5②）要求「重定基轮与旧锚对老 stable 案逐 subtest 连续性
证明（同案同果）」。本预检把该证明**提前到 m2s4 时点**做一次单跳演练：
① 验证对账方法在真实锚对上成立；② 捕捉五个切片两两对账传递链之外的
累积漂移；③ 预编退役清单。M 末收口时对**终态锚**重算一次为准。

## 对账

- 旧锚：[一期终态锚 m6-residual](../../webcrypto-compat/evidence/2026-10-17-m6-residual-full.json.gz)
  （123 案 / 33,109 keys = P 25,788 + F 7,320 + T 1；与二期收口锚
  [2026-10-31-m1-baseline-full](../../webcrypto-compat-v2/evidence/2026-10-31-m1-baseline-full.json.gz)
  逐位相同）。
- 新锚：[m2s4](2026-11-02-m2s4-full.json.gz)（360 案 / 81,851 keys）。

结果（逐 (case, subtest) 单跳对照）：

- **0 案缺失**：一期 123 案全部在 m2s4 在位（新增式语料保留兑现）。
- **共享 keys 32,864 个状态逐位相同**；245 个状态迁移**全部 F→P**、
  零散——精确落 M2-1 门禁面三案：supports.tentative（171）+
  supports-modern.tentative（53）+ getPublicKey.tentative（21）。
- **1T 销案迁移**：algorithm-discards-context 案级 Timeout 键退役 +
  13 个子测试键 None→Pass（M2-4，见其 evidence）。
- **P→非P = 0；F→非P = 0；T→非P = 0**——五个切片两两零回归对账的
  传递链单跳复验成立，无累积漂移。
- （注：M2-1 门禁面共 +543P，此处只现 245——其余为上游语料在
  一期 pin 之后新增的子测试键，不在一期分母内，与上游事实节一致。）

## 退役清单预编账（DC-5②）

- 一期分母内 `.tentative.` 路径案：**49 案 / m2s4 态 7,340 keys**——
  收口重定基随终账退役（上游已删路径，无回归义务）。
- m2s4 全账 `.tentative.` 路径案：98 案 / 14,150 F（含上游后续新增的
  49 案）——M 末终账按同一路径规则整体退役，本地 65 个上游已删文件
  的语料清理随收口执行（goal 范围内既定动作，非不可再生资产误删）。
- 退役判据 = 路径含 `.tentative.`（上游 HEAD 布局无此维度）。

## M 末收口重算清单（DC-5② 履行时）

2. 终账 = HEAD 布局全量双腿账（98 案 tentative 退役后）；
3. 语料清理 65 个上游已删文件 + rev 记账更新。
