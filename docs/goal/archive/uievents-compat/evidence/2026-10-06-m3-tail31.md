## 落地（五件）

1. **TextEvent 接口特化**（part05/06）：`new TextEvent()` 抛 TypeError（throw
   wrapper 共享 prototype——`instanceof`/`window.TextEvent.prototype` 面不变）；
   内部 ctor（`_zwTextEventCtorRef`）供 createEvent('TextEvent') 与 shim dispatch；
   `data` 字段 + `initTextEvent`（0 参 TypeError；data 缺省 `'undefined'` =
   String(undefined)；view 缺省 null；字段填充同 initEvent R106/R110 面）。
2. **textInput 事件序**（UI Events legacy 附录）：`text_plan`（page-runtime）
   followup_events 首位插 textInput（insertText 类；beforeinput → textInput →
   input）；CE 插入管线 `__zw_ce_insert` 于 beforeinput 后插 textInput（**可取消
   完整保留**——取消中止插入）；shim dispatch 层 textInput → TextEvent 实例
   （bubbles/cancelable/view=window/data）。
3. **编辑键 key 名 + 键表**（runner send_keys）：uE003/uE004/uE006|uE007/uE017
   透传 **WebDriver 键名**（Backspace/Tab/Enter/Delete）——旧版原始 PUA 字符使
   页面 `e.key === 'Backspace'` 门铃恒 miss；uE006（WebDriver Return）接 Enter
   语义（Submit——keyboard-click-event 的 keyMapping 写 uE006）；uE017 接
   **ForwardDelete**（page-runtime 新 `HtmlUserAction::ForwardDelete` variant +
   `plan_text_forward_delete`——collapsed 删 caret 后一 UTF-16 单元（代理对安全）、
   caret 吸附原位；CE 宿主 noop 挂账——`__zw_ce_delete` 是 Backward 语义复用删错
   字符实证）。
4. **testdriver selectorFor shim 权威形优先**：`element.__zwSelector` 回查自指
   （querySelector 命中同一元素）才信任；stub 启发式（tag/attr/nth）对**无 id
   元素**产 tag 形（`input`）与 shim listener 注册 key 形不一致 → keydown/keyup
   经 sel-key listener store 静默丢（zzprobe 复刻实证：有 id `#i` 全序正常、无 id
   class 形只余 beforeinput/input（PageNodeRef 通道））。
5. **selection 状态 key sel 主导 + textarea value 直读**（part03/04）：
   - `_textSelKey(sel, handle)`（sel 主导）替换 selection getter/setter/
     setSelectionRange/setRangeText/select 的 key——`_elKey` handle 主导形在
     render_html rebuild 后 handle 换代孤儿化（前序命令 mutation 重建树 → 后续
     text control 的 selection 读缺省 (0,0)）。
   - value getter 直读分支对 TEXTAREA 补 `__zw_get_text(sel)`（child text live
     读——非 stable key 直读 value attr 恒 ''，无 value setter 的初始 child-text
     textarea 的 `.value` 丢初值 → DeleteBackward 快照 clamp (0,0) →
     NothingToDelete）。
