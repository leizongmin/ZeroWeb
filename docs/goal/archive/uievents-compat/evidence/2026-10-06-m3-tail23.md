## 落地（四件）

1. **body id 落视图**（part01 `_zwFinishIframeEntry`）：从原始 markup 直提
   `<body id=…>`，`setAttribute` 落 body 视图（视图 extensible、setAttribute/getAttribute
   链可用——probe 实证；`_r159BodyAttrs` 提取链对 fetch 形态断链的绕行）。
2. **per-frame capture 状态机**（part06 `__zwPortalCapture{Set,Release,Has}` +
   `__zwPortalProcessPendingCapture` + `st.portalFrame/portalCap/portalCapPending`）：
   ① 仅指针活跃于该 frame（`doc.__zwFrameSel === st.portalFrame`）可设，否则
   NotFoundError（inactivate_pointer 双向断面）；② 单指针单捕获；③ **pending 模型**——
   setPointerCapture 只记 pending，gotpointercapture 于**下一个 portal 事件派发前**
   随结算派发（PE spec process-pending；sync 派发曾使 corpus log 序 got 先于
   pointerdown——subtest 1 断言面）；④ pointerup 隐式释放派 lostpointercapture。
3. **视图方法补齐**（`__zwPortalAttachCaptureMethods`）：setPointerCapture/
   releasePointerCapture/hasPointerCapture 落 inner target（路由全局状态机）。
4. **portal 路由守卫**：捕获期全部事件随捕获目标（视口出框不丢）；外层真实捕获
   （st.capture/pending）优先，portal 不劫持；指针无捕获离框时 frame 活跃态清除。

## 调试陷阱（记入排除路径）

- `_zwPortalDispatch` 内引用跨函数 `st`（未声明）→ ReferenceError 被 dispatch 的
  try 吞 → 整个 portal 派发静默失效（probe canary 分层定位：caller 态 ✓ + callee
  首行 canary 未达 = 函数入参前抛）。修：显式 `_zwPtrState` 引用。
- 门户方法全局名裸标识符 `typeof _zwPortalCaptureRelease` → ReferenceError（仅
  globalThis.* 存在）——条件恒 false。修：`globalThis.__zwPortalCaptureRelease`。

  不可达）——回退 doc.body 优先。
