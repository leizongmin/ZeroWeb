## 失败聚类 → M2/M3 修复队列

1. **testdriver Actions 指针链退化**（M2 主根因）：注入 stub `pointerDown/pointerUp`
   no-op + `send()` 折叠为单 click——click-order/mouseover-out/mouse_buttons 等
   事件序断言全簇无从记录。修法：Actions 记录有序步骤 → 逐步入队 host 命令
  （`pointer_move`/`pointer_down`/`pointer_up`），事件序合成移到宿主层（keyboard
   keydown/keyup 命令先例同构）。
2. **宿主派发面缺事件类型**（M2）：`__zw_dispatch_event` mouse 分支无
   detail/button/buttons/relatedTarget、无 dblclick 组合、click 恒泛型 Event；
   pointer 类型落泛型分支（非 PointerEvent 类）。
3. **边界事件机制缺失**（M2/M3）：mouseover/out/mouseenter/leave 与 pointer
   对应物零合成——pointer 边界序、relatedTarget 断言全簇 fail。
4. **Pointer Capture 语义面**（M3）：R3068 permissive 捕获集——无 got/lostpointercapture
   派发、无 pending capture override、无隐式释放、无 NotFoundError 校验。
5. **touch-action CSS 面**（pointerevents parsing/touch-action 族 ~40 案）：`touch-action`
   解析/计算值已有 css-parser 面（parsing 三案 0P 待核对），交互面（scroll 干预）挂账评估。
6. **textInput 族**（0/7）：textInput 事件（legacy UI Events）+ enter/delete 编辑序——
   beforeinput 管线先例可复用，M2 尾评估。
