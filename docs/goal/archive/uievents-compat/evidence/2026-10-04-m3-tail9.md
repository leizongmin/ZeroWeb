## 修复（五件）

1. **image-map 几何命中**（runner `resolve_pointer_target` 命中测试 JS）：通用 gBCR
   扫描得 `best` 后，遍历 `img[usemap]` → map（getElementById / `map[name=]` 回落）
   → `querySelectorAll('area')`，按 shape rect/circle/poly（ray casting）+ default
   做局部坐标几何命中（**文档序首个 inside 即 top-most**——上游断言「insertBefore
   的新 area 为 top-most」实证），双 img 共 map 时镜像 containment 校验。+12 主面。
2. **跨目标 click 组合以实派 target 为准**（shim `__zw_pointer_up_sequence`）：
   `effDown = st.downSel || downSel || upSel`（旧序 downSel 编码值优先）——stub 编码的
   downSel 是 down 步 **origin 元素**（enqueue 时点近似；image-map 面 origin=img 而
   实派目标=area），组合目标折算以 shim 实派记录为准（UI Events §5.2.2 mousedown
   target 语义）。+2（click@area 双 variant）。
3. **mutation 驱动悬停失效的变异代际扩面**（part04 钩子）：悬停元素自身属性变异
   （coords/width/style 等可改几何）+ IMG 的 image-map 绑定属性（usemap/coords/
   shape/width/height）+ AREA 插入（appendChild/insertBefore/R334 带位三站）推进
   `mutTick`——探测环 settle 判据（尾簇 8）覆盖「新 area 可用/area 收缩/usemap 切换」
   断言面。
4. **settle 延迟结算**（shim `__zw_mut_hover_settle`）：命中目标非空但
   `_zwIsConnected` 为否（R334 结构 wire 未 drain——hit test 读 live 视图可见、
   applied/视图路径不可见）时不消费代际返 `'deferred'`，runner 下轮探测 flush 后
   重结算。防「半结算」：跨界序在目标父链缺失时派发产出错序事件（leave@map 提前等）。
5. **悬停指针命令入口 settle**（runner `mut_hover_settle_if_dirty`）：同一 Actions
   批的命令在本 runner 同 turn 连发、探测环 settle 来不及——pointer_down/pointer_up
   命令派发前按最后已知指针位重结算（渲染机会边界近似）。

## 跨批 handle 插入的序列化落地（附带的宿主活性修复）

**根因链**（ZW_TD_DEBUG 三轮探针实证）：页内 listener 于事件派发中
`createElement('area')` + `insertBefore`（本批排队 CreateElement+SetAttrOnHandle）→
中间任何 `refresh_if_html_changed` 全量重建（mutation 代际门控触发）只按 sel 对
rebind（R100）→ handle-only 镜像节点丢失 → 后续 `InsertBefore{child_handle}`
硬错 `unknown child handle`（apply 侧 P19 钉死不 lenient，
`test_apply_dangling_child_handle_stays_hard_error_p19`）→ **webview 吞咽 Err 且
游标不推进 → 同批每轮 flush 重选重败 → 共享队列永久卡死**（批尾全部 mutation 连带
丢失）。

- **创建代际印章 + 跨批序列化落地**（part06 createElement 印
  `_zwHandleBirthGen` + part04 insertBefore sel 父分支 `_zwIb9Serialized`）：创建
  代际 ≠ 当下 apply 代际（跨批，存在重建窗口）→ child outerHTML（shim 唯一真相）
  经 `InsertAdjacentHtml('beforebegin'/'beforeend')` 于 ref 前/父尾物化——镜像侧
  解析拷贝与移动语义在「管线 doc 仅布局镜像」设计下等价；同批创建走原路径零变化。
  "new \<area\> is available" 双文件主案 +2。
- **apply 硬错批丢弃推进游标**（webview `apply_pending_shared_mutations`）：Err 不再
  吞咽重试——warn + 丢批推进游标，队列活性优先，镜像由 shim html 刷新主同步路径
  收敛。
- **id 型 handle 节点移除改派 selector Remove**（part04 `el.remove()`/`removeChild`）：
  镜像绑定失效（序列化落地拷贝无 handle 绑定/跨批 rebuild 换代）时 RemoveHandle 对
  镜像 no-op → 已移除元素在镜像/hit test/ohtml 永久泄漏（case 8 首移命中 case 7
  cleanup 残留）。有 id 改派 `__zw_remove('#id')`；无 id 回落原路径（受限已知偏差）。

## 排除路径（实证，勿重试）

- apply 侧 unknown-handle **不可 lenient 化**：`test_apply_dangling_child_handle_
  stays_hard_error_p19` 钉死（siteopt t4 P19/defect N3——悬垂 handle = 引擎自身 bug
  契约）。活性修复只能在 webview 批丢弃层做。
- hit test 的 top-most 取**文档序首个** inside area（非逆序）：上游
  `map1.insertBefore(area1_2, area1_1)` 后断言命中 area1-2 实证。
- settle 消费时机：命中目标未落 applied 快照时消费代际 = 半结算（本轮跨界定态后
  仍以 stale overSel 走最终 move——事件序错）；必须 defer。
