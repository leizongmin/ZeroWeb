## 落地（三件）

1. **`'value' in el` tag-gate**（part05 has 白名单）：`prop === 'value'` 无条件 true
   （cdp-protocol PW locator 面引入）使**非 form-control 元素**（CE div）的
   `'value' in el` 恒 true——消费方 `'value' in el ? el.value : el.textContent` 分支
   读 value getter 恒 ''（WPT textInput/api 尾部 execCommand CE 案断言面；探针实证
   `in=true tc="a"`）。gate 到 IDL value 接口成员族（INPUT/TEXTAREA/SELECT/OPTION/
   BUTTON/OUTPUT/METER/PROGRESS/PARAM/LI/DATA——PW 表单字段探测在 gate 内不受影响）。
2. **CE Enter 元素 caret 分支**（`__zw_ce_enter`）：空宿主/元素边界 caret（fallback
   range startContainer=el）旧版 no-op return——input 事件缺失使 basic.sub.js 的
   resolve 永挂（enter-textarea CE 案 TO）。补完整事件序 beforeinput(insertLineBreak)
   → textInput('\n') → `<br>` 直插宿主 → input。
3. **CE Enter 变更走本地 shim 树**：caret 文本节点拆分（nodeValue 本地写）+ `<br>`
   insertBefore + tail 文本节点——取代 innerHTML setter（SetInnerHtml mutation 异步
   apply，input handler 同步读 innerHTML 空的同族不可见面）。

## 判例注记

- **`'value' in` 无条件 true 的历史**：cdp-protocol objectId 桥（PW injectedScript
  locator `queryEngineAll` 的 `"value" in e` 表单字段探测）引入时未 tag-gate——
  PW 探测对象是表单字段，gate 后语义不变。
- **探针纪律沿用**：resolve 不带值（尾簇 31 教训）；document 捕获 listener 定位
  「keydown/keyup 到了、beforeinput/input 未派」的 gate 面断点。

## 余挂（textInput 域清零）

- **keyboard-click-event TO**：行为面已通（尾簇 32 探针 4/4）——EventWatcher/
  mini-report 交互层挂账不变。
- **CE insertParagraph（块级拆分）**：仍走 outerHTML mutation 通道——编辑 goal 域
  邻接，未在本 goal 语料断言面内。
