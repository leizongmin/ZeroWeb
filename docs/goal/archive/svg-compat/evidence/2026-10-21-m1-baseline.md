## 通道契约（DC-1 落地）

- 语料：`scripts/goals/80-svg-compat.sh` 拉取上游 `svg/`（WPT pin
  `315976933870b34d6ea30e3f6643403edae678ba`）到 `wpt-data/svg/`（gitignored）
  ——**2144 文件**（1240 `.svg` + 885 `.html` + 1 `.htm` + 15 `.js` + 2
  `.headers` + 1 `.xml`）。上游 pin 全树 2224 blobs，差 80 = 元数据文件
  （`.yml`/`.md`/`.py` 等）按扩展过滤排除；svg/ 语料无 `.json`/`.xhtml`，
  对账干净。

  等），shallow Contents API 只递归一层拉不全——goal 脚本 `GOAL_FETCH_DEEP=1`

- runner 通道：`testharness-svg` 子命令（`src/testharness_svg.rs`——独立模块，
  workers/webmessaging 先例；`pub(crate)` 复用执行底座 `run_testharness_html_inner`）。
  全递归目录扫描（`resources`/`support` 逐层跳过）+ 只收 `.html`/`.htm` +
  `svg_case_skipped` 内容规则筛减，fetch 脚本头注释与 skip 规则同源。
- Makefile：`fetch-wpt-svg` / `testharness-svg`（test-guard 包裹，workers 先例；
  `FILTER=` 子串透传，`TIME_LIMIT=` 透传 test-guard）。

## 可执行子集甄别

本地规则副本（与 `svg_case_skipped` 逐字同镜像）甄别出 **486 案**可执行子集，
排除面分类：

| 排除面 | 规则 | 重入条件 |
|---|---|---|
| secure context | 路径含 `.https.` | security-hardening 面 |
| reftest/ref/manual/demo 页 | `.html`/`.htm` 不含 `testharness` | 渲染断言面（rendering-compat） |
| frame 树面 | 内容标记 `iframe` | navigation-compat M3 frame 门槛后随其重入 |
| 第二文档面 | 内容标记 `window.open` | 同 iframe 门槛 |
| `.svg` 文档 | 扫描层按扩展名排除（1240 案） | runner testharness 管线按 HTML 解析，XML 文档解析路径缺位——契约「XML 底座复用」评估项（M2 重入条件） |

SMIL（`animations/`）不设目录级排除：SVGAnimationElement 接口面属 DOM 类层级
（M2 面），SMIL 时序面按 goal 契约评估后挂账（M4 定稿）。

甄别实证：runner 实跑案集合与本地规则副本 486 案集合一致（对账见下节）。

## 基线（2026-10-21，v2 定谳）

v2（helper 补拉后重跑，03:22-03:38，test-guard 4G/8G 包裹，EXIT=1 = 含失败正常
语义）：**486 案 1527 子测试：134 Pass / 1339 Fail / 36 Timeout / 18 NotRun
= 8.8%**，全绿案 20/486（crash-regression 5 + interact async/script 面 7 +
styling attr 面 3 + 负向历史面等）。runner 实跑案集合与本地规则副本逐案一致
（v1 对账零静默误伤；v2 案集合不变）。

`createSVGElement/smil_async_test is not defined` 脚本死（每案 1 条假失败）
