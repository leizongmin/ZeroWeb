# M4a RSA 依赖选型（2026-10-17）

webcrypto M4a（RSA-OAEP/RSASSA-PKCS1-v1_5/RSA-PSS 签名与加密系）新增依赖：
`rsa = "0.9"`（workspace 顶层 + zero-engine）。

## 选型对比

| 候选 | 结论 |
|---|---|
| **rsa 0.9（RustCrypto，选定）** | 官方 pure-Rust RSA：OAEP（label）、PSS（saltLength 可调）、PKCS1v15 签名齐备；`pkcs8`/`spki` DER 编解码（`EncodePrivateKey`/`DecodePrivateKey` trait）+ `from_components`（jwk n/e/d/p/q/dp/dq/qi 导入）覆盖 corpus 全部格式；与既有 sha2 0.10、aes-gcm/cbc/ctr 同为 RustCrypto 家族，构建栈一致 |
| ring | C/asm 混合，构建链新增 cc/汇编工具链依赖；RSA 原语面（PSS saltLength 自定义、pkcs8/spki 导出）API 偏窄，jwk 分量导入需手拼 DER |
| rsa3/openssl-sys | 非纯 Rust/引入系统 OpenSSL，违反 workspace 纯 Rust 构建（Android NDK 交叉编译复杂化） |

## 影响面

- 传递依赖：`num-bigint-dig`、`pkcs1`/`pkcs8`/`spki`/`der`/`const-oid`、`signature`、
  `zeroize`、`pem-rfc7468`（default features；sha2 复用既有 0.10）。全部纯 Rust，
  无构建脚本新增。MSRV：rsa 0.9 = 1.65 < workspace MSRV 1.85。
- 性能门禁：不触碰解析/样式/布局/绘制热路径；JS shim 仅新增 RSA 分派臂。
- 密钥材料零落日志：RSA 分量与 DER 仅经 CSV 桥进出 host，无 tracing 输出。

## 验证

- `cargo build -p zero-engine` 通过（28s，增量）。
- WPT corpus 定向域：rsa_importKey 1,056F、generateKey RSA 三文件 412F、
  sign_verify rsa_pss 144F / rsa_pkcs 68F、encrypt_decrypt rsa_oaep 180F、
  wrapKey_unwrapKey RSA-OAEP wrapper 25F（M4a 验收面）。
