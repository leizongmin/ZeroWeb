## 失败簇（M2 可执行清单）

1. **随机源语义（DC-2 守护面）** `getRandomValues.any.js` 12F：
   Float16/32/64 与 DataView 应抛 TypeMismatchError（现接受或错抛）；
   「Large length」×10 应抛 QuotaExceededError（>65536 上限语义失效）。
2. **normalize-algorithm-name 4F**：U+212A（KELVIN SIGN）不参与 ASCII 大小写折叠——
   JS `toUpperCase()` 把 `K`（U+212A）折成 `K` 导致 "PBKDF2" 伪装合法；需 ASCII-only 折叠。
3. **digest 16F**：`{}` 空 algorithm 对象 ×4（期望 reject，错误类型待核对 spec）；
   「transferred buffer during call」×12（输入 buffer 在调用中被转移的时序语义）。
4. **tentative XOF 域 419F**（cSHAKE/KangarooTwelve/SHA3/TurboSHAKE）：上游 tentative
   扩展算法，非现行 WebCrypto spec 面——M1 记账不修，挂账待 spec 落地再评估。
5. **未实现算法域**（预期红）：RSA 家族（OAEP/PSS/RSASSA-PKCS1）、EC 家族
   （ECDSA/ECDH/Ed25519/X25519）、AES-CBC/CTR/KW/OCB、ChaCha20-Poly1305、ML-DSA/ML-KEM/
   Argon2/KMAC、jwk/pkcs8/spki 导入格式、wrapKey/unwrapKey —— M3/M4 补面切片按此分域。
