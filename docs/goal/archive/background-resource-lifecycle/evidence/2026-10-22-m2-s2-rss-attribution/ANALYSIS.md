# M2-S2 renderer RSS 随导航增长——归因与有界性判定

**运行身份**：HEAD `f28b04990`（M2-S1 修复后）；zero-browser sha256 `364b0ebf…`（同 M2-S1 复测产物）。协议同 M1（headless、viewport 800x600、sampler 250ms、一次性 profile、24G scope）。
**问题**：M1 基线读数「renderer RSS 随 30 次导航近线性 +224MB」，M2-S1 连接取消修复后仍 +216MiB——增长主因待归因。

## 方法

M2-S1 修复消除连接滞留后做两组隔离对照（`bg03-nav` 编排 + 新增 `BG_NAV_SRC/DST/CYCLES` 透传）：

1. **plain/plain 隔离腿**：`bg03-nav-target.html` ↔ `bg03-nav-plain.html`（均为零资源持有纯文本页）——若仍增长，则增长在文档替换路径本身，与 source 页持有形态无关。
2. **120 次长程配对腿**：plain/plain 与 source/target（fetch+timer 持有形态）各 120 次导航——区分「爬坡+平台」与「无界线性」。

## 结果

| 腿 | 导航 | renderer RSS 首→尾 | 形态（十分位 MiB） |
|---|---|---|---|
| plain/plain | 30 | 44.9 → 209.1 MiB（+164） | 44.9 / 130.3 / 182.5 / 175.3 / 196.5 / 197.5 / 219.1 / 247.3 / 219.1 / 208.4 / 209.1 |
| source/target（M2-S1 复测） | 30 | 36.8 → 253.2 MiB（+216） | 前段爬坡后高位震荡（原样见 [M2-S1](../2026-10-22-m2-s1-fetch-cancel/ANALYSIS.md)） |
| plain/plain 长程 | 120 | 44.7 → 236.8 MiB，峰值 263.4 | 44.7 / **196.4** / 205.6 / 260.8 / 232.0 / 211.8 / 201.1 / 238.1 / 210.8 / 219.3 / 236.8 |
| source/target 长程 | 120 | 32.1 → 243.4 MiB，峰值 301.0 | 32.1 / **199.8** / 244.2 / 248.1 / 252.4 / 263.2 / 243.4 / 209.8 / 273.1 / 245.2 / 243.4 |

**判定：爬坡 + 有界平台，非无界增长。**

- 两条长程腿前 ~12 次导航快速爬升至高水位（plain ~196MiB、source ~200MiB），其后 100+ 次导航在约 200–273MiB 带内震荡，无单调上行（plain 末位 236.8 与第 3 十分位 260.8 同带；source 末位 243.4 低于第 5 十分位 263.2）。爬坡后边际增长 ≈0.4MB/次，在震荡噪声带内，对比爬坡期 ~12.6MB/次。
- 尾部导航延迟稳定（plain 尾 20 次 avg 529ms；source 尾 584ms），无退化。
- M1「近线性 +224MB」为读数假象：30 次窗口大部分落在爬坡段；平台期在其窗口外。
- source/target 平台带（~245MiB 末位、301 峰值）整体高于 plain（~237/263）——持有形态残留抬高水位约 +10–40MiB，量级有界。

## 取消路径持续压力验证（附带收获）

source/target 长程腿全程 61 次 stall fetch 创建（每次 source 重访 1 条 24h 挂起请求）、**60 次 `stall_closed_by_peer`**（每次导航离开即关闭）、终态 stall_active=1（最后一条仍挂起，符合预期）；120/120 nav_ok。M2-S1 取消机制在 61 次 create/cancel 循环下零失手。

## 结论与对 DC-3 的影响

- M1 候选 #2「重复导航 renderer RSS 线性增长」**降级**：文档替换路径不构成无界泄漏；「高频调用使堆建立 ~200MiB 级高水位、其后复用震荡」是 JS 引擎工作集形态。平台水位绝对值（纯文本页 ~200MiB）是否偏高属 M4 阈值议题，非本切片缺陷。
- M1 候选 #2 剩余面：DC-3 验收要求的**文档存活计数**（旧文档对象/回调真被释放的直接证据）未建——RSS 有界不等于对象释放（堆可复用滞留对象）；拟沿 page-runtime/renderer 文档 teardown 诊断入口补计数后闭环。
- M1 候选 #3（BG-01 高频 timer 页 RSS ~200–326MB）是否同形态（爬坡+平台 vs 真增长）待同款长程腿判定，未开始。
