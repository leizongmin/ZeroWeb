## 现有实现面盘点（M1 关键发现）

R2938/R2939（2026-08-07，Fullscreen 同轮）已在 js_dom_shim 落地 **spec-alike
锁态语义**（早于本 goal 立项）：

- `element.requestPointerLock()` → Promise：grant 路径（host
  `__zw_pointer_lock_enabled` 未注册或返 '1'，默认）设
  `document.pointerLockElement` + 派 `pointerlockchange` + resolve；deny 路径
  （返 '0'）派 `pointerlockerror` + reject。同元素重复请求 no-op resolve。
- `document.exitPointerLock()` → **void**（区别于 exitFullscreen 的 Promise，
  符合 Pointer Lock spec），清态 + 派 `pointerlockchange`，未锁时 no-op。
- `document.pointerLockElement` getter；document `onpointerlockchange`/
  `onpointerlockerror` IDL handler。
- host 桥：`__zw_pointer_lock_enabled` 可插拔 deny 开关（headless 无真 OS
  指针锁，状态与事件可观察）。

**与 spec 的已知缺口**（甄别结论，M2 RFC 输入）：

1. **无 transient activation 门**：无用户手势也 grant（B 面两案红的根因）。
2. **deny 拒绝类型为 `TypeError`**：spec 要求 `NotAllowedError` DOMException。
3. **无 movementX/Y 相对位移流**（锁定时鼠标事件不移出/不 retarget）。
4. **无 `options.unadjustedMovement`** 参数（含 NotSupportedError 语义）。
5. **无锁定目标移除自动解锁**、无 shadow DOM retarget、无 boundary 事件抑制、
   无 fullscreen 联动。

## 失败聚类（三簇，归因两种）

1. **`Event.NONE` 未定义**（constructor.html s1）：`assert_equals(ev.eventPhase,
   Event.NONE)`——Event 接口 phase 常量（NONE/AT_TARGET/BUBBLING_PHASE/
   CAPTURING_PHASE）在 **native 绑定面缺失**。实证：探针案
   `Function.prototype.toString.call(Event)` = `function () { [native code] }`——
   生产路径为 native 绑定（R384：native 是唯一生产路径），`dom_bindings/
   event.rs` 只有 `eventPhase` 值（NONE=0）无常量定义；JS shim part05 R23 的
   常量（static + prototype）被 native 绑定遮蔽不生效。**跨域记账**：dom/events
   面（uievents goal 50 已收口的 residual），非 pointerlock 域缺陷；
   movementX/Y init 字典扩展本身已支持（s2 同案 Pass 实证）。
2. **requestPointerLock 缺 transient activation 门**（B 面两案同根因）：
   shim 默认 grant——`pointerlockchange` 携带非空 `pointerLockElement` 派发，
   `t.unreached_func` 触发；promise resolve 而非 NotAllowedError reject。
   属门控实现面（M2 RFC 必须覆盖的第 1/2 项缺口），不是可自主收敛的引擎 bug。
