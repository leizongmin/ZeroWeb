## 修复内容（2 个根因，3 处落地）

### ① R194b/R179 轻量 shadow root 缺 mutation 面 + own 查询桩遮蔽（聚类 1，~155 subtest）

**根因**：`Element.prototype.attachShadow` 泛型（part03 R194b，detached/plain 宿主
路径）与工厂元素版（part05 R179）产出的 shadow root 是 plain 对象：
- 无 `appendChild`/`insertBefore`/`removeChild`——WPT shadow-dom `createTestTree`
  惯例 `shadowRoot.appendChild(document.importNode(template.content, true))` 直接
  TypeError（`shadow-dom/resources/shadow-dom.js` 是 slots/slotchange/event-composed
  16 案的固定装配）；
- own `querySelector: () => null` / `querySelectorAll: () => []` 桩遮蔽
  `ShadowRoot.prototype` 的 R366 子树 walk——即使内容挂上，shadow 树内查询恒 miss。

**修复**（part03 + part05）：配齐 fragment 语义的 mutation 面（fragment 子展平、
摘旧父、parentNode 反链、WebIDL 类型校验、NotFoundError/TypeError 对齐）；删除 own
查询桩（原型 R366 walk 经原型链可达，探针实证 `#s1` 命中）。

### ② plain TEMPLATE 无 `content`（聚类 1 第二根因 + template 域解锁）

**根因**：deepClone 产物（`host.cloneNode(true)` 后的 detached 树——createTestTree
装配形态）中的 TEMPLATE 是 `_zwMEl` plain 对象，`template.content` 得 undefined →
`importNode(undefined)` TypeError。R95/R145 的 content 视图只覆盖 proxy 元素与
sel 模板（part04 get trap）。

**修复**（part03 `_zwMEl`）：TEMPLATE tag 的 plain 元素补 `content` getter——惰性
**视图** fragment（plain 对象，childNodes 别名模板子数组 + mutation 面
append/insert/remove + 简单选择器/compound 的 querySelector(All) DFS）。
**视图而非深拷贝**：拷贝语义在有环装配下无限递归（见挂账）。
