## 变更（纯 JS shim：part01/part03/part04/part05/part06）

### ① notify mutation observers spec 直译（part01 + part03/part05 flush 体）

- 旧 `_moFlushBody`：每个 observer 投递后排空**活** signalSet + 末尾兜底排空。两处偏离
  spec notify 步骤 4-7：投递期间（MO 回调内）入队的新 signal 被并入本轮单一事件（两轮
  变异 → 一个 distinct slotchange）；且 signal 派发时点绑定 per-observer 投递（分轮断言
  失真）。
- 新（spec 直译）：步骤 4-5 = 投递**前**快照 signalSet（`__zwSlotSignalRoots` 移出 +
  per-root `__zwTakeSlotPending` 取走 pending slot 集 + 复位 queued 标记）；步骤 2-3 =
  notifySet = 本轮开启时 record 队列非空的 observer 快照（投递期新入队落下一轮）；步骤 6
  = **全部** observer 投递完才步骤 7；步骤 7 = 对**快照**派发 slotchange。signal a slot
  change 自带 queue a mutation observer microtask（queue 函数恒调 `__zw_mo_flush_lite`
  + push 活列表）→ 两轮变异 → 两个 distinct slotchange。
- part03 `__zwFlushSlotSignals` 增快照参数（传快照不清活列表）；无参路径保留旧语义。

### ② slotchange diff 判定 queue 时化 + 双 map 口径（part03 plain + part05 handle 同构）

- transition 判定从 flush 时移到 **queue 时**（对照 prev 链 = 上次 queue 时快照；轮首
  回落 last = 上次 dispatch 快照）。命中 slot 并入 per-root **pending signal 集**
  （`__zwSlotchangeMarked`），dispatch 只消费快照点取走的列表——投递期新 signal 留
  pending 落下一轮。
- diff 口径由单一 flatten 改**双 map**：`a` = assignedNodes()（spec assign slottables 的
  identical 比较——signal 的正依据）、`f` = assignedNodes({flatten:true}）。三规则：
  ① assigned 变化 → mark（含出树 slot——removed-immediately 面）；② **空分配** slot 的
  fallback 面变化 → mark（spec insert/remove「parent 是空分配 slot → signal parent」
  ——fallback 增删）；③ 新入树 slot 即获配 → mark。嵌套级联（内层 slot assigned 变化
  改外层 flatten 但不改 assigned）不再误标——级联可见性由 slotchange **冒泡**（assigned
  slot 父边）承担，WPT nested slots 的 2 次监听计数不变。

### ③ slot/name 属性变更挂钩（part04 setAttribute/removeAttribute + part03 plain 工厂）

- spec「use these attribute change steps to update a slot's/slottable's name」：slot 的
  `name` / slottable 的 `slot` 属性变更步进 assign slottables → signal。旧版靠 flush 时
  sweep 顺带覆盖（无挂钩），queue 时化后须显式挂钩：handle 域走
  `__zwMaybeQueueSlotchange(handle)`（③上溯找 shadow root）、sel 域走
  `__zwQueuePlainSlotchange(proxy)`（parentNode 上溯）；part03 `_zwMEl` 工厂的
  setAttribute/removeAttribute 同步挂钩。

### ④ innerHTML 的 slotchange 队列点下移（part04）+ 空文本注册不构成子节点（part06）

- innerHTML setter 的 slotchange 钩子原在 `_zwRegisterTextEl`（本地文本视图重注册）之前
  ——queue 时 diff 经 `_zwLocalChildNodes` 回落文本注册表，读到的还是旧文本（如 'baz'），
  innerHTML='' 轮的 [baz]→[] 差分失配丢 fire。钩子下移到注册块之后。
- `_zwLocalChildNodes`：空文本注册（innerHTML=''/textContent='' 覆写）返回 `[]` 而非
  `[text('')]`——spec string-replace-all 空串 → node null → 无子；否则注册表残留空文本
  使 childNodes/assignedNodes 虚报 1 子。

### ⑤ 事件派发接收者 identity 保持（part03 `_dispatchWithBubble` + part04 dispatchEvent）

- `el.dispatchEvent(ev)` → `_dispatchWithBubble` 内 `event.target = _makeProxy(sel,
  handle)`——R52 消零清 `_proxyCache` 后重建分裂 proxy B，event.target 与页面持有对象
  分裂（WPT slotchange-event removed-immediately 簇 `event.target === slot` 断言
  expected/got 同 handle 字符串不同 proxy 的根因）。dispatchEvent trap 透传接收者 proxy
  （新第 6 参 `receiverProxy`），target 站 identity = 页面持有对象（R315 重挂 identity
  翻转同款「页面视角 identity = 页面持有 proxy」口径）。
