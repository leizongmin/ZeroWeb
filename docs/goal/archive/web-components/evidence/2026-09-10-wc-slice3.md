## 修复内容（8 处）

### ① CEReactions：setAttributeNS / removeAttributeNS / toggleAttribute / setAttributeNode(NS) / removeAttributeNode 派发接线（part04/part05）

- 上述变体此前直写 host 属性层（绕过带 `_ce_dispatchAttrChange` 的 setAttribute 路径），
  attributeChanged 反应全缺。现在各变体在 host 写入前捕获旧值（`_ce_attrValue`）、
  写入后按 presence/newValue 语义派发（移除 → null；setAttributeNS 的 host 写门
  `_r122Added && _r122IsFirst` 与派发共享——非首实例 host 不写则不派发）。

### ② attributeChangedCallback 4 参签名 + namespace 参数（part03）

- spec `attributeChangedCallback(localName, oldValue, newValue, namespace)`——旧派发恒 3 参，
  WPT `assert_attribute_log_entry` 断言 `log.namespace === null`（缺参 = undefined）全簇 Fail。
  `_ce_dispatchAttrChange` 与 `_ceFireInitialAttrChanges` 均补 namespace 传参
  （NS 变体传真 ns，无 ns 恒 null）。

### ③ IDL 反射 setter 的 CEReactions（part03 映射表 + part04 set trap 头捕获 + part05 汇流派发）

- `el.id=` / `el.className=` / `el.tabIndex=` / `el.hidden=` / aria* 等反射 setter 直写 host
  属性层，同样缺反应。新增 `_zwCeReflectionAttr(p)`（IDL 名 → 内容属性名，与 set trap 各
  分支写入名同源）；set trap 头部捕获 CE entry + 旧值，末尾汇流点（`moAttr` 命中 = 真写入）
  派发——handle 路径新值经 pending mutations 回读（set 得新串 / 布尔移除得 null / presence
  得 ''），sel 路径回落写串。
- 收益：AriaMixin-string-attributes **0→80**（单案最大增量）、HTMLElement 0→10、
  ElementContentEditable 0→2、NamedNodeMap +5、attribute-changed-callback +7。

### ④ `_ceApplyConn` 重构：plain 元素分支 + seen 防环 + adopted 判定（part03）

- **plain 元素分支**：detached doc 树（new Document / createHTMLDocument / createDocument /
  cloneNode）与 innerHTML/insertAdjacentHTML 解析子树是 `_zwMEl` plain 对象（无 sel/handle），
  旧 `!ns && !nh → continue` 跳过，CE 回调从不触发。现按 tag 反查 registry、子代走
  `childNodes`（双源遍历：handle registry + plain childNodes）。
- **seen 防环**：嵌套 template 装配的 childNodes 回指环（master.md 切片 2a 已知挂账）下
  纯 childNodes 遍历会无限递归；身份去重守卫。
- **adopted 判定**：`_ceConnDoc[key]` 记录最近连接的树文档（连接时 root-walk 判定 +
  hintDoc 优先；断开时在拆链前记录）。再连接到另一文档树 → adoptedCallback(oldDoc, newDoc)
  先于 connectedCallback；首连回落 ownerDocument 作 oldDoc（spec concept-node-adopt）。

### ⑤ el.remove() 的断连派发提前到 host 移除前（part04）

- 断开记账需读「当下」树文档（拆链后 root-walk 不可达）。提前派发后原尾部派发因同态跳过
  成为 no-op，零双派发。

### ⑥ template contents owner document（part03 + part04）

- `_zwMEl` plain TEMPLATE 与 proxy TEMPLATE 的 `content` 视图补 `ownerDocument`：
  per-**源文档**共享的独立 inert 文档（`_zwTplOwnerDocFor`——同一 document 的全部 template
  共享一个 owner，WPT template-content-node-document.html 断言）。
- proxy `content` 视图补 mutation 面（appendChild/insertBefore/removeChild——fragment 展平 +
  摘旧父 + CE 派发带 hintDoc=owner doc）。

### ⑦ DOMParser 产物 doc 的 gNI 认主 + NS 创建 tag 可查（part03 + js_dom_bridge.rs）

- `query_tag_from_mutations` 补 `CreateElementNS` 分支（qualified name）——旧只匹配
  CreateElement，`createElementNS(HTMLNS,'template')` 的 `_realTag` 恒回落 DIV，get trap
  的 TEMPLATE 门（content 等）全部 miss。
- **R3019 DOMPurify e2e 回归根因**：DOMPurify 3.2.7 加载时把 `document = 
  template.content.ownerDocument` 并解构 createNodeIterator/createDocumentFragment/
  getElementsByTagName——detached doc 缺这些方法 → `createNodeIterator.call(...)` 抛
  'Cannot read properties of undefined'。detached doc 补齐 Document 方法面
  （createNodeIterator/createTreeWalker/importNode/adoptNode 委托主文档；getElementsByTagName
  honor-`this`——`this` 为另一 Document 时委托其 querySelectorAll，否则保持 doc 作用域
  queryAll，R3013/R3016 detached 查询语义零变化）。

### ⑧ detached docEl appendChild 的 hintDoc（part03 synthetic + part05 factory 路径）

- plain docEl 链 root walk 不可达（get trap 不回 expando 的 parentNode 赋值），连接派发直传
  已知树文档作 hint。
