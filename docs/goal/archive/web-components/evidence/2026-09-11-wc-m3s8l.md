## 变更（纯 JS shim：part03/part04）

### ① CE markup 构造/连接附着口（part03 `__zwCeAttachForAdded`）

- spec「创建元素」步：markup 解析产物逐根 **upgrade**（`_ceUpgradeSubtree`——ctor 体 +
  初始 attributeChanged（observed 且存在的属性））→ **connected**（`_ceApplyConn`，was 门
  去重）。连接判定**双源**：调用方 parentConnected（sel host contains / handle 记账）+
  根自身 parent 链上行（`_elConnected`——spec connected = 树根是 document，detached doc
  亦真；跨文档插入等记账未覆盖形态的兜底）。
- `_ceUpgradeNode` 升级期派 connected 时同步 `_ceConn` 记账（key 经新 helper
  `_ceConnKeyFor`），防 attach 后续 applyConn 重复派发。
- **plain 元素连接记账 key 碰撞修复**：`_ceApplyConn` 对 _zwMEl（无 sel/handle）用
  `'plain:' + _elKey(null,null)` = `'plain:null'`——全部 plain 元素共享一个记账键，只有
  首个 plain custom element 派过 connected。`_ceConnKeyFor` 按**对象身份**盖章
  （`__zwPlainCeId`）派生稳定 key。

### ② innerHTML 接 CE 附着 + 被替换子树断连（part04）

- innerHTML setter 末段（本地视图定稿后）`__zwCeAttachForAdded(_ihAdded, ...)`。
- 整体替换前捕获的 `_ihRemoved` 逐根 `_ceApplyConn(root, false)`——前一轮解析产物的
  disconnectedCallback（testNodeDisconnector 'parentNode.innerHTML = ""' 簇）。

### ③ insertAdjacentElement/HTML 的 handle-only 容器形态（part04）

- 旧两分支均 gate 在 `sel` → createElement 容器 + createElement 元素形态整体 no-op。
  新增 handle-only 分支：经既有 proxy 插入原语（appendChild/insertBefore——registry
  记账 + MO record + CE 全链）实现四位置；移动语义显式预断连；插入后按**元素自身**
  parent 链（`_elConnected`）收口连接态（detached doc documentElement 容器无记账的
  漏 connected 面；adopted 由 `_ceApplyConn` 的 old/new doc 比对面承接）。
- insertAdjacentHTML handle-only：`_zwFragmentAdded` 解析 + 逐个落位（beforeend→
  appendChild / afterbegin→insertBefore(原首子) / beforebegin·afterend→父 insertBefore）。

### ④ outerHTML 的 handle 父容器 + plain 元素形态（part04/part03）

- handle 父容器（WPT 'firstChild.outerHTML = markup' 首轮）：registry 原位替换（摘自身、
  解析产物同位插入）+ parent 链重指（解析产物 parentNode 原挂解析 pseudo-body，不重指
  则后续以该元素为基准的关系/CE 判定全走假树）+ MO record + 自身断连 + 产物附着。
- plain 元素（前轮解析产物作替换基准）：`_zwMEl` 工厂新增 outerHTML **set** accessor
  （get 缺省 undefined 与现状一致零读回归）——_zwMEl 父 splice childNodes / handle 容器
  splice `_handleChildren` 双形态 + parent 链重指/清链 + handle 父 MO + CE 附着。旧赋值
  成 own expando 静默 no-op。

### ⑤ `_zwMEl` NS 读/测/删三件（part03）

- `getAttributeNS`/`hasAttributeNS`/`removeAttributeNS`——WPT reactions harness 的
  `create_attribute_changed_callback_log` 调 `element.getAttributeNS(ns, name)` 记账，
  _zwMEl 缺方法 → TypeError 被派发侧吞 → upgrade 初始 attributeChanged 日志缺项
