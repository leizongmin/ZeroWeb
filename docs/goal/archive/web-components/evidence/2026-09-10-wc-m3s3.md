### ② find-flattened-slotables 规范形（plain + handle 双路径同构）

- 旧实现的嵌套 slot 递归在「sub 空 → 推 fallback 子」上双错：light-DOM slot（根非
  shadow root）应**原样输出**（spec step 5.2——slots-outside-shadow-dom）、已摘除 slot
  不得展平其 fallback（slots-fallback 'Remove a slot'）。
- 重写为 spec 形：assigned 空 → slottables 取自身子（step 4）；嵌套 slot 仅当
  `__zwRootIsShadowRoot(e)` 才递归（fallback 语义由递归内同规则承担），否则原样输出。
  双实现（part03 plain / part05 handle-sel）同步；`__zwRootIsShadowRoot` 为 world 无关
  的 parentNode 链顶判定。

### ③ find-a-slot 树序仲裁（find-slotables step 3）

- 旧实现按 name 裸匹配 → 同名 slot 全部认领同一 slottable。补宿主 shadow 树 DFS
  树序仲裁：plain 域新增 `__zwFindSlotInShadow`（pre-order、slot 命中后仍递归其子）、
  handle 域提取 `__zwFindSlotInHandleShadow`；assignedNodes 仅在 winner === 本 slot 时
  收编（WPT 'No direct host child' 双 slot1 全归 s1、'Mutation: Add a slot: after/before'

  slots-fallback-in-document 的 light slot 内层 fallback 文本不得入列）。
