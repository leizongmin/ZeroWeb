## M3a — Mixed Content 子资源面接线

**kill-switch**: `WebViewConfig::mixed_content_enforcement`（**default-on**；env
`ZW_MIXED_CONTENT_ENFORCEMENT=0` 为默认值侧回退入口，照 `ZW_MO_HOST_TRIGGER` 先例——
DC-3 off 臂全量 A/B 经此执行）。

三个子资源面接 `SecurityContext::check_resource_url`（HSTS 升级 + mixed_content 分级
判定统一入口，语义库 R3343 面已备）：

| 面 | 位置 | 分级语义 |
|---|---|---|
| 外链 stylesheet | `resolve_external_css`（CSP 检查点后） | Blockable → 不抓取不并入；Upgraded → 抓取/url() 解析按升级 URL |
| img（markup + CSS url()） | `fetch_image_subresources`（data: 分支外） | OptionallyBlockable → 升级 HTTPS 后抓取；**缓存键仍按 markup 原始 URL**（painter 按 src 解析查找，升级键失配即白图） |
| 外链 script/module | `run_page_scripts_impl`（CSP 检查点前） | Blockable → 不抓取不执行；Upgraded → fetch 走升级 URL（`mc_script_fetch_src`） |

配套：
- `complete_fetched_page` 补 `set_page_origin`（与 `fetch_url` 对齐——异步路径子资源
  判定的页面源前提）。
- 零影响面（结构性）：判定以 `page_origin.is_secure()`（scheme == https）为前提——
  file:// 工作区（make test / reftest / 产品 fixture）页面源非 https，检查点恒短路。
- img/eval corpus `{{location[scheme]}}` 模板族、mixed-content corpus 2 案
  （blob-popup/window.open + `{{domains[]}}`/ResourceTiming）维持预存 infra 挂账
  （M1 基线 0 绿 → 本轮不变，非本轮回归）。

## M3b — HSTS net 响应注册

`WebView::note_hsts_response`（pub(crate)，单测可达）：最终响应 URL 为 https 时解析
`Strict-Transport-Security` 头 → `SecurityContext::register_hsts(host, value)`；
非 https / 无头 / 解析失败静默跳过。挂点 `fetch_url` Ok 分支（按 `response.url` 最终
URL，重定向后为准），`mixed_content_enforcement` 门内（同一策略面）。

单测覆盖：注册后 HTTP 子资源/导航强制升级、includeSubDomains 子域传播、HTTP 响应头
不注册、无头/坏头静默。

## M4 — navigator.permissions JS 面

**诚实设计说明**：JS 面挂 shim 权限注册表（`__zwPermissionState`/`__zwSetPermission`，
WAB2-M2-s3 已建的 headless store——clipboard/fullscreen 消费同一注册表）；zero-security
`PermissionManager` 保留为 browser app UI 侧存储（app_input.rs），两侧不合并（headless
runner 无 app UI，合并引入双 store 分歧风险 > 收益）。

part02.js 改动（WAB2-M3-s1 基础上）：
1. **单例 status**：同 descriptor 两次 query 返回同一 PermissionStatus 实例（spec
   §dom-permissions-query identical-descriptor）——change 通知锚点。
2. **state 活值**：getter 实时读 `__zwPermissionState(name)`（spec state 为当前状态
   查询非快照）。
3. **change 事件**：状态**实际变化**时（`__zwSetPermission` / request）对既有单例派
   `'change'` Event + 调 onchange（listener/onchange 异常互不短路；同值重设不派发）。
4. **request(desc)**：headless 语义——`'prompt'` 自动授予（经 `__zwSetPermission` 落
   同一注册表并触发通知）；`'denied'` 维持；resolve 同一单例。
5. **desc 校验**：query/request 非对象或缺 `name` 字符串 → rejected promise（TypeError，
   spec 必选字典成员）。fullscreen `allowWithoutGesture:false` TypeError 保留（WAB2-M3-s1）。

**既有测试适配**（1 处，WAB2-M2-s3 test_clipboard_permission_denied_and_validation）：
同 execute 内「query → 注入 → 再 query」的 `default:prompt` 断言依赖旧快照语义——
活值 getter 下微任务排空前注入已生效。按测试意图拆为两次 execute（注入前捕获 default，
注入后捕获 after），**期望串不变**（`default:prompt|after:granted|readText:""`）。
