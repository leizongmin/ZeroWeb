## 修齐语义

1. **配额强制**（https://html.spec.whatwg.org/multipage/webstorage.html#storage-set-item-steps）：
   UA 定义值取 5MiB/storage（localStorage/sessionStorage 独立计数）；单项 size =
   key.length + value.length（UTF-16 code units）；超限写入不落项并抛
   QuotaExceededError。字节计数存 target 内部槽 `__zwBytes`，写入面统一收口
   `_storageWrite`（set trap / defineProperty trap / setItem 经 named setter 同路）。
2. **QuotaExceededError 接口**（spec WebIDL quotaexceedederror）：DOMException 子接口，
   `requested`/`quota` 缺省 null；`e.constructor === self.QuotaExceededError`（WPT
   assert_throws_quotaexceedederror 口径）。part01b 新增 global 定义；实例属性直接填
   （不经 `DOMException.call`——V8 native 构造器 flip 后 QE.prototype 链落在原生侧时，
   词法 polyfill 的 `this instanceof DOMException` 判 false 会填替身对象，R384 同族坑，
   probe 实证后修正）。
3. **native DOMException 补映射**（共享路径根因）：`dom_bindings/dom_exception.rs`
   `code_for_name` 缺 `"QuotaExceededError" => 22`、构造器常量缺 `QUOTA_EXCEEDED_ERR`
   （shim polyfill 与 quickjs 胶水两表均有，唯 V8 native 表漏）——抛出的 QuotaExceededError
   code 恒 0。probe 定位后补齐；crypto.getRandomValues 等同受益。
