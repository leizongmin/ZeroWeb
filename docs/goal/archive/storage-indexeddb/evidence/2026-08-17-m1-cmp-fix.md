## 修复

+ `cmp` 缺少两个参数时抛 `TypeError`
+ `null`、`NaN`、非法数组 key 抛 `DataError`
+ key 类型顺序对齐 Number < Date < String < Binary < Array
+ binary 按视图有效区间的无符号字节词典序比较
+ array key 递归比较并处理前缀顺序
