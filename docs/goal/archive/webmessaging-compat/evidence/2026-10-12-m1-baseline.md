## M2 失败簇（47 non-pass，按簇收敛顺序预期）

1. **targetOrigin 解析 + options dictionary 签名簇（~19 F，最大簇）**：现 shim
   （R2983）第二参只认字符串且失配同步抛 SecurityError——
   - spec 要求 targetOrigin 按 URL 解析：不可解析 → **SYNTAX_ERR**（001/003 现抛
     SecurityError）、解析成功按 serialized origin 比较，**同源尾斜杠等价**
     （002/006 `'https://wpt.test//'` 应放行）、失配 → **静默丢弃非抛**（015
     different origin 现抛 SecurityError）。
   - 第三参 options dictionary（with-options/ 8 案全 F）：`{targetOrigin,
     transfer}` 解包现被 String() 成 '[object Object]'；`{transfer: null}` 应
     TypeError 现走 SecurityError 分支。
   - 零参/`undefined` data：009 零参应 TypeError（现 lenient 放行）、010
     `undefined` data 克隆后应保持 undefined（现 null）。
2. **transfer/ports 传递簇（~11 F）**：window.postMessage 第三参 transfer 数组未
   实装（with-ports 023/025/026/027 WebIDL sequence 校验全不抛；027 e.ports
   expected 2 got 0——ports 不随消息转移）；Channel_postMessage_clone_port/
   with_transfer 三案（转移后 e.ports 空，`Cannot set properties of undefined`）；
   close.any.js 关闭 port 转移应抛 DataCloneError；e.ports 应为 frozen 数组。
3. **BroadcastChannel IDL/语义簇（7 F）**：constructor 缺 new/缺名应 TypeError、
   postMessage() 无参应 TypeError、close 后 postMessage 应 InvalidStateError（含
   uncloneable 数据）、message 事件 e.origin 应为 channel origin（现空串）、
   close-and-recreate 投递序。
4. **零散面**：MessageEvent-trusted（postMessage 派发的 message 事件 isTrusted 应
   true）；infinite_loop（port 消息投递经 microtask 递归饿死 task——spec 要求 task
   承载，fileapi M2-P3 事件 task 语义先例）；messageerror.html on* 内容属性编译面；
   without-ports/023 structured clone 应只克隆 own properties；with-ports/010 同
   undefined data 簇 1。
5. **挂账**：garbage-collected.tentative.any.js Timeout——entangled port GC 驱动
   close 事件（WeakRef + 引擎 GC 联动，超出 JS shim 面）；user-activation.tentative
   Fail 根因 `navigator.userActivation.isActive` 缺失（user-activation 域，非
   messaging 面，该案其余断言通过）。
