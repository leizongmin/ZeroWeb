## 关键修复（driving WPT 用例）

1. radial 渐变全几何（二次方程 + f64 精度 + 半径穿零伪根 + 较大有效根）— cone.*/touch*/equal/transform.*
2. 文本真字体光栅（@font-face FontLoader → rustybuzz shape → glyph 位图 blit）— text.draw.*
3. 基线偏移真实 ascent/descent + 对齐 em 方块 + maxWidth 缩放 + rtl 方向 — baseline.*/align.*/maxWidth.*/rtl
4. letterSpacing/wordSpacing（原始串 + 相对单位随字号重解析）— drawing.style.spacing.*
5. drawImage 阴影 + source 独占未覆盖清除 — shadow.image/canvas.*、uncovered.image.*
6. pattern 平铺锚定 fill 空间（CTM 逆）— pattern.paint.*
7. fetch 同步返回契约 + wpt-data handler — composite.image/canvas.*
8. CSS Color 4 面（CSSRGB/CSSHSL/color object/currentColor/NaN 拒绝）— colorObject/CSSRGB/parse.*
9. 0 尺寸 SVG + SVG <image> 元素源 — pattern.zerowidth/zeroheight、svgimage.*
