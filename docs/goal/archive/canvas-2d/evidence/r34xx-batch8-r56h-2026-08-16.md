## process_learnings

- WPT 套件内部不一致（stroke.skew vs stroke.scale1/2）——单一模型不可调和时
  按多数派语义 + 文档化 skip，比强行满足单侧测试更诚实
- img 元素加载与 createImageBitmap 是两套语义（img 零尺寸 = loaded 事件 +
  naturalWidth 0 vs createImageBitmap 零尺寸 = InvalidStateError）——分开处理
- de Casteljau 递归控制点传参笔误只表现为局部几何失真（y=-30 假段）——A/B
  回归门抓到，比推理快
- 段端点 t 微负（弧首 cos/sin ±1e-7）——命中测试需容差，否则路径起点恒 miss
