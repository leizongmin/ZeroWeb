## 修齐内容（part02.js / js_dom_bridge.rs / testharness.rs）

1. **helper 资产补拉**（`/common/subset-tests(-by-key).js` + `url/resources/
   a-element(-origin).js`，WPT pin 同 rev）——url-constructor（815/893）、a-element
   （414/892）、a-element-origin（319/412）页级解锁。
2. **WHATWG UTF-8 解码器重写**（`_zw_utf8_decode_stream`，encoding.spec §utf-8
   decoder 逐字节语义）：每个最大无效子部分产 1 U+FFFD（%FE%FF → 2 个，非合并）；
   0xC0/0xC1/0xF5+ 非法前导；0xE0/0xF0 次字节下界（long-form 排除）、0xED 上界
  （代理排除）、0xF4 上界（>U+10FFFF 排除）；越界第二字节 → 1 U+FFFD + 重处理
  （%C2x 面）——urlencoded-parser 75→79/105。
3. **protocol setter 剥离 + 失败无操作**（`set_url_part` protocol 臂）：剥 TAB/LF/CR、
   尾 ':' 修剪、小写化；set_scheme 失败 → **url 不变且不抛**（URL spec scheme setter
   失败即 return——WPT setters-stripping leading-U+0000 面同判）。setters-stripping
   198→206/260。
4. **url crate panic 防护**（`serialize_url` catch_unwind）：url 2.5.8 username()/
   password() getter 在 setter 后内部字节偏移不一致时 panic（lib.rs:2881 "byte range
   starts at 6 but ends at 4"——url-setters.any hostile username/password 面）——
   捕获 → 空串（shim 抛 TypeError 单案收场）。**整跑 abort（panic-in-panic）消除**，
   url 全 corpus 首次完整跑通（6065 subtests）。
5. **探针 JSON 孤代理消毒**（`sanitize_lone_surrogate_escapes`）：urltestdata 含代理
   测试串 → test 名经 V8 well-formed JSON.stringify 逃逸为孤代理 `\uD800`-`\uDFFF`
   → serde 严格拒绝 → 探针全案失败；孤代理转义 → `�`（合法代理对保留）。
6. 存量引擎测试翻新 1 处（`test_set_url_part_rust_r2780`：非法 protocol 期望由
   返空串改为无操作保留——随 spec 收敛）。
