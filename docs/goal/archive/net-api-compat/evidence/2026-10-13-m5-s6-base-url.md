# M5-S6 — url 基址链：`<base>` 元素 + document.baseURI 接线（2026-10-13）

**背景**：M5-S5 残差记账——锚点 accessor 基址 = 页面 location 而非文档基 URL；
`<base>` 元素 / document.baseURI 未实现。本切片实证清偿。

## 探针实证（修前，4 子测试 0/4）

探针页（`url/zz-probe-base.html`，跑后已删）：

1. `<base id=base>` 可查、`getAttribute('href')` 反映 JS 置值（latest-wins 可见）——**过**
2. `setBase('http://example.org/foo/bar')` 后 `a.href`（相对输入 `test.txt`）得
   `http://wpt.test/url/test.txt`——**挂**（基址 = 页面 location，base 元素被无视）
3. `document.baseURI` = **undefined**（R130 分支只覆盖元素节点；document 对象无此
   getter——不是「页面 URL 近似」而是整体缺失）
4. base = about:blank + 相对输入 `a`：期望解析失败返原串 `a`，实得页面绝对 URL——**挂**

规模核对：urltestdata.json 相对输入 **145 条全部为非页面基**（M5-S5 所记 +5 仅是
翻转残差中可归因部分；本簇真实面 = 全部相对输入腿）。

## 实施（shim 三处，零 .rs 变更）

1. **`globalThis._zwDocBaseURL`（part03 接口注册区，A/AREA stringifier 注册后）**：
   HTML spec document base URL——首个带 href 内容属性的 `<base>` 元素（树序，
   querySelectorAll 枚举 + `hasAttribute` 门）的 frozen base URL：href 对 fallback
   base URL（页面 location）经 `__zw_parse_url` 解析，解析失败回落 fallback；
   无 base 元素 → fallback。
2. **A/AREA accessor（part03）**：href/pathname/… 组件族解析基改用 helper
  （无 helper 时回落 location——旧语义兜底）。
3. **element `baseURI`（part04 R130 分支）+ document `baseURI`（part06 document
   字面量新增 getter）**：共用 helper（dom spec node base URL——文档即其 document
   base URL）。

BASE/LINK href getter 维持对 fallback（location）解析——spec 语义（对文档地址
解析，防自引用），不改。
