## 修齐内容（part01.js / part02.js / testharness.rs）

1. **Headers 校验**（Fetch §5.1 validate）：name = field-name token（ByteString）；
   value = ByteString 无 0x00/LF/CR、无首尾 HTTP tab/space；先 Normalize（剥首尾
   HTTP whitespace）后 validate；非法 → TypeError（fill/get/has/set/append/delete 全
   方法）。sequence 形态逐项恰为二元组（`new Headers([["name"]])` / 三元组 → throw）；
   ctor `null`/非对象 → TypeError（undefined 缺省不填充）。
2. **forbidden-override**（§forbidden-header-name step 3）：X-HTTP-Method(-Override) /
   X-Method-Override 值经 get-decode-split（quoted-string 感知切分）任一值为
   CONNECT/TRACE/TRACK → forbidden（append 静默丢弃）。headers-forbidden-override
   0/90 → 全绿。
3. **request-no-cors guard**：Request ctor mode no-cors → guard `request-no-cors`；
   append 按 combine 后整体 CORS-safelisted 判定（accept/accept-language/
   content-language/content-type + 值长 ≤128 + CORS-unsafe byte + essence 白名单）、
   set 按单值、delete 非 safelisted 非 privileged 阻断；变更后清除 Range（privileged
   no-CORS）。headers-no-cors 基本面全绿。
4. **迭代语义**（§5.1 sort-and-combine + live）：value pairs 按 name 升序（set-cookie
   多值保序独立成对——iterator does not combine set-cookie）；entries/keys/values 改
   **live 光标**（每次 next 基于当前 header list 重算）+ 原型链对齐
   %ArrayIteratorPrototype%（checkIteratorProperties）。header-setcookie 19→22/24。
5. **fetch() 同步异常 → rejected Promise**（fetch 方法步骤 step 2）：Headers init
   校验 throw 不再同步抛出（header-values `fetch() with value %00 needs to throw` 面）。
   `_headersToWire` 改经 guard-request Headers fill（校验 + normalize + 禁止头过滤
   单一路径）。
6. **runner `self.GLOBAL` shim**（testharness.rs reporter 注入）：
   `{isWorker:false, isWindow:true, isShadowRealm:false}`——上游 pinned
   testharnessreport.js 不含 window 变体 GLOBAL 标记，header-values 族脚本前置崩溃
   （`Cannot read properties of undefined (reading 'isWorker')`）解除。
