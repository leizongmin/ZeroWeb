## 修齐内容

### shim（part03/05）

- **abort() spec 化**（xhr.spec §the-abort()-method + §request error steps）：
  OPENED+sent / HEADERS_RECEIVED / LOADING → request error steps（DONE +
  readystatechange 先于响应重置 → abort + loadend → **静默置 UNSENT**——spec 步骤 3
  不派发事件，abort-progress-events「UNSENT 态零事件」面）；DONE → 置 UNSENT +
  reset（无事件）。重置含 status/statusText/responseText/response/**responseURL/
  响应头表**（network error 语义——responseurl-after-abort 全簇）。
- **请求代际守卫**（`_zwReqGen`）：send 计代、异步回调校验——abort/复用后晚到响应
  不再回填（responseurl-after-abort「reuse」页的竞态根因：open() 清 aborted 旗标后
  前一请求的迟滞 fill 污染复用对象）。
- **`xhr.upload`**（XMLHttpRequestUpload，EventTarget 形）：send() async 且有体时
  同步派发 loadstart + progress（`lengthComputable` true、total = 体字节长——Blob 走
  字节长、FormData 走 multipart 编码长、其余 UTF-8 长）；晚注册不可见（finite 模型
  同步派发——event-upload-progress「registered too late」面）。
- **withCredentials**：默认 false + IDL setter（state 非 UNSENT/OPENED **或 send()
  flag 已置** → InvalidStateError——withCredentials 页两面）。
- **ProgressEvent WebIDL interface-object 保真**（part05，泛型 `_defineEventSubclass`
  改专设定义）：①`length` 1（options 默认参）②prototype 属性描述符 non-writable/
  non-enum/non-config ③attribute getter-only（enumerable + configurable + **brand
  check**——prototype 自身读抛 TypeError）④global 属性 non-enumerable。init dict IDL
  转换维持 M3-S2 语义（NaN→0、大小写敏感键——progressevent-constructor 零回退）。
