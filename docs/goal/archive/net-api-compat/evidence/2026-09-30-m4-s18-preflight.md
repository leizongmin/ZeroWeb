## 修齐内容

### shim（part01/03）

- **CORS-preflight（fetch spec §cors-preflight-fetch）**：非 safelisted cors 请求
  （method ∉ GET/HEAD/POST、自定义头、非安全 MIME Content-Type）先发 OPTIONS
  （ACRM/ACAH + Origin）→ 2xx + ACAO（include 拒 `*`）+ ACAM/ACAH 覆盖 → 继续，
  失败 → network error。异步 + 同步 XHR 双路。
- **文档 origin 门控**（`_zwHasRealPageOrigin`）：about:-scheme/空 origin（裸
  sandbox）无 CORS 执行语境——preflight 与 cors check/filter 三处门控（存量
  管路桥测 r3020/r3015/r3221 零翻新回绿）。
- **cors-filtered-response 暴露头过滤**：cors 响应仅暴露 safelisted 响应头 + ACXH
  白名单；Set-Cookie 恒排除；`*` 通配（include 模式仅字面 `*`——cors-expose-star
  三面）。
- **redirect 链补强**：跨源跳丢弃 Authorization（authorization-redirect cross-origin
  "none" 面）；同步循环补逐跳 CORS 门控 + 同步入口 Origin 注入。

### runner（testharness.rs）

- **OPTIONS 支持**：非 GET blanket 拒绝后移至 fixture 全集之后（OPTIONS 放行至
  各 fixture 自派派）+ 无 OPTIONS 分支端点统一 200 + ACAO 回显 + ACAM。
- `redirect-cors.py` OPTIONS 分支（上游语义：preflight 不重定向 + ACAM + Max-Age；
  `redirect_preflight` 才 302）、`fetch/api/redirect.py` OPTIONS 分支（ACAH）。
- `xhr/resources/top.txt`（cors-expose-star 载体，`?pipe=header(...)` 经既有
  wpt_pipe_headers）+ pass.txt/well-formed.xml 补 ACAO `*`（runner 页面 https 而
  get-host-info HTTP_ORIGIN 为 http 的跨 scheme hop 放行——环境适配记账）。
