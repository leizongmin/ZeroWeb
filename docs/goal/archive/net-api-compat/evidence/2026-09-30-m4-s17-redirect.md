## 修齐内容

### shim（part01/03）

- **redirect 跟随循环**（fetch spec §redirect status）：301/302 POST→GET 丢体、
  303 → GET、307/308 保方法体；上限 20 跳；逐跳 content-length 重算；`manual` 模式
  不跟随（既有 opaqueredirect 面）。**同步返回契约消费**——headless webview 的
  `__zw_fetch` 直返 wire，跳发出须就地结算（否则挂等永不回调的 resolver——
  intercept 探针定位的根因）；主流程 sync-consume 调用点同步补齐新签名
  （arity 缺参曾致跳发 m=undefined）。
- **逐跳 CORS 门控**：跨源跳转响应本身过 cors check（`redirect-cors.py` 无 ACAO 跳
  → network error 面）+ 跨源跳请求补文档 Origin 头（allow.py 的 Origin 回显门控）。
- **credentials-aware cors check**：mode 'include' → ACAO `*` 不可用且须 ACAC true
  （with-credentials 重定向两面）。
- **同步 XHR redirect 循环**（与异步同规；authorization-redirect 的同步 XHR 面）。
- **XHR credentials 接线**：send() → fetch init credentials =
  withCredentials ? 'include' : 'same-origin'（同步 wire 第 10 参同修——**读侧误用
  `self._zwWithCreds`（未定义实例属性）而非闭包变量**，intercept 探针定位）。
