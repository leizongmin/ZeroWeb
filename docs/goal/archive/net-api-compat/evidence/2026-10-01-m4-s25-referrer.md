- fetch 消费 `init.referrerPolicy` + `init.referrer` 计算外发 Referer；JS 不可
  自设（forbidden request-header）——guard 过滤后追加，**先于 preflight 构建**
  （preHeaders 派生自 headersWire——首版插在 Origin 注入位、preflight 拿不到
  Referer，x-preflight-referrer 恒 ''，断言前移暴露后一轮定位）。
- 策略矩阵（目标跨源）：`''`/strict-origin-when-cross-origin/origin-when-cross-
  origin（cross）/origin/strict-origin → origin-only（**scheme 宽化**——
  `http://wpt.test/` 期望面：HTTP_ORIGIN 恒 http 而 runner 页面锚 https）；no-
  referrer-when-downgrade/unsafe-url → 全 URL（location.href——https 形态与测试
  期望一致）；no-referrer → 不发送。init.referrer 非空 → URL 解析为源。
- 主 fetch 与 hop 再 preflight 同值（x-preflight-referrer / x-referrer 双回读面）。
