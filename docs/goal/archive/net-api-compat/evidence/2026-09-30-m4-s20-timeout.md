## 修齐内容

### shim（part01/02/03）

- **timeout IDL**（xhr.spec §the-timeout-attribute）：默认 0；setter 于 sync XHR
  → InvalidStateError；**open() 于 sync XHR 且 timeout ≠ 0 → InvalidStateError**
  （synconmain open-after-timeout 面）。
- **timeout 计时器**：send 后 `setTimeout(_zwTimeoutMs)`——到达且在飞 → abort +
  DONE + readystatechange + reset（status 0/头清/responseURL 清）+ fire('timeout')
  + loadend（request error steps for TimeoutError，M4-S16 abort 面同构）；迟到响应
  由 `_zwXhrAborted`/代际守卫丢弃。
- **delay.py shim 侧延迟**：runner 同步契约下 host sleep 冻结 JS（timeout 计时器
  不可竞争）——改 shim `setTimeout(_issueFetch, ms)` 延迟 host 发题，页面计时器
  窗口照常泵送。
- **ES object 面**（send-data-es-object）：非 Blob/FormData/USP body send 时即
  String 化（toString 抛出/返回对象 → 从 send 同步上抛——原在 fetch promise 内
  异步化，assert_throws 不可见）+ `XMLHttpRequest.prototype`/`ReadableStream.
  prototype` 的 `Symbol.toStringTag` 品牌化（`'[object XMLHttpRequest]'`/
  `'[object ReadableStream]'`——置于 part06 尾段，全部构造器就绪后）。
- **FormData.forEach** 走 entries 迭代器（live 语义与迭代一致）；`_zwFdEntry`
  转换规则 spec 化——Blob(非 File) → 新 File；File + filename → 按新名复制
  （lastModified 保真）；File 无 filename → 原对象保留（foreach 身份面）。

### runner（testharness.rs）

- **文件缺失 → 404 响应**（HTTP 语义：缺文件非网络错误——responseurl 面）；
  存量断言 `encoding.py.bak is_err()` 随语义翻新（改断 404）。
- `delay.py`（shim 延迟 + 立即应答 "TEST"）与 `image.gif`（1×1 GIF，responseurl
  重定向目标）fixture。
