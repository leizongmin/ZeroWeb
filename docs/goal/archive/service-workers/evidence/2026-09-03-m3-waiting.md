# Service Worker Waiting Core Promotion

## Scope

Promote upstream WPT
`service-workers/service-worker/waiting.https.html` from
`defer-lifecycle-waiting` to the Service Worker core runner.

This slice covers:

- A newly registered top-level Service Worker registration exposing a non-null
  `registration.waiting` worker after install completion.
- `getRegistration(scope)` returning the SameObject waiting worker for the same
  underlying service worker.
- Newly loaded iframe controller nullability before activation.
- Replacement registration waiting/active slot projection and SameObject
  identity across top-level and iframe registration views.

source change was required; this slice only assets the WPT and promotes it into
the pinned core baseline.
