## gap 归类（M2 切片输入，按失败消息聚类）

1. **Navigation API 未实现**（0/196，156 案 `navigation is not defined`）——整个
   `window.navigation` 对象缺席；M2 评估面（entry doc 列为「评估面」，量大，建议
   独立切片 + 门控评估，先例同 iframe 深结构）。
2. **Location 接口语义**（history 41.9% 主因）：`Location is not defined`（
   `window.Location` 构造器/原型面缺席）、hash 赋值后 `expected "#test" but got ""`、
   location 写侧同步导航（`expected "baz" but got "foo"`——重入 guard 缺口）。
3. **traverse 事件序**（history-traversal 62.2%）：`["load","popstate"]` 序断言、
   `isTrusted`、PopStateEvent 构造器/`hasUAVisualTransition` 属性面。
4. **跨文档导航语义**（navigating-across-documents 0%）：除 helper 缺失外，
   `load`/`unload` 事件序与跨文档 URL 归属全缺。
