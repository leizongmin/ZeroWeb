## 实现

detached factory 的 `queryBody` 对纯 tag 选择器（`div` / `*`）**遍历自身
`_tree`**（活树——mutation 即时可见），消 detHtml 序列化 → host re-parse →
JSON 往返。真实节点直接返回（identity 与遍历/mutation 面统一）；缓存键 pin
真实节点（后继查询同对象）。

### 保守守卫（probe 驱动，三件）

1. **html/body 容器例外**：`_tree` 源是 body 内容（无容器——容器只在 detHtml
   的 R159 属性保真包装层），容器 tag 走 JSON 往返
2. **空 outerHTML 元素中止**：棵 createElement 产物（bare div）等形态下
   序列化/活树内容分歧——树遍历遇此形态整体 abort 回落 JSON（probe 实证
   bare div 树查询结果 nodeName 为空串）
3. **零命中落 JSON**：树零命中不早退 `[]`（曾致 post-mutation QSA 计数
   102≠103 回归）——继续旧路径语义
