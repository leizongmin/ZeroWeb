## ui/design-system（StylePack + Zero default 首个风格包 = DC-15 终局需求）
从 105 行骨架升级（spec §8.4.1 design-system / DC-15 首个风格包 Zero default）。

- 新增 `SpacingTokens`（密度缩放 xs/sm/md/lg/xl/xxl，基线 4/8/12/16/24/32 × density factor）。
- 新增 `RadiusTokens`（none/sm/md/lg/full）+ `TypographyScale`（caption/body/title/headline）。
- **`StylePack`**：聚合 name + density + motion + spacing + radius + typography（风格包）；
  `spacing_value(SpacingStep)` 便捷 API。
- **`zero_default() -> StylePack`**（DC-15 首个风格包：Comfortable 密度 + 默认动效 + 标准 token）+
  `zero_compact()`（Compact 密度，间距 ×0.8）。
- **与主题边界**：风格包只管几何/动效/字号密度 token；颜色由 ui/core::theme semantic token 提供（不在风格包重复，spec DC-5）。
- 保留 Density / MotionTokens / ComponentVariant。

测试：7 测全绿（density / reduced motion / spacing 密度缩放 / radius+typography 默认 / Zero default
风格包聚合 / zero_compact 缩放 / StylePack serde roundtrip；原 3 测）。
Coverage（scoped）：design-system/lib.rs **89.78%**。

测试：12 lib 测 + 1 集成测全绿（snapshot 确定性/text/stroke/clip 4 + semantics 1 + layout_bounds 2 +
golden 5；原 5 测）。
Coverage（scoped）：golden 100% / layout_bounds 100% / scene_snapshot 85.23% / semantics 97.62% / lib 100%。

## ui/devtools（Inspector dev overlay + Timeline 统计）
从 Inspector+Timeline skeleton 扩展（spec §8.4.1 devtools / §8.4.1B UI 调试回归）。

- `Inspector` 加 `hovered` + dev overlay 开关（`show_layout_bounds` / `show_semantics` /
  `show_paint_regions`）+ `any_overlay()`（host 决定是否额外调试 paint pass）+ `toggle_layout_bounds()`。

测试：5 测全绿（inspector select/hover/overlay + timeline average + min/max/percentile +
jank/fps + 空统计；原 2 测）。
