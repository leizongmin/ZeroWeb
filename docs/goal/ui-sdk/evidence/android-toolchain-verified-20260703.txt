## cargo linker 配置

**决策**：用环境变量，不入 `.cargo/config.toml`。

**理由**：cargo `[target.<triple>] linker` 字段不支持环境变量插值（[rust-lang/cargo#9362](https://github.com/rust-lang/cargo/issues/9362)）。写死本机路径（含用户名 `leizo` + 绝对路径 `C:\Users\leizo\AppData\...`）到项目级 `.cargo/config.toml` 会：
1. 违反 AGENTS.md 第 6 条「路径通用化」
2. 把用户名泄漏到 git 公开仓库（仓库曾因此触发 SL-008/SL-010，见 commit `58e74ac8`）
3. 在他人/CI 机器上失效

**配置位置**：用户级 PowerShell `$PROFILE`（`C:\Users\leizo\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1`）：

```powershell
$env:ANDROID_NDK_HOME = "C:\Users\leizo\AppData\Local\Android\Sdk\ndk\30.0.14904198"
$ndkToolchain = Join-Path $env:ANDROID_NDK_HOME "toolchains\llvm\prebuilt\windows-x86_64\bin"
$env:CARGO_TARGET_AARCH64_LINUX_ANDROID_LINKER = Join-Path $ndkToolchain "aarch64-linux-android24-clang.cmd"
$env:CARGO_TARGET_X86_64_LINUX_ANDROID_LINKER = Join-Path $ndkToolchain "x86_64-linux-android24-clang.cmd"
```

**API level 选择**：24（Android 7.0，广泛兼容下限）。升级 NDK 只改 `ANDROID_NDK_HOME` 一处；切换 API level 需同步改 clang 文件名后缀（如 `android24` → `android28`）。

**项目级 `.cargo/config.toml` 保持干净**（只有原 RUSTY_V8_ARCHIVE），未引入本机路径。

   Compiling serde_core v1.0.228
   Compiling rustversion v1.0.22
   Compiling serde v1.0.228

**整条链路验证**：rustc（host）→ NDK clang（`aarch64-linux-android24-clang.cmd`）→ Android `.a`/`.so`（target）。`Finished dev profile` 无任何错误。

（PowerShell 的 `NativeCommandError` 提示是因 cargo 把编译进度输出到 stderr，非真错误——cargo build 成功完成。）
