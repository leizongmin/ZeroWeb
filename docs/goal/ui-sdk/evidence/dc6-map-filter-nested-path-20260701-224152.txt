  嵌套路径投影 `map($items, "a.b.c")` 留作 follow-up（master.md TBD-10 原文）。

实现（ui/dsl/src/engine.rs）
---------------------------
- `project_field(v, path)` 改为按 `'.'` 分段逐段下钻 object：
  - 单段 `"title"` 行为与历史逐位一致（向后兼容，由既有 `map_filter_field_projection` 测试守护）。
  - 嵌套 `"meta.count"` → `o["meta"]["count"]`；任一非 object 中段 → `Null`；缺失叶 → `Null`。
- map/filter 复用同一 `project_field`，无需改 call 分发或 PURE_FN。
- map/filter 文档注释同步更新（嵌套路径已支持；谓词过滤仍需 lambda，超范围）。
- 安全：每元素下钻深度 = 路径段数（小常数），数组迭代仍受 `bump(a.len())`（max_iterations）约束；
  无新可计算能力、无 lambda、无递归、无副作用（sandbox 边界不变）。

测试（1 新测 `map_filter_nested_path_projection`，含 8 组断言，全绿）
-----------------------------------------------------------------
- 嵌套 map：`map($items,"meta.title")` → ["zero","one"]；`map($items,"meta.count")` → [1,2]。
- 嵌套 filter：`filter($items,"meta.active")` → 1 项。
- 缺失叶子：`map($items,"meta.missing")` → [Null,Null]；`count(filter(...,"meta.missing"))` → 0。
- 中段缺失：`map($items,"nope.x")` → [Null,Null]。
- 路径穿过非 object 叶子（`meta.title` 是 Text，`.deep`）→ [Null,Null]。
- 单段向后兼容：`map($items,"meta")` → [Object,Object]。
