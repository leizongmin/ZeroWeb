## 变更
`ui/runtime/src/host.rs`：
1. **fill-sizing（遵守 min 约束）**：`measure_linear` 容器主/交叉尺寸钳到 `[min, max]`
   （`content.max(min_main).min(max_main)` / cross 同）。修正此前「容器忽略 min、恒 content-sized」
   的限制——现 tight/exact 约束下容器能填满空间。默认 loose（min=0）与历史 content-sized 逐位等价。
2. **主轴对齐 `main_axis_align`**（start/center/end，默认 start 向后兼容）+ `MainAxisAlignment`
   + `main_axis_offset` + `main_axis_alignment_from_props`（读 prop，Row 接受 left/right、
   Column 接受 top/bottom 别名）。`arrange` Row/Column 臂按整组子节点打包长度算剩余主轴空间，
   按对齐分配起始偏移。

## 为什么（闭合上一轮 main-axis 架构备忘）
上轮记录：main-axis 对齐无法生效，因 `measure_linear` 忽略 min → 无 flex 子节点时容器=内容尺寸、
剩余主轴空间恒 0。本轮以 **fill-sizing** 解之：父给 tight/exact 主轴约束时容器填满 → 剩余空间 > 0
→ 主轴对齐生效。弹性子节点（flex>0）消费全部剩余空间 → free=0 → 对齐无可见效果（与 CSS flexbox
一致：flex-grow 优先于 justify-content）。chrome 工具栏可用此居中固定标题组 / 右对齐按钮组。
