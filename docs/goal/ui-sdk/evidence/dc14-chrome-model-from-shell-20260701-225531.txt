  但**缺少从 `zero-browser-shell::BrowserShell` 实际状态投影出模型的桥**。

实现（browser-ui/chrome/src/chrome_model.rs）
---------------------------------------------
新增 `BrowserChromeModel::from_shell(shell: &BrowserShell) -> BrowserChromeModel`：
纯只读映射、无副作用、不触渲染。映射范围：
- tabs + active_tab_index：shell.tabs() → BrowserTab{id,title,loading}；active 由 TabId 匹配落 index。
- navigation：active tab 的 history（can_go_back = history_index>0；can_go_forward = history_index+1<history_len）。
- address_text：active tab url。
- security：browser-shell 不追踪页面安全 → 按 URL scheme 派生（http://→Insecure，其余→Secure）。
- page_load：active tab is_loading → PageLoadIndicator{loading, fraction:None}。
- bookmarks：shell.bookmarks().list_root() → BookmarkNode{id:BookmarkId.0.to_string(), title, url:Some}。
- downloads：shell.downloads().iter() → DownloadItemView，状态映射 shell 6 态 → chrome 3 态
  （Pending/Downloading/Paused→InProgress、Completed→Completed、Cancelled/Failed→Cancelled）。
- find：shell.find_state() is_active → FindBar（match_index 1-based→0-based，match_count 仅 total>0 时）。
- permissions：browser-shell 当前不追踪 per-site 权限 → 空（DC-13 platform 域后续接入）。

辅助：`security_from_url`、`map_download`（私有 free fn）。

测试（7 新测，全绿；browser-ui/chrome 53→61 测）
-------------------------------------------------
1. from_shell_default_has_initial_tab — BrowserShell::new() 预建 1 空 tab（active index 0），bookmarks/downloads 空。
2. from_shell_tabs_and_active_index — 3 tabs（initial+2 new_tab），active index 2，address/security/初始导航断言。
3. from_shell_navigation_back_forward — navigate 压入历史 → go_back → can_go_forward=true/can_go_back=false。
4. from_shell_http_is_insecure — http:// URL → Insecure。
5. from_shell_bookmarks_and_downloads — 投影 bookmark + download（Downloading→InProgress）。
6. from_shell_find_active_projects — find_start+set_matches → FindBar query/match_count。
7. from_shell_find_inactive_is_none — 未 find_start → model.find None。
