DC-2 host 交叉轴对齐（cross_axis_align）— 2026-07-02

## 变更
`ui/runtime/src/host.rs` 线性容器（Row/Column）加交叉轴对齐：
- 新增 `CrossAxisAlignment { Start, Center, End }`（默认 Start，向后兼容）+ `cross_offset(align, container_cross, child_cross)`。
- 新增 `cross_axis_alignment_from_props(props)` 读 `cross_axis_align` prop（`"start"`/`"center"`/`"end"`，大小写不敏感；Row 接受 `top`/`bottom`、Column 接受 `left`/`right` 别名；未知值回落 Start）。
- `arrange` Row/Column 臂按对齐把子节点在交叉轴上偏移：容器交叉尺寸 = 最高/最宽子节点（measure_linear total_cross），故满高/宽子节点偏移恒 0，较短子节点按对齐定位（chrome 工具栏「高元素满高、短元素垂直居中」所需）。

## 为什么
DC-14 chrome 迁移需要真实排版：工具栏 Row 中地址栏文本/图标需垂直居中。此前 host Row/Column 把所有子节点硬编码到交叉轴起点（顶/左），无法居中。master.md Next Steps #5 列为「随 chrome 迁移需求驱动」的 SDK-only 打磨项。默认 Start 与旧实现逐位等价（向后兼容）。
