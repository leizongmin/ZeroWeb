--- 变更摘要 ---

1. ui/dsl/src/loader.rs action 简写（DC-6 phase-5）：`actions:` 项除 `{trigger, action, payload?}`
   外，新增四种声明式引用形式，展开为约定 ActionBinding（宿主注册 reducer）：
   - `command: <cmd_id>` → action = ActionId(cmd_id)（糖：触发已注册命令）。
   - `navigate: <route>` → action = ACTION_NAV_PUSH("nav.push")，payload = Value::Object{route: <name>}。
   - `open_overlay: <id>` → action = ACTION_OVERLAY_OPEN("overlay.open")，payload = Value::Object{id: <id>}。
   - `close_overlay: <id>` → action = ACTION_OVERLAY_CLOSE("overlay.close")，payload = Value::Object{id: <id>}。
   - 约定 ActionId 常量 pub（ACTION_NAV_PUSH/ACTION_OVERLAY_OPEN/ACTION_OVERLAY_CLOSE）。
   - 缺所有形式 → DslError::Parse。
   辅助：map_text / payload_of / nav_payload / overlay_payload。
   sandbox 安全：不涉及表达式求值，仅结构化引用 → 受控 payload。

2. ui/dsl/src/asset_bridge.rs（新模块，parallel to i18n_bridge）：
   - `is_asset_object(value) -> bool`：判断 prop 值是否 `{asset: <id>}` 对象。
   - `asset_id_of(value) -> Option<AssetId>`：提取 AssetId（id 须为文本）。
   - DSL loader 已把 `asset:` prop 以 Value::Object 原样保留（yaml_to_value 递归）；
     asset_bridge 在装配期解析为 AssetId，宿主用 AssetProvider 加载。
   - Cargo.toml 加 zero-ui-assets 依赖（通用 crate，DC-1 机械验证零浏览器耦合）。
