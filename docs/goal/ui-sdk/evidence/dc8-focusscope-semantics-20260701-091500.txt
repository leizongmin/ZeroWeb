--- 变更摘要 ---

1. ui/core::focus FocusScope::next 尊重 trap 字段（DC-8 phase-3）：
   - trap=true（modal/popup）：到达作用域边界折返（wrap），焦点永不逃逸。
   - trap=false：到达边界返回 None（逃逸到外层焦点遍历）。
   - 首次进入（current 不在作用域）：Forward→首项，Backward→末项。
   - 3 个新测（non_trap_forward_escapes_at_end / non_trap_backward_escapes_at_start /
     first_entry_lands_on_edge），原 forward_backward_wrap（trap=true）保持绿。

2. ui/core::semantics SemanticsFlags 补 BitOrAssign impl（flags 类型自然补全，
   使 host 可 `s.flags |= FOCUSABLE`）。

3. ui/runtime::host WidgetHost 焦点作用域（modal/popup trap）：
   - 新字段 active_scope: Option<FocusScope>。
   - enter_focus_scope(scope_root, trap)：收集子树可聚焦项，进入后聚焦首项。
   - exit_focus_scope()：退出作用域（焦点保持当前位置）。
   - active_focus_scope()：只读查询（断言/调试）。
   - focus_next：活跃作用域内遍历（trap 折返 / 非 trap 逃逸后落全局）。
   - set_root：reconcile 后按 scope.id 重收集可聚焦项；作用域根已移除则清除（防悬空）。

4. ui/runtime::host WidgetHost 无障碍语义树（FR-011 / DC-8 phase-3）：
   - semantics() -> Option<SemanticsNode>：遍历 retained 树，对有 widget 的节点调
     Widget::semantics 取自描述，填绝对 rect + OR 进 host 级焦点标志
     （FOCUSABLE / FOCUSED），按实际层级组装。纯容器节点 semantics merge（子节点上浮）。
   - self_semantics / build_semantics 辅助。
   - 5 个新 host 测（focus_scope_traps_tab_within_subtree /
     focus_scope_cleared_when_subtree_removed /
     semantics_tree_mirrors_widgets_with_focus_flags /
     semantics_carries_widget_label_and_role / semantics_is_none_before_set_root）。
