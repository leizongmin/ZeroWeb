--- 变更摘要 ---

ui/dsl 新增 `i18n_bridge` 模块（spec FR-013 / DC-10 闭环最后一片）：
- `i18n_value_to_message(value: &Value, engine: &Engine, ctx: &EvalContext)
   -> Result<LocalizedText, DslError>`：把 DSL loader 保留的 `i18n:` 对象
  （`Value::Object { i18n: <id>, params?: { <name>: <expr> } }`）解析为
  `LocalizedText::Message(MessageRef)`。每个 param 表达式按 EvalContext 求值：
  Text→文本参数，Int/Float→计数参数。结构不符/缺 id/表达式语法错/求值非文本计数
  → DslError。
- `is_i18n_object(value) -> bool`：判断 prop 是否为 i18n 对象（含 `i18n` 键）。
- 依赖方向：ui/dsl → ui/i18n → ui/core（全通用 crate，零浏览器耦合，DC-1 已机械验证）。
  不在 loader 内解析（保持 loader 不依赖 i18n），由宿主/求值期调用桥接。
