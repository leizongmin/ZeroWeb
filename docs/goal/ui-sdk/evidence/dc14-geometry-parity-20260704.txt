手绘 chrome `bookmarks_bar_visible = show_bookmarks_bar && !bookmarks.empty`；默认 fresh app 无书签 →
不渲染 bookmarks bar（chrome 高 = tab 40 + toolbar 44 = 84）。SDK 此前**无条件**渲染 bookmarks bar
（28px）→ SDK chrome 高 112，在 y=84-112 画 toolbar_bg(248) 覆盖手绘已是页面(255)的位置（~36k 像素错配）。

修复：BrowserChromeModel 加 `bookmarks_bar_visible` 字段（from_shell = settings.show_bookmarks_bar &&
!bookmarks.empty），DesktopBrowserShell 据此条件渲染 BookmarksBar 行。
