1. 加固汇总（1 回归测 + 2 doc 契约澄清，零行为变更）
================================================================

加固 A —— clip.rs：补 ClipStack「不可见传播 sticky-ZERO」回归测
  现状：ClipStack.push 对无交集（intersect None）压入 Rect::ZERO 表示不可见；
  一旦 ZERO，后续 push(current=ZERO).intersect(any)=None → 继续 ZERO（不可见子树
  整支被裁，不“复活”）。此正确传播此前**未被显式测试**（既有测只覆盖 intersect
  收窄 + disjoint→ZERO，未覆盖第三层 push 与 pop 回退）。
  新测 invisible_propagates_sticky_zero：第三层 push（与第一层有交集）仍 ZERO +
  pop 回退仍 ZERO + 再 pop 回第一层才恢复可见。锁定正确传播，防未来回归。

加固 B —— backend.rs：澄清 RenderBackend::apply_clip(None) 语义（契约歧义）
  现状：apply_clip(Option<Rect>) docstring 仅说「后续绘制受 clip 约束」，未定义 None。
  关键背景：Rect::intersect 对无交集返回 None；host（ui/runtime）paint_node 用
  parent_clip.and_then(|pc| pc.intersect(node.rect))，视口外节点经此链产出 own_clip=None
  → SceneEntry.clip=None → paint_scene apply_clip(None)。
  风险：若后端实现把 None 当「无限大画布」（不裁），视口外节点像素会越界泄漏。
  现状安全是因为 bridge（ui/adapters/render-foundation）把 None 回落为视口 rect
  （见 DC-14 overlay stateful-clip 修复），但这是 bridge 的「补偿」，非契约保证——
  未来新 RenderBackend 实现可能踩坑。
  加固：docstring 明示 None=「不主动裁剪，只受后端自然边界（surface/视口）约束」，
  并警告后端须确保 None 下回落视口而非无限画布。零行为变更（仅 doc），但消解契约歧义。

加固 C —— hit_test.rs：修正坐标契约注释（误导）
  现状：注释「point 在该 node 的坐标系内（已减去父级偏移）」与实现矛盾——实现把
  point 原样传给子节点（hit_test(child, point)），子节点 rect.contains(point) 直接判，
  故所有 rect 与 point 须在同一坐标空间（通常绝对）。既有测用绝对 rect 验证。
  加固：注释改为「node.rect/clip 与 point 须同一坐标空间（通常绝对），子节点 rect
  直接同空间判定，不递归减偏移；靠后子节点 z 序更高 → children.iter().rev()」。
  注：hit_test.rs 当前无外部调用（host 用自己的 dispatch hit-test），属 standby 工具，
  但契约注释须准确以防未来误用。

3. 跨 crate 观察（记录，不在本轮修）
================================================================

O1（ui/runtime host clip 链，非 ui/render）—— host paint_node 用
    parent_clip.and_then(|pc| pc.intersect(node.rect))，视口外节点产出 own_clip=None。
    当前由 bridge None→视口回落 补偿（安全）。若要契约更纯（None=真正无 clip），
    可改 host 为 parent_clip.map(|pc| pc.intersect(node.rect).unwrap_or(Rect::ZERO))，
    使视口外节点得 Some(ZERO)（被裁）。但 DC-14 overlay 像素渲染经精心调试（stateful
    clip + None→视口），改 host clip 链有回归风险，且 bridge 已补偿——本轮不动，
    记为 follow-up（独立 turn 评估 host clip 链与 bridge None 语义对齐）。
