2. 新发现 + 修复：rustc 1.91.0 debug 增量编译 ICE
================================================================
现象: `cargo build --workspace`（debug）在 zero-webview (lib) 上失败，rustc 报
  "the compiler unexpectedly panicked. this is a bug"（query stack during panic，
  exit 101）。rustc 1.91.0 (f8297e35 2025-10-28)。
关键定性:
  - `cargo build -p zero-webview`（单独）成功（1.78s）→ 非 zero-webview 代码缺陷。
  - 关闭增量 `CARGO_INCREMENTAL=0 cargo build --workspace` 成功（11.14s）→
    根因 = target/debug/incremental 缓存损坏（rustc 1.91.0 已知增量编译 ICE 类问题）。
修复: `rm -rf target/debug/incremental`（清除损坏缓存）。修复后
  `cargo build --workspace`（默认增量）成功（8.26s）→ 缓存损坏非常驻 rustc bug，
  清缓存即持久修复。
影响范围: 仅 debug 增量构建路径；release 构建（reftest/product-smoke）不受影响。
对后续轮次的处置: 若再遇 "could not compile ... the compiler unexpectedly panicked"，
  先 `rm -rf target/debug/incremental`（或临时 `CARGO_INCREMENTAL=0`）再重试，不要
  误判为代码回归。本轮所有 scoped test 命令均带 CARGO_INCREMENTAL=0 防御。
