## 目的

继 counter（commit 3a6a6d07）后，把 form 示例也改为经 WinitDriver 驱动，证明 driver
处理**更丰富的交互闭环**（受控文本输入 + Tab 焦点遍历 + Enter 提交 + 非空校验 + 指针点击
+ ime_rect 查询），并进一步 DRY 示例代码。driver 现已覆盖指针 + 键盘 + 焦点 + 校验全路径。

## 交付

- `ui/examples/src/form.rs`：加 `impl UiApp for FormApp`（root_spec→build_spec；
  dispatch→reduce，ACTION_CHANGE|ACTION_SUBMIT→Handled 否则 UnknownAction；
  FormApp::reduce 返回 ()，故由 action-id 匹配决定 Handled）。保留既有 reduce/build_spec。
- `ui/examples/examples/form.rs`：重写为 WinitDriver 驱动（begin + pump_event + pump_frame）。
- `ui/examples/tests/form_retained.rs`：3 测全部改经 WinitDriver：
  ① form_typing_focus_submit_and_validation（Tab 焦点 + 键盘受控输入 'Hi' + Enter 提交
     → 'Hello, Hi!' + Backspace 清空 + Enter → 'Error'，断言 scene 文本 + 焦点 wrap）；
  ② submit_button_click_via_pointer（指针 click Submit 经 driver.pump_event）；
  ③ ime_rect_tracks_focused_text_field_caret（driver.begin 设布局 + host 访问器查
     focused TextField 的 ime_rect 绝对位 = field origin + caret 局部）。

借用处理：driver 持 &mut app，中间状态经 scene 文本断言（'Hi|'/'Hello, Hi!'/'Error'），
最终 app.name/message 在 driver 作用域外读（与 counter 同模式）。

## example 实跑（cargo run -p zero-ui-examples --example form）

    initial: ["Type your name, then press Enter", "Name"]
    after typing 'Ada': ["Type your name, then press Enter", "Ada|"]
    after submit: ["Hello, Ada!", "Ada|"]
    after empty submit: ["Error: name is required", "Name"]

driver 内部 dispatch→reducer→重建→invalidation→帧；受控输入回灌（'Ada|'）、校验通过
（'Hello, Ada!'）、清空后校验失败（'Error: name is required'，回 placeholder 'Name'）。

断言要点：
- Tab 聚焦首个 focusable（TextField 'name'）；Tab→Submit→Tab→name（wrap）。
- 键盘 'Hi' → form.change(Text)→reducer→重建回灌 → scene 含 'Hi|'。
- Enter（聚焦 name）→ form.submit → 校验通过 → scene 含 'Hello, Hi!'。
- Backspace×2 清空 → Enter → 校验失败 → scene 含 'Error'。
- 指针点击 Submit（press+release）→ form.submit → app.message 含 'Hello, Ada!'。
- focused TextField ime_rect = field 绝对 origin + caret 局部（22,6）。
- 最终（driver 作用域外）：app.name=="" + app.message 含 'Error'。
