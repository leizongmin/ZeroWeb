实现（ui/runtime/src/host.rs）
------------------------------
WidgetHost 新增：
- 字段 `a11y_backend: Option<Box<dyn AccessibilityBackend>>` + `last_pushed_focus: Option<WidgetId>`。
- `set_accessibility_backend(backend)`：挂载后端并标记 NEEDS_SEMANTICS（首次 flush 推全树）。
- `needs_semantics()`：读 NEEDS_SEMANTICS 标记。
- `flush_accessibility()`：NEEDS_SEMANTICS 时重建 `semantics()` 推 `backend.update_tree`；
  焦点与上次推送不同时推 `backend.focus_moved`（仅焦点变化不重建全树，廉价，与 Flutter a11y 一致）；
  无后端时清掉 NEEDS_SEMANTICS（避免标记累积）。
- `announce(msg)`：经后端发短暂通告（「页面已加载」「已复制」），平台屏幕阅读器朗读。
- `set_root` 两个分支均补 NEEDS_SEMANTICS（结构/props 变化可能影响语义树 label/role/焦点项）。

设计要点
--------
- 焦点变更检测用「focused vs last_pushed_focus 比较」，避免在本 host 所有改焦点位点
  （focus_next / set_focus / click-to-focus / 焦点作用域）分别埋标记——单点检测，零遗漏。
- 仅焦点变化不重建全树：平台以 focus_moved 事件追踪焦点，结构变化时重建的树才刷新
  FOCUSED 标志（与 Flutter semantics 一致）。
- borrow 处理：先在 &self 期间算出 owned `tree = semantics()`，再 &mut 借用 a11y_backend，
  避免 `self.semantics()`(&self) 与 `self.a11y_backend.as_mut()`(&mut self) 冲突。
