1. 加固汇总（2 回归测，零生产行为变更）
================================================================

加固 A —— geometry.rs：补 Rect::contains 边界含端点（edge-inclusive）回归测
  现状：contains 用 `p.x >= left && p.x <= right && p.y >= top && p.y <= bottom`
  （含端点）。hit-test 据此判定——相邻 rect 共享边界点会同时 contains（由 z 序
  rev() 仲裁 topmost）。此边界含端点语义此前未被显式测（既有测只覆盖内部点
  (50,50) 与外部点 (150,50)）。
  新测 rect_contains_is_edge_inclusive：四角（(0,0)/(100,100)/...）+ 边上点
  ((50,0)/(100,50)) 含；紧贴外侧（-0.001/100.001）不含。锁定 hit-test 语义。

加固 B —— geometry.rs：补 Rect::intersect 边相接 → None 回归测
  现状：intersect 用 `if right <= left || bottom <= top { None }`，故**恰好共享
  一条边**（边相接，零面积重叠）→ None。此语义承载 host clip 链（ui/render 审查
  O1：相邻/相接节点经 intersect 得 None → host own_clip=None → bridge None→视口
  回落）。既有测只覆盖真重叠（Some）与分离（None），未覆盖边相接。
  新测 rect_intersect_edge_touching_is_none：x 边相接（a.right=100=b.left）→ None；
  y 边相接 → None；1px 真重叠 → Some。锁定 `right <= left` 边界判定。
