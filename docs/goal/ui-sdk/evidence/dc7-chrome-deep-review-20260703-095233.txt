1. 修复汇总（1 medium，Phone 布局倒置）
================================================================

bug（medium）—— PhoneBrowserShell::layout 在键盘/小窗口下产出倒置 rect
  根因：`bottom_h = 56.0.min((avail_bottom - top_chrome.bottom()) * 0.4)`。
  当 avail_bottom（= inner.bottom - keyboard）≤ top_chrome.bottom() 时，
  `(avail_bottom - top)*0.4` 为负 → bottom_h 负 → bottom_chrome =
  from_ltrb(left, avail_bottom - bottom_h, right, avail_bottom) 倒置
  （top > bottom）→ 下游 size.height 变负；viewport = from_ltrb(..., bottom_chrome.top())
  亦倒置。
  真实触发：横屏手机（800×390）+ 物理尺寸键盘（340）+ safe area（34）→
  inner 高 356 < top chrome（48）+ keyboard（340）→ avail_bottom=16 < 48 → 倒置。
  分屏小窗口 + 物理键盘同理（键盘物理尺寸 > 应用窗口高度）。
  TDD 证明：phone_layout_no_inverted_rects_when_keyboard_exceeds_space RED
  （bottom_chrome height -12.8，origin y=28.8 > bottom 16）。
  修复：avail_bottom ≤ top_chrome.bottom() 时 bottom_h=0（收缩 bottom bar）+
  viewport 底取 bottom_chrome.top().max(top_chrome.bottom())（非倒置，空间不足
  退化为零高 acceptable）。现有 phone_layout_avoids_keyboard_and_safe_area 测
  （正常键盘 300）逐位不变（avail_bottom 480 > 48 → bottom_h=56 正常路径）。
  chrome 84→85 测全绿 + 下游 bridge 23/browser 默认 191/sdk-chrome 202 零回归。
