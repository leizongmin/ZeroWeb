## 新增公开 API（event_map.rs，15 个 pub fn + 1 const）
- 物理像素→逻辑像素：`to_logical_point` / `to_logical_size`（scale<=0 防御除零）
- 窗口度量：`map_window_metrics(PhysicalSize, scale) -> WindowMetrics`（resize 桥，safe_area/keyboard 初始 0）
- 键盘：`map_key_action(ElementState, repeat) -> KeyAction`、`map_logical_key(&Key) -> KeyCode`
  （Named→Debug 形态 "Tab"/"Enter"/"ArrowLeft"，与 host-runtime 既有转换一致；Character→字面；Dead/Unidentified）、
  `key_text(Option<&SmolStr>) -> Option<String>`、`map_key_event(&KeyEvent, modifiers) -> UiEvent::Key`
- 指针：`map_pointer_phase`、`map_mouse_input(MouseButton,ElementState,Point,modifiers)`、
  `map_cursor_moved`、`map_touch_phase`、`map_touch(phase,location,scale,modifiers)`
  （Touch 拆为可构造入参因 winit::event::Touch 含 pub(crate) DeviceId）
- 滚轮：`map_mouse_wheel(MouseScrollDelta, scale, Point, modifiers)`
  （LineDelta×LINE_HEIGHT_PX=20；PixelDelta 物理/scale；y 取反——winit y-up vs UI delta.y-down=向下滚）
- IME：`map_ime(Ime) -> UiEvent::Ime`（Preedit 选择区 (start,end)→单光标 start）

## 关键约束
- 保留 M1 既有 `map_mouse_button` / `map_modifiers`（向后兼容）。
- winit 类型唯一落点为本 adapter；产出全部为浏览器无关 UiEvent（spec §6.4 / DC-1）。
- `winit::event::KeyEvent` 与 `Touch` 含 `pub(crate)` 字段无法仓外构造 →
  `map_key_event`/`map_touch` 的可测逻辑抽到可构造入参的子函数（map_logical_key/map_key_action/
  key_text/map_touch_phase）单测覆盖，主函数为薄组合。

## 端到端契约（adapter↔runtime integration，3 测）
新增 `adapter_runtime_integration` 模块——证明 winit 事件经映射后真正驱动
`ui-runtime::WidgetHost` retained 运行态（DC-2「接 winit 事件循环」核心证据）：
- `winit_left_click_drives_host_focus_and_emit`：winit 左键按下 @ ClickBox 中心 →
  map_mouse_input → host.dispatch_event → emit `app.click` + click-to-focus 命中点 ClickBox。
- `winit_cursor_move_does_not_emit`：光标移动不触发 emit。
- `winit_click_outside_widget_no_emit`：widget 外点击不 emit。
（任何 phase/button/位置约定错误都会让 host 不命中、不聚焦、不 emit → 这 3 测守卫契约。）
