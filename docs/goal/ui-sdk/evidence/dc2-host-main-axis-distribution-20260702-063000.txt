日期：2026-07-02
分支：ui-sdk

## 范围
闭合 master.md Next Steps #5 列出的「host 主轴分布 space-between/around」可选项——
完善 ui/runtime `WidgetHost` 线性容器（Row/Column）的主轴分布故事（CSS `justify-content` 对齐）。
此前已有 Start/Center/End（main_axis_offset，仅起始偏移 + 均匀 gap），本轮补齐分布语义。

## 变更（ui/runtime/src/host.rs）
- `MainAxisAlignment` 加 3 变体：`SpaceBetween` / `SpaceAround` / `SpaceEvenly`。
- `main_axis_offset(align, free) -> f32` 替换为 `main_axis_layout(align, extra, n) -> (offset, between_extra)`：
  返回起始偏移 + 子节点间额外间距。`extra` = 容器主轴 − 子节点尺寸和 − gap*(n−1)（钳非负）。
  - Start/Center/End：between_extra=0，offset=0/extra/2/extra（**与旧 main_axis_offset 逐位等价**）。
  - SpaceBetween：offset=0，between_extra=extra/(n−1)（n>1；n≤1 退化 Start）。
  - SpaceAround：offset=extra/(2n)，between_extra=extra/n。
  - SpaceEvenly：offset=between_extra=extra/(n+1)。
  - extra≤0（溢出）或 n=0 → 退化 Start。
- `arrange` Row/Column 臂：content=子节点尺寸和，gaps_min=gap*(n−1)，extra=(main−content−gaps_min).max(0)，
  spacing=gap+between_extra；按 offset 起始、spacing 步进放置。**Start/Center/End 行为不变**（spacing=gap+0）。
- `main_axis_alignment_from_props`：归一化去 `-`/`_` 后匹配，接受 `space_between`/`space-between`/`spacebetween`
  （around/evenly 同）。

## 测试（7 新，ui-runtime host::tests 46→53）

- `row_main_axis_space_around_equal_margin_each`：a 75..125 / b 275..325（两侧 75 对称）。
- `row_main_axis_space_evenly_equal_divisions`：a 100..150 / b 250..300（n+1=3 等分）。
- `row_main_axis_space_between_three_children`：tight(500)+3×Patch(50) → a 0 / b 225 / c 450..500。

- `row_main_axis_space_between_single_child_degenerates_to_start`：n=1 → flush left（退化 Start）。
- `column_main_axis_space_between_vertical`：Column tight(100,400) → a top 0 / b top 350..400（垂直分布）。
