DC-11 foundation/text 深度审查
==============================
日期: 2026-07-03

审查范围: foundation/text 全 crate（14 文件 ~1421 行：backend.rs/shaping.rs/text_measure.rs/glyph_cache.rs
/font_request.rs/font_database.rs/grapheme.rs/text_blob.rs/glyph_atlas.rs/font_fallback.rs
/bidi.rs/line_break.rs/diagnostics.rs/lib.rs）。

核心落点: backend.rs（652 行）—— FontdueBackend（fontdue+rustybuzz），生产文本路径。

审查结论: 0 medium/high behavior bugs。代码清洁、测试充分（14 测全绿）。

逐段审查:
- FontdueBackend::load_family: 空数据→错误、fontdue parse 失败→错误、单调递增 FontId、保存原始字节供 rustybuzz
- rasterize_glyph: size≤0 guard、字体查找、fontdue rasterize_indexed（正确按 glyph id，非 char）
- best_match: 大小写不敏感族匹配、无匹配回落首个字体（零 panic）
- FontProvider::query/fallback_chain: 代理 best_match + 覆盖检测去重
- TextShaper::shape: size≤0 + 空文本→空 runs（零 panic）、rustybuzz Face 解析失败回退逐字符
- TextMeasurer::measure: 可选 max_width 贪心折行 + fontdue line metrics（descent 取反已文档化）+ 空 metrics 回落
- shape_with_font: rustybuzz→fontdue 逐字符两层回退、RTL 方向映射、.notdef→0.6*size 防塌陷、upem 缩放
- shape_fallback_per_char: char_indices() 正确字节偏移、.notdef 同回退
- wrap_width_and_lines: 贪心折行、单字符超宽不额外空行（line_w>0 守卫正确）

观察（低风险，不修）:
1. rasterize_glyph glyph_id as u16 截断：对 >65K glyph 字体（罕见 CJK 扩展）可能截断，实用场景可接受
2. shape_with_font info.glyph_id.min(u16::MAX) 钳位：仅用于 fontdue metrics_indexed() 取 advance，
   PositionedGlyph 保留完整 u32 glyph_id，rasterize_glyph 同样截断——行为一致

依托仓库既有依赖: fontdue 0.9 + rustybuzz 0.20 + hashbrown（零新依赖）。

DC-1: foundation/text 仅依赖 fontdue/rustybuzz/hashbrown/ttf-parser/unicode-*/serde/compact_str/thiserror，
零浏览器业务 crate 依赖。

结论: foundation/text 后端生产可用。DC-11 文本基础层就绪。
