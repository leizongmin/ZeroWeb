## 目的

把 DC-15 移动 SDK 各已闭合组件（WindowMetrics::phone() preset、PhoneBrowserShell、
GestureArena Tap/Pan/Pinch、UiEvent::Pointer.pointer_id 多指、BackNavigationService、
Navigator 回落）组装为一个 headless 可运行制品（example 二进制 + 共享 run_phone_demo
函数 + 3 测），证明它们在一条移动事件流里正确组合，而非孤立单测。

## 事件流（run_phone_demo）

1. sample_model（1 安全 tab + address + nav back 可用）→ WindowMetrics::phone()
   （390×844 / scale 3.0 / safe_area top 47 + bottom 34 / Portrait / Compact）。
2. AdaptiveBrowserChrome.build（Mobile + Touch）→ 选 PhoneBrowserShell。
3. WidgetHost retained 闭环：register_chrome_factories → set_root → layout(phone
   tight 约束) → paint。
4. GestureArena（Tap + Pan + Pinch）经 host.set_gesture_arena 接入。
5. 触摸 Tap（单指 pointer_id=0）于地址栏区（195,60）：Pressed→Released。
6. 触摸 Pinch（双指 id=0 + id=1）于内容区：down(0)@130,400 + down(1)@260,400 +
   move(1)@310,400（距离 130→180）→ 双指 Pinch。
7. take_gestures 收集 → gesture_kinds = ["Tap", "Pinch"]。
8. 平台 back 仲裁：InMemoryBackNavigation.push_handler("overlay") →
   on_platform_back = Handled（消耗，不退栈）；再 on_platform_back（无 handler）=
   DefaultBack → Navigator.pop（settings 出栈，剩 home，depth=1）。

- phone metrics → Phone shell（非 desktop/tablet）。
- viewport_top_y=95.0 > 0（chrome + safe_area top 47 避让）。
- bottom_chrome_height=56.0 > 0（phone 有底部导航栏，desktop/tablet 为 0）。

- gesture_kinds 含 Tap + Pinch（多指经 pointer_id 区分）。
