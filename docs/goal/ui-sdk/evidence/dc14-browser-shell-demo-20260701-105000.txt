=== DC-14（browser-shell-demo 示例 — 浏览器 chrome + WebView + ScrollBar 组合）===
日期: 2026-07-01
分支: ui-sdk
SDK-only：新增 browser-ui/chrome 内 demo 模块 + example 二进制（不接真实浏览器进程，未触碰 apps/browser/render-foundation）。

--- 交付物 ---

1. `browser-ui/chrome/src/shell_demo.rs`（参考组合模块，example + tests 共用）：
   - `build_demo_spec(model)` 组装桌面式声明树：security_badge 栏 / toolbar(row)[NewTab·MenuOpen·AddressBar] /
     TabStrip / content(row)[ScrollBar·WebView] / menu(column)[MenuClose]。
   - `FocusBarButton`（demo 可聚焦控件：背景+文案，click/Enter emit action，a11y BUTTON）。
   - `ScrollBarWidget`（demo 控件：用 `ui/widgets::scrollbar` 的 layout_scrollbar/paint_scrollbar
     画 track+thumb 进统一 Scene；固定 12px 宽）。
   - `register_demo_factories`（chrome 叶子 + FocusButton + WebViewWidget + ScrollBar）。
   - `build_demo_host(model, tokens, theme, viewport)` 跑 retained 闭环（set_root→layout→paint）。
   - `count_primitives` / `find_sem_by_label`（demo 打印/断言辅助）。
2. `browser-ui/chrome/examples/browser_shell_demo.rs`：可运行二进制，打印统一 Scene（按图元种类）+
   layout 区域 + a11y 树（WebView 节点 rect + 可聚焦按钮）+ 焦点遍历 + FocusScope trap 演示。
