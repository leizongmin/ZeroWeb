# corpus 快照二进制 A/B 的内容差法证与增益三桶归因

## 问题描述

WPT corpus A/B（B0/B1 快照二进制）出现超出本刀代码域的增益（flip 刀 42 增益中 39 例在
钳制位采样点翻转，而刀代码在该位置被证明恒等）。若直接把对间净差记为本刀增益，会把
外来内容差（peer WIP、构建瞬态、迟到的他刀效应）错误入账，污染控制面总账。

## 根因分析

三个叠加因素：

1. **快照二进制 ≠ 提交时刻的 HEAD**。B0 构建时刻早于其对应刀的提交时刻时，树中
   「未提交后回退」的瞬态修改会进二进制但永不进 commit diff——提交 diff 只记录净变化，
   回退的瞬态对它是不可见的。本例 bin-cadd-b1（17:43）早于 cadd 提交（18:16），
   内嵌了 tick 钳制位无发射的瞬态形态。
2. **「 crates 域不相交」的 mtime 论证会被 nm 推翻**。mtime 在构建窗口之外只能证明
   「该文件何时最后被改」，不能证明二进制内容；es_module s419 在 mtime 论证中被判
   「零重叠」，nm 符号集 diff（76 vs 460）证明内容差实锤存在。
3. **strings 负证明不可靠**。rustc 会合并/优化字符串字面量（`{m}` 格式串双向 0 命中，
   连确定含该串的二进制也 0 命中），0 命中不能证缺席。

## 解决方案

### 内容差法证四工具（按证明力排序）

1. **verbatim blob 匹配（最强）**：`python3 -c` 用 `bytes.find` 在二进制中搜源文件
   全串（先取前 200 字节定位再全串比对）。2 MB shim blob 精确命中 1 次＝二进制含
   该版本源文件逐字节证明；0 命中＋已知含其超集＝版本差异证明。
2. **nm 符号集 diff（crate 域定位）**：`nm --defined-only` 后按 crate 路径片段
   （如 `zero_script_sandbox9es_module`）过滤 mangled 名，对间 diff——符号集规模差
   ＝该 crate 内容差实锤。注意符号尺寸差（如 interpolate_property_value
   0x1e57 vs 0x1abc）在内联决策变化下是噪声，不可单独定谳。
3. **删行审计（刀自身无罪）**：`git diff | grep '^-[^-]'`——若刀 WIP 对 HEAD 的删行
   仅限 import + 被替换逻辑块，则注册/构建流纯增量，行为差只能出自替换块本身。
4. **矛盾排除法（归因收口）**：同输入必同输出的路径上（注册配置同源已证）观测到
   输出异 ⇒ 该路径域代码必异。用于把「tick 域内容必异」从候选清单中钉死。

### 增益三桶分类器（插值类 A/B 通用）

对每个 gained 子测名并行解析两个信号：

- 采样位置：`at \((-?[0-9.]+)\)`——t≤0 或 t≥1 为钳制位；
- 期望形态：名内 `should be \[X\]` 是否 ∈ {from, to} 端点字面量
  （composition 命名是 `from replace [x]` / `to add [x]`，正则须带可选前缀）。

三桶：**钳制位**（外来差嫌疑——本刀在钳制位恒等时直接排除自身）、**interior 端点
期望**（离散翻转采纳类刀的直接面）、**interior 非端点期望**（中点真插值——只可能
出自插值臂，是「端点采纳类刀」的不可能性判据 litmus）。

工程细节：corpus JSON 是 `[page, [subtest]]` 列表（subtest 可为 null）、状态值
`Pass/Fail` 首字母大写（比较前归一）；message 里 expected 文本格式不稳，期望值
优先取名内 `should be [X]`。

### 记账纪律

护栏电池 0 lost / 0 regressed 的有效性不依赖归因成立（B1 相对 B0 无任何子测劣化），
可以先行入账；gained 必须等三桶拆分完成后按归属入账，外来桶挂待归因账留给后继
干净 A/B 对。
