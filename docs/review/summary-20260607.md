### Dismissed（7 个，误报）

| ID | 原严重性 | dismiss 原因 |
|------|----------|-------------|
| SEC-04 | 高 | script-sandbox 是浏览器页面级 JS 执行环境，"sandbox"指 V8 Isolate 隔离而非 eval 限制，页面脚本需要 eval/Function |
| SEC-06 | 中 | Origin 只能通过 parse/from_url 构建（均有验证），Origin::parse("null") 返回错误，无效源在解析阶段即被拒绝 |
| LAY-07 | 低 | CacheRequest 仅存储 url/method，匹配字段新旧完全相同，保留旧 request 无任何可观测行为差异 |
| CSS-03 | 中 | 简单比较运算符在 1305-1321 行另有处理，finding 仅看了范围语法部分 |
| CSS-05 | 低 | 对格式错误输入默认 {a:0, b:0}（不匹配任何元素）是合理的 fail-safe，与真实浏览器容错行为一致 |
| IPC-02 | 低 | 阻塞 poll 是单线程进程通信的刻意设计，已有 try_recv() 提供非阻塞读取 |
| IPC-03 | 低 | Protocol 用于可信 IPC（父子进程），PipeTransport 已有 16 MiB MAX_FRAME_SIZE 限制 |

## 修复日志（2026-06-07）

全部 34 个 verified 问题已修复，10,649 测试全部通过。

### 高严重性（10 个）

| ID | 修复说明 |
|------|---------|
| SEC-01 | 添加 `host_only` 字段到 Cookie，`cookie_matches_url` 对 host-only cookie 做精确 host 匹配（不匹配子域名）。添加 `add_from_url` 方法正确设置 domain。 |
| SEC-02 | `parse_set_cookie` 中拒绝含 `\r`/`\n`/`\0` 的 cookie name 和 value。 |
| SEC-03 | 跨域重定向时通过 `same_origin` 比较剥离 `Authorization`、`Cookie` 等敏感头。 |
| SEC-13 | `execute()` 中当 `timeout_ms > 0` 时启动定时器线程，超时后调用 `isolate.thread_safe_handle().terminate_execution()`。 |
| DOM-01 | `replace_child` 添加 `new_child == self.root` 检查和 `is_ancestor(new_child, parent)` 循环检测。 |
| DOM-02 | `set_text_content` 在清除子节点前调用 `remove_id_map_recursive(*child)` 清理 id_map。 |
| LAY-01 | 修正 `align_content` 从 `style.align_content`（而非 `style.justify_content`）读取，新增 `convert_align_content` 函数。 |
| LAY-02 | atlas 满时 `upload_glyph_to_atlas` 返回 None 并清除 atlas；调用者使用 `retry_glyphs` 循环，溢出时 `truncate` 已有 glyph 顶点（旧 UV 失效）并从头重新上传，最多重试 3 次。 |

### 中严重性（18 个）

| ID | 修复说明 |
|------|---------|
| SEC-05 | `check_cors` 和 `generate_preflight_response` 中 `allow_headers` 含 `"*"` 且 `!allow_credentials` 时视为通配。 |
| SEC-07 | `cookie_matches_url` 路径匹配添加分隔符检查：cookie_path 须以 `/` 结尾或请求路径下一字符为 `/`。 |
| SEC-08 | `parse_set_cookie` 完成属性解析后检查 `same_site == None && !secure` 则拒绝。 |
| SEC-09 | 添加 `MAX_COOKIE_COUNT = 4096` 常量，`add` 中超限时驱逐过期和最旧 cookie。 |
| SEC-10 | `Client::with_config` 使用 `.expect("failed to build HTTP client")` 替代 `unwrap_or_default()`。 |
| SEC-11 | Max-Age 计算使用 `now_secs.saturating_add(max_age as u64)` 防止溢出。 |
| SEC-12 | `parse_http_date` 复用 `cookie::parse_expires_date` 精确解析函数。 |
| DOM-03 | `DomBridge::register` 添加 `reverse_map: HashMap<u64, u64>` 实现 O(1) 双向查找。 |
| DOM-04 | 递归遍历方法使用 `children.iter().copied().collect()` 避免完整 Vec clone。 |
| DOM-05 | `merge_overlapping` 改为排序后单遍扫描合并，复杂度从 O(n³) 降至 O(n log n)。 |
| LAY-03 | `GpuRenderer` 使用持久化 `uniform_buffer`/`uniform_bind_group`，每帧 `write_buffer` 更新。 |
| LAY-04 | `WebStorage` 维护增量 `used_bytes` 字段，`set()`/`remove()` 时增减更新。 |
| CSS-01 | `consume_declaration_block` 仅在 `consume_declaration` 返回 None 且非终止符时 advance，分号由匹配逻辑消耗。 |
| CSS-02 | `parse_var` 使用 `find_top_level_comma` 进行括号感知的逗号搜索。 |
| CSS-04 | media_query `not`/`only` 前缀及媒体类型使用 `to_ascii_lowercase()` 匹配。 |
| IPC-01 | `SharedMemoryChannel` 使用 `VecDeque` 替代 `Vec`，`recv` 用 `pop_front` 实现 FIFO。 |

| ID | 修复说明 |
